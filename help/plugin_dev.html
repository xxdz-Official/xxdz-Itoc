🛠️ 插件开发指南

Itoc 插件系统基于 Python，用一个 ItocMod.py 入口文件 + 一个 Attribute.txt 元信息文件，就能把自定义功能挂进 Itoc 的菜单、工具栏、右键菜单和侧边栏。

📌 本篇的范围：
讲的是怎么开发 Itoc 插件：目录结构、生命周期、完整 API 参考、示例代码。
如果你只是想用别人写好的插件，请参考《插件使用指南》文档。
⚠️ 前置要求：
写插件需要一定的 Python 基础。你需要会：
· Python 基本语法（函数、类、字典、列表）
· tkinter 的基本用法（知道 Frame、Button、Label 是什么）（是的，目前只支持TK框架，不支持PYQT框架嘤嘤嘤）
· 看得懂 JSON 格式
如果这些还不熟，建议先补一下再回来。
💡 一个偷懒的办法：
如果你对 Python 不熟，但又有想实现的功能，可以把这份开发文档直接喂给 DeepSeek（或其他 AI），然后描述你想要的功能，让它帮你生成插件代码。
比如这样说：
“根据这份 Itoc 插件开发文档，帮我写一个插件，功能是：把所有选中音符的音高 +3，并且弹一个通知。”
AI 会照着文档里的 API 给你写出能跑的 ItocMod.py。你只要复制到 mod/你的插件名/ 里，再配一个 Attribute.txt 就能用了。

当然，前提是你要能看懂 AI 生成的代码有没有问题——至少知道它有没有在乱改数据、有没有漏掉保存快照。完全不懂的话，建议还是先补一下基础，或者找个懂 Python 的朋友帮你把关。

一、插件目录结构

一个插件的目录长这样：

mod/
└── 音符批量工具/              ← 插件文件夹（名字随意，但建议用英文/拼音）
    ├── ItocMod.py            ← 【必须】插件入口文件
    ├── Attribute.txt         ← 【必须】插件元信息
    ├── icon.png              ← 可选：插件自己的资源
    └── helper/               ← 可选：插件自己的子模块
        └── utils.py

Itoc 启动时会扫描 mod/ 下的所有子文件夹，每个包含 ItocMod.py 的文件夹就是一个插件。

二、Attribute.txt 格式

这个文件告诉 Itoc 插件的基本信息，格式是"键: 值"，一行一条：

name: 音符批量工具
version: 1.0.0
author: 小小电子xxdz
website: https://xxdz-official.github.io/x
description: 演示新版插件 API 的完整示例，包含菜单、工具栏、快捷键、事件、右键菜单、侧边栏选项卡。
字段是否必须说明
name是插件的显示名（会出现在插件管理器里）
version是版本号，字符串
author是作者名
website否作者网站，可点击打开
description否插件描述，支持多行（用 \n 换行）
💡 文件编码用 UTF-8：
中文写进去要保存成 UTF-8 格式，否则读出来可能是乱码。

三、ItocMod.py 入口文件

这是插件的核心文件。Itoc 加载插件时会调用里面四个模块级函数：

函数调用时机是否必须
initialize_mod(app, tab_frame, app_data, api) 插件被加载时（启动 Itoc 时，或插件启用时） 是
activate_mod(app) 插件选项卡被切到时 否
deactivate_mod(app) 插件选项卡被切走时 否
cleanup_mod(app) 插件被卸载或程序退出时 否

3.1 initialize_mod 的参数

参数类型说明
appMidiToCZE 实例主程序实例，可以直接访问 app.all_notes、app.canvas 等
tab_framettk.Frame分配给插件的底部选项卡 Frame，你的插件 UI 放这里面
app_data对象旧版数据传递对象，保留兼容，新插件建议用 api
apiModAPI 实例新版 API 对象，推荐用这个
💡 推荐用 api：
api 是官方（我..）封装好的接口，屏蔽了主程序内部细节。直接用 app.xxx 虽然也能跑，但主程序内部改动时你的插件可能会挂。

四、ModAPI 完整参考

api 对象提供以下方法。所有方法都做了异常保护，调用失败不会让 Itoc 崩溃。

4.1 菜单相关

add_custom_menu_items(menu_title, items)

在菜单栏创建一个全新的主菜单。

参数说明
menu_title菜单标题，如 "音符工具"
items菜单项列表，每项是 (label, command, icon_key) 或 None（None 表示分隔线）
 
api.add_custom_menu_items("音符工具", [
    ("📋 查看选中音符列表", self.show_selected_notes, "manager"),
    ("📤 导出选中音符为 JSON", self.export_selected_json, "export"),
    None,  # 分隔线
    ("＋ 全部音高 +1", lambda: self.shift_pitch(1), "move_up"),
])

add_menu_item(parent_menu_label, label, command, icon_key=None)

把菜单项挂到主程序已有的菜单下。

参数说明
parent_menu_label父菜单名，如 "编辑"、"文件"、"视图"
label菜单项文字
command点击回调（无参数函数）
icon_key可选，图标 key（见附录 A）
 
api.add_menu_item(
    "编辑",
    "★ 音符工具：音高 +1",
    lambda: self.shift_pitch(1),
    icon_key="move_up"
)

4.2 工具栏相关

add_toolbar_button(text, command, icon_key=None, tooltip=None, slot="left")

在工具栏添加一个按钮。Itoc 工具栏有四个位置可以挂：

slot 值位置
"left"（默认）快捷操作栏¹（第一行左侧）
"left2"快捷操作栏²（第二行右侧）
"file"文件选择栏
"play"播放控制栏
 
api.add_toolbar_button(
    "升2音",
    lambda: self.shift_pitch(2),
    icon_key="move_up",
    tooltip="【快捷操作栏¹】把所有选中的音符升高 2 个半音",
    slot="left"
)

api.add_toolbar_button(
    "全选",
    self.select_all_notes,
    icon_key="select_all",
    tooltip="【播放控制栏】选中所有音符",
    slot="play"
)

4.3 快捷键相关

register_hotkey(keysym, callback, description="")

注册一个全局快捷键。

参数说明
keysymtkinter 格式的按键，如 "<Control-Alt-Up>"
callback按下时调用的函数（无参数）
description可选，描述文字
 
api.register_hotkey(
    "<Control-Alt-Up>",
    lambda: self.shift_pitch(1),
    description="选中音符音高 +1"
)

4.4 事件订阅

subscribe_event(event_name, callback)

订阅主程序的事件。事件触发时，主程序会调用你的 callback(event_data)。

目前支持的事件：

事件名触发时机event_data
"selection_changed"选中音符变化时选中音符列表
 
api.subscribe_event("selection_changed", self._on_selection_changed)

def _on_selection_changed(self, event_data):
    print(f"选中变化: {len(event_data)} 个音符")

4.5 右键菜单

add_context_menu(target, label, callback)

在右键菜单里添加一项。

target 值位置
"note"音符右键
"track"轨道右键
"canvas_blank"画布空白右键
"adjust_layer"调整图层右键
 
api.add_context_menu("note", "🎵 本音符显示八度", self.ctx_show_note_octave)
api.add_context_menu("track", "🎼 本轨道全部升 2 音", self.ctx_shift_track_up)
api.add_context_menu("canvas_blank", "✨ 全选所有音符", self.select_all_notes)
api.add_context_menu("adjust_layer", "🎨 查看图层信息", self.ctx_show_adjust_layer_info)

4.6 侧边栏选项卡

add_sidebar_tab(title, build_func, group="bottom")

在侧边栏添加一个选项卡。

参数说明
title选项卡标题
build_func(parent)构建函数，接收到一个空的 parent Frame，往里面 pack 控件即可
group"bottom"（默认，参考媒体/字幕/便签/全局命令那一排）或 "top"（显示器/历史/窗口类名/窗口编组那一排）
 
api.add_sidebar_tab(
    "音符工具面板",
    self._build_sidebar_panel,
    group="bottom"
)

def _build_sidebar_panel(self, parent):
    ttk.Label(parent, text="🎵 音符工具面板").pack(pady=10)
    ttk.Button(parent, text="音高 +1",
               command=lambda: self.shift_pitch(1)).pack(pady=3, fill="x", padx=8)

4.7 数据读写

方法返回说明
get_selected_notes() list[dict] 获取当前选中的音符，每个是字典，含 note_id、track_idx、start_beat、duration、note_value
get_all_notes() list[dict] 获取工程里所有音符，格式同上
update_note(note_id, **kwargs) bool 更新指定音符的字段，如 update_note(123, note_value=64)
select_notes(note_ids) None 选中指定的音符（传入 note_id 列表）
get_project_info() dict 获取工程信息：path、target_bpm、original_bpm、total_beats、current_beat、has_midi、has_audio 
notes = api.get_selected_notes()
for n in notes:
    print(n["note_id"], n["note_value"])

# 全部升 2 个半音
for n in notes:
    new_val = min(127, n["note_value"] + 2)
    api.update_note(n["note_id"], note_value=new_val)

4.8 通知 / 弹窗

方法说明
notify(message)用主程序底部的轮播图显示一条通知（不弹窗）
show_info(title, message)弹一个信息框
show_warning(title, message)弹一个警告框
show_error(title, message)弹一个错误框

4.9 高级用法

api.app 直接返回主程序实例，可以用它访问主程序的任何公开属性 / 方法。比如：

app = api.app

# 直接改 all_notes（谨慎使用）
app.all_notes[0] = (0, 0.0, 1.0, 60, 12345)

# 调用主程序的重绘
app.draw_all_notes_from_data()

# 保存撤销快照
app.save_undo_snapshot_before_modify("我的插件修改")

# 标记工程已修改
app.mark_project_modified()
⚠️ 用 api.app 是双刃剑：
灵活但危险。主程序内部实现可能变化，你的插件可能会挂。
能用 api.xxx 的，尽量用 api.xxx。

六、完整示例插件源码

下面是一个功能完整的示例插件，演示了所有 API 的用法。你可以把它复制到 mod/音符批量工具/ItocMod.py，直接就能跑。

# mod/音符批量工具/ItocMod.py
# 音符批量工具 - Itoc 新版插件 API 官方示例（完整版 + 侧边栏选项卡）

import tkinter as tk
from tkinter import ttk, messagebox, filedialog
import json
import os
from datetime import datetime


# ============================================================
# 插件主类
# ============================================================
class NoteBatchTool:
    """音符批量工具 - 演示新版插件 API 所有能力

    功能演示清单：
      1. 自定义主菜单（add_custom_menu_item / add_custom_menu_items）
      2. 挂到主程序已有菜单（add_menu_item）
      3. 工具栏按钮多位置挂载（add_toolbar_button 的 slot 参数）
         - left  → 快捷操作栏¹
         - left2 → 快捷操作栏²
         - file  → 文件选择栏
         - play  → 播放控制栏
      4. 全局快捷键（register_hotkey）
      5. 事件订阅（subscribe_event）
      6. 右键菜单（add_context_menu）
         - note          → 音符右键
         - track         → 轨道右键
         - canvas_blank  → 画布空白右键
         - adjust_layer  → 调整图层右键
      7. 数据读写（get_selected_notes / update_note / ...）
      8. 通知 / 弹窗（notify / show_info / show_warning）
      9. 侧边栏选项卡（add_sidebar_tab）
         - group="bottom" → 下组（参考媒体/字幕/便签/全局命令）
         - group="top"    → 上组（显示器/历史/窗口类名/窗口编组）
      10. 高级用法：直接访问主程序实例（api.app）
    """

    def __init__(self, app, tab_frame, app_data, api):
        self.app = app
        self.tab_frame = tab_frame
        self.app_data = app_data
        self.api = api

        # 页面上的动态标签
        self.status_var = None

        # 侧边栏面板里的动态标签
        self.sidebar_status_var = None
        self.sidebar_top_status_var = None

        # 先构建插件页面 UI（底部选项卡）
        self._build_ui()

        # 再注册菜单 / 工具栏 / 快捷键 / 事件 / 右键菜单 / 侧边栏
        self._register_actions()

        # 立即刷新一次状态
        self.refresh_status()

        print("[音符批量工具] 初始化完成")

    # --------------------------------------------------------
    # 1. 构建插件页面（显示在底部选项卡里）
    # --------------------------------------------------------
    def _build_ui(self):
        # 清掉可能残留的内容
        for w in self.tab_frame.winfo_children():
            w.destroy()

        # 顶部标题
        ttk.Label(
            self.tab_frame,
            text="🎼 音符批量工具（完整示例）",
            font=("Microsoft YaHei", 14, "bold")
        ).pack(pady=(10, 5))

        # 状态栏：显示当前选中的音符数量
        self.status_var = tk.StringVar(value="当前选中：0 个音符")
        ttk.Label(
            self.tab_frame,
            textvariable=self.status_var,
            font=("Microsoft YaHei", 10),
            foreground="#0066CC"
        ).pack(pady=5)

        ttk.Separator(self.tab_frame, orient="horizontal").pack(fill="x", padx=20, pady=8)

        # ===== 第一排：音高调节 =====
        row1 = ttk.LabelFrame(self.tab_frame, text="音高调节", padding=8)
        row1.pack(fill="x", padx=20, pady=5)
        ttk.Button(row1, text="音高 +1", width=10,
                   command=lambda: self.shift_pitch(1)).pack(side="left", padx=3)
        ttk.Button(row1, text="音高 -1", width=10,
                   command=lambda: self.shift_pitch(-1)).pack(side="left", padx=3)
        ttk.Button(row1, text="音高 +12", width=10,
                   command=lambda: self.shift_pitch(12)).pack(side="left", padx=3)
        ttk.Button(row1, text="音高 -12", width=10,
                   command=lambda: self.shift_pitch(-12)).pack(side="left", padx=3)
        ttk.Button(row1, text="镜像音高", width=10,
                   command=self.mirror_pitch).pack(side="left", padx=3)

        # ===== 第二排：数据工具 =====
        row2 = ttk.LabelFrame(self.tab_frame, text="数据工具", padding=8)
        row2.pack(fill="x", padx=20, pady=5)
        ttk.Button(row2, text="📋 查看选中列表", width=14,
                   command=self.show_selected_notes).pack(side="left", padx=3)
        ttk.Button(row2, text="📤 导出为 JSON", width=14,
                   command=self.export_selected_json).pack(side="left", padx=3)
        ttk.Button(row2, text="🎯 全选所有音符", width=14,
                   command=self.select_all_notes).pack(side="left", padx=3)

        # ===== 第三排：右键菜单演示说明 =====
        row3 = ttk.LabelFrame(self.tab_frame, text="右键菜单演示", padding=8)
        row3.pack(fill="x", padx=20, pady=5)
        ttk.Label(
            row3,
            text="本插件已注册以下右键菜单，去对应位置右键试试：\n"
                 "  · 音符上右键  → 「本音符显示八度」\n"
                 "  · 轨道上右键  → 「本轨道全部升 2 音」\n"
                 "  · 画布空白右键 → 「全选所有音符」\n"
                 "  · 调整图层右键 → 「查看图层信息」",
            font=("Microsoft YaHei", 9),
            foreground="#555555",
            justify="left"
        ).pack(anchor="w")

        # ===== 第四排：侧边栏演示说明 =====
        row4 = ttk.LabelFrame(self.tab_frame, text="侧边栏演示", padding=8)
        row4.pack(fill="x", padx=20, pady=5)
        ttk.Label(
            row4,
            text="本插件已经在左侧侧边栏里挂载了 2 个选项卡：\n"
                 "  · 下组： 「音符工具面板」\n"
                 "  · 上组： 「音符工具工具」\n"
                 "去侧边栏切换选项卡看看～",
            font=("Microsoft YaHei", 9),
            foreground="#555555",
            justify="left"
        ).pack(anchor="w")

        # ===== 底部提示 =====
        ttk.Label(
            self.tab_frame,
            text="提示：先在主界面选中音符，再点上面的按钮。\n"
                 "工具栏按钮挂在 4 个不同位置，找找看～",
            font=("Microsoft YaHei", 9),
            foreground="#888888",
            justify="center"
        ).pack(pady=(10, 5))

    # --------------------------------------------------------
    # 2. 注册菜单 / 工具栏 / 快捷键 / 事件 / 右键菜单 / 侧边栏
    # --------------------------------------------------------
    def _register_actions(self):
        api = self.api

        # ========== 2.1 自定义主菜单「音符工具」 ==========
        api.add_custom_menu_items("音符工具", [
            ("📋 查看选中音符列表", self.show_selected_notes, "manager"),
            ("📤 导出选中音符为 JSON", self.export_selected_json, "export"),
            ("🎯 全选所有音符", self.select_all_notes, "select_all"),
            None,  # None 会被自动跳过（此处仅作演示）
            ("＋ 全部音高 +1", lambda: self.shift_pitch(1), "move_up"),
            ("－ 全部音高 -1", lambda: self.shift_pitch(-1), "move_down"),
            ("＋ 全部音高 +12", lambda: self.shift_pitch(12), "move_up"),
            ("－ 全部音高 -12", lambda: self.shift_pitch(-12), "move_down"),
            ("🔄 镜像音高 (127 - 音高)", self.mirror_pitch),
        ])

        # ========== 2.2 挂到主程序「编辑」菜单下 ==========
        api.add_menu_item(
            "编辑",
            "★ 音符工具：音高 +1",
            lambda: self.shift_pitch(1),
            icon_key="move_up"
        )

        # ========== 2.3 工具栏按钮 - 挂到 4 个不同位置 ==========

        # 位置 1：快捷操作栏¹（默认位置）
        api.add_toolbar_button(
            "升2音",
            lambda: self.shift_pitch(2),
            icon_key="move_up",
            tooltip="【快捷操作栏¹】把所有选中的音符升高 2 个半音",
            slot="left"
        )

        # 位置 2：快捷操作栏²
        api.add_toolbar_button(
            "降2音",
            lambda: self.shift_pitch(-2),
            icon_key="move_down",
            tooltip="【快捷操作栏²】把所有选中的音符降低 2 个半音",

    def shift_pitch(self, delta):
        """把所有选中音符的音高加 delta 个半音。"""
        selected = self.api.get_selected_notes()
        if not selected:
            self.api.show_info("音符工具", "请先在主界面选中一些音符。")
            return

        selected_ids = {n["note_id"] for n in selected}
        app = self.api.app

        if hasattr(app, "save_undo_snapshot_before_modify"):
            app.save_undo_snapshot_before_modify(f"音符工具：音高{delta:+d}")

        changed = 0
        for i, nd in enumerate(app.all_notes):
            if len(nd) >= 5 and nd[4] in selected_ids:
                new_val = max(0, min(127, nd[3] + delta))
                if new_val != nd[3]:
                    app.all_notes[i] = (nd[0], nd[1], nd[2], new_val, nd[4]) + nd[5:]
                    changed += 1

        if hasattr(app, "mark_project_modified"):
            app.mark_project_modified()
        if hasattr(app, "draw_all_notes_from_data"):
            app.draw_all_notes_from_data()

        self.api.notify(f"已把 {changed} 个音符的音高调整了 {delta:+d}")
        self.refresh_status()
        self._refresh_sidebar_panel_status()

    def mirror_pitch(self):
        """把选中音符的音高镜像：新音高 = 127 - 原音高。"""
        selected = self.api.get_selected_notes()
        if not selected:
            self.api.show_info("音符工具", "请先在主界面选中一些音符。")
            return

        selected_ids = {n["note_id"] for n in selected}
        app = self.api.app

        if hasattr(app, "save_undo_snapshot_before_modify"):
            app.save_undo_snapshot_before_modify("音符工具：镜像音高")

        changed = 0
        for i, nd in enumerate(app.all_notes):
            if len(nd) >= 5 and nd[4] in selected_ids:
                new_val = 127 - nd[3]
                if new_val != nd[3]:
                    app.all_notes[i] = (nd[0], nd[1], nd[2], new_val, nd[4]) + nd[5:]
                    changed += 1

        if hasattr(app, "mark_project_modified"):
            app.mark_project_modified()
        if hasattr(app, "draw_all_notes_from_data"):
            app.draw_all_notes_from_data()

        self.api.notify(f"已镜像 {changed} 个音符的音高")

    def export_selected_json(self):
        """把选中音符导出成 JSON 文件。"""
        notes = self.api.get_selected_notes()
        if not notes:
            self.api.show_info("音符工具", "当前没有选中的音符。")
            return

        timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
        default_name = f"selected_notes_{timestamp}.json"

        file_path = filedialog.asksaveasfilename(
            title="导出选中音符",
            defaultextension=".json",
            initialfile=default_name,
            filetypes=[("JSON 文件", "*.json"), ("所有文件", "*.*")],
            parent=self.app.root,
        )
        if not file_path:
            return

        export_data = {
            "exported_at": datetime.now().isoformat(),
            "count": len(notes),
            "project_path": self.api.get_project_info().get("path", ""),
            "notes": notes,
        }

        try:
            with open(file_path, "w", encoding="utf-8") as f:
                json.dump(export_data, f, ensure_ascii=False, indent=2)
            self.api.notify(f"已导出 {len(notes)} 个音符到 {os.path.basename(file_path)}")
        except Exception as e:
            self.api.show_error("导出失败", f"写入文件失败：\n{e}")

    def ctx_show_note_octave(self):
        """音符右键：显示选中音符的音高和八度。"""
        notes = self.api.get_selected_notes()
        if not notes:
            self.api.show_info("音符工具", "请先在音符上右键。")
            return

        # 只取第一个显示（右键一般点一个）
        n = notes[0]
        note_val = n["note_value"]
        octave = (note_val // 12) - 1
        # 音名表
        names = ["C", "C#", "D", "D#", "E", "F", "F#", "G", "G#", "A", "A#", "B"]
        note_name = names[note_val % 12]

        self.api.show_info(
            "音符信息",
            f"音高值（MIDI）：{note_val}\n"
            f"音名：{note_name}{octave}\n"
            f"八度：第 {octave} 八度\n"
            f"轨道：{n['track_idx'] + 1}\n"
            f"起始节拍：{n['start_beat']:.2f}\n"
            f"时长：{n['duration']:.2f}"
        )

    def ctx_shift_track_up(self):
        """轨道右键：把选中音符（这一轨）全部升 2 音。"""
        # 右键轨道时，主程序通常会把该轨道的音符选中；
        # 为保险起见，直接用当前选中音符
        selected = self.api.get_selected_notes()
        if not selected:
            self.api.show_info("音符工具", "请先选中这条轨道上的音符。")
            return

        app = self.api.app
        if hasattr(app, "save_undo_snapshot_before_modify"):
            app.save_undo_snapshot_before_modify("音符工具：整轨升2音")

        changed = 0
        for i, nd in enumerate(app.all_notes):
            if len(nd) >= 5 and nd[4] in {n["note_id"] for n in selected}:
                new_val = min(127, nd[3] + 2)
                if new_val != nd[3]:
                    app.all_notes[i] = (nd[0], nd[1], nd[2], new_val, nd[4]) + nd[5:]
                    changed += 1

        if hasattr(app, "mark_project_modified"):
            app.mark_project_modified()
        if hasattr(app, "draw_all_notes_from_data"):
            app.draw_all_notes_from_data()

        self.api.notify(f"已把这条轨道的 {changed} 个音符升高了 2 个半音")

    def ctx_show_adjust_layer_info(self):
        """调整图层右键：显示调整图层信息。"""

            return

            line += (f"#{i}  ID={ly.get('id', '?')}\n"
                     f"   轨道：{ly.get('track_idx', 0) + 1}\n"
                     f"   起始节拍：{ly.get('start_beat', 0):.2f}\n"
                     f"   时长：{ly.get('duration', 0):.2f}\n"
                     f"   颜色：{ly.get('color', '?')}\n\n")
        if len(layers) > 10:
            line += f"... 还有 {len(layers) - 10} 个图层\n"

        self.api.show_info("调整图层", line)

_instance = None


def initialize_mod(app, tab_frame, app_data, api):
    """初始化插件。

    参数：
        app:       主程序实例
        tab_frame: 分配给插件的选项卡 Frame
        app_data:  数据传递对象（老接口，保留兼容）
        api:       新版 API 对象（推荐用这个）
    """
    global _instance
    _instance = NoteBatchTool(app, tab_frame, app_data, api)


def activate_mod(app):
    """插件选项卡被切到时调用。"""
    if _instance is not None:
        _instance.refresh_status()
        _instance._refresh_sidebar_panel_status()


def deactivate_mod(app):
    """插件选项卡被切走时调用。"""
    pass


def cleanup_mod(app):
    """插件被卸载 / 程序退出时调用。"""
    global _instance
    if _instance is not None:
        print("[音符批量工具] 正在清理...")
        _instance = None

八、开发流程

  1. 在 mod/ 下新建一个文件夹，比如 mod/我的插件/。
  2. 在里面写 ItocMod.py 和 Attribute.txt。
  3. 重启 Itoc，打开「插件管理器」，看看插件有没有出现在列表里。
  4. 启用插件，再重启 Itoc，检查菜单 / 工具栏 / 右键菜单 / 侧边栏是否生效。
  5. 调试：插件里的 print() 会输出到 Itoc 的控制台 / 终端。
💡 调试技巧：
· 开发阶段可以在 initialize_mod 里多 print，看加载到哪一步。
· 如果插件加载失败，插件管理器里状态会显示「(错误)」，去控制台看报错。
· 改完 ItocMod.py 后要重启 Itoc 才会重新加载。

九、最佳实践

  • 用 api 而不是直接操作 app：更稳定，主程序升级不容易挂。
  • 改工程前先保存撤销快照：调用 app.save_undo_snapshot_before_modify("描述")，让用户能 Ctrl+Z 撤回。
  • 改完调 mark_project_modified：让标题栏出现 *，提醒用户保存。
  • 改完调 draw_all_notes_from_data：刷新画布显示。
  • UI 用 ttk 而不是 tk：风格和主程序一致。
  • 回调里做好异常保护：别让插件崩溃拖垮整个 Itoc。
  • 不要在主线程里做耗时操作：会卡住界面，用 threading。

十、常见问题

Q1：插件加载了但菜单没出现？

检查 initialize_mod 里有没有调用 api.add_custom_menu_items() 或 api.add_menu_item()。另外确认插件是"已启用"状态，并且重启过 Itoc。

Q2：工具栏按钮没显示？

检查 slot 参数是不是四个合法值之一（"left" / "left2" / "file" / "play"）。

Q3：右键菜单没生效？

检查 target 参数是不是四个合法值之一（"note" / "track" / "canvas_blank" / "adjust_layer"）。

Q4：侧边栏选项卡没出现？

检查 group 参数是 "top" 还是 "bottom"，然后去对应那一排找。选项卡标题就是你传的 title。

Q5：插件里的 print 输出到哪里？

输出到 Itoc 的终端（底部选项卡「终端」）。如果终端没打开，会输出到控制台（如果你是用 python main.py 启动的）。

Q6：怎么让插件支持多语言？

可以在插件里自己维护一个 lang_map，根据 app.current_language 切换。目前插件系统没有内置语言包机制。

Q7：插件能访问网络吗？

能。插件就是普通 Python 代码，可以用 requests、urllib 等库。但注意：网络操作最好放到子线程，别卡界面。

Q8：插件能读写文件吗？

能。但建议只读写插件自己目录下的文件，或者用户明确选择的文件。不要偷偷改工程文件或系统文件。

Q9：怎么分享插件？

把整个插件文件夹打包（zip 或 7z），发给别人。对方用「📥 导入插件」导入即可。

Q10：插件 API 会变吗？

我尽量保持向后兼容。旧的 app_data 接口会保留，但新插件建议只用 api。如果 API 有变动，会在更新日志里说明。

十一、小结

Itoc 插件系统的关键点：

  • 目录结构：mod/插件名/ItocMod.py + Attribute.txt。
  • 四个生命周期函数：initialize_mod / activate_mod / deactivate_mod / cleanup_mod。
  • 十大 API 能力：自定义菜单、挂载已有菜单、工具栏按钮、快捷键、事件订阅、右键菜单、侧边栏选项卡、数据读写、通知弹窗、直接访问 app。
  • 四个工具栏位置：left / left2 / file / play。
  • 四种右键菜单：note / track / canvas_blank / adjust_layer。
  • 两个侧边栏组：top / bottom。
