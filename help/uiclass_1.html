🧩 初识模类

前面我们讲了 CZEmaker 怎么把音符变成弹窗，但那些弹窗都是 Itoc 内置的——信息框、警告框、错误框、询问框、图片框……说白了长得都挺"系统"的。那如果我们想弹一个完全自定义的窗口呢？比如一个长得像文件复制进度框的窗口，或者一个 UAC 提权窗口，甚至一个假密码输入框？

这时候就该模类出场了喵 ( ⓛ ω ⓛ *)

这一篇是模类的入门篇。我们会从"模类是什么"讲起，然后带你搭第一个模类，重点讲清楚模类怎么保存、用模类管理器怎么管理、怎么在工程里用它。读完这一篇，你就能独立做出自己的第一个模类弹窗了。准备好了吗？Let's go！

一、模类到底是个啥？

模类呢，是小小电子xxdz为 Itoc 设计的自定义窗口前端。它的英文名是 UI Class，文件扩展名是 .UIclass。你可以把它理解成"一个没有代码逻辑、只有外观和布局的窗口模板"。

为什么说它"没有代码逻辑"呢？因为它的定位很明确——

💡 模类的定位：
弹窗类鬼畜（Crazy Error）的每个弹窗大多不会持续太久，且大多无需用户操作，所以模类不重视窗口内的交互，更没有代码逻辑。它只是一个前端，会被 Itoc 弹窗程序调用，支持 Itoc 的所有通用指令。

也就是说，你不需要在模类里写什么"点击按钮就执行 XX 操作"之类的代码。你只需要把窗口长什么样搭出来，然后告诉 Itoc："这个音符触发的时候，弹这个模类"。至于什么时候弹、弹在什么位置、弹多久、弹完之后干什么——全部交给 Itoc 的全局命令系统去控制。

这样一来，模类就变成了一个特别纯粹的"视觉积木"。你搭一次，可以在无数个工程里重复使用，就像 CZEmaker 配参一样方便。

模类能做什么？

别看它没有逻辑，能玩的花样可多了。下面这些"经典鬼畜弹窗"，用模类都能轻松复刻：

场景 怎么搭 配合什么命令
📁 文件复制进度框 编组框 + 进度条 + 标签（链接进度条显示百分比） 窗口寿命、进度条自动动画
🛡️ UAC 提权窗口 矩形 + 标签 + 两个按钮（是/否） 窗口位移动画、鼠标移动+点击
🔒 密码输入窗口 标签 + 编辑框（虚占位符）+ 按钮 打字录入命令、模拟按键
⚠️ 自定义错误弹窗 图片控件（放个自定义图标）+ 标签 + 按钮 系统提示音、窗口寿命
📊 安装进度界面 选项卡 + 多个进度条 + 状态标签 窗口位移动画、进度条时长控制
🎨 花哨的桌面装饰 矩形 + 图片 + 各种字体标签 透明度、屏幕随机位置

而且模类窗口本身也支持 Itoc 的所有通用指令——也就是说，它可以被全局命令移动、关闭、缩放，也可以加入编组被批量操作，甚至可以被阵列接管按图案排列。这一点我们会在进阶篇详细讲。

二、模类文件里长什么样？

.UIclass 文件本质上是一个 JSON 文件。用记事本打开它，你会看到类似这样的结构：

{
    "name": "登录对话框",
    "width": 800,
    "height": 600,
    "bg_color": "#F0F0F0",
    "minimize_btn": true,
    "maximize_btn": true,
    "close_btn": true,
    "components": [
        {
            "id": 1,
            "type": "label",
            "name": "标题标签",
            "x": 50,
            "y": 30,
            "width": 200,
            "height": 40,
            "text": "用户登录",
            "font": {"family": "微软雅黑", "size": 20, "color": "#0066CC"}
        },
        {
            "id": 2,
            "type": "entry",
            "name": "用户名输入框",
            "x": 50,
            "y": 100,
            "width": 200,
            "height": 30,
            "text": "请输入用户名"
        }
    ]
}

看着挺像那么回事吧？其实核心就两块：顶层字段描述窗口本身（标题、尺寸、背景色、按钮），components 数组描述窗口里的每一个控件。

📌 记住这个心法：
模类文件里没有"逻辑"，只有"外观"。你看到的每一个字段，都是描述"这个窗口长什么样"的。什么时候弹、弹在哪、弹多久，全部由音符的 CZEmaker 配置和 Itoc 全局命令决定。

三、模类设计器长什么样？

手写 JSON 当然可以，但太累了。所以小小电子xxdz做了一个专门的模类设计器，一个可视化编辑器。

在主程序里，点菜单栏的「模类(U)」→「新建模类」，就会在独立进程中启动它。启动之后你会看到这样的界面：

区域 位置 干什么的
📋 菜单栏 顶部 文件、编辑、窗口、视图、帮助五组菜单，包含新建/打开/保存/导出、撤销/重做、删除、点阵、自动对齐等功能
🔧 工具栏 菜单栏下方 新建、打开、保存、▶运行、删除选中、复制控件、图层顺序调整、层叠/平铺等快捷按钮
🎨 控件列表 右侧 10 种控件按钮，按住拖到设计区就能添加
🖼️ MDI 设计区 中间 你的画布，模类窗口在这里可视化编辑
📝 属性列表 左侧 选中控件后，在这里编辑它的所有属性
📄 JSON 源数据视图 底部 实时显示当前模类的 JSON，支持直接编辑并应用
💡 三个面板都可以拖动/停靠：
属性列表、控件列表、JSON 视图都可以拖到窗口的任意边缘停靠，也可以浮动成独立窗口。如果你觉得某个面板挡视线，直接关掉它，在「窗口」菜单里还能重新打开。

四、搭一个最简单的模类

好，理论讲完了，我们来实操一个最简单的模类——一个只有标题和一段文字的窗口。

4.1 第一步：新建模类

在主程序里点「模类(U)」→「新建模类」。模类设计器启动后会弹出一个"新建模类"对话框，让你输入模类名称。这里我们输入 我的第一个模类，点确定。

新建完成后，设计区会出现一个空白窗口，尺寸默认 900×400，背景白色。窗口标题栏会显示 模类设计器 - 我的第一个模类。

4.2 第二步：拖一个标签进来

在右侧的控件列表里找到「标签」按钮，按住它拖到设计区里，松开鼠标。一个标签控件就出现了，默认名字是"标签1"。

📌 也可以直接点击控件按钮：
如果你不想拖拽，直接单击控件按钮，它也会自动在默认位置添加一个控件。拖拽只是为了让你能精确控制初始位置。

4.3 第三步：编辑属性

点击选中刚才添加的标签，左侧的属性列表会显示它的所有属性。我们把文本内容改成 你好，Itoc！，字号改成 24，颜色改成 #6b4a9a（一种淡淡的紫色）。

改完之后你会看到设计区里的标签立刻更新了——这就是可视化编辑的好处。

4.4 第四步：预览运行

点工具栏上的「▶ 运行」按钮，或者菜单「文件」→「运行」。会弹出一个真正的窗口，展示模类的最终效果。这个窗口和你之后在 Itoc 里弹出来的窗口长得一模一样。

💡 预览窗口是"真的"：
运行预览时，模类设计器会按照和运行时几乎一致的规则构建窗口，包括控制钮、背景色、透明度、组件、进度条动画、链接进度标签等等。所以预览看到的效果，就是最终效果。

五、模类怎么保存？（重点）

搭完模类之后，最重要的一步就是保存。这一步决定了你的模类之后能不能被找到、能不能被使用、能不能跨工程复用。所以我要重点讲清楚。

5.1 第一次保存：弹出"保存方式"对话框

点工具栏的「保存」按钮，或者按 Ctrl+S。第一次保存时，模类设计器会弹出一个"保存模类"对话框，让你选择保存到哪里：

按钮 保存到哪 适合什么场景
📄 保存到模类文件 (.UIclass) 你选定的文件路径（弹文件保存对话框） 想单独存档、分享给朋友、备份
📦 保存到 czemidi 工程内置 当前工程的内置模类数据里 想在当前工程里直接用，随工程一起走
📄📦 以上两者都保存 文件和工程都存一份 既要归档又要用
💾 保存为全局模类 UI_Class_Files 文件夹 想在所有工程里都能用这个模类
💡 我是新手，应该选哪个？
如果你是刚开始玩、只想在这个工程里用一下，选「保存到 czemidi 工程内置」就对了。它会直接把模类数据存进工程文件里，之后无论工程文件被拷到哪里，模类都跟着走。

如果你觉得这个模类挺通用、以后别的工程也想用，选「以上两者都保存」——同时存一份到工程里用，再存一份到全局文件夹备用。

新手不推荐单独用「保存为全局模类」，因为 Itoc 解释器（runCZE）只读取工程内置模类，纯全局模类运行时用不了（这个坑我们在进阶篇会详细解释）。

5.2 保存后发生了什么？

根据不同选择，模类会以不同的形式存在：

保存方式 存在形式 怎么找到它
保存到模类文件 磁盘上的一个 .UIclass 文件 在你选的路径下
保存到工程内置 工程文件里的内置模类数据 「模类(U)」菜单 →「─ 工程内置模类 ─」列表
保存为全局模类 UI_Class_Files 文件夹里的一个 .UIclass 文件 「模类(U)」菜单 →「─ Itoc全局模类 ─」列表

保存成功后，模类设计器状态栏会显示「模类保存成功咯！」，窗口标题栏上的星号 *（表示未保存）也会消失。

5.3 后续保存：自动沿用上次的选择

第一次保存之后，模类设计器会记住你的选择。之后再按 Ctrl+S，会直接保存到上次的位置，不再弹对话框。

如果你想换一个保存方式，可以用菜单「文件」→「另存为」。另存为会重新弹出保存方式对话框，让你重新选择。

5.4 保存后的模类在菜单里的样子

保存到工程内置或全局之后，你可以打开主程序的「模类(U)」菜单，会看到类似这样的结构：

模类(U)
├─ 新建模类
├─ 管理模类
├─ 导入模类
├─ 导出模类
├─ 刷新模类列表
├─ ──────────────
├─ ─ 工程内置模类 ─
│   ├─ 我的第一个模类        ← 刚保存的
│   └─ 文件复制进度框
├─ ──────────────
└─ ─ Itoc全局模类 ─
    ├─ 通用信息框            💾
    └─ 通用警告框            💾

带 💾 标记的是全局模类。点击菜单里的任意一项，都能直接在模类设计器里打开它进行编辑。

📌 工程内置模类的"两个名字"：
工程内置模类有一个"内部 ID"（形如 我的第一个模类_a1b2c3d4e5f6...）和一个"显示名称"（就是你在菜单里看到的那个名字）。内部 ID 是 Itoc 用来区分的，你平时不用管它，菜单里会显示友好的名字。

六、模类管理器是啥？（基础）

搭了几个模类之后，你会发现一个问题：模类越来越多，找起来麻烦，有些还想删掉、有些想改名、有些想导出来给朋友……这时候就该模类管理器登场了。

6.1 怎么打开它？

在主程序里点「模类(U)」→「管理模类」，就会弹出模类管理器窗口。

6.2 界面长什么样？

模类管理器是一个带两个选项卡的窗口：

选项卡 显示什么
📦 工程内置 当前工程里所有内置模类
💾 Itoc全局 UI_Class_Files 文件夹里的所有全局模类

每个选项卡里都有一个表格，列是这样的：

列名说明
☑（复选框）点击切换选中状态，用于批量操作
文件名模类的原始文件名（不含扩展名）
窗口名模类数据里的 name 字段，也就是窗口标题
哈希值(MD5)模类内容的"指纹"，用来判断两个模类是否完全相同
组件数模类里控件的数量
💡 哈希值是啥？
你可以把它理解成模类内容的"身份证号"。内容完全相同的两个模类，哈希值也完全相同；哪怕改了一个空格，哈希值也会变得完全不一样。模类管理器用它来判断"这个模类是不是已经导入过了"。
（进阶篇里会讲哈希值在导入去重中的具体用法）

6.3 常用按钮一览

模类管理器的工具栏有两行按钮，常用的操作都在这：

第一行：主要操作

按钮作用
🔄 刷新重新扫描模类列表，更新表格显示
➕ 新建关闭管理器，打开模类设计器新建模类
📥 导入从文件或文件夹导入模类（支持多选和文件夹批量导入）
📤 导出选中把选中的模类导出为 .UIclass 文件
📤 导出全部把当前选项卡的所有模类导出到文件夹
🗑️ 删除删除选中的模类
✏️ 编辑在模类设计器里编辑选中的模类（仅工程内置支持）
☑ 全选切换当前选项卡的全选状态

第二行：进阶操作

按钮/输入框作用
克隆到 Itoc全局（或克隆到工程内置）把当前选项卡选中的模类克隆到另一个选项卡。按钮文字会根据当前选项卡自动变化
✏️ 重命名重命名选中的模类（仅支持单选）
搜索框按窗口名或文件名搜索，实时过滤表格。点 ✕ 清空搜索

6.4 三个最常用的操作

① 用搜索快速找到模类

模类多了之后，找起来眼睛都花。在搜索框里输入关键字（比如"复制"），表格会立刻过滤出所有名字或文件名里带"复制"的模类。找完点 ✕ 清空，全部模类又回来了。

② 把全局模类导入到工程里用

这是新手最容易困惑的地方。前面说过，Itoc 解释器只读取工程内置模类。所以你如果有一个"全局模类"想用，需要先把它导入到工程里：

  1. 打开模类管理器，切到「Itoc全局」选项卡
  2. 勾选你想用的模类
  3. 点「克隆到工程内置」（按钮文字会自动变化）
  4. 成功后会弹提示，模类就出现在「工程内置」选项卡里了

③ 把工程里的模类导出分享给朋友

  1. 打开模类管理器，切到「工程内置」选项卡
  2. 勾选要分享的模类（可多选）
  3. 点「📤 导出选中」，选一个文件夹
  4. 模类会作为 .UIclass 文件导出到那个文件夹
  5. 把文件夹打包发给朋友，他在模类管理器里用「📥 导入」就能导入
💡 图片跟着一起走：
模类里的图片是 Base64 嵌入在文件里的，所以你导出 .UIclass 文件时，图片会自动一起带走，不会出现"图片找不到"的问题。放心分享吧！

七、在工程里使用模类

模类保存到工程内置之后，就可以在工程里使用了。这一步是在 CZEmaker 面板里完成的：

  1. 在时间轴上选中一个音符块
  2. 在底部的 CZEmakers 面板里，把窗口类型选成「模类框」
  3. 这时候面板上会多出一个「选择模类」下拉框，点开它，里面会列出当前工程所有可用的模类
  4. 选中你刚才创建的 我的第一个模类
  5. 点「应用 (Insert)」按钮

搞定！现在这个音符触发的时候，就会弹出你自定义的模类窗口了。

📌 模类框的字段名：
在 CZEmaker 里，模类框的 window_type 英文键名是 UIclass（同时也兼容 class 和中文 模类框）。它选中的模类名称保存在 selected_class_name 字段里。

模类和 CZEmaker 的关系

很多刚接触 Itoc 的朋友会搞混模类和 CZEmaker，这里专门澄清一下：

CZEmaker（配参） 模类（UIclass）
本质 一个弹窗的配置参数 一个自定义窗口的外观模板
文件扩展名 .CZEmaker .UIclass
保存位置 工程内置 / CZEmaker_Files 文件夹 工程内置 / UI_Class_Files 文件夹
怎么用 在音符上挂一个配参 在配参里把窗口类型选成"模类框"，再选具体模类
能否复用 可以，一个配参能挂到多个音符 可以，一个模类能被多个配参引用

简单说：CZEmaker 决定"弹什么、弹在哪、弹多久"，模类决定"弹出来的窗口长什么样"。两者配合使用，威力无穷。

八、一个完整的小例子

我们来串一遍，做一个"文件复制进度框"模类，并在工程里用它：

  1. 新建模类，名字叫 文件复制进度框
  2. 拖一个编组框到设计区，标题写 正在复制文件...，尺寸设成 400×120
  3. 拖一个标签到编组框里，文本写 正在复制: example.txt，位置 (20, 30)
  4. 拖一个进度条到编组框里，位置 (20, 60)，宽度 350，初始 0，结束 100，时长 3
  5. 拖一个标签到编组框里，位置 (340, 60)，宽度 50，在属性面板里把"链接进度条"设成刚才那个进度条的 ID
  6. 预览运行，看效果对不对
  7. 保存到工程内置（或"以上两者都保存"）
  8. 回到主程序，选中一个音符，在 CZEmaker 里窗口类型选"模类框"，选 文件复制进度框，应用
  9. 测试运行（按 F5），看效果

是不是很简单？这就是模类的威力——把一个复杂的窗口"搭积木"一样拼出来，然后挂在音符上，它就会跟着音乐弹出来。

九、小结

这一篇我们了解了：

  • 模类是 Itoc 的自定义窗口前端，文件扩展名 .UIclass
  • 它没有代码逻辑，只负责"长什么样"，什么时候弹由 Itoc 控制
  • 模类文件本质是 JSON，顶层描述窗口，components 数组描述控件
  • 模类设计器是一个可视化编辑器，有菜单栏、工具栏、控件列表、设计区、属性面板、JSON 视图
  • 可以用拖拽或点击的方式添加控件，在属性面板里编辑属性
  • 模类有四种保存方式：保存到文件、保存到工程内置、两者都保存、保存为全局模类
  • 新手推荐「保存到工程内置」，因为 Itoc 解释器只读工程内置模类
  • 模类管理器是管理模类的工具，有两个选项卡（工程内置 / Itoc全局），可以刷新、新建、导入、导出、删除、编辑、重命名、搜索、克隆
  • 在 CZEmaker 里把窗口类型选成"模类框"，再选具体模类，就能在工程里用了
