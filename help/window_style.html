🎨 窗口样式钮

样式钮是 CZEmaker 顶部右侧功能区里的第三个下拉框，它管的是窗口的「外衣」——窗口边框长什么样、标题栏上显示哪些按钮、窗口是不是置顶、背景要不要画。说白了，它决定了用户第一眼看到这个弹窗时的「手感」。

这篇把样式钮的下拉框、设置对话框、三种窗口样式、各种联动规则、以及每种窗口类型下的实际表现，全部讲清楚。看完之后你应该能明确回答：我的弹窗到底该用普通边框、工具窗，还是无边框。

入口与下拉框

在 CZEmaker 面板的窗口标题行最右边，有一排控件：图标、效果音、样式钮、按钮区、透明度。找到「样式钮」，它默认显示「自动」。

下拉框只有两个选项：

  • 自动：使用系统默认配置，等价于 normal_fixed + 关闭按钮 + 置顶。
  • 设置：打开「窗口控制按钮与窗口样式设置」对话框，让你逐项配置。

如果你在对话框里点了确定，下拉框的选项会变成第三个值，形如「自定义: 关闭、置顶」「自定义: 最大化、最小化、不置顶」这样的摘要，让你一眼看出当前配置。

💡 取消会恢复显示： 如果你只是点开「设置」看看，没改任何东西就点了取消，下拉框会恢复成原来的值，不会一直停在「设置」上。这是因为程序在取消回调里重新刷新了下拉框显示。

设置对话框

对话框标题是「窗口控制按钮与窗口样式设置」，从上到下分成几个区域：

  1. 窗口样式：三个单选框，决定窗口边框。
  2. 窗口背景：一个复选框，控制是否绘制白色背景。
  3. 亚克力或云母：一个复选框，启用磨砂玻璃效果（详见 亚克力与云母 文档）。
  4. 窗口层级：一个「窗口置顶」复选框。
  5. 标题栏按钮：关闭/最大化/最小化三个复选框。
  6. 底部按钮：取消在左，确定在右。

对话框是模态的（grab_set），会阻止你操作主窗口，直到确定或取消。ESC 和回车都有绑定。

三种窗口样式详解

普通边框窗口（normal_fixed）

这是默认值，也是最常见的 Windows 窗口样式。有完整的标题栏、图标、标题文字、关闭/最大化/最小化按钮。用户可以拖动窗口（拖动标题栏），也可以根据需要调整窗口大小（如果勾选了「可调窗口」复选框）。

按钮显示规则：

  • 关闭按钮：受「关闭按钮」复选框控制。
  • 最大化按钮：受「最大化按钮」复选框控制。
  • 最小化按钮：受「最小化按钮」复选框控制。

这三个复选框是启用的，可以自由组合。但如果你同时勾了「最大化」和「帮助按钮」（模类框里可能有），Qt 会用帮助按钮占用最大化的位置，最大化按钮会被自动隐藏——这是 Qt 的设计，不是 bug。

适用场景： 常规的提示框、警告框、错误框、询问框、以及没有特殊需求的图片框/视频框。绝大多数弹窗都用这个。

Windows 工具窗（tool_fixed）

工具窗是 Windows 的一种特殊窗口样式，标题栏会被系统压缩成约标准高度的一半，字体更小，看起来更「轻」。它的本质是给窗口加了 WS_EX_TOOLWINDOW 扩展样式（Qt 里对应 Qt.Tool）。

行为特征：

  • 标题栏变矮，关闭按钮变小。
  • 不会出现在任务栏和 Alt+Tab 切换列表里——这是系统级行为，无法通过配置绕过。
  • 系统只提供关闭按钮，最大化/最小化按钮会被强制隐藏。
  • 按钮区配参（关闭/最大化/最小化复选框）全部忽略。

视频框禁用工具窗： 视频框使用 mpv 播放器，mpv 的窗口样式由 mpv 自己的 --no-border / --border 参数控制，无法可靠地模拟工具窗。所以当窗口类型是「视频框」时，设置对话框里的「Windows 工具窗」单选框会被自动禁用。如果你之前给视频框保存过 tool_fixed，打开对话框时会自动回退到 normal_fixed，并打印一条日志。

适用场景： 不想在任务栏留下痕迹的小工具窗口、旁路提示、贴在桌面边缘的悬浮窗。如果你希望用户能在任务栏找到它，就千万别用工具窗。

⚠️ 注意： 工具窗在任务栏不显示，是系统强制的，不是你程序的问题。如果你需要「不显示任务栏但可 Alt+Tab」，目前没有完美方案——Qt.Tool 会把两者都隐藏。

无边框窗口（borderless）

无边框窗口没有标题栏、没有边框、没有系统按钮。用户看到的就是一个「纯内容」的矩形。它的实现方式是给窗口加 Qt.FramelessWindowHint。

行为特征：

  • 没有标题栏，无法通过标题栏拖动（需要窗口自己实现拖动逻辑）。
  • 没有关闭按钮，用户无法通过点击关闭（需要快捷键或代码关闭）。
  • 没有最大化/最小化按钮。
  • 按钮区配参全部忽略。

镂空图片框强制无边框： 当你给图片框勾选了「镂空」，无论样式钮选的是什么，图片框都会走无边框路径（Qt.FramelessWindowHint）。这是因为镂空需要透明背景，而有边框窗口的标题栏会遮挡透明区域，视觉上很别扭。镂空图片框支持左键任意位置拖动、右键关闭，算是把无边框的交互补回来了。

适用场景： 纯图片展示、自定义绘制的窗口、需要完全透明背景的窗口、贴纸风格的弹窗。如果你要做「一张图弹出来」的效果，无边框 + 镂空是标配。

💡 无边框不等于不可操作： 镂空图片框自己实现了鼠标拖动和右键关闭，所以你不用担心用户关不掉。但普通弹窗如果选了无边框，确实会没有关闭按钮，需要你另外配置一个「确定」按钮或者其他关闭手段。

窗口背景

「窗口背景」复选框控制窗口要不要绘制白色背景。默认勾选。

勾选时： 窗口有白色背景（内容区、按钮区都是可见的）。

不勾选时： 程序会在 paintEvent 里把整个窗口填充为 QColor(1, 2, 3)，然后用 Win32 的 SetLayeredWindowAttributes 把这个 RGB 值设为色键透明。最终效果是窗口背景「镂空」，只有控件本身可见。

与亚克力的联动： 不勾选「窗口背景」时，「亚克力或云母」复选框会被自动取消勾选。这是因为亚克力需要窗口有实际的背景层来承载模糊效果，色键透明窗口没有背景层，亚克力会失效。反过来，勾选「亚克力或云母」会自动勾选「窗口背景」。

与镂空的关系： 镂空图片框走的是另一套透明机制（Qt 的 WA_TranslucentBackground），和「窗口背景」复选框没有直接关系。镂空图片框会忽略「窗口背景」的设置。

窗口置顶

「窗口置顶」复选框控制窗口是否永远浮在其他窗口上面。默认勾选。

勾选时： 窗口创建时带上 Qt.WindowStaysOnTopHint，mpv 视频框会带 --ontop 参数。窗口会浮在其他普通窗口之上，除非有另一个置顶窗口盖住它。

不勾选时： 窗口是普通层级，用户切换到其他窗口时会被盖住。

运行时动态设置： 对于视频框，程序在 mpv 窗口句柄拿到之后，还会用 Win32 的 SetWindowPos 再补一次置顶/取消置顶（HWND_TOPMOST / HWND_NOTOPMOST）。这是因为 mpv 的 --ontop 参数在某些版本上会被忽略，Win32 兜底更可靠。

💡 全局命令也能改置顶： 除了样式钮，全局命令里的 focus_window 也支持 topmost=true/false 参数，可以在运行时动态切换任意窗口的置顶状态。

标题栏按钮

三个复选框：关闭按钮、最大化按钮、最小化按钮。默认关闭按钮勾选，最大化/最小化不勾选。

联动规则：

  • 选择「无边框窗口」时，三个复选框全部强制取消勾选并禁用。无边框窗口没有标题栏，按钮无处安放。
  • 选择「Windows 工具窗」时，关闭按钮强制勾选、最大化/最小化强制取消勾选，三个复选框全部禁用。工具窗只提供关闭按钮。
  • 选择「普通边框窗口」时，三个复选框恢复启用，可以自由勾选。

这套联动是实时生效的：你在对话框里切换窗口样式，下面的按钮复选框会立刻变灰或变亮，不需要点确定。

各窗口类型的实际表现

常规弹窗（信息框/警告框/错误框/询问框）

完全遵循样式钮配置。普通边框、工具窗、无边框三种样式都支持。按钮区配置也生效（会动态创建对应数量的按钮）。

图片框

支持三种样式。但需要注意：

  • 镂空图片框强制无边框，忽略样式钮里的样式选择。
  • 非镂空图片框正常遵循样式钮配置。
  • 工具窗样式下，图片框会带 Qt.Tool，在任务栏不显示。

视频框

视频框的样式由 mpv 参数和 Win32 样式共同决定：

  • 普通边框：mpv 用 --border，程序再用 SetWindowLongW 裁剪按钮样式。
  • 无边框：mpv 用 --no-border，程序再移除 WS_CAPTION 等样式位。
  • 工具窗：不支持，对话框里该单选框会被禁用。

视频框的置顶在 mpv 启动参数里用 --ontop / --no-ontop 控制，窗口句柄拿到后还会用 Win32 补一次。

模类框

模类框也遵循样式钮配置，但窗口的实际样式还受模类数据自己的 minimize_btn / maximize_btn / close_btn / resizable / taskbar_show 等字段影响。当样式钮选了「工具窗」时，模类框会用 Qt.Tool + Qt.WindowCloseButtonHint，忽略最大化和最小化配置。

配置文件字段

样式钮的配置保存在音符的 cze_makers 里，字段结构如下：

  • window_control："custom"（自定义）或 "default"（自动）。
  • window_control_detail：详细配置字典，包含：
    • close：布尔，是否显示关闭按钮。
    • maximize：布尔，是否显示最大化按钮。
    • minimize：布尔，是否显示最小化按钮。
    • topmost：布尔，是否置顶。默认 true，兼容旧工程。
    • window_style："normal_fixed" / "tool_fixed" / "borderless"。
    • window_background：布尔，是否绘制窗口背景。默认 true。
    • window_material：布尔，是否启用亚克力/云母。默认 false。

旧工程没有 topmost / window_style / window_background / window_material 字段时，程序会分别回退到 true / "normal_fixed" / true / false，保证兼容。

翻译与语言包

设置对话框里的所有文本（窗口标题、单选框标签、复选框标签、按钮文字）都走主程序的语言包翻译。如果你用了语言包，打开对话框会看到翻译后的文字。下拉框的「设置」选项在翻译后可能变成「Settings」，程序在判断时会同时匹配中英文，不会因为翻译导致点击「设置」没反应。

取消与恢复

点「取消」时：

  • 对话框关闭，不保存任何修改。
  • 程序会临时设置 1 秒静默期，防止「恢复下拉框显示」这个动作误触发「已修改」标记。
  • 下拉框的显示会被恢复成打开对话框之前的值。

点「确定」时：

  • 配置写进 control_config 字典。
  • 调用 mark_property_edited('window_control')，触发「应用」按钮亮起、拦截层激活。
  • 下拉框更新为「自定义: xxx」摘要。
💡 多选编辑： 多选时修改样式钮，只会把 window_control 加进 edited_properties，应用时只更新选中音符的样式配置，其他字段保持不变。

常见问题

Q：选了工具窗，为什么任务栏没有图标？

A：这是工具窗的系统级特性。如果你需要任务栏图标，请选「普通边框窗口」。

Q：选了无边框，用户怎么关闭窗口？

A：无边框窗口没有关闭按钮。你需要：① 在按钮区配一个「确定」按钮，它会调用 close_window；② 或者用全局命令 close_all_popups / close_group_popups 批量关闭；③ 镂空图片框额外支持右键关闭。

Q：视频框为什么不能选工具窗？

A：mpv 的窗口样式由它自己的参数控制，工具窗的压缩标题栏效果无法可靠模拟。强行设置可能导致 mpv 窗口和 Qt 窗口样式冲突，所以程序直接禁用了这个选项。

Q：勾了亚克力但没效果？

A：检查「窗口背景」是否勾选。亚克力必须配合窗口背景使用，不勾背景时亚克力会被自动取消。另外 Windows 7 及以下系统不支持亚克力，Windows 10 早期版本只支持模糊不支持云母。详见 亚克力与云母。

Q：样式钮改了但窗口没变化？

A：窗口样式是创建时应用的，修改配置后需要重新触发弹窗（重新播放到这个音符，或者点「应用」后重跑）。已经打开的窗口不会实时变样式。

小结

样式钮管的是窗口的「外衣」，核心是三件事：

  1. 选样式：普通边框 / 工具窗 / 无边框，三种选一种。
  2. 定按钮：关闭、最大化、最小化，按需勾选（但受样式联动限制）。
  3. 配层级和背景：置顶与否、背景画不画、亚克力开不开。

记住几个关键联动：工具窗不显示任务栏、无边框没有系统按钮、镂空强制无边框、亚克力必须配合窗口背景。这些规则清楚了，样式钮就不会踩坑了喵 ( ⓛ ω ⓛ *)
