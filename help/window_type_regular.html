🪟 普通弹窗：信息框 / 警告框 / 错误框 / 询问框

这四种窗口类型是 Itoc 里最基础、最常用、最"一眼就懂"的弹窗。它们内部其实都是同一个 RegularPopup 类，区别只在于「图标长什么样」和「默认播什么音效」。所以这篇把四个类型一起讲，省得你来回翻。

如果你之前玩过 Windows 的 MessageBox，那这四种弹窗就是那个味道——只不过现在弹什么、什么时候弹、长什么样，全部由你在 CZEmaker 面板里说了算。

四种类型有什么区别

先看一张表，你就明白它们本质上是"同一个人换了四件衣服"：

中文名英文 key默认图标默认音效使用场景
信息框info蓝色 ℹSystemAsterisk普通提示、通知、说明
警告框warning橙色 ⚠SystemExclamation需要注意的风险
错误框error红色 ⛔SystemHand出错了、失败了
询问框question蓝色 ?SystemQuestion问用户一个问题

你可以把「警告框」改成用「信息框」的图标，也可以把「错误框」的默认音效换掉，这些都是面板上的可选配置，不是硬绑定的。

💡 图标风格可以跨版本： 面板上的「图标」下拉框可以选 Windows11 / Windows10 / Windows XP / Windows Logon 等不同风格。也就是说，你可以在 Windows 11 上做出一张 Windows XP 风格的弹窗，玩怀旧梗特别方便。

窗口尺寸是怎么决定的

普通弹窗的尺寸不是写死的，而是根据内容动态计算出来的。程序用 QFontMetrics 一行一行量你的标题和内容，算出一个刚好能装下文字又不显得太空的尺寸。

具体来说：

  • 宽度：图标区宽度 + 每行文本像素宽度的最大值 + 安全余量，最小 240，最大 900。
  • 高度：按文本在可用宽度下会折几行来算，再叠上内容区上下边距和按钮区高度，最小 140，最大 700。

所以你写一句「你好」，弹窗就是个小方块；你写一篇小作文，弹窗就会自动拉高，不需要你手动调尺寸。

如果动态尺寸不合适，可以在面板里勾上「自定义尺寸」手动填 W/H，或者点尺寸拾取按钮（⊕）在屏幕上拖一个框出来。勾了自定义尺寸之后，动态计算就失效了，弹窗永远按你填的宽高来。

💡 窗口内容支持多行： 你在「窗口内容」文本框里敲的换行，弹窗里会原样显示。动态尺寸计算是逐行算的，所以换行越多，弹窗越高。

三种会显示在弹窗上的东西

窗口标题（标题栏文字）

弹窗最上面那行字。在面板的「窗口标题」输入框里填。旁边有个 ◥ 按钮，可以打开大编辑器写长标题，支持查找替换、Ctrl+Z 撤销、Ctrl+Shift+Z 重做。

如果你把标题留空，程序会用「xxdz Itoc」兜底——这是为了避免任务栏/标题栏回退成「python」这个丑样子。

窗口内容（正文）

弹窗中间那段文字。支持多行，支持中英文混排，支持 emoji。旁边的 ◥ 按钮同样可以打开大编辑器。

如果你选的是图片框或视频框，内容框会被禁用并变灰——这是正常的，因为那两种窗口不需要「文字内容」。但普通弹窗是永远可编辑的。

图标

图标有两种来源：

  • 系统图标（默认）：程序会加载 ico/ 目录下对应风格的 xinxi.ico（信息）、jinggao.ico（警告）、cuowu.ico（错误）、xunwen.ico（询问）。
  • 风格图标：面板上的「图标」下拉框可以选 Windows11 / Windows10 / Windows XP 等风格，程序会去对应的文件夹找同名图标。找不到时回退到系统检测的版本。

选「自动」时，程序会检测当前 Windows 版本，加载对应文件夹的图标。

⚠️ 图标加载失败怎么办？ 如果对应的 .ico 文件不存在，程序会回退到用 Unicode 字符显示（ℹ ⚠ ⛔ ?），不会崩溃。所以即使你没放图标文件，弹窗也能正常显示，只是图标变成了文字符号。

顶部右侧功能区的五个配置

普通弹窗的顶部右侧功能区是全部可用的（不像图片框/视频框会禁用图标，也不像气泡/执行代码会整个隐藏）。这五个控件分别是：

图标

就是上面说的那个。可选：自动、Windows11、Windows10、Windows Logon、Windows Vista、Windows 7、Windows 8、Windows XP、Windows XP以下。

效果音

弹窗出现时播放的音效。可选：自动、信息框、警告框、错误框、询问框、没有。

  • 自动：根据窗口类型播放对应的系统音效。
  • 信息框 / 警告框 / 错误框 / 询问框：强制播放对应类型的音效，不管窗口类型是什么。
  • 没有：完全静音，什么也不播。

保存字段是 window_sound，取值 default / info / warning / error / question / none。

控制钮

控制标题栏显示哪些按钮。下拉选「设置」会打开对话框，三个复选框：关闭、最大化、最小化。另外还有一个独立的「窗口置顶」复选框和「窗口背景」「亚克力或云母」复选框——详见 窗口样式钮 文档。

保存字段是 window_control（custom / default）和 window_control_detail（含 close / maximize / minimize / topmost / window_style / window_background / window_material）。

按钮区

弹窗底部那一排按钮。下拉选「设置」会打开对话框，可以拖动按钮调顺序、点击删除、从预设里挑、也能自定义文本。

预设按钮有：确定、取消、保存、删除、应用、OK、是、否、关闭、重试、忽略。点「确定」后，下拉框会显示「自定义: 3个按钮」这样的摘要。

保存字段是 window_button（custom / default）和 window_button_detail（含 buttons 列表）。

透明度

窗口整体透明度，0% ~ 100%。默认 100。填了之后程序会用 setWindowOpacity 应用。100 以下会看到桌面透过来，50 以下基本就是「幽灵弹窗」了。

保存字段是 window_opacity。

窗口寿命

「寿命」复选框控制弹窗显示多少毫秒后自动关闭。勾了之后，右边输入框填毫秒数（比如 3000 = 3 秒）。

旁边还有个「使用音符块时长」复选框。勾了它之后，寿命输入框会被禁用，弹窗的寿命直接取这个音符在时间轴上的时长（秒转毫秒）。适合做「音符弹多久，弹窗待多久」的卡点效果。

互斥规则是这样的：

  • 寿命未勾选 → 输入框禁用，「使用音符块时长」也禁用。
  • 寿命勾选 + 使用音符块时长勾选 → 输入框禁用，寿命 = 音符时长。
  • 寿命勾选 + 使用音符块时长不勾 → 输入框启用，寿命 = 输入框的值。

保存字段是 window_life，结构是 {enabled, value, unit, use_note_duration}。

在任务栏显示 & 可调窗口

两个复选框：

  • 在任务栏显示：默认勾选。勾选时弹窗会在任务栏留一个图标，不勾选时用 Qt.Tool 样式隐藏任务栏图标。注意：如果你在样式钮里选了「工具窗」，任务栏图标会被系统强制隐藏，这个复选框就不起作用了。
  • 可调窗口：默认不勾选。勾选后用户可以拖动窗口边缘改变大小，不勾选时窗口尺寸固定。注意：勾了「自定义尺寸」时，如果又勾了「可调窗口」，窗口初始大小还是按自定义尺寸来，但用户可以拖大拖小。

保存字段是 show_in_taskbar 和 resizable。

窗口位置

位置配置是四种模式，详见 CZEmaker 基础篇 的「窗口位置控制」章节。这里只提一句：普通弹窗的位置计算里有一个标题栏补偿——因为你填的 (x, y) 是内容区左上角，但窗口实际位置需要往下偏移一个标题栏高度。程序会自动加上这个偏移。

如果你用的是镂空图片框，就没有标题栏补偿，因为镂空窗口没有标题栏。

销毁模式（↠∅ 按钮）

窗口类名输入框旁边的 ↠∅ 按钮，点开有两个选项：

  • 销毁即销毁（destroy）：窗口关闭时彻底销毁，所有资源释放。默认。
  • 销毁即脱壳（shell）：窗口关闭时，把窗口的几何信息（位置、宽高）存到内存缓存里。之后如果有别的窗口「链接」到这个类名，即使这个窗口已经关了，链接位置也能用缓存里的坐标算出来。

保存字段是 window_class_destroy_mode。

💡 脱壳模式配合「与窗口链接」： 场景是「A 弹出来，B 跟在 A 旁边」。如果 A 已经消失了，B 还要出现在 A 原来在的位置，这时候 A 就需要设成「销毁即脱壳」。详见 窗口类名 文档。

拖动与关闭

普通弹窗的交互：

  • 拖动：只有点标题栏区域才能拖。点内容区不能拖，这是为了避免误拖。程序在 mousePressEvent 里用 PM_TitleBarHeight 判断点击位置是否在标题栏内。
  • 关闭：点关闭按钮、点按钮区的任意按钮、或者到寿命自动关闭，都会触发 close_window()。
  • 关闭流程：先播放出场过渡动画（如果配置了），动画完成后清理注册信息（从类名桶、编组桶、current_windows 里移除），最后真正 close。
⚠️ 注意： 如果你在样式钮里选了「无边框窗口」，标题栏就没了，普通弹窗就拖不动也关不掉了（除非你配了按钮区的按钮）。所以普通弹窗一般不建议用无边框，除非你有特殊设计。

常见问题

Q：弹窗尺寸看起来怪怪的，明明内容很短却很宽？

A：动态尺寸有个最小宽度 240，是给图标区留的空间。如果你觉得太宽，可以勾「自定义尺寸」手动填。

Q：弹窗里的 emoji 显示不出来？

A：普通弹窗用的字体是 Microsoft YaHei + Segoe UI。这两个字体对大部分 emoji 支持还行，但个别生僻 emoji 可能显示成方块。如果需要特殊 emoji，建议把它放进窗口标题或内容里，或者改用图片框。

Q：按钮区配了 5 个按钮，结果按钮挤在一起怎么办？

A：按钮区是固定高度 45px，按钮宽度固定 96px。5 个按钮需要 480px 以上的宽度，如果弹窗太窄就会挤。解决方案：① 减少按钮数量；② 用自定义尺寸把窗口拉宽；③ 用更短的按钮文字。

Q：透明度设成 0 会怎样？

A：窗口变成完全透明，用户看不见，但仍然在运行、仍然接收事件。一般不建议这么干，除非你想做「隐形弹窗 + 后台逻辑」的效果。

Q：普通弹窗能显示图片吗？

A：不能。普通弹窗只有文字内容。要显示图片请用「图片框」类型。

小结

普通弹窗的四件事：

  1. 选类型：信息 / 警告 / 错误 / 询问，决定默认图标和音效。
  2. 填内容：标题 + 正文，尺寸会自动算。
  3. 配外观：图标风格、效果音、控制钮、按钮区、透明度、样式钮。
  4. 定行为：位置、寿命、任务栏、可调窗口、销毁模式。

普通弹窗是 Itoc 里最"老实"的窗口，没有花里胡哨的东西，但也正因为如此，它是最稳定、最不容易出问题的。如果你只是想弹个提示，选它准没错喵 ( ⓛ ω ⓛ *)
