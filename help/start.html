初识 Itoc

Itoc 是做什么的呢？

Itoc 呢，是小小电子xxdz（也就是我...）开发的一个 Windows Crazy Error 开发工具 说白了，就是让你能把音乐（MIDI 文件）配上 Windows 的各种弹窗效果，做成那种一个接一个弹窗跳出来的表演

以前想做这种效果，直接写代码可麻烦死了 你得懂 Windows API，还得自己写一堆跟音乐对齐的逻辑 现在呢，你只要把 MIDI 导进去，在音符上挂上弹窗，它就能跟着音乐节奏一个个蹦出来 就这么简单

这整套工作流——把 MIDI 音乐当成演出模板，在音符上挂弹窗，按时间轴编排，测试运行，最后编译成 exe——在它出现之前呢...世界上没有项目这么干过 音乐就是剧本，音符就是可并行的时间线，整个流程从头到尾都是一个创新的东西呢

这个工具里面有哪些东西

你会用到这么几种 ITOC 文件类型：

扩展名 它是啥 干嘛用的
.czemidi 工程文件 你平时编辑的就是这个，里面存了你所有的音符、弹窗、动画、命令这些设置 想在编辑器改你这个作品，就得打开这个文件
.UIclass 模类文件 这个是你自己用模类设计器搭建的弹窗模板，是 Itoc 最自由的弹窗 如果你老是要弹出同样样子的窗口，可以把它导入 Itoc 模类文件夹，下次直接用就行
.CzeData 中间数据文件 这是从工程渲染出来的中间文件，Itoc 的播放器会读它来演出 一般在开发的时候用，给播放器拿来跑一下看看效果 它不算最终产物

大概的工作流程

拿到 Itoc 之后，基本就是这几步：

  1. 先把工程建起来

    新建一个工程，然后导入你喜欢的 MIDI 谱子（当然你也可以不导入，自行绘制事件块，这适合做窗口MV等不严格逐音卡点的领域） 把伴奏的 MP3 音频也选一下

  2. 然后在音符上挂弹窗

    在时间轴上挑一个音符，给它绑上一个弹窗 你想让它在哪出现、长什么样、什么动画、待多久，都在这里设好 一首歌变成一场演出，还挺有意思的哈

  3. 先跑一下看看

    设好了之后点一下测试运行，不用编译，马上就能看到效果 如果弹窗位置不对或者动画太奇怪，回去改一改，再跑一下 直到你觉得对了为止 呃...其实这个阶段挺容易上头的，一改就停不下来 qwq

  4. 最后再打包分享

    觉得差不多了，就可以把它编译成可以单独运行的 exe 程序，发给朋友玩喵 ( ⓛ ω ⓛ *)
