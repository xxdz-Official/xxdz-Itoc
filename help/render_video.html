渲染视频文件

前面我们讲了 CZEmaker 弹窗、全局命令、音符块、调整图层、过渡动画、批量赋音效、渲染为音频文件。现在讲 Itoc 输出环节的压轴大戏——渲染视频文件。它能把整份 Itoc 工程"演"成一段完整的视频，弹窗出现消失、过渡动画、位移动画、调整图层特效、桌面壁纸、背景音乐……全都在里面。

📌 本篇的范围：
讲的是视频渲染的入口、流程、两个窗口的界面、输出设置、显示器尺寸、虚拟机模拟设置、预览渲染、常见问题。关于音频渲染本身，请参考《渲染为音频文件》；关于弹窗怎么配，请参考《CZEmaker 弹窗编排》系列。

一、这个功能是干嘛的？

Itoc 工程本身是"弹窗数据 + 时间轴"。视频渲染就是把这些数据按时间轴"跑一遍"，每一帧都画成一个画面，最后编码成一段 MP4（或 AVI / MOV / MKV）视频。

跟音频渲染相比，视频渲染多了这些活儿：

  • 把弹窗（常规框、图片框、视频框、模类框、通知）画到画面里
  • 把过渡动画、位移动画、调整图层特效画到画面里
  • 把桌面背景（图片或纯色）画到画面里
  • 把 set_wallpaper 命令指定的壁纸画到画面里
  • 最后把音频轨混进视频里

所以视频渲染比音频渲染慢得多，但也"完整"得多。

二、从哪里打开？

菜单位置：「渲染(R)」 → 「渲染视频文件」。

快捷键：Ctrl + Alt + V。

💡 别按错了：
音频渲染是 Ctrl + Alt + E，视频渲染是 Ctrl + Alt + V。两个窗口长得有点像，别搞混。

前置条件

打开视频渲染前，程序会先检查：

检查项不满足时的提示怎么解决
是否有打开的工程"请先打开或保存一个工程文件"先新建或打开一个工程
工程里是否有音符"当前工程没有音符数据，无法渲染视频"先在时间轴上画几个音符

三、渲染流程概览

视频渲染不是"一步到位"，而是分三个阶段自动串起来跑的。你点一次"开始渲染视频"，程序会在后台依次执行：

阶段做什么你会看到
阶段 0准备工程数据与资源配置窗口日志显示"阶段0"相关进度
阶段 1渲染音频 + 写入配置配置窗口日志显示音频渲染进度
阶段 2启动视频渲染器自动弹出"渲染为视频文件"窗口，开始画帧
📌 你会看到两个窗口：
第一个是你打开的配置窗口，点了"开始渲染视频"之后它不会自动关闭，会一直显示进度；
第三个阶段会再弹出一个"渲染为视频文件 - Itoc"窗口，那个才是真正画帧的地方。
两个窗口可以同时存在，配置窗口会提示"已交接给视频渲染器"，你可以关掉它，视频渲染器会继续干活。

四、第一个窗口：配置面板

从菜单打开后，会先出现一个左右分栏的配置窗口。视频模式比音频模式多了一列"视频渲染"面板，所以是三栏布局：

区域内容
左栏音频设置（跟音频渲染一样）：输出设置、音源设置、范围设置、输出路径
中栏视频设置：视频输出设置、渲染设置
右栏波形显示器、渲染进度、渲染日志

左栏和右栏跟音频渲染完全一样，这里不再重复。重点讲中栏。

4.1 视频输出设置

格式

可选 MP4 / AVI / MOV / MKV。日常分享用 MP4 就行，兼容性最好。

分辨率

可选 1920×1080 / 1280×720 / 3840×2160 / 自定义。选"自定义"时会出现两个小输入框，手动填宽高。

⚠️ 自定义分辨率有上限：
宽高都必须是正整数，且最大 7680。超过会弹提示，渲染不会开始。
另外，宽高会被自动改成偶数，所以填了奇数会自动减 1。

显示器尺寸

这个是视频渲染里最容易搞混的一项，跟"分辨率"不是一回事，下一章专门讲。

帧率

可选 30 / 24 / 25 / 60。旁边还有一个"预览："下拉框，可选 15 / 10 / 5 / 30，是给"预览渲染"按钮用的。

编码器

可选 H.264 / H.265 / VP9。H.264 兼容性最好；H.265 体积更小但兼容性差一些；VP9 主要给网页用。

4.2 渲染设置

选项说明
渲染模式完整版 / 快速预览 / 仅弹窗。目前主要用于记录，实际渲染以完整版为准
线程数自动 / 1 / 2 / 4 / 8。选"自动"会用 CPU 核数（最多 8）。多线程渲染能快好几倍
虚拟机模拟设置按钮，点开一个独立窗口，调桌面、字体、焦点颜色等

4.3 范围设置

跟音频渲染一模一样，三种粒度：

选项说明
全部音符从第一个音符渲染到最后一个音符
仅时间选区范围只渲染时间轴上有选区的那一段。没有选区时灰掉不可选
自定义范围手动填起止秒数，只渲染这一段

范围设置会同时作用于音频阶段和视频阶段——视频渲染器也会读取范围信息，并据此裁剪弹窗和全局命令。

4.4 输出路径

这个路径就是最终视频文件的路径。默认是：

工程目录/export/工程名_日期时间.mp4

下面两个复选框跟音频渲染一样：

  • 渲染后打开文件夹 —— 视频渲染完成后自动打开输出目录
  • 渲染后播放视频 —— 视频渲染完成后用系统默认播放器打开

4.5 开始渲染视频

点击中栏底部的 「开始渲染视频」，就会启动三阶段流程。按钮变成"渲染中..."，同时显示日志和进度。

五、第二个窗口：视频渲染器

第三阶段会弹出一个窗口，标题是"渲染为视频文件 - Itoc"。这才是真正画帧的地方，左右分栏：

区域内容
左栏（窄）输出设置、渲染设置、范围设置、输出路径、底部按钮
右栏（宽）视频预览显示器、渲染进度、渲染日志

5.1 输出设置

跟第一个窗口的中栏几乎一样，也是格式 / 分辨率 / 显示器尺寸 / 帧率 / 编码器。不同的是这里的值通常会被自动填好，一般不需要手动改。

5.2 渲染设置

线程数 + "虚拟机模拟设置"按钮。跟第一个窗口一样。

5.3 范围设置

三个单选按钮：全部音符 / 仅当前选区范围 / 自定义范围。

跟第一个窗口不同的是，这里的"仅当前选区范围"是否可用，取决于第一个窗口里有没有设置时间选区。如果有，会自动勾选并把选区起止填到自定义范围输入框里。

5.4 输出路径

跟第一个窗口一样，一行输入框 + 浏览按钮。下面两个复选框：

  • 渲染后打开文件夹（默认勾选）
  • 渲染后播放视频（默认勾选）

5.5 视频预览显示器

一块黑底区域，渲染过程中会每 5 秒刷新一次，显示当前帧的画面（等比例缩放居中）。

注意这是"渲染过程中的快照"，跟最终成品有一点点差别（比如正在做动画的那一帧可能被采样到）。渲染结束后不会显示最后一帧，而是停留在最后一次刷新的画面上。

💡 预览是节流的：
窗口缩放时不会立刻重绘，而是等 0.5 秒后再刷，避免频繁重绘卡顿。

5.6 渲染进度

区域内容
阶段标签待机中 → 渲染中 → 渲染完成
进度条0 ~ 100%
已用时 / 剩余MM:SS 格式
已处理比如"已处理: 1234 / 8920 帧"
预估大小 / 实际大小渲染前显示预估，完成后显示实际大小

5.7 渲染日志

一块文本区，按时间顺序打印渲染过程。多线程渲染时，日志会提前按时间顺序打印所有"音符创建/关闭"事件，避免多线程交错把顺序搞乱。

5.8 底部按钮

按钮作用
取消未渲染时关闭窗口；渲染中则停止渲染并退出
预览渲染用虚拟机模拟设置里的"预览"参数快速渲染（低分辨率、低帧率），输出文件名加 _preview 后缀
开始渲染用当前参数正式渲染

六、分辨率 vs 显示器尺寸

这两个参数长得很像，但作用完全不同。理解它们的区别，对渲染出正确的视频很关键。

参数作用
分辨率输出视频的像素尺寸。1920×1080 就是输出 1080p 视频
显示器尺寸视频里"虚拟屏幕"的尺寸。弹窗的百分比坐标、对齐位置、随机位置、最大 60% 尺寸等，都按这个尺寸算
📌 举个例子：
假设你把分辨率设成 1280×720，显示器尺寸设成 1920×1080。
那么视频文件是 720p 的，但工程里"从屏幕左边滑入"的弹窗，会按 1920×1080 的屏幕来算起点，最后等比缩放到 1280×720 画进视频。
这样做的意义是：渲染出来的画面，跟你在 1080p 屏幕上预览时看到的位置关系完全一致，只是分辨率低了一点。
💡 推荐配置：
· 想快速看效果：分辨率 1280×720，显示器尺寸跟主程序预览一致
· 想输出成品：分辨率 1920×1080 或 3840×2160，显示器尺寸跟主程序一致

七、虚拟机模拟设置

从任一窗口点"虚拟机模拟设置"按钮，会弹出一个独立窗口。这里配置的是"渲染时，虚拟桌面长什么样"。

7.1 分辨率（拉伸）

字段说明
分辨率正式渲染时使用的输出分辨率。可选 1920×1080 / 1280×720 / 640×360 / 3840×2160 / 自定义
预览分辨率点"预览渲染"时使用的分辨率，通常设低一点（默认 640×360）

7.2 屏幕尺寸

字段说明
屏幕尺寸正式渲染时的虚拟屏幕尺寸，用于计算弹窗位置
预览屏幕尺寸点"预览渲染"时使用的虚拟屏幕尺寸

7.3 桌面

字段说明
桌面图片可选。一张包含桌面 + 任务栏的图片，会作为视频背景铺满。推荐用 1920×1080 的截图
桌面颜色没指定桌面图片时生效。默认 #FFFFFF（纯白）

7.4 系统字体

一个字体文件（.ttf / .ttc / .otf）。视频里所有中文都靠这个字体渲染。不指定的话，程序会依次尝试：

  1. 工程自带的 TTF/Dengl.ttf
  2. 系统常见中文字体（微软雅黑、黑体、宋体……）
  3. 默认字体（这个不支持中文，会显示方块）

7.5 窗口焦点颜色

视频里弹窗的标题栏，会根据"是不是焦点窗口"显示不同颜色。焦点窗口就是"当前时刻最新出现的那个弹窗"。

字段作用
焦点标题背景焦点窗口标题栏的背景色，默认 #0078D7（Windows 蓝）
焦点标题文字焦点窗口标题栏的文字色，默认 #FFFFFF（白）
非焦点背景非焦点窗口标题栏的背景色，默认 #F0F0F0（浅灰）
非焦点文字非焦点窗口标题栏的文字色，默认 #6E6E6E（中灰）

改完点"应用"，会立即生效——不需要重启程序，也不需要重新打开渲染窗口。

八、预览渲染

视频渲染很慢，正式渲染一次可能要几分钟甚至几十分钟。如果你想先看看效果，用「预览渲染」按钮。

预览渲染会：

  • 用"虚拟机模拟设置"里的预览分辨率（默认 640×360）
  • 用"虚拟机模拟设置"里的预览屏幕尺寸（默认 1920×1080）
  • 用预览帧率下拉框的值（默认 15）
  • 输出文件加 _preview 后缀，比如 output_preview.mp4
📌 两种"预览"的来源不一样：
· 手动点"预览渲染"按钮 → 输出文件名加后缀
· 由主程序侧边栏自动启动的预览 → 输出文件名不加后缀（因为侧边栏在等固定文件名）

九、常见问题

Q1：点了"开始渲染视频"，为什么弹了两个窗口？

正常。第一个是配置窗口（你打开的那个），第二个是视频渲染器（自动启动的独立进程）。前者负责准备数据和启动后者，后者负责真正画帧。

看到配置窗口里出现"已交接给视频渲染器"的日志，就说明第二个窗口已经起来了，你可以关掉配置窗口了。

Q2：视频里的弹窗位置，跟主程序预览时不一样？

大概率是显示器尺寸跟主程序不一致。视频渲染里所有位置计算都按"显示器尺寸"来，如果这个值跟主程序预览时用的屏幕尺寸不同，弹窗位置就会整体偏移。

解决方法：把"显示器尺寸"设成跟主程序屏幕一样的分辨率（比如 1920×1080）哦。

Q3：视频里的中文显示成方块 / 乱码？

三个可能：

  • 没指定系统字体，且工程里没有 TTF/Dengl.ttf，且系统也没常见中文字体
  • 指定的字体文件路径错了
  • 字体文件本身不包含中文字形

在"虚拟机模拟设置"里手动选一个中文字体文件（比如 C:/Windows/Fonts/msyh.ttc），就能解决。

Q4：视频渲染完了但没有声音？

两个可能：

  • 配置窗口里没勾"包含载入的音频轨道"，或者工程本身没加载音频
  • 系统里缺少混流组件（通常打包版会自带，如果用的是开发版可能需要手动放一个）

看渲染日志里有没有 [音频混流] 开头的行，就能知道是哪种情况。qwq

Q5：自定义分辨率填了奇数，渲染出来会怎样？

会自动减 1，改成偶数。比如填 1921×1081，实际渲染成 1920×1080 呀。

Q6：渲染中途能取消吗？

可以。点视频渲染器的"取消"按钮，或者直接关窗口。配置窗口那边点"取消"也可以中断三阶段流程。

不过要注意：视频渲染是边渲染边写文件的，取消后会留下一个不完整的 MP4。下次渲染同名文件会直接覆盖。

Q7：渲染速度太慢，怎么加速？

几个思路：

  • 把线程数拉到"8"或"自动"
  • 用"预览渲染"先看效果，满意了再正式渲染
  • 分辨率降到 1280×720
  • 帧率降到 24 或 25
  • 范围用"自定义范围"只渲染关键那一段

Q8：视频渲染器窗口的"预览显示器"一直黑屏？

两个可能：

  • 刚启动还没渲染到第一帧。等 5 秒再看
  • 工程里第一个弹窗的起始时间很晚（比如第 30 秒才出现）。预览只会显示"当前正在渲染的那一帧"，前面几十秒都是空桌面

Q9：视频里的弹窗标题栏颜色不对？

标题栏颜色由"虚拟机模拟设置"里的焦点/非焦点颜色决定。焦点窗口是"当前帧里最新出现的弹窗"。

如果你觉得焦点判定不对，检查一下弹窗的起始时间是否相同——同一时刻出现的多个弹窗，焦点会落在那批里最后一个。

Q10：桌面背景怎么设？

两种方式：

  • 在"虚拟机模拟设置"里指定一张桌面图片，会作为默认背景铺满整个视频
  • 在工程里用 set_wallpaper 全局命令，在时间轴的特定时刻切换壁纸（支持图片和视频壁纸）

两种可以同时用：set_wallpaper 生效时用壁纸，不生效时用默认桌面。

十、小结

「渲染视频文件」是 Itoc 输出环节的压轴功能，把整份工程变成可以播放、分享的视频。

  • 入口：菜单「渲染(R)」→「渲染视频文件」，或 Ctrl+Alt+V
  • 三阶段流程：准备数据 → 渲染音频 → 启动视频渲染器
  • 支持 MP4 / AVI / MOV / MKV 四种格式
  • 分辨率决定视频尺寸，显示器尺寸决定弹窗位置的计算基准，两者不是一回事
  • 支持多线程渲染，线程数可调
  • 支持预览渲染，用低分辨率、低帧率快速看效果
  • 虚拟机模拟设置可调桌面、字体、焦点颜色，改完立即生效
  • 支持全部 / 时间选区 / 自定义三种范围
  • 渲染过程中可随时取消，配置窗口和渲染窗口都可以中断
