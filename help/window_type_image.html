🖼️ 图片框

图片框就是「弹窗里显示一张图」的窗口类型。听起来简单，但它其实是 Itoc 里花头最多的窗口之一——支持静态图、GIF 动图、镂空、缩放、自定义尺寸，还能跟过渡动画配合玩出花来。

这篇把图片框从「选图」到「显示」的整个流程讲清楚。镂空的细节在 镂空窗口 里单独讲，这篇只提它和图片框的关系。

先认识 ImagePopup

图片框在代码里对应 ImagePopup 类，它继承自 QWidget。你可以把它理解成「一个装满 QLabel 的 QWidget，QLabel 里放着图片或 GIF」。

它和普通弹窗最大的区别是：

  • 没有「窗口内容」文本框——内容就是图片本身。
  • 有「图片路径」配置，用来指定显示哪张图。
  • 有「镂空」「缩放百分比」这些图片专属选项。
  • 如果勾了镂空，会强制走无边框模式，并支持左键拖动 + 右键关闭。

选图片

在 CZEmaker 面板里，图片框的左侧区域有一个文件选择框，点「浏览...」会打开文件对话框。

支持的格式：PNG / JPG / JPEG / GIF / BMP / ICO。

选完之后，程序会自动把图片复制到工程的 img/ 目录（如果目录不存在会自动创建）。这个复制是在后台线程里做的，复制的时候窗口会稍微卡一下（大图会久一点），但不会真的卡死。

重名处理： 如果 img/ 里已经有同名文件：

  • 文件大小相同 → 认为就是同一张图，直接复用。
  • 文件大小不同 → 自动加数字后缀，变成 xxx_1.png、xxx_2.png 这样，不会覆盖你的旧图。

保存到配置文件的字段是 image_path，值是相对路径，比如 img/avatar.png。

💡 为什么用相对路径？ 因为工程文件夹是可能被整体移动或分享的。绝对路径（比如 D:\project\img\xxx.png）换个电脑就失效了。相对路径 img/xxx.png 是相对于工程文件所在目录的，跟工程走，搬家也不怕。

GIF 动画

如果选的图是 .gif，程序会自动把它当动画处理，而不是只显示第一帧。

处理流程：

  1. 用 PIL（Image）打开 GIF。
  2. 逐帧 seek + copy，把所有帧存到 _gif_frames 列表里，每帧的延迟存到 _gif_durations。
  3. 如果镂空启用了，每帧显示时会应用镂空处理（alpha 直接保留透明通道，chroma 逐像素替换）。
  4. 用 after() 按每帧的延迟时间递归调度下一帧，循环播放。

面板上的「图片预览」画布会实时显示 GIF 动画，所见即所得。

💡 GIF 镂空的性能： alpha 模式几乎不耗性能（直接用透明通道），chroma 模式每帧都要逐像素遍历，帧数多、分辨率大的 GIF 会明显变慢。如果你的 GIF 本身就有透明通道，优先用 alpha。

缩放百分比

图片框的左侧区域有一个「缩放百分比」输入框 + 滑块，范围 10% ~ 200%。

但这里有个容易搞混的点：缩放百分比不是直接控制弹窗大小的，它是通过通知主面板的 W/H 输入框来间接控制的。

具体流程是：

  1. 你拖动滑块，程序算出新的百分比。
  2. 用「原始图片宽度 × 百分比」算出新的目标 W/H。
  3. 调用 czemakers._update_image_size_from_percent(new_w, new_h, percent)。
  4. 主面板把 W/H 写进自定义尺寸输入框。
  5. 弹窗创建时按这个 W/H 设置窗口大小。

所以你会看到：滑块动 → 主面板 W/H 跟着变 → 弹窗大小也跟着变。三者是联动的。

⚠️ 如果滑块是灰的： 说明「自定义尺寸」没勾。滑块状态的启用/禁用由主面板的 _toggle_custom_size_controls 控制。想用缩放滑块，先勾「自定义尺寸」。

镂空（简版）

镂空是图片框的招牌功能，完整讲解在 镂空窗口。这里只说要点：

  • 勾选「镂空图片窗口」后，下面会出现「透明通道」和「色度抠图」两个单选框。
  • 透明通道（alpha）：用 PNG 自带的透明通道，干净无损。
  • 色度抠图（chroma）：指定一个颜色变透明，适合纯色背景图，但容差为 0，有绿边。
  • 选 PNG 图片时，如果镂空已勾，程序会自动切到 alpha 模式。
  • 选非 PNG 图片时，如果镂空已勾，程序会自动切到 chroma 模式。
  • 镂空图片框强制无边框，支持左键拖动 + 右键关闭。

自定义尺寸

图片框支持自定义尺寸。勾了「自定义尺寸」后，W/H 输入框启用，可以手动填宽度和高度（像素）。

旁边有个尺寸拾取按钮（⊕），点击后在屏幕上拖一个框，程序只记录宽高、不记录位置。框太小（小于 10×10）会被忽略。按 ESC 取消。

和图片比例的关系： 如果你手动改了 W/H，程序会检查当前 W/H 的比例是否匹配原始图片比例：

  • 比例匹配 → 启用缩放滑块，并把百分比同步到「当前宽 ÷ 原始宽 × 100」。
  • 比例不匹配 → 禁用缩放滑块，并在尺寸显示里标「(自定义比例)」，提醒你这张图会被拉伸或压扁。

保存字段是 custom_size_enabled / custom_width / custom_height。

哪些配置不生效

图片框有一些普通弹窗的配置是不生效的，这里列一下免得你找不到：

  • 窗口内容：禁用，灰色。图片框没有「文字内容」这个概念。
  • 效果音：生效，可以配。虽然图片框本身没声音，但弹窗出现时可以播一个效果音。
  • 图标下拉框：禁用。图片框不显示标题栏图标（尤其镂空模式下根本没标题栏）。
  • 按钮区：禁用。图片框没有「确定 / 取消」按钮区。
  • 控制钮：生效。但如果勾了镂空，控制钮配参会被无边框模式覆盖（镂空强制无边框）。

图片框的交互

非镂空图片框

和普通弹窗差不多：

  • 拖动标题栏移动窗口。
  • 点关闭按钮关闭。
  • 如果勾了「可调窗口」，可以拖边缘改大小。
  • 如果配了「寿命」，到时间自动关。

镂空图片框

因为强制无边框，没有标题栏，所以程序补了两套交互：

  • 左键任意位置拖动：点图片任意位置（包括透明区域）按住左键拖，窗口跟着走。
  • 右键任意位置关闭：点右键调 close_window()，播出场动画（如果有）后关闭。

这两套交互是镂空图片框专属的，非镂空图片框没有。

透明度、置顶、任务栏

图片框遵循样式钮的配置：

  • 透明度：window_opacity 生效。100 = 完全不透明，50 = 半透明。注意：镂空图片框的透明度是作用在整张图上的，透明区域仍然是透明的，不透明区域会跟着变淡。
  • 窗口置顶：topmost 生效。默认置顶。
  • 在任务栏显示：show_in_taskbar 生效。但工具窗样式会强制隐藏任务栏。
  • 可调窗口：resizable 生效。但镂空图片框一般不推荐勾，因为无边框 + 可调大小的体验很怪。

常见问题

Q：图片路径是相对路径，但换了个工程打不开？

A：相对路径 img/xxx.png 是相对于当前打开的工程文件所在目录解析的。换工程后，如果新工程的 img/ 目录里没有这张图，就会加载失败。解决方案：把图片一起拷到新工程的 img/ 目录。

Q：GIF 不动，只显示第一帧？

A：可能原因：① GIF 本身只有一帧（伪动图）；② GIF 帧加载失败（文件损坏）；③ 镂空 chroma 模式逐帧处理太慢，卡在第一帧。先看控制台日志，如果打印了「检测到 N 帧动画」，说明程序识别到了，只是没播起来。

Q：图片框和图片本身的比例对不上？

A：如果你勾了自定义尺寸，填的 W/H 比例和原图比例不一致，图片会被拉伸。程序会在尺寸显示里标「(自定义比例)」提醒你。想保持比例，就按原图比例填 W/H，或者用缩放百分比。

Q：镂空图片框右键没反应？

A：右键关闭绑定在 ImagePopup.mousePressEvent 里。如果透明区域收不到右键，检查窗口是否设置了 WA_TransparentForMouseEvents。正常情况下程序已经显式关闭了这个属性，整张图（包括透明部分）都能接收右键。

小结

图片框的四件事：

  1. 选图：PNG / JPG / GIF / BMP / ICO，自动复制到 img/。
  2. 缩放：通过缩放百分比间接控制，滑块状态由自定义尺寸复选框控制。
  3. 镂空：alpha 干净，chroma 通用但有绿边，选 PNG 自动 alpha。
  4. 交互：非镂空拖标题栏，镂空拖任意位置 + 右键关闭。

图片框的坑基本都在「路径」和「比例」上，把这两件事搞定了，剩下的就是选图、调大小、加动画了喵 ( ⓛ ω ⓛ *)
