🖼️ SVG 阵列

SVG 阵列是「懒人福音」。你只要丢一个 SVG 文件进去，程序会自动解析里面的路径，然后把弹窗沿着路径均匀分布。你不需要手动摆点，缩放一下就行。

一、操作方式

操作说明
选择SVG文件从磁盘选一个 .svg 文件
清空清空当前 SVG，保留缩放参数
缩放滑块整体缩放 SVG 背景和弹窗位置

二、采样规则

SVG 里可能有多条路径。程序会：

  1. 按路径的文件定义顺序依次分配弹窗
  2. 每条路径内部独立均匀采样
  3. 弹窗总数 N 会按路径数量尽量平均分配，余数分给前面的路径
  N = 10，3 条路径
  路径1：4 个弹窗
  路径2：3 个弹窗
  路径3：3 个弹窗

三、支持的 SVG 元素

元素支持
<path>✅ 完整支持（M/L/H/V/C/S/Q/T/A/Z）
<circle>✅ 转为路径
<ellipse>✅ 转为路径
<rect>✅ 转为矩形路径
<line>✅ 转为直线
<polyline>✅ 转为折线
<polygon>✅ 转为闭合折线

四、背景显示

SVG 会被光栅化成一张半透明背景图，保留原色，alpha 为 0.5。你可以一边看背景，一边看绿点分布。

💡 中心点就是锚点：
SVG 的几何中心（优先 viewBox 中心）就是阵列的锚点。所有弹窗位置都是相对于这个中心计算的。

五、适用场景

  • 把公司的 Logo 变成弹窗阵
  • 用文字路径做弹窗排列
  • 复杂图形一键映射成弹窗位置
