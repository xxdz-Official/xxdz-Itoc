❄️ 亚克力与云母

亚克力（Acrylic）和云母（Mica）是 Windows 10/11 的两种「磨砂玻璃」窗口材质。开启之后，窗口背景会变成半透明的模糊效果，透出后面的桌面或窗口内容，看起来很有质感。

Itoc 通过 Win32 API 给弹窗加上这个效果。这篇把怎么开、原理是什么、哪些系统支持、和窗口背景/镂空怎么联动，全部讲清楚。

入口

亚克力/云母的开关在「样式钮」的设置对话框里。打开方式：

  1. 在 CZEmaker 面板顶部右侧找到「样式钮」下拉框。
  2. 选择「设置」，打开「窗口控制按钮与窗口样式设置」对话框。
  3. 在「窗口样式」区域下方，找到「亚克力或云母 （如果系统支持的话）」复选框。

勾选之后点确定，配置就保存了。下次弹窗出现时会应用这个效果。

💡 复选框的悬浮提示： 鼠标悬停在「亚克力或云母」复选框上，会显示一段提示：「勾选此框后，窗口将呈现半透明磨砂玻璃效果（亚克力/云母），需要运行时的系统支持。如果取消勾选『窗口背景』，此功能将失效喵」。

和「窗口背景」的联动

亚克力必须配合「窗口背景」使用。两条联动规则：

  • 勾选亚克力 → 自动勾选窗口背景。 因为亚克力需要窗口有实际的背景层来承载模糊效果，没背景就没处模糊。
  • 取消勾选窗口背景 → 自动取消勾选亚克力。 反过来，没有背景时亚克力会失效，程序干脆帮你取消掉，避免配置矛盾。

这套联动是双向的、实时生效的。你在对话框里勾一个，另一个会自动跟着变，不需要手动同步。

⚠️ 注意： 如果你在配置文件里手动把 window_material=true 和 window_background=false 同时写进去，程序在创建窗口时会以「窗口背景」为准——不勾背景就不启用亚克力。所以别在配置里制造矛盾。

Win32 实现原理

Itoc 不是用 Qt 自带的毛玻璃（Qt 在 Windows 上对亚克力的支持不稳定），而是直接调 Win32 的 SetWindowCompositionAttribute 接口。核心流程在 enable_acrylic(hwnd, color) 函数里：

  1. 构造一个 ACCENTPOLICY 结构体，AccentState 设为 ACCENT_ENABLE_ACRYLICBLURBEHIND（值为 4），GradientColor 设为传入的颜色（默认 0x33FFFFFF，半透明白）。
  2. 构造一个 WINDOWCOMPOSITIONATTRIBDATA 结构体，Attribute 设为 WCA_ACCENT_POLICY（值为 19），Data 指向上面那个 ACCENTPOLICY。
  3. 调用 user32.SetWindowCompositionAttribute(hwnd, &data)。

如果系统是 Windows 11，函数还会额外调两次 DwmSetWindowAttribute：

  • DWMWA_CAPTION_COLOR（35）：把标题栏背景色强制设为白色（0x00FFFFFF），防止标题栏在亚克力下发黑或变透明。
  • DWMWA_TEXT_COLOR（36）：把标题栏文字色强制设为黑色（0x00000000），保证白底黑字可读。

这两步是 Windows 11 专属的修复。Windows 10 上没有这两个属性，调用会被忽略（不会报错）。

💡 为什么不用 Qt 自带效果： Qt 在 Windows 上没有稳定的「亚克力」封装，不同 Qt 版本、不同 Windows 版本表现不一致。直接调 Win32 接口最可靠，而且能精确控制 AccentState 和颜色。

系统版本支持

亚克力/云母对系统版本有要求：

Windows 版本亚克力（Acrylic）云母（Mica）说明
Windows 11（22H2+）✅ 支持✅ 支持完整支持，Itoc 会额外修复标题栏颜色
Windows 11（21H2）✅ 支持⚠️ 部分支持云母效果不稳定，可能只显示模糊
Windows 10（1803+）✅ 支持❌ 不支持只有亚克力，没有云母
Windows 10（早期版本）⚠️ 部分支持❌ 不支持可能只显示简单的模糊，不是完整的亚克力
Windows 8.1 / 8 / 7❌ 不支持❌ 不支持SetWindowCompositionAttribute 不存在或无效

Itoc 不检测系统版本，直接调 API。如果 API 不存在（Windows 7 及以下），调用会失败，函数内部有 try/except 兜底，不会崩溃，只是没有效果。

应用范围

亚克力/云母支持哪些窗口类型？

  • 常规弹窗（信息框/警告框/错误框/询问框）：支持。窗口设置 WA_TranslucentBackground，内容区透明，然后调 enable_acrylic。
  • 图片框：支持（非镂空模式）。镂空图片框不支持，因为镂空窗口本身就是全透明的，亚克力无处附着。
  • 模类框：支持。模类框创建时如果 window_material=true，会在窗口 show 之后调 enable_acrylic。
  • 视频框：不支持。视频框是 mpv 进程的窗口，不受 Qt 控制，无法应用 Qt 的透明背景 + Win32 亚克力组合。
  • 气泡/通知：不支持。气泡是系统通知，不是 Itoc 创建的窗口。

与窗口透明度的关系

亚克力和「透明度」输入框（window_opacity）是两套独立的机制：

  • 透明度：用 Qt 的 setWindowOpacity 或 Win32 的 SetLayeredWindowAttributes(LWA_ALPHA) 控制整个窗口（包括内容）的不透明度。0% 完全透明，100% 完全不透明。
  • 亚克力：只影响窗口背景的模糊和半透明，不影响前景控件。前景文字、按钮仍然是清晰的。

两者可以叠加使用。比如「透明度 80% + 亚克力」= 整体 80% 不透明，背景有模糊效果。但叠加太多可能会导致视觉混乱，建议二选一，或者透明度不要调太低。

与镂空的关系

镂空图片框和亚克力互斥。原因：

  • 镂空窗口用 WA_TranslucentBackground，背景完全透明，没有可承载模糊的图层。
  • 亚克力需要窗口有一个半透明的背景层，通过 GradientColor 控制模糊的色调。
  • 两者同时开启时，程序以镂空为准，亚克力不生效（但配置里的 window_material 字段可能还是 true，不会自动改）。

如果你想要「镂空 + 模糊」的效果，目前做不到。镂空窗口就是纯粹的透明，没有背景模糊。

与色键透明的关系

「窗口背景」不勾选时，程序用 paintEvent + SetLayeredWindowAttributes(LWA_COLORKEY) 做色键透明。这套机制和亚克力也是冲突的：

  • 色键透明是「某个 RGB 颜色变透明」，没有背景层。
  • 亚克力需要背景层。
  • 所以不勾「窗口背景」时，亚克力被自动取消。

配置文件字段

亚克力配置保存在音符的 cze_makers.window_control_detail 里：

  • window_material：布尔，是否启用亚克力/云母。默认 false。
  • window_background：布尔，是否绘制窗口背景。默认 true。亚克力要求这个为 true。

示例：

{
  "window_control": "custom",
  "window_control_detail": {
    "close": true,
    "maximize": false,
    "minimize": false,
    "topmost": true,
    "window_style": "normal_fixed",
    "window_background": true,
    "window_material": true
  }
}

旧工程没有 window_material 字段时，默认为 false，不会自动开启亚克力。这是为了保持兼容，避免旧工程突然变样。

性能与视觉建议

性能： 亚克力会让 DWM（桌面窗口管理器）多做一层模糊合成，对 GPU 有一定开销。单个弹窗无所谓，但如果同时弹出几十个亚克力窗口，低端机器可能会掉帧。批量弹窗的场景建议关掉亚克力。

视觉：

  • 亚克力适合「轻量、悬浮」的提示窗，比如通知、小工具、悬浮球。
  • 不适合内容密集的弹窗（文字多的信息框），因为背景模糊会分散注意力。
  • 深色壁纸 + 浅色亚克力效果最好；纯白壁纸 + 白色亚克力几乎看不出效果。
  • Windows 11 的云母比 Windows 10 的亚克力更「收敛」，只有标题栏和背景轻微着色，不会过度模糊。
💡 调色： enable_acrylic(hwnd, color) 的 color 参数控制亚克力的渐变色调，默认 0x33FFFFFF（半透明白）。目前 Itoc 没有在界面上暴露这个参数，用的都是默认值。如果你想改，需要改代码里的默认参数。

常见问题

Q：勾了亚克力但没效果？

A：按顺序检查：①「窗口背景」是否勾选（不勾背景亚克力会失效）；② 窗口类型是不是视频框/气泡（不支持）；③ 是不是镂空图片框（互斥）；④ 系统版本是否支持（Windows 7 及以下不支持）；⑤ 壁纸是不是纯白（白色亚克力看不出效果）。

Q：Windows 11 上标题栏变透明了？

A：这是 enable_acrylic 里的修复逻辑在起作用。函数会额外调 DwmSetWindowAttribute(DWMWA_CAPTION_COLOR, 0x00FFFFFF) 把标题栏强制设为白色，避免亚克力把标题栏也模糊掉。如果你的系统版本不支持这个属性，调用会被忽略，标题栏可能仍然是系统默认色。

Q：亚克力窗口能拖动吗？

A：能。亚克力不影响拖动逻辑。普通弹窗拖动标题栏，镂空图片框拖动任意位置（但镂空和亚克力互斥，所以镂空窗口没有亚克力）。

Q：亚克力 + 透明度 50% 是什么效果？

A：整体 50% 不透明，背景有模糊。但因为整体半透明，模糊效果会被削弱，看起来更像「半透明的磨砂玻璃」。建议透明度不要低于 70%，否则亚克力效果不明显。

Q：视频框为什么不能用亚克力？

A：视频框是 mpv 进程的窗口，不受 Qt 的 WA_TranslucentBackground 控制。mpv 自己的窗口透明机制（--window-transparency）在某些版本上被移除或不稳定，Itoc 没有对视频框应用亚克力。

Q：模类框的亚克力怎么生效的？

A：模类框创建时，如果 window_material=true，会在 class_window.show() 之后用 QTimer.singleShot(0, lambda: enable_acrylic(int(class_window.winId()))) 延迟一帧调用，确保窗口句柄已经创建。

Q：亚克力窗口在任务栏显示正常吗？

A：取决于「在任务栏显示」复选框和「窗口样式」。亚克力本身不改变任务栏行为。工具窗样式下仍然不显示任务栏。

小结

亚克力与云母的三件事：

  1. 开关：在样式钮设置对话框里勾「亚克力或云母」，必须配合「窗口背景」。
  2. 原理：Win32 SetWindowCompositionAttribute + ACCENT_ENABLE_ACRYLICBLURBEHIND，Windows 11 额外修标题栏颜色。
  3. 限制：视频框/气泡不支持，镂空互斥，Windows 7 及以下无效，深色壁纸效果最好。

记住几个关键点：亚克力不是所有窗口都能用，不是所有系统都支持，和镂空/色键透明互斥。这些清楚了，磨砂玻璃效果就能稳稳用上了喵 ( ⓛ ω ⓛ *)
