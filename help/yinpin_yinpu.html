🔊 音频音谱

底部选项卡里有一个「音频音谱」，点开一看是一排会跳的小灯——绿的、黄的、红的，跟着音频忽上忽下。对，那就是它。连我自己都管它叫「没啥用的 · 音频电平表」，主打一个没用。。。

📌 这篇唠的是啥：
就讲底部选项卡里的「音频音谱」——它长啥样、LED 颜色咋分的、两种电平来源、底部信息栏咋看。
关于音频文件本身的加载，请参考《文件操作》相关文档。

一、这玩意儿是干啥的？

简单说，它就是个LED 电平表。播放工程的时候，那排小灯跟着音频的高低一跳一跳，让你一眼就能看出「现在这段响不响」。

它一共 36 个 LED，从左边往右边点亮。音频越响，点亮的 LED 越多，颜色也跟着从绿→黄→红过渡。

💡 说句实话：
这玩意儿确实"没啥用"——它不参与任何编辑操作，也不会影响渲染结果。
但看着那排小灯跟着音乐跳，确实挺带感的，就当是个氛围组件吧。

二、界面长啥样？

从上到下分成三块：

区域内容
顶部标题栏 左边写着「没啥用的 · 音频电平表」，右边显示实时信息（FPS 和延迟）
中间电平表 一整排 LED，加上 dB 刻度和峰值指示线
底部信息栏 左边显示「当前」和「峰值」的 dB 值，右边显示活动状态（音符数 + LED 数，或"静音待机"）

2.1 电平表的 LED

LED 是横向排列的，从左边开始点亮，颜色分三段：

位置颜色含义
左侧 0% ~ 70%🟢 绿色正常电平，安全区
中间 70% ~ 90%🟡 黄色偏高电平，要注意
右侧 90% ~ 100%🔴 红色接近满电平，可能会削波

每个点亮的 LED 亮度会随着位置变化——越靠近"当前电平前沿"的 LED 越暗，越靠左的越亮，看起来有个渐变效果。

2.2 dB 刻度

电平表顶部有一排刻度，标着 dB 值：

0     -6    -12          -24         -36              -48        -60
|      |      |            |           |                |          |
红     黄     黄           绿          绿               灰         灰

从右往左，数值越来越大（0 dB 在右边，-60 dB 在左边）。刻度线是虚线，颜色跟着区段走。

2.3 峰值指示

除了那排会跳的 LED，还有一个橙色的峰值指示器：

  • 一条橙色垂直线，显示近期达到过的最高电平
  • 线顶有一个小三角，三角上方写着具体的峰值 dB 数值
  • 峰值会保持 1 秒，然后慢慢往下降

这个峰值线让你能"抓住"一瞬间的尖峰——有些极短的爆音，LED 一闪就过去了，但峰值线会留在那里，方便你事后检查。

三、电平是怎么算的？

它有两种模式，按优先级自动切换：

3.1 有音频文件时：读真实波形

如果你已经加载了音频文件，电平表会直接去读音频的真实波形数据：

  1. 从 MMBTrack 里取出已经解码好的波形数据（就是画波形图那份数据）
  2. 根据当前播放位置，找到对应时刻的波形数据点
  3. 取这一小段的 max / min 绝对值里较大的那个作为电平值
  4. 做一个 5 点滑动平均，避免电平跳得太猛
  5. 再乘一个 1.4 的放大系数，让视觉上更带劲

这样算出来的电平，跟音频实际响度是对得上的——哪里鼓点重，哪里灯就跳得高。

3.2 没有音频时：按音符数量估算

如果没加载音频，它就退而求其次，根据当前正在播放的音符数量来估算：

同时播放的音符数估算电平
0 个0%（并且带 0.6 秒的衰减期，不会"啪"一下归零）
1 个35%
2 个55%
3 个70%
4 个82%
5 个90%
6 ~ 8 个93% ~ 99%
8 个以上最多 99%

为了不让灯看起来死板，估算模式下还会加一点随机波动（±0.02），看起来更"活"。

💡 两种模式怎么选？
不用你选，程序自动判断：
· 有音频文件 → 走真实波形模式（准确）
· 没有音频文件 → 走音符估算模式（凑合看）
所以想要灯跳得准，记得加载音频文件。

3.3 上升和下降的速度

灯跳起来是有讲究的，不是"咻"一下到顶也不是"啪"一下掉底：

方向响应速度说明
上升（变响）快，系数 0.7音频一响，灯立马跟上去
下降（变轻）慢，系数 0.1音频轻了，灯慢慢退下来，更接近真实听感

这个"快升慢降"的行为，就是真正的专业电平表会干的事——因为人耳对"变响"更敏感，对"变轻"反应慢。

四、底部信息栏

4.1 当前 / 峰值

左边两个标签：

  • 当前：现在的电平，单位 dB，范围 -60 ~ 0 dB
  • 峰值：保持 1 秒内的最高电平，单位 dB

dB 值是这么换算的：dB = 电平值 × 60 - 60，所以 0% 对应 -60 dB，100% 对应 0 dB。

4.2 活动状态

右边显示当前的状态，分两种情况：

显示内容含义
🎵 N 音符 | 💡 M LED有音符正在播放，显示音符数和点亮的 LED 数
🔇 静音待机没有音符播放

这个标签的颜色也会跟着电平变：

  • 🔴 红色：电平高（dB > -12）
  • 🟡 黄色：电平中（-24 < dB ≤ -12）
  • 🟢 绿色：电平低（dB ≤ -24）

4.3 FPS 和延迟

顶部右上角会显示类似 FPS: 14 | 延迟: 70ms 的文字，告诉你当前刷新速度。

默认是 70ms 刷新一次，也就是大约 14 FPS。这个速度足够让灯看起来流畅，又不会吃太多 CPU。

五、什么时候用？

坦白说，它不影响任何编辑功能，纯粹是"看着爽"。不过有几种场景确实能用上：

  • 检查音频响度：如果灯一直在红色区，说明音频可能削波了，需要降音量
  • 对齐鼓点：看着灯在鼓点上跳一下，比看波形图更直观
  • 调音量：一边拖音量滑块一边看灯跳的高度，比纯靠耳朵准
  • 纯粹好看：讲真，这排灯跟着音乐跳，确实挺有感觉的

六、常见问题

Q1：灯一直不动，全灭？

可能的原因：

  • 没在播放（点了播放按钮吗？）
  • 没加载音频，也没音符在播（那就真的没声音，灯不亮是正常的）
  • 音频文件没加载成功，路径失效了

Q2：灯跳得不准，跟听到的声音对不上？

检查一下有没有加载音频文件：

  • 有音频：应该跟音频响度一致，如果差太多，可能是波形数据没加载好，切到别的选项卡再切回来试试
  • 没音频：走的是音符估算模式，本来就是"大致对应"，不可能完全精准

Q3：红色区老是亮着，是不是有问题？

说明你的音频电平经常接近满值。这种情况有两种可能：

  1. 音频本身就录得很满，属于正常
  2. 音频有削波（爆音），建议去调低一下总音量或者音频音量

看「当前」dB 值，如果经常贴在 0 dB 附近，就说明该降音量了。

Q4：为什么有时候灯跳得很"虚"？

因为你没加载音频，走的是音符估算模式。这种情况下，灯的高低是按音符数量算的，跟实际响度没关系。加载音频之后就准了。

Q5：这个电平表影响渲染结果吗？

不影响。它只是一个"看"的东西，纯粹显示用。你导出的音频、视频、exe 里都不会带上这个电平表。

Q6：能关掉吗？

它就在底部选项卡里，你不点它就不显示。切到别的选项卡（比如 CZEmakers）它就停了，不占资源。

Q7：FPS 和延迟能调吗？

当前版本固定是 70ms 刷新一次，没做成可调项。我觉得这个速度是"流畅 + 省资源"的平衡点。

七、小结

「音频音谱」就是底部选项卡里的那个 LED 电平表，我自己也常说它"没啥用"。关键记住这几条：

  • 位置：底部选项卡 →「音频音谱」
  • 外观：36 个 LED，绿 → 黄 → 红，从左边往右边点亮
  • 两种模式：有音频走真实波形，没音频按音符数估算
  • 峰值保持：橙色线显示近期最高电平，保持 1 秒
  • 快升慢降：变响时灯立刻跟上，变轻时灯慢慢退下
  • 刷新速度：70ms 一次，约 14 FPS
  • 不影响渲染：纯显示，不会出现在导出结果里
