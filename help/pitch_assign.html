🎹 按音高应用配参

平时挂配参是「一个音符挂一个配参」，一个个点太慢了。如果一首曲子里不同音高段本来就该弹不同的东西——比如低音区弹错误框、中音区弹询问框、高音区弹警告框——那逐个音符去配就太麻烦了。

按音高应用配参就是解决这个场景的：你把音高区间切成几段，每段挂一个配参，点一下「应用」，工程里所有落在这段音高范围内的音符就全部换成对应的配参。

这一篇讲清楚：从哪进、界面怎么用、拖拽怎么调、应用时哪些音符会被改、哪些不会。

一、入口与前提

1.1 从配参管理器进入

这个功能挂在配参管理器里。打开方式：

  1. 主程序菜单 → 「配参(G)」→ 「管理配参」（或类似的入口，具体以当前版本菜单为准）。
  2. 在弹出的「配参管理器」里，勾选你想用的配参（可以多选，至少一个）。
  3. 点顶部第二行的「赋值到指定音高音符」按钮。

进窗口时，你勾选的那些配参会自动按数量平均分配到音高范围上，形成初始的「段」。比如你勾了 3 个配参，窗口打开后会看到 3 个段，分别对应低、中、高三个音高区间，每段一个配参。

💡 勾几个配参都行：
勾 1 个配参 → 打开后整条音高范围就一个大段，全是这个配参；
勾 2 个 → 低音段一个、高音段一个；
勾 3 个以上 → 按音高从低到高平均分布，一个配参一段；
想给某个段换配参、或者一个段都不用你勾的配参，进窗口后还可以手动改（见第五节）。

1.2 打开前的准备（可选）

进窗口前你还可以在主界面上做两件事，用来限定这次应用的范围：

  • 框选音符：在时间轴上拖出一个选框，选中一批音符。
  • 画时间选区：在时间轴上拉一段时间的选区（不是选框，是选区）。

这两个都不是必做的。不做就默认对全部音符生效；做了就会在窗口顶部出现对应的复选框，可以自己勾选启用。

⚠️ 框选和选区的复选框默认是「自动勾上」的：
如果你打开窗口前已经框选了音符 / 画了时间选区，窗口打开后对应的复选框会自动勾上。意思是：窗口默认只处理你选中的那部分。如果你改主意了要处理全部，进去手动取消勾选就行。

二、界面概览

窗口分五块：

区域位置干什么的
📊 顶部栏 最上面 显示当前处理目标（框选了 N 个 / 全部音符）、勾选「仅时间选区内」「仅框选音符」
🎹 音高渐变表 左栏 从低到高画出 0~127 所有音高，你的每一段都画在这里。可以在画布上直接拖拽建段/改段
📦 配参池 中栏 列出所有可用配参（分工程内置 / Itoc全局 / 已用三块），勾一个配参等于「快速给最大空档建一段」
📝 属性面板 右栏 每个段一张卡片，显示音高范围、音符数、配参、颜色，可以直接编辑
🔘 底部按钮 最下面 添加段 / 删除段 / 自动均分 / 预览效果 / 应用 / 取消
📌 音高范围不一定是 0~127：
窗口打开时会扫一遍工程里所有音符的音高，取最小值和最大值作为音高表范围。如果所有音符的音高跨度小于 24 个半音（比如都挤在一个八度里），会自动向上下各扩一点，把范围撑到 24 个半音左右，方便你在表上操作。0 和 127 是音高的硬边界，不会越界。

三、音高渐变表怎么用

左边这块是主战场。纵轴是音高（越往上越高），横轴是段。每一段用一块带色半透明色块覆盖它对应的音高范围，色块上写着「段名 起始音高~结束音高（音符数）」。

背景那条彩虹色只是视觉参考（低音偏紫、高音偏红），不代表任何数据。

3.1 建一个新段（在空白处拖拽）

在没有被已有段覆盖的空白音高区域，按住鼠标左键从一头拖到另一头，松开就是一个新段。

  • 段的音高范围 = 鼠标起点到终点之间的音高。
  • 如果拖的距离小于 1 个半音（比如手抖没拖动），会取消不建。
  • 拖出来的范围如果和已有段重叠，会弹「范围重叠」提示，取消这次建段。
  • 新段会自动挑一个「当前没被用过的」配参塞进去；如果没有未用过的，就留空（你之后手动选）。
💡 新建段的默认配色： 程序按段在列表里的位置从调色板里挑一个颜色（红、黄、绿、蓝、紫、橙、青、粉，8 色循环）。颜色只是视觉标记，不影响任何实际数据。同一个配参被分配给多个段时，段颜色可以不同。

3.2 调整段的上下边界（拖边缘）

把鼠标放到某个段的上边缘或者下边缘，会变成上下箭头光标，按住拖动就是调整边界：

  • 拖上边缘：改这个段的高音端（能拖到的最高是 127，不能低于本段低音端）。
  • 拖下边缘：改这个段的低音端（能拖到的最低是 0，不能高于本段高音端）。
  • 拖动时如果和相邻段撞上了，会自动停在相邻段的边界内侧，不会真的重叠。
💡 边缘容差 5 像素： 只有当鼠标落在段边缘 5 像素以内时，才进入「调整边界」模式。稍微往里一点就是「整体移动」模式。所以靠近边缘时注意一下光标变成上下箭头了才是调整边界，没变就是整体移动。

3.3 整体移动段（拖中间）

鼠标放在段的内部（离边缘超过 5 像素），按住拖动会让整段上下平移（音高范围不变，只是整体升降）。

  • 如果推到边界外（0 以下或 127 以上），会被夹回边界。
  • 如果推的过程里和别的段撞上了，这一帧就不动（避免重叠）。

3.4 右键菜单（向上填充 / 向下填充 / 删除）

右键点某个段，会弹出一个小菜单：

菜单项效果
向上填充 把本段的上边界一直往上扩，直到贴到「上面最近的那个段的下边界 - 1」。如果上面没有段，就一路扩到 127。
向下填充 把本段的下边界一直往下扩，直到贴到「下面最近的那个段的上边界 + 1」。如果下面没有段，就一路扩到 0。
删除此段 删掉这一段（音高范围就空出来了，不会被其他段自动吃掉）。

这两个「填充」很适合做「让某一段占满整个音域」的操作，比手动拖要准得多。

3.5 段与段不能重叠

整个音高表上，任意两段的音高范围不能有任何重叠。这保证了应用时每个音符只会命中一个段，不会出现「同一个音符被两个配参争抢」的歧义。

如果强行制造重叠（拖边缘、拖中间、手动输入音高范围），程序会自动帮你纠正——要么拒绝这次修改，要么把边界挪开。

四、配参池（中栏）

中栏是配参池，按来源分三块，从上到下：

  1. 工程内置配参：当前工程所有音符里出现过的配参（按内容去重）。
  2. Itoc全局配参：CZEmaker_Files 文件夹里的全部 .CZEmaker 文件。
  3. 已用配参：当前已经被分配到某个段的配参（去重后列表，带颜色小方块）。

4.1 勾选一个配参 → 快速建段

在「工程内置」或「Itoc全局」区里勾一个配参，程序会自动找当前最大的空白音高区间，用它的前一半建一个新段，把配参塞进去。这样你就不用自己在左边画，勾一下就有段了。

如果音高表已经被占满，会提示「音高范围已全部占满」——先删掉一些段或者调整边界。

4.2 「已使用」标记

如果一个配参已经被分配到某个段，在配参池里它旁边会显示「已使用」（绿色），不再显示勾选框。意思就是：这个配参已经出现在段里了，别重复加。

但要注意：「已使用」只是标记它在段里出现了，不代表「不能再用一次」。同一个配参可以出现在多个段里（比如低音段和高音段都用同一个警告框），只是不能再从配参池里勾它来建段——你需要去右栏的属性面板里，把某个已有段的配参改成它。

五、右栏属性面板

右栏列出所有段的卡片，一个段一张，从上到下按音高从低到高排。每张卡片包含：

字段能改吗说明
音高范围（两个数字） ✅ 可编辑 直接输入数字，回车或失焦生效。如果输入反了（低 > 高），会自动交换；如果和别的段重叠，会保留原值不动。
音符数 ❌ 只读 当前有多少个音符落在这一段里（受顶部过滤条件影响）。
配参 ✅ 可改 下拉框，可以选「（无）」清空，也可以换成任何一个可用配参。换了以后段名字、来源也会跟着变。
颜色 ❌ 只读 色块，跟左边音高表里那块半透明色一样。
预览 ❌ 只读 当前配参的窗口类型 + 窗口标题前 20 个字，方便你快速确认。

点卡片空白处可以选中这一段（右边红框），选中后再按底部的「删除段」就能删掉它。

六、顶部过滤条件

顶部有两个复选框，控制「这次应用的范围」：

  • 仅时间选区内：只处理起播时间落在时间选区内的音符。
  • 仅框选音符：只处理框选中（主界面选中列表里）的音符。

6.1 两个都勾 = 交集

两个都勾的时候，音符必须同时满足「在时间选区内」和「在框选中」才会被应用。任何一个不满足都跳过。

6.2 两个都不勾 = 全部

两个都不勾就处理工程里所有音符——不管框选了什么，也不管时间选区画在哪。

6.3 勾不了的情况

如果你打开窗口前没框选音符，「仅框选音符」是禁用状态的，强制不勾。同理没画时间选区时「仅时间选区内」也禁用。这样可以防止你勾了一个不存在的范围导致一个音符都处理不到。

📌 时间选区的换算：
时间选区是画在时间轴像素上的，换算成 beat 的时候会考虑 BPM 变化（midi_original_bpm / target_bpm）。所以即使你导入了变速 MIDI，时间选区的起点终点也是对的。

七、应用规则

点底部「应用」按钮（或底部右边那个），弹确认框「即将把 N 段配参应用到 M 个音符块」，确认后开始执行。

7.1 每个音符怎么匹配

对每一个音符，按下面的顺序判断：

  1. 如果勾了「仅框选音符」，且这个音符不在框选列表里 → 跳过。
  2. 如果勾了「仅时间选区内」，且这个音符的起播时间不在选区内 → 跳过。
  3. 拿这个音符的音高去段列表里找：落在哪一段的 low_pitch <= pitch <= high_pitch，就用哪一段的配参。
  4. 如果没有任何段覆盖这个音高（比如你在表中间挖了个空）→ 这个音符不动。

7.2 覆盖式写入

匹配到段之后，直接把这一段配参的完整内容覆盖写入音符的 cze_makers 字段。原来音符上有什么配参都会被覆盖掉，不会保留。

音符的其他字段（轨道、起播时间、时长、音高、note_id）完全不动，只替换 cze_makers。

7.3 应用前会保存撤销快照

点「应用」并确认后，程序会先保存一次撤销快照（跟你平时 Ctrl+Z 撤销用的是同一套）。所以即使应用错了，也可以在主界面按 Ctrl+Z 撤回。

7.4 应用后的刷新

应用完成后：

  • 工程被标记为「已修改」。
  • 所有音符块的高亮标记会按新配置刷新。
  • 画布会重绘一次。
  • 如果主界面有轮播图，会在上面弹一个「已对 N 个音符块赋值配参」的通知。
⚠️ 应用后窗口会关闭：
「应用」执行完就会自动关掉按音高赋值窗口。这是故意的——避免你改了一半又去别的地方改，然后回来改这次已经不用再改了。想再微调就重新从配参管理器开一次。

八、自动均分 / 预览效果

8.1 自动均分

底部的「自动均分」按钮会：

  1. 把当前所有段清空。
  2. 按「配参池里的可用配参数量」重新平均切分音高范围。
  3. 依次给每个新段分配一个配参（优先用外部传入的，没有就用配参池里的）。

如果你对音高范围已经满意，只是想重新分配一下配参，用这个按钮最省事。

💡 均分是「按音符数」还是「按音高」？
如果工程里有音符：按音符数量的分位数均分，保证每一段分到的音符数大致相等；
如果工程里一个音符都没有：纯按音高范围平均分。

8.2 预览效果

底部的「预览效果」按钮只统计、不写入。点了以后底部会出现一行提示：

预览统计：段#1[错误框]=12 | 段#2[询问框]=8 | 段#3[警告框]=3 | 合计=23 | 未匹配=1
  • 段#N[配参名]=N：这一段命中了多少个音符。
  • 合计=N：总共命中多少个音符。
  • 未匹配=N：落在所有段之外（有音高没被任何段覆盖）的音符数。

这是应用前最值得点一次的功能。如果「未匹配」不是 0，说明有音符的音高不在任何段里，它们不会被改哦。

九、常见问题

Q1：应用完了，为什么有些音符没变？

按顺序检查：

  • 这些音符的音高不在任何段的范围里（看「预览效果」里的「未匹配」数）。
  • 勾了「仅框选音符」但这些音符不在框选里。
  • 勾了「仅时间选区内」但这些音符的起播时间在选区外。
  • 这些段是空的（没有选配参）——空段的音高范围依然会占位，但不会写入任何东西。

Q2：段重叠了怎么修？

程序其实会自动防重叠，正常情况下你造不出重叠。如果你是通过手改右栏音高范围撞上了，它会拒绝这次修改保留原值。所以如果你看到「改了没生效」，八成是撞上了。(๓´˘`๓)

想强行「占满」一块区域，用右键菜单的「向上填充 / 向下填充」比手改准确。

Q3：一个配参能给多个段吗？

能。不同段可以指向同一个配参（比如低音段和高音段都用「错误框」）。但有一个限制：你不能从配参池里勾一个已经用过的配参来建新段——它显示为「已使用」，没有勾选框。想加新段就手动在左边空白处拖一个，然后在右栏的下拉框里选它。

Q4：时间选区怎么画？

这是主界面的功能，不是这个窗口里的。在时间轴上按住鼠标拖一段（不是框选，是拖动时间标尺区域，具体以当前主界面版本为准），会形成一条带虚线边框的选区。画完再进这个窗口就能看到时间选区对应的秒数显示在顶部。

Q5：应用后能撤销吗？

能。应用前程序保存了撤销快照，回主界面按 Ctrl+Z 就行。但注意撤销的粒度是「整个应用操作」，不是「某一段」或「某个音符」——撤销一次就回到应用之前的状态。

Q6：我勾了配参，进窗口后段是空的？

几种可能：

  • 勾的配参内容是空的（cze_makers 是空字典），段建出来了但没有有效配参。右侧属性面板会显示「（无）」，自己手动换一个。
  • 你勾的多个配参内容完全相同（按内容去重后只剩 1 个），可能只建了一个段。这属于正常去重，不是 bug。
  • 工程里的音高跨度极小，音符总数少于段数，均分时会有些段的音符数是 0——这是正常的，段依然在那里。

Q7：想只给「低音区的音符」批量换配参，但不动高音区，怎么做？

最省事的做法：进这个窗口，把段删到只剩一个低音段（右键删除其他段），然后把这个段的下边界拖到你想覆盖的最低音高，上边界拖到低音区的最高音高。应用时，只有落在这个范围内的音符会被改，其他音符（音高高于这个范围）不会被处理。

这正是「按音高」相比「框选」的优势：不用手动一个个挑，直接按音高范围切呀。

十、小结

按音高应用配参这个功能，核心就三件事：

  1. 切段：在音高渐变表上拖出几块音高区间，每段挂一个配参。段之间不能重叠，这是硬规则。
  2. 配参：进窗口前在配参管理器里勾好配参，窗口会自动均分；或者进窗口后手动给每个段挑配参。
  3. 应用：按段覆盖式写入，先筛范围再匹配音高，不改则不动。应用前建议点一次「预览效果」，确认「未匹配」是 0 再动手。

这个功能最舒服的场景是：一首曲子里不同音区的「效果」不一样（低音弹错误、高音弹警告），或者你想整首曲子的同一音区统一换成某个配参——用「按音高」比「一个个点」快一个数量级。
