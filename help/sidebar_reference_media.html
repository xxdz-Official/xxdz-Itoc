🎞️ 参考媒体

前面我们讲了侧边栏的整体结构，以及第一个选项卡「显示器」。现在讲侧边栏下半部分的第一个选项卡——参考媒体。它的作用是把图片、视频、音频当作“参考素材”打开，边看边做工程。

📌 本篇的范围：
讲的是参考媒体选项卡的定位、界面布局、打开方式、播放控制、自动同步、音量调节、右键菜单、全屏和设置。关于显示器选项卡，请参考《显示器》文档；关于侧边栏整体结构，请参考《侧边栏》文档。

一、这个功能是干嘛的？

做 Itoc 工程的时候，你可能需要一边看参考素材，一边调整音符。参考媒体就是干这个的：

  • 打开一张参考图，边看边对位置。
  • 打开一段参考视频，边看边对节奏。
  • 打开一段参考音频，边听边对节拍。

它和“显示器”的区别：

显示器参考媒体
内容来源你正在做的工程外部素材文件
用途检查自己做的效果对照参考素材
播放器内置视频播放器内置视频/音频播放器
同步跟随判定线自动渲染跟随判定线自动 seek
💡 参考媒体会自动导入工程：
如果你已经打开了工程，打开参考媒体时，程序会把它复制到工程目录下的 media/ 文件夹里，并使用相对路径记录到工程文件中。
这样工程发给别人时，参考媒体会一起带过去，不会因为路径变化而丢失。

二、从哪里打开？

参考媒体不是独立窗口，它就在侧边栏的下半部分，选项卡标题是「参考媒体」。

如果侧边栏当前是隐藏状态，先通过菜单「视图(V)」→「显示侧边栏（停靠）」把它显示出来，然后点「参考媒体」选项卡即可。

播放菜单里也提供了一个快捷入口：

菜单项作用
【参考媒体】打开媒体文件等同于点参考媒体里的“打开”按钮

三、界面布局

参考媒体选项卡从上到下分成四部分：

区域内容
上半部分预览画布（显示图片、视频或音频波形）
媒体信息显示当前媒体类型和文件名
进度条与音量条播放进度条、音量图标、音量条
按钮行打开 / 播放暂停 / 停止 / 音量 / 自动 / 设置

3.1 预览画布

预览画布是一个黑色区域，没加载媒体时显示一行占位文字「播放器已经就绪ing...」。

  • 加载图片后，这里会显示图片。
  • 加载视频后，这里会嵌入视频播放器。
  • 加载音频后，这里会嵌入音频播放器（显示波形/播放界面）。
  • 加载GIF后，这里会显示动画。

3.2 媒体信息

显示当前媒体的类型和文件名，例如：

🎬 视频: demo.mp4
🖼️ 图片: reference.png
🎵 音频: bgm.mp3
🎞️ GIF: animation.gif

3.3 进度条与音量条

控件作用
进度条显示播放进度，可以拖动 seek
音量图标按钮点击静音 / 恢复音量，默认隐藏，点音量按钮后出现
音量条拖动调节音量，默认隐藏

3.4 按钮行

按钮作用
打开打开参考媒体文件
▶ / ⏸播放 / 暂停
■停止并回到开头
🔈展开 / 折叠音量条
自动（复选框）开启后，参考媒体自动跟随主程序判定线
设置打开首选项中的面板设置

四、打开参考媒体

点「打开」按钮，会弹出文件选择框，支持以下类型：

类型扩展名
图片.png .jpg .jpeg .gif .bmp .webp
视频.mp4 .avi .mov .mkv .wmv .flv .webm
音频.mp3 .wav .flac .m4a .ogg

4.1 自动导入工程

如果已经打开了工程，打开参考媒体时，程序会：

  1. 计算源文件的哈希值。
  2. 检查工程 media/ 目录里是否已有相同内容的文件。
  3. 如果有，直接使用已有文件，不重复复制。
  4. 如果没有，复制到 media/ 目录，并自动处理同名文件（加 _1、_2 后缀）。
  5. 把路径记录到工程文件中（相对路径）。
📌 如果没有打开工程：
参考媒体仍然可以打开和播放，但不会被复制到工程目录，也不会记录到工程文件。建议先打开工程再导入参考媒体。

4.2 加载后的行为

媒体类型行为
图片直接显示在预览画布上，等比缩放
GIF用播放器播放，自动循环
视频用播放器播放，默认暂停在第一帧
音频用播放器播放，显示播放界面

默认情况下，打开视频/音频/GIF 后，播放器会自动启动但保持暂停，显示第一帧或就绪状态。你点「▶」才开始播放。

💡 启动时是否自动启动播放器？
可以在「设置」里配置“启动时自动启动 mpv”。如果关闭，打开媒体后播放器不会立即启动，需要手动点播放。

五、播放控制

5.1 播放 / 暂停

点「▶」开始播放，点「⏸」暂停。播放时按钮显示为暂停图标，暂停时显示为播放图标。

5.2 停止

点「■」停止播放并回到开头，保持暂停状态，不会自动继续播放。

5.3 拖动进度条

拖动进度条可以 seek 到任意位置。拖动时进度条不会自动更新，松开后才会执行 seek。

5.4 同步主程序

播放 / 暂停 / 停止时，会同时通知主程序：

  • 点参考媒体的播放按钮，主程序也会开始播放。
  • 点参考媒体的暂停按钮，主程序也会暂停。
  • 点参考媒体的停止按钮，主程序也会停止并回到开头。

这个同步是双向的，目的是让参考媒体和主程序保持一致的播放状态。

六、自动同步

「自动」是一个复选框，控制参考媒体是否跟随主程序判定线。

6.1 开启后的行为

主程序操作参考媒体行为
拖动判定线参考媒体 seek 到判定线对应的时间
开始播放参考媒体同步开始播放，位置对齐
暂停参考媒体同步暂停
停止参考媒体同步停止，回到开头

6.2 状态记忆

「自动」的勾选状态会保存到配置文件，下次打开程序时自动恢复。

💡 什么时候开“自动”？
如果你需要参考素材和工程时间轴严格对齐，建议开启。
如果你只是想随便看看素材，不要求同步，保持关闭即可。

七、音量控制

7.1 展开音量条

点「🔈」按钮，会在进度条右边展开音量图标按钮和音量条。再点一次折叠。

7.2 调节音量

拖动音量条调节音量，范围 0~100。音量图标会根据音量大小变化：

图标音量范围
🔇静音或音量为 0
🔈音量小于 40
🔉音量 40~70
🔊音量大于 70

7.3 静音 / 恢复

点音量图标按钮可以静音，再点一次恢复之前的音量。

7.4 状态保存

音量和静音状态会保存到工程文件中。下次打开这个工程时，参考媒体的音量会自动恢复。

📌 音量保存是静默的：
调节音量不会标记工程已修改，退出时会静默写入工程文件。所以调完音量后不需要手动保存工程。

八、右键菜单和全屏

8.1 右键菜单

在预览画布上点右键，会弹出菜单：

菜单项作用
打开当前预览文件所在位置在资源管理器中定位到当前参考媒体文件
全屏参考媒体把参考媒体切换到全屏播放（快捷键 Ctrl+Shift+`）

8.2 全屏参考媒体

全屏参考媒体会把画面放大到整个屏幕，适合仔细对照素材。

  • 图片：等比缩放铺满全屏。
  • 视频 / 音频 / GIF：把播放器窗口吸附到全屏，继续播放。

进入全屏的方式：

  • 右键菜单选「全屏参考媒体」。
  • 按 Ctrl+Shift+`。

按 Esc 退出全屏，画面重新吸回侧边栏的预览画布里。

九、设置

点「设置」按钮，会打开首选项窗口，并直接定位到「面板设置」分类。这里面包含参考媒体相关的选项：

选项说明
启动时自动启动 mpv打开参考媒体后是否立即启动播放器
其他面板设置参考媒体所在面板的通用设置

十、常见问题

Q1：打开参考媒体后，为什么播放器没有自动播放？

默认情况下，打开视频/音频/GIF 后播放器会启动但保持暂停，显示第一帧或就绪状态。需要手动点「▶」开始播放。如果你想让它自动播放，可以在设置里调整。

Q2：参考媒体和主程序不同步？

检查「自动」是否开启。只有开启「自动」后，参考媒体才会跟随主程序的判定线和播放状态。如果没有开启，它们各自独立。

Q3：参考媒体文件被复制到哪里了？

如果打开了工程，文件会被复制到工程目录下的 media/ 文件夹。如果没有打开工程，文件不会被复制。

Q4：参考媒体音量调了，但工程文件里没保存？

音量状态是静默保存的，不会立即写入。程序退出时会自动写入工程文件。如果你在退出前手动关闭了工程，音量可能不会保存到那个工程里。

Q5：全屏参考媒体黑屏怎么办？

先按 Esc 退出全屏，再重新进入。如果还是黑屏，检查一下显卡驱动，或者尝试用不同的媒体文件测试。

Q6：参考媒体和显示器可以同时用吗？

可以。它们是两个独立的选项卡，各自有独立的播放器。显示器播放工程画面，参考媒体播放外部素材，互不干扰。

Q7：支持哪些音频格式？

支持 .mp3 .wav .flac .m4a .ogg。如果某种格式无法播放，可能是播放器不支持该编码，可以尝试转换成 MP3 或 WAV。

Q8：参考媒体会自动循环播放吗？

GIF 和视频默认是循环播放的。音频默认也是循环播放的。停止后不会自动继续，需要手动点播放。

Q9：参考媒体的进度条拖不动？

进度条需要播放器已经加载完成并且知道媒体时长才能拖动。如果刚打开媒体，等播放器就绪后再试。

Q10：参考媒体可以同时打开多个吗？

不行。同一时刻只能加载一个参考媒体。打开新的媒体会替换旧的。

十一、小结

「参考媒体」是侧边栏里的参考素材播放器，把外部图片、视频、音频当作参考，边看边做工程。

  • 位置：侧边栏下半部分，第一个选项卡
  • 支持图片、视频、音频、GIF
  • 打开后自动导入工程 media/ 目录（如果有工程）
  • 播放控制：播放 / 暂停 / 停止 / 拖动进度条
  • 自动：开启后跟随主程序判定线同步播放
  • 音量：可调音量、静音，状态保存到工程文件
  • 右键菜单：定位文件、全屏参考媒体
  • 快捷键 Ctrl+Shift+` 切换全屏，Esc 退出全屏
  • 设置按钮打开首选项中的面板设置
