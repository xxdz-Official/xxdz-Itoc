⚙️ 编译为 exe

前面我们讲了 CZEmaker 弹窗、全局命令、音符块、调整图层、过渡动画、批量赋音效、渲染为音频文件、渲染视频文件、渲染为 Python 代码、渲染为 CZE 数据文件。现在讲一个“分发”功能——编译为 exe。它能把你的 Itoc 工程变成一个独立的 Windows 可执行文件（.exe），让别人不需要安装 Python、不需要配置环境，双击就能运行。

📌 本篇的范围：
讲的是“编译为 exe”的入口、前置条件、两个窗口的界面、参数设置、操作步骤和常见问题。关于“组装打包模式”（另一种分发方式），请参考《组装打包模式》文档。

一、这个功能是干嘛的？

Itoc 工程本身是数据，需要解释器才能运行。而解释器是一个 Python 程序，普通用户电脑上不一定有 Python 环境。编译为 exe 就是把“解释器 + 你的工程数据”一起打包成一个独立的 .exe 文件，用户双击就能看到你的弹窗演出。

它分两步走：

  1. 第一步：渲染为 Python 代码。 把你的工程数据转换成 Python 代码，并生成一个临时的 .py 文件。
  2. 第二步：用 PyInstaller 打包。 把这个 .py 文件、解释器依赖、图片、音频等一起打包成 exe。

整个过程由两个窗口配合完成：第一个是“转换窗口”，第二个是“编译器窗口”。

二、从哪里打开？

菜单位置：「编译(C)」 → 「编译为exe」。

快捷键：目前没有默认快捷键，建议从菜单打开。

💡 和“渲染为Python代码”的区别：
· “渲染为Python代码”只是生成一个 .py 文件，不会打包成 exe。
· “编译为exe”会先做同样的转换，然后自动进入编译器环节，最终生成可执行文件。

前置条件

打开编译流程前，程序会先检查：

检查项不满足时的提示怎么解决
是否有打开的工程“请先打开或保存一个工程文件”先新建或打开一个工程
工程里是否有音符“当前工程没有音符数据”先在时间轴上画几个音符
是否安装了 PyInstaller“未找到 PyInstaller”编译器会询问是否自动安装
⚠️ 编译需要 Python 环境：
编译为 exe 的过程需要本机安装 Python 和 PyInstaller。如果电脑上没有 Python，编译无法进行。
如果你希望“不需要 Python 环境”的分发方式，请使用组装打包模式（另一篇文档）。

三、第一个窗口：转换窗口

从菜单打开后，会先出现一个左右分栏的转换窗口。这个窗口和“渲染为 Python 代码”的窗口非常像，但底部按钮不同。

区域内容
左栏工程信息、BPM 设置、选项、底部按钮
右栏上部数据预览表格（音符、命令列表）
右栏下部Python 代码预览（深色背景）

3.1 工程信息

显示当前工程的文件名、音符数量、命令数量、目标 BPM。如果工程关联了音频文件，也会一并显示。

3.2 BPM 设置

一个输入框，让你设置转换时使用的 BPM。默认是工程当前的 target_bpm。旁边会实时显示“每拍多少秒”。

3.3 选项

选项默认说明
包含CZEmaker勾选是否把音符的 CZEmaker 配置一起写进 Python 代码
保留节拍数据不勾选是否在代码里同时保留节拍单位
包含全局命令勾选是否把全局命令一起写进代码

3.4 底部按钮

按钮作用
取消关闭窗口，不进入编译器
进入编译器环节把当前设置生成为临时 Python 文件，并打开编译器窗口
💡 刷新预览：
右上角有一个“刷新预览”按钮。修改 BPM 或选项后，点一下就能看到最新的预览效果。

四、第二个窗口：编译器窗口

点“进入编译器环节”后，会弹出一个新的窗口，标题是“Itoc v1 程序编译器”。这才是真正打包 exe 的地方，左右分栏：

区域内容
左栏文件选择、EXE 属性、编译选项、开始编译按钮
右栏编译日志（黑底绿字）

4.1 载入的 Python 文件

显示临时生成的 .py 文件路径。如果是自动加载的，输入框会是灰色不可编辑状态。

4.2 音频文件（可选）

如果工程关联了音频文件，这里会自动填入。也可以手动选择一个音频文件。编译完成后，音频会被复制到 exe 所在目录并重命名为 Audio.mp3。

4.3 EXE 文件属性

字段说明
以管理员身份运行勾选后，编译出的 exe 会请求管理员权限（需要手动编辑 manifest，编译器会给出提示）
文件说明exe 属性中显示的“文件说明”
文件版本exe 属性中显示的“文件版本”，格式如 1.0.0.0
产品名称exe 属性中显示的“产品名称”
产品版本exe 属性中显示的“产品版本”
版权信息exe 属性中显示的“版权”

右上角有一个“重置配置文件”按钮，可以把所有设置恢复为默认值。

4.4 编译选项

选项说明
窗口模式“无控制台窗口”适合弹窗程序；“显示控制台窗口”会保留一个命令行窗口，方便调试
清理临时文件编译完成后自动删除 _build、.spec 等临时文件
UPX压缩用 UPX 压缩 exe 体积（需要本机有 UPX）
程序图标选择一个 .ico 文件作为 exe 的图标
输出名称exe 的文件名（不含扩展名）
输出目录exe 的输出位置，默认是编译器所在目录

4.5 开始编译

点击 「开始编译」 按钮，就会启动 PyInstaller 进行打包。右栏的日志区会实时显示编译过程。

编译过程中按钮会变灰，进度条滚动。编译完成后会弹出成功提示，显示 exe 的位置、ICO 文件夹位置、IMG 文件夹位置等信息。

4.6 编译日志

右栏是黑底绿字的日志区，显示：

  • Python 环境检查结果
  • 依赖分析结果
  • PyInstaller 执行的完整命令
  • 编译过程的详细输出
  • 编译完成后的文件复制情况

五、操作步骤

  1. 打开一个包含音符的工程。
  2. 点击菜单「编译(C)」→「编译为exe」。
  3. 如果工程已修改，按提示选择是否保存。
  4. 在转换窗口里调整 BPM 和选项（一般保持默认即可）。
  5. 点“进入编译器环节”。
  6. 在编译器窗口里检查各项设置：
    • 音频文件是否正确
    • EXE 属性是否满意
    • 窗口模式、图标、输出名称、输出目录是否合适
  7. 点击“开始编译”。
  8. 等待编译完成，查看日志和成功提示。
  9. 到输出目录里找到生成的 .exe 文件，双击测试。

六、生成结果

编译成功后，输出目录里会生成一个以“输出名称”命名的文件夹（或直接放在输出目录下），里面包含：

文件/文件夹说明
你的程序.exe主程序，双击即可运行
ico/图标文件夹，包含程序运行需要的图标资源
img/图片文件夹，包含工程里用到的图片资源
Audio.mp3背景音频（如果工程关联了音频）
_internal/PyInstaller 生成的依赖文件夹（包含 Python 运行库等）
📌 分发时注意：
要把整个文件夹一起打包分发，不要只发 exe 文件。因为 exe 需要同目录下的 _internal、ico、img、Audio.mp3 等文件才能正常运行。

七、常见问题

Q1：提示“未找到 PyInstaller”怎么办？

编译器会弹窗询问是否自动安装。点“是”即可自动安装。如果自动安装失败，可以手动在命令行执行 pip install pyinstaller。

Q2：编译很慢，正常吗？

正常。PyInstaller 需要把 Python 解释器和所有依赖打包进去，第一次编译通常需要几十秒到几分钟，取决于工程大小和电脑性能。

Q3：生成的 exe 在别的电脑上打不开？

检查一下是否把整个输出文件夹都复制过去了。exe 需要同目录下的 _internal 等文件才能运行。如果只复制了 exe，就会报错。

Q4：exe 启动后弹窗显示不正常？

可能是 Tkinter 运行时库没有正确打包。编译器会自动添加 Tcl/Tk 库，如果仍然有问题，可以查看日志里是否有“复制Tk库”相关的信息。

Q5：音频没有播放？

检查 exe 所在目录下是否有 Audio.mp3。如果工程关联了音频，编译器会自动复制并重命名。如果没有，可以手动放一个 Audio.mp3 进去。

Q6：图标没有生效？

确认选择的图标文件是标准的 .ico 格式。有些 PNG 改后缀的 ico 可能不生效。另外，如果勾选了 UPX 压缩，有时会影响图标显示，可以尝试取消 UPX。

Q7：版本信息没有显示？

版本号格式必须是 1.0.0.0 这样的四段数字。如果格式不对，编译器会弹窗提示。修正后重新编译即可。

Q8：编译完成后临时文件在哪里？

如果勾选了“清理临时文件”，_build、.spec 等会被自动删除。如果没有勾选，它们会留在输出目录附近，可以手动删除。

Q9：可以编译 32 位 exe 吗？

这取决于你本机的 Python 是 32 位还是 64 位。PyInstaller 打包出的 exe 位数和 Python 一致。如果需要 32 位 exe，请使用 32 位 Python 环境。

Q10：编译时提示缺少某些模块？

看日志里的“分析Python文件依赖”部分，如果缺少某个库，可以用 pip 安装。编译器也会在环境检查时提示缺失的模块。

八、小结

「编译为 exe」是把 Itoc 工程变成独立可执行文件的功能，适合分发给没有 Python 环境的用户。

  • 入口：菜单「编译(C)」→「编译为exe」
  • 前置条件：有打开的工程 + 有音符 + 本机有 Python 和 PyInstaller
  • 两个窗口：转换窗口设置 BPM 和选项，编译器窗口设置 exe 属性和编译选项
  • 支持自定义图标、版本信息、窗口模式、输出名称、输出目录
  • 编译完成后生成 exe + ico + img + Audio.mp3 + _internal 等文件
  • 分发时要复制整个输出文件夹，不能只发 exe
