Itoc 解释器

前面我们讲了各种弹窗编排、全局命令、渲染视频、编译为 exe 等。但在这些背后，真正负责把你的工程数据变成屏幕上绚丽动画的核心，是Itoc 解释器。

📌 本篇的范围：
讲的是 Itoc 解释器的定义、双版本兼容性、内部文件结构、工作原理以及分发时的注意事项。关于如何配置解释器，请参考《解释器自定义配置》文档。

一、什么是 Itoc 解释器？

Itoc 的架构是编辑器与解释器分离的。编辑器负责“写代码”（制作工程），而解释器负责“跑代码”（播放弹窗）。

你可以把它理解为独立播放器。它本身是一个现成的可执行程序（.exe），启动后会自动读取同目录下的 .CzeData 数据文件，然后按照时间轴、解析其中的 JSON，把弹窗、图片、视频、特效一一呈现在屏幕上。

💡 开源生态：
Itoc 解释器是完全开源的！这意味着如果你懂编程，你可以自己修改它的底层逻辑，定制出独一无二的解释播放器，甚至把它移植到其他语言。

二、双版本与兼容性

目前Itoc原版里有两个版本的解释器，它们在兼容性和性能上有所取舍：

版本底层依赖最低系统要求特点
Python 版 (原版)Python + PyQt5Windows 7 / 8 / 8.1 / 10 / 11兼容性极强，满血支持所有旧系统，使用 PyInstaller 打包。
C++ 版 (性能版)C++ + Qt6Windows 10 (1809+) / 11原生执行效率极高，启动快，完美支持高并发动画与阵列，但不支持老旧系统。
⚠️ 关于 32 位与 64 位：
解释器分为 32 位和 64 位。32 位解释器可以运行在 32 位和 64 位系统上，但受限于内存；64 位解释器只能运行在 64 位系统上，能处理极其复杂的阵列特效。

三、窗口模式与控制台模式

为了适应不同的使用场景，每个版本还分为“窗口”和“控制台”两种形态：

  • 窗口模式（无控制台）： 运行时只会看到弹窗演出，画面纯净，适合给观众看。
  • 控制台模式（带黑框）： 会保留一个黑色的命令行窗口。如果在播放过程中报错、丢图片、缺音频，错误信息会实时打印在这个黑框里，非常适合创作者调试工程。

四、解释器文件结构

如果你想打包或者给解释器扩容，了解它的文件结构非常重要。一个完整的解释器文件夹通常长这样：

文件/文件夹作用
runCZE.exe主程序（解释器本体），名字可能因版本而异。
runcze.CzeData默认读取的工程数据文件，如果没有指定其他文件，它会读这个。
Audio.mp3背景音乐。解释器启动后会自动加载并同步播放。
ico/图标文件夹。包含 11、10、XP 等各个版本的窗口图标。
img/图片素材文件夹。工程里引用的图片框、背景图都放在这里。
video/视频素材文件夹。视频框引用的 mp4 文件放这里。
mpv/视频播放引擎。解释器依赖它来播放视频框和视频壁纸。
temp/临时文件夹。用来存放信号文件 launch_info.json，用于实现“双击 .CzeData 文件直接打开”的功能。

五、解释器是如何工作的？

为了让分发更灵活，解释器在启动时，会按优先级寻找需要播放的数据：

  1. 第一优先级：信号文件。检查 temp/launch_info.json，如果找到了，就读取里面指定的目标 .CzeData 绝对路径。
  2. 第二优先级：内置占位符。检查程序内部是否被打包了预设的数据（针对单文件 exe）。
  3. 第三优先级：同目录文件。如果上面都没有，就去读取同目录下的 runcze.CzeData。

找到数据后，解释器会启动一个极其精准的“心跳时钟”（精确到毫秒级），当时间走到对应音符时，就会立刻弹出窗口、执行动画，并且依靠看门狗进程（Watchdog）来保证意外崩溃时能够完美清理残留的 mpv 进程。

六、常见问题

Q1：为什么有人的解释器有黑框，我的没有？

因为你用的是“窗口模式”解释器，他们用的是“控制台模式”解释器。如果你要发给普通用户，请用窗口模式；如果你要排查 bug，请换控制台模式，看里面报了什么错。

Q2：别人的弹窗有亚克力效果，我的为什么没有？

亚克力效果（Acrylic）需要 Windows 10 及以上的系统支持。如果你用的是老旧系统，或者系统没有开启透明效果，亚克力会自动降级为普通纯色背景。

Q3：杀毒软件报毒怎么办？

解释器因为需要注入按键（模拟按键）、移动鼠标、注册全局互斥体，某些敏感的杀毒软件可能会误报。你可以把它加入白名单，或者向社区反馈由开发者提交给微软。

Q4：解释器可以播放其他格式的音乐吗？

目前默认优先寻找 Audio.mp3。为了完美兼容，建议在打包时统一把背景音乐重命名为 Audio.mp3。解释器底层使用的是 MPV 引擎，理论上支持绝大多数常见音频格式。

Q5：如果我改了工程，需要重新下载解释器吗？

不需要。解释器只负责“播放”，不负责“保存”。你的工程逻辑全在 .CzeData 里。改了工程只需要重新渲染数据，解释器本身无需更新。

Q6：我可以自己修改解释器吗？

当然可以！解释器是完全开源的。你可以修改它的 UI、添加自己的全局命令、甚至修改引擎让它支持你专属的特效。这也是为什么我们把它和编辑器分离的原因呀。

七、小结

「Itoc 解释器」是让你的作品能够跑起来的核心引擎。

  • 它是独立运行的播放器，负责读取 .CzeData 播放弹窗
  • 分为 Python 版（高兼容）和 C++ 版（高性能）
  • 有窗口模式（纯演出）和控制台模式（调错）
  • 标准目录下包含 ico、img、video、mpv 等资源文件夹
  • 通过信号文件、占位符、同目录文件三级优先级加载
  • 完全开源，社区可以自行魔改和维护
