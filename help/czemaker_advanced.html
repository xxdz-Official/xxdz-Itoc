🎯 CZEmaker 弹窗编排 · 进阶篇

基础篇教会了你「怎么让一个音符弹出窗口」。进阶篇要解决的是：这个窗口弹在哪儿？怎么弹？长什么样？

这里面涉及窗口位置控制（四种模式的完整参数）、特殊窗口类型（图片镂空、GIF 动画、mpv 视频、模类框的完整配置）、顶部右侧功能区、自定义尺寸与窗口寿命的互斥关系。

特殊窗口类型

图片框

弹窗里显示一张图片。支持 PNG、JPG、JPEG、GIF（动图）、BMP、ICO。选择图片后会自动复制到工程的 img/ 目录，保存为相对路径 img/xxx.png。

缩放百分比（scale_percent）： 调整图片显示大小（10%-200%）。滑块和输入框联动，修改时会同步更新主面板的 W/H 输入框。

镂空图片窗口（hollow_enabled）： 让图片的背景变透明。支持两种模式：

  • 透明通道（alpha）： 直接使用 PNG 自带的透明通道。选择 PNG 图片时，如果镂空已勾选，会自动切换到此模式。
  • 色度抠图（chroma）： 指定一个颜色变成透明。透明色由 hollow_color 控制，可以手动输入十六进制值，也可以点「选择」按钮打开颜色选择器，或点「拾取」按钮从图片上取色。

透明色相关控件只有在「镂空已勾选 且 色度抠图模式」时才启用。非 PNG 图片如果勾选了镂空，会自动切换到色度抠图模式。透明色输入框带有悬浮提示，内容为「透明色是将裁剪像素的颜色，容差为 0」。

💡 图片拾取器： 点击「拾取」按钮会打开一个独立的颜色拾取窗口（600×700，模态），在画布上点击图片任意位置取色。窗口底部显示当前颜色、RGB 值、点击位置的原始像素坐标。有「确定」/「取消」按钮，绑定 ESC 键。窗口关闭按钮（X）被拦截，提示「请使用「确定」或「取消」按钮关闭此窗口」。
💡 GIF 动图： 选择 GIF 文件后会自动分离帧并启动动画播放。每帧按自身延迟时间播放，循环往复。切换到其他音符或关闭面板时会停止动画。

自定义尺寸与图片比例匹配： 当「自定义尺寸」复选框勾选时，W/H 输入框启用。如果用户手动修改了 W/H 的值，会检查当前比例是否匹配原始图片比例：

  • 比例匹配： 启用缩放百分比滑块，并自动将百分比设置为「当前宽度 ÷ 原始宽度 × 100」。
  • 比例不匹配： 禁用缩放百分比滑块，并在缩放后尺寸显示「(自定义比例)」提示。

图片加载时，主面板的 W/H 输入框会显示原始尺寸（但输入框保持禁用），然后检查比例并同步滑块状态。

保存到配置文件的字段结构如下：

  • window_type："image"
  • image_path：图片的相对路径（如 img/xxx.png）
  • hollow_enabled：是否启用镂空（true / false）
  • hollow_mode：镂空模式（"alpha" / "chroma"，仅镂空启用时保存）
  • hollow_color：透明色（十六进制，仅色度抠图模式保存）
  • scale_percent：缩放百分比

视频框

弹窗里播放视频。支持 MP4、WMV、AVI、MOV、MKV、FLV、WebM。选择视频后会自动复制到工程的 video/ 目录，保存为相对路径 video/xxx.mp4。

mpv 内嵌播放器： 视频框使用 mpv 内嵌播放器。点击播放/暂停按钮会启动 mpv 进程，然后把 mpv 窗口「吸」到视频预览容器里。

mpv 查找： 程序会在 runCZE/ 目录下查找 mpv 可执行文件，优先 mpv.com，其次 mpv.exe；会遍历一级子目录，优先带 v3 / x86_64 的版本。找不到时会提示你去 shinchiro 的 SourceForge 下载 mpv，解压后把整个文件夹放到 runCZE\ 目录下。

音量与静音（video_volume / video_muted）： 音量条和音量图标按钮常驻显示。图标会随音量变化（🔇/🔈/🔉/🔊）。音量/静音状态会保存到工程，下次打开时恢复。

进度条： 支持拖动 seek。暂停时不推进，拖动时不覆盖，松开时跳转到目标位置并同步本地计时器。

💡 全局鼠标松开监听： 因为进度条控件内部可能吃掉鼠标松开事件，程序额外监听了整个窗口的鼠标松开，只在拖动进度条时响应。

全屏播放： 右键菜单里有「全屏播放」，会创建一个无边框、置顶的全屏窗口，把 mpv 窗口重新吸到全屏容器里，并注册 ESC 低级键盘钩子（因为 mpv 会抢焦点，Tk 的 ESC 绑定收不到）。按 ESC 退出全屏。

右键菜单： 视频预览区域右键会弹出菜单，包含「打开当前预览文件所在位置」和「全屏播放」。

💡 透明拦截层： mpv 被吸进预览容器后会覆盖整个区域，鼠标事件被 mpv 接收，Tk 收不到右键。程序在 mpv 之上叠一个几乎全透明的窗口，专门接收右键事件。全屏模式下也有对应的拦截层。

视频信息显示： 左侧有一个只读文本框，显示文件大小、分辨率、帧率、时长（格式化为 MM:SS）。

视频尺寸控制： 与图片框一样，视频也支持「自定义尺寸」复选框。视频加载时会通知主面板更新 W/H，并检查比例同步滑块。

💡 音频说明： mpv 支持音频，音量条和静音按钮就是为音频设计的。如果听不到声音，检查 mpv 是否正常启动、音量是否为 0、是否处于静音状态。

保存到配置文件的字段结构如下：

  • window_type："video"
  • video_path：视频的相对路径（如 video/xxx.mp4）
  • video_volume：音量（0-100）
  • video_muted：是否静音（true / false）
  • video_scale_percent：缩放百分比

气泡/通知

屏幕角落弹出的通知条，几秒后自动消失。配置很简单：在文本框里写通知内容就行。没有窗口标题、类名这些概念。文本框使用暗色配色，方便写长文本。

在解释器中，会依次尝试三种方式发送通知：

  1. 使用 plyer 库发送系统通知。
  2. 使用 win10toast 库发送 Toast 通知。
  3. 使用 Windows 原生消息框作为最后的备选方案。

保存到配置文件的字段结构如下：

  • window_type："notice"
  • notice_content：气泡内容

执行代码

这个比较特殊——它实际上 不是一种窗口类型，而是一个 全局命令。在 CZEmaker 面板里把它当成窗口类型来配置，但解释器在检测到「执行代码」时，会将代码内容在后台执行，而不会弹窗。

执行代码时提供了 QApplication、QWidget、player、self 等上下文变量。

暗色代码编辑器： 点击「打开文本编辑窗口」按钮会打开一个暗色配色的代码编辑器（800×900，模态），支持：

  • 语法高亮： 关键字（橙红）、字符串（绿）、注释（亮灰）、数字（蓝）、函数名（黄）、类名（青）、内置函数/类型（亮蓝）。
  • 查找/替换： 编辑菜单里有「查找...」（Ctrl+F）和「替换...」（Ctrl+H），支持查找下一个、查找全部、替换下一个、替换全部。
  • 全选： Ctrl+A。
  • 确定/取消： 回车确认，ESC 取消。

主面板的代码框也使用暗色配色，每次输入时会自动重新高亮。

⚠️ 注意： 「预览和组装打包模式无法运用 Python 代码，只有编译模式可以」——也就是说，在 Itoc 里按 F5 测试运行时，代码不会执行。只有编译成 exe 后才会跑。所以别在测试阶段拿它调试逻辑。

保存到配置文件的字段结构如下：

  • window_type："code"
  • code_content：Python 代码内容

模类框

窗口类型里有个特殊的「模类框」——它不直接配置弹窗内容，而是从「模类设计器」（UI Class）制作的模板文件里读取窗口结构。选「模类框」后，窗口类型选择器上方会出现一个「选择模类」下拉框。

模类选择器的交互流程：

  1. 下拉框中的模类名称来自工程内置模类和全局模类文件夹。
  2. 选择模类后，程序会判断该模类是否来自全局文件夹。如果是全局模类，会将其复制到工程内置模类（带进度条窗口，用哈希去重）。
  3. 然后后台读取模类数据，并在主线程中应用：设置窗口标题（禁用状态）、内容文本框显示控件列表（灰色背景）、加载编组、加载位置配置、加载窗口寿命。
  4. 加载完成后，会标记为已修改，让「应用」按钮可用。
💡 模类选择器的幂等创建： 如果模类选择器已存在，只会刷新下拉列表值，不重建。避免「模类框→模类框」同类型切换时反复销毁重建界面。

模类框的特殊限制：

  • 窗口标题输入框被禁用，内容文本框被禁用并变为灰色背景。
  • 自定义尺寸复选框被强制禁用。
  • 图标下拉菜单、控制钮下拉菜单、按钮区下拉菜单都被禁用。
  • 「选择模类」下拉框位于窗口标题行的第一个位置（在「窗口标题」之前）。

在解释器中，模类框会解析模类数据中的控件列表，动态创建标签、按钮、输入框、单选框、复选框、进度条、分组框、选项卡等控件。模类数据从工程文件的模类字段加载。

保存到配置文件的字段结构如下：

  • window_type："UIclass"
  • selected_class_name：选中的模类名称
  • window_title：窗口标题（从模类数据自动读取）
  • window_group / window_life / window_position：如果模类数据里带了这些字段，也会被加载

顶部右侧功能区

在窗口标题行的最右边，有五个控制选项。在「图片框」「视频框」「模类框」模式下，图标下拉菜单会被禁用；在「气泡/通知」「执行代码」模式下，整个顶部右侧功能区会被隐藏，切换到其他类型时恢复显示。

图标

窗口标题栏的图标样式，可模拟不同 Windows 版本风格。选项包括：自动、Windows11、Windows10、Windows Logon、Windows Vista、Windows 7、Windows 8、Windows XP、Windows XP以下。选择「自动」时，解释器会根据当前系统版本自动选择对应的图标文件夹。

保存到配置文件的字段是 window_icon。

效果音

弹窗出现时播放的音效。选项：自动、信息框、警告框、错误框、询问框、没有。选择「自动」时，解释器会根据窗口类型播放对应的系统提示音。选择「没有」则不播放任何声音。

保存到配置文件的字段是 window_sound，取值包括 default / info / warning / error / question / none。

控制钮

窗口标题栏显示哪些按钮（关闭、最大化、最小化）。下拉选项：「自动」和「设置」。选择「设置」后会打开一个对话框，用三个复选框分别控制关闭、最大化、最小化按钮的显示。

选择「设置」并确认后，下拉菜单的选项会变成「自定义: 关闭、最大化、最小化」。保存到配置文件的字段是 window_control（值为 "custom" 或 "default"）和 window_control_detail（包含 close / maximize / minimize 三个布尔值）。

按钮区

对话框底部的按钮（确定、取消、保存等），可以自定义顺序。下拉选项：「默认」和「设置」。选择「设置」后会打开一个更复杂的对话框，包含：

  • 按钮预览区域： 显示当前按钮列表（右对齐，和 Windows 对话框一致），点击按钮会弹出菜单，可以「← 向前移动」「向后移动 →」「✕ 删除」。
  • 预设按钮： 点击即可添加（确定、取消、保存、删除、应用、OK、是、否、关闭、重试、忽略），5 列网格布局。
  • 自定义按钮： 输入框 + 添加按钮，可以添加自定义文本的按钮，回车键也能添加。

关闭对话框时，下拉菜单显示会更新（如「自定义: 3个按钮」）。保存到配置文件的字段是 window_button（值为 "custom" 或 "default"）和 window_button_detail（包含 buttons 列表）。

透明度

窗口的透明度（0%-100%）。输入框修改后会自动标记为已修改。在解释器中，透明度会应用到窗口上。

保存到配置文件的字段是 window_opacity。

自定义尺寸与窗口寿命

自定义尺寸

勾选后可以手动指定窗口的宽度和高度（单位：像素）。不勾选的话，窗口尺寸由系统根据内容自动决定。

尺寸拾取按钮（⊕）： 点击后会打开一个全屏覆盖层，按住鼠标左键拖拽选取区域，松开确定。状态栏显示「拖拽选取区域: 宽度: Wpx 高度: Hpx」，只记录尺寸（宽度和高度），不记录位置。按 ESC 取消。区域太小（<10×10）会被忽略。

互斥关系：

  • 「模类框」模式下，自定义尺寸复选框被强制禁用，即使勾选了也会被取消。
  • 「图片框」和「视频框」模式下，复选框本身是启用状态，但 W/H 输入框的启用状态由复选框控制。
  • 切换窗口类型时，会恢复之前的自定义尺寸状态。

W/H 输入框变化时，会检查图片/视频比例是否匹配，并相应地启用/禁用缩放滑块。

保存到配置文件的字段结构如下：

  • custom_size_enabled：是否启用（true / false）
  • custom_width：宽度（像素，仅启用时保存）
  • custom_height：高度（像素，仅启用时保存）
💡 滑块状态同步： 自定义尺寸复选框不仅控制主面板的 W/H 输入框，还控制特殊功能区里的缩放滑块。所有控件状态会保持一致。

窗口寿命

指定窗口显示多少毫秒后自动关闭。

「使用音符块时长」的互斥逻辑：

  • 当「寿命」未勾选时：寿命输入框禁用，「使用音符块时长」复选框禁用。
  • 当「寿命」已勾选但「使用音符块时长」已勾选：寿命输入框禁用，「使用音符块时长」复选框启用。
  • 当「寿命」已勾选且「使用音符块时长」未勾选：寿命输入框启用，「使用音符块时长」复选框启用。

如果「使用音符块时长」勾选，窗口寿命会由音符的时长字段决定（秒转毫秒），忽略寿命输入框中的值。

保存到配置文件的字段结构如下：

  • window_life：
    • enabled：是否启用（true / false）
    • value：寿命值（字符串，单位 ms）
    • unit：单位（固定 "ms"）
    • use_note_duration：是否使用音符块时长（true / false）

在解释器中，会先检查是否使用音符时长，如果为「是」则直接使用音符的时长字段，否则使用寿命输入框中的值（单位 ms）。

多选编辑的「属性编辑标记」

在多选模式下，每个控件的变化事件都会被触发记录。支持的属性名包括：

  • 窗口标题（window_title）
  • 窗口内容（window_content）
  • 窗口类名（window_class）
  • 所在编组（window_group）
  • 窗口类型（window_type）
  • 图标（window_icon）
  • 效果音（window_sound）
  • 控制钮（window_control）
  • 按钮区（window_button）
  • 透明度（window_opacity）
  • 窗口寿命（window_life，包括复选框和输入框）
  • 窗口位置（window_position，所有位置相关的控件）
  • 销毁模式（window_class_destroy_mode）
  • 自定义尺寸（custom_size_enabled）
  • 自定义尺寸 W/H（custom_width / custom_height）
  • 在任务栏显示（show_in_taskbar）
  • 可调窗口（resizable）
  • 模类选择（selected_class_name）
  • 图片/视频缩放百分比（scale_percent / video_scale_percent）

应用时，只有被编辑过的属性会被更新，其他属性保持不变。这就是「智能更新」的核心实现。

💡 单选也触发修改标记： 无论单选还是多选，修改控件都会启用「应用」按钮并显示拦截层。多选时额外记录被编辑的属性名，用于智能更新。

视频音量配置的保存与加载

视频音量会保存到工程配置的 video_volume / video_muted 字段。加载时恢复。

💡 加载时避免误标记： 恢复音量时会临时设置加载标志，避免因为设置音量而触发「已修改」标记。面板初始化时也会跳过标记。

视频进度驱动机制

视频进度条不轮询 mpv 的播放位置，而是用「本地计时驱动」：

  • 记录当前播放时间，记录上次 tick 的时间戳。
  • 每 100ms 执行一次，计算时间差，如果未暂停则累加。
  • 如果时间差过大（卡顿/拖动后遗症），限制单次推进不超过 1 秒。
  • 暂停时不推进；拖动时不推进也不覆盖进度条，只持续刷新冻结点。
  • 松开进度条时发送跳转命令，并把本地计时器对齐到目标时间。
  • 用 try/finally 保证无论内部发生什么异常，都会重新调度自己，避免循环因一次异常永久停止。

时长只查一次，通过 IPC 获取，保存在内存中。

  • 多选编辑的智能更新机制
  • 拦截层与修改保护
  • 视频音量保存/加载、进度驱动、全屏播放、右键菜单、透明拦截层
