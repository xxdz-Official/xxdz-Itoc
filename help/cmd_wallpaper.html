🖼️ 全局命令 · 设置桌面背景

设置桌面背景就是「把桌面换成你指定的图片或视频」。听起来简单，但因为是全局命令，所以你可以做到「歌曲放到某一拍的时候，桌面突然变成一张奇怪的照片」这种事——很适合做鬼畜。

  时间轴：     │           │                │
               ▼           ▼                ▼
          开始播放      播放到3秒        播放到10秒
                       换壁纸           换回壁纸

一、两种原理：mpv vs 传统

原理字段值能设什么底层做什么
mpv原理principle=mpv原理图片 + 视频用 mpv 把内容渲染成桌面壁纸
传统原理principle=传统原理只有图片调用 Windows 系统 API 设置壁纸
💡 怎么选？
· 只是换张静态图 → 传统原理，最稳，兼容性最好。
· 想让桌面放视频 → 必须用 mpv原理，传统原理不支持视频。
· 用的是 GIF 图 → 两种都行，但 mpv原理 播 GIF 更流畅。

二、文件选择

字段说明
文件路径图片或视频的文件路径

点「浏览...」按钮选择文件，程序会自动根据扩展名分类：

  图片扩展名：            视频扩展名：
  .jpg .jpeg .png         .mp4 .avi .mov
  .bmp .gif .tiff         .mkv .wmv .flv
                          .webm .m4v

  选图片 → 复制到工程的 img/ 目录
  选视频 → 复制到工程的 video/ 目录
  路径存为相对路径（如 "img/星空.jpg"）
💡 相对路径自动处理：
如果你用「浏览...」选的文件不在工程目录，程序会自动把它复制到工程的 img/ 或 video/ 目录，并把路径写成相对路径。
这样工程拷给别人也能跑。

三、视频参数（仅 mpv原理 + 视频）

字段字段名说明
音量volume0 ~ 100，默认 0（静音）
循环播放loop视频循环播放，默认勾选
壁纸寿命(ms)lifetime多少毫秒后自动恢复原壁纸，留空 = 永久
视频播放完成就销毁壁纸destroy_on_finish非循环下，播完自动恢复

3.1 循环播放 vs 播完销毁

  循环播放：        ▶️────▶️────▶️────▶️────▶️ ... （永远在放）

  播完销毁：        ▶️────▶️──── 停 → 恢复原壁纸

  壁纸寿命：        ▶️────▶️── 3秒后 ── 恢复原壁纸
                  （还没播完就被掐了）
⚠️ 三个互斥规则：
① 「循环播放」勾上时，「视频播放完成就销毁壁纸」会被禁用并自动取消勾选
② 「壁纸寿命」填了之后，「视频播放完成就销毁壁纸」会被取消勾选
③ 勾了「视频播放完成就销毁壁纸」，「壁纸寿命」会被自动清空
💡 三者的关系：
· 想让视频一直循环 → 勾「循环播放」，其他都不填
· 想让视频放一遍就恢复 → 取消「循环播放」+ 勾「播完就销毁」
· 想让视频放一会儿就恢复 → 取消「循环播放」+ 填「壁纸寿命」（比如 5000 = 5 秒）

四、图片壁纸的参数变化

如果文件是图片（不管原理是 mpv原理 还是 传统原理），视频参数区域会自动禁用并清空：

  ┌──────────────────────────────────┐
  │ 视频参数（图片壁纸不需要）        │
  │  ┌──────────────┐                │
  │  │ 音量：[灰]     │                │
  │  │ 循环：[灰]     │                │
  │  │ 寿命：[灰]     │                │
  │  │ 销毁：[灰]     │                │
  │  └──────────────┘                │
  └──────────────────────────────────┘

五、完整参数结构

  principle=mpv原理
  path=img/星空.jpg
  volume=0
  loop=True
  lifetime=0
  destroy_on_finish=False
参数值说明
principlempv原理 / 传统原理壁纸原理
path文件路径相对路径（img/... 或 video/...）或绝对路径
volume0 ~ 100仅 mpv原理 + 视频有效
loopTrue / False仅 mpv原理 + 视频有效
lifetime毫秒数，0 = 永久壁纸显示多久后自动恢复
destroy_on_finishTrue / False仅 mpv原理 + 非循环 + 视频有效

六、组合示例

6.1 「播放到某一拍，桌面变成星空」

  原理：传统原理
  文件：img/星空.jpg

最基础的用法。传统原理 + 图片，兼容性最好。

6.2 「播放到某一拍，桌面变成一个 5 秒的视频」

  原理：mpv原理
  文件：video/鬼畜.mp4
  循环播放：不勾
  壁纸寿命：5000
  音量：0

视频播 5 秒后自动恢复原壁纸。

6.3 「播放到某一拍，桌面循环放一个动态壁纸」

  原理：mpv原理
  文件：video/呼吸灯.mp4
  循环播放：勾
  音量：0

视频一直循环，直到程序退出或下一条设置壁纸命令替换它。

6.4 「播完视频后恢复原壁纸」

  原理：mpv原理
  文件：video/短片.mp4
  循环播放：不勾
  视频播放完成就销毁壁纸：勾

视频播完自动恢复原壁纸。适合「放一个小短片做转场」的场景。

6.5 「有声视频壁纸」

  原理：mpv原理
  文件：video/音乐mv.mp4
  音量：50
  循环播放：勾

视频播放时带声音。注意：整个程序只有一条音频流，如果同时有背景音乐在播放，会两个声音重叠。

七、常见问题

Q1：为什么「传统原理」选了视频文件，什么都不发生？

因为传统原理不支持视频。程序会在后台提示「传统原理不支持视频壁纸，跳过」。想放视频必须切成 mpv原理。

Q2：为什么我选了视频，但视频参数区域是灰的？

检查两点：① 原理是不是 mpv原理；② 文件路径的扩展名是不是视频扩展名。
两者都满足时视频参数区域才会启用。

Q3：mpv原理需要额外装什么吗？

需要 mpv 可执行文件。mpv 一般放在 runCZE 目录下，程序会自动找到它。找不到的话控制台会打印提示哦。

Q4：壁纸设置后，怎么恢复？

三种方式：
① 再写一条「设置桌面背景」命令，把路径指回原壁纸；
② 用「壁纸寿命」让它自动恢复；
③ 程序退出时，runCZE 会尝试恢复原壁纸。

Q5：视频壁纸能不能只有画面没有声音？

可以。把「音量」设为 0（默认就是 0）就是静音播放。

Q6：视频壁纸和背景音乐能同时响吗？

技术上都能响，但会互相叠加，听感很乱。推荐做法：视频壁纸音量设为 0，只放背景音乐。

Q7：为什么我的 GIF 壁纸不动？

传统原理设 GIF 是静态的（Windows 桌面壁纸不支持动态 GIF）。
要让 GIF 动起来必须用 mpv原理——mpv 会把 GIF 当视频播，画面就动起来了呀。

Q8：路径填相对路径还是绝对路径？

推荐相对路径（比如 img/星空.jpg）。
用「浏览...」选文件时，程序会自动复制到工程目录并写成相对路径，工程拷给别人也能跑。(๓´˘`๓)

八、小结

  • 两种原理：mpv原理（图片 + 视频） / 传统原理（只有图片）
  • 图片：两种原理都能设，但传统原理兼容性最好
  • 视频：必须用 mpv原理
  • 视频参数：音量 / 循环 / 壁纸寿命 / 播完销毁
  • 三个互斥规则：循环、寿命、播完销毁 三者只能选其一（或都不选）
  • 用「浏览...」选文件时，程序自动复制到工程目录并写成相对路径
  • 推荐：视频壁纸音量设为 0，避免和背景音乐打架
