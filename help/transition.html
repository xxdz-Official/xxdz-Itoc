🎬 过渡动画

前面我们讲了 CZEmaker 弹窗、全局命令、音符块、调整图层。现在轮到过渡动画了。它可以让弹窗或调整图层在出现和消失的时候，带上一段炫酷的动画效果——比如从屏幕边缘滑进来、弹跳着出现、以弹性方式展开，或者直接硬闪出来，等等。

过渡动画不是单独的一个东西，它是挂在音符块和调整图层上的一个配置。你选中一个音符或调整图层，然后给它设置“入场动画”和“出场动画”，它下次弹窗或激活时就会按你选的效果来。

📌 本篇的范围：
讲的是过渡动画的类型、设置方法、过渡配置选项卡、参数说明，以及它在工程文件里的字段。关于弹窗本身怎么配置，请参考《CZEmaker 弹窗编排》系列；关于调整图层的其他属性，请参考《调整图层》文档。

一、过渡动画是什么？

过渡动画分两种：

  • 入场动画： 弹窗/调整图层出现时播放的动画。
  • 出场动画： 弹窗/调整图层消失时播放的动画。

你可以只设置入场，也可以只设置出场，也可以两个都设。不设置的话，弹窗就是直接出现、直接消失。

设置好之后，音符块上会出现两个小竖条：

标记含义
左侧绿色小条表示这个音符/调整图层设置了入场动画
右侧橙色小条表示这个音符/调整图层设置了出场动画

二、怎么设置过渡动画？

有两种方式：菜单和选项卡。推荐用选项卡，因为可以设置时长；菜单只能快速选类型。

2.1 通过菜单设置

在菜单栏找到 「过渡(T)」 菜单，点开。你会看到：

  • ── 入场动画 ── 分组标题
  • 无： 清除入场动画
  • 各种入场动画分组（淡入淡出、滑动、微滑、弹跳、弹性、展开、闪烁）
  • ── 出场动画 ── 分组标题
  • 无： 清除出场动画
  • 各种出场动画分组（淡出淡入、滑动、微滑、弹跳、弹性、收缩、闪烁）

选中一个或多个音符/调整图层，然后从菜单里点一个动画，就会立即应用（使用默认时长 500ms）。

2.2 通过过渡配置选项卡设置

在底部面板切换到 「过渡配置」 选项卡。选项卡里分左右两栏：左边是入场，右边是出场。

每一栏都有：

  • 动画选择按钮： 点击后弹出一个分组菜单，选择动画类型。按钮上会显示当前选中的动画名称。
  • 时长输入框： 设置动画时长（单位毫秒，默认 500）。
  • 微滑距离输入框： 只有当前选中「微滑」类动画时才亮起。单位像素，默认 50，范围 0~300。

设置好之后，点右下角的 「应用 (Insert)」 按钮，就会把配置应用到选中的音符/调整图层上。

💡 多选时的“应用全部”：
如果你选中了多个目标，并且想把这些设置统一覆盖到所有目标上，可以点 「应用全部」 按钮。它会弹出确认框，确认后会把面板上所有设置强制覆盖到每个目标。

闪入 / 闪出 是透明度闪烁——窗口始终可见，只是透明度在 0 和 目标值 之间反复横跳，看起来像在“忽明忽暗地闪”。
硬闪入 / 硬闪出 是物理隐藏闪烁——窗口会真的 hide() 掉再 show() 回来，看起来像被“啪、啪、啪”地打了三下。后者更有冲击力，但也更“糙”一些，按需选择。

3.3 方向示意（字符画）

所有带方向的动画（滑动、微滑、弹跳、弹性、展开/收缩）都遵循同一套方向语义：

  • 入场：表示“从哪边来”；
  • 出场：表示“往哪边去”。

8 个方向对应的相对位置如下（[目标] 是窗口最终应停的位置）：

        ↖        ↑        ↗
          ╲      │      ╱
           ╲     │     ╱
            ╲    │    ╱
     ← ────── [目标] ────── →
            ╱    │    ╲
           ╱     │     ╲
          ╱      │      ╲
        ↙        ↓        ↘

3.3.1 滑动 / 微滑 的方向差异

“滑动”和“微滑”共用同一套 8 方向语义，区别只在起点/终点距离和缓动曲线：

动画起点/终点缓动
滑动屏幕外 / 屏幕外（大距离，8 方向）OutQuad（入场）、InQuad（出场）
微滑目标位置附近（小距离，可配置，默认 50px，8 方向）OutQuad（入场）、InQuad（出场）

微滑入场字符画示意：

        ↖        ↑        ↗
          ╲      │      ╱
           ╲     │     ╱
            ╲    │    ╱
     ← ────── [目标] ────── →
            ╱    │    ╲
           ╱     │     ╲
          ╱      │      ╲
        ↙        ↓        ↘

以「左侧微滑入」为例：

起点：x = 目标x - distance
终点：x = 目标x
y 不变

动画效果：
  窗口先出现在目标位置左边 distance 像素处
  然后缓出，滑到目标位置
  最终停住

微滑出场字符画示意：

        ↖        ↑        ↗
          ╲      │      ╱
           ╲     │     ╱
            ╲    │    ╱
     ← ────── [目标] ────── →
            ╱    │    ╲
           ╱     │     ╲
          ╱      │      ╲
        ↙        ↓        ↘

以「向上微滑出」为例：

起点：当前x，当前y
终点：当前x，当前y - distance
动画完成后关闭
💡 微滑的缓动为什么固定是缓入/缓出？
微滑的手感是“出现后向一个方向缓动一小段，然后最终停止”。
入场需要“开始快、结束慢”，像减速停住，所以固定用 OutQuad（缓出）。
出场需要“开始慢、结束快”，像加速离开，所以固定用 InQuad（缓入）。
这两个曲线是微滑的“手感配方”，不受外部缓动设置影响。

四、透明度支持

所有弹窗都支持通过 window_opacity 字段设置目标透明度（0% - 100%）。过渡动画会完整尊重这个设置：

动画类型透明度处理方式
淡入 / 淡出从 0.0 渐变到用户设置的目标透明度（不再固定到 1.0）
滑动 / 微滑 / 弹跳 / 弹性 / 展开整个动画过程保持用户设置的目标透明度，不会忽明忽暗
闪入 / 闪出围绕用户设置的目标透明度做闪烁（0 ↔ 目标值），最终稳定在目标值
硬闪入 / 硬闪出每次 show 出来时立即恢复用户设置的目标透明度
📌 举个例子：
假设你把某个弹窗的透明度设置为 50%，并且给它设置了「从左边滑入」的入场动画。
那么它从屏幕左边滑进来的整个过程中，透明度会全程保持 50%，而不会先变到 100% 再降回 50%。
如果你给它设置的是「淡入」动画，那么它会从 0% 渐变到 50%，而不是渐变到 100%。

五、过渡配置选项卡详解

选项卡的布局如下：

区域内容
顶部显示当前选中的是音符还是调整图层，以及数量
左侧栏入场动画设置：动画选择按钮 + 时长输入框 + 微滑距离输入框
右侧栏出场动画设置：动画选择按钮 + 时长输入框 + 微滑距离输入框
底部按钮重置 / 应用 (Insert) / 应用全部（多选时出现）

5.1 动画选择按钮

按钮上显示当前选中的动画名称，后面有一个 ▶ 符号表示可以点开菜单。菜单里按分组列出所有动画，点一个就选中。选“无”表示清除这个方向的动画。

5.2 时长输入框

设置动画持续多少毫秒。默认 500ms（0.5 秒）。可以填 0 到 10000 之间的整数。填 0 表示瞬间完成（可能看不到动画效果）。

5.3 微滑距离输入框

只有当前选中「微滑」类动画时才亮起。设置微滑从目标位置偏移多少像素。默认 50，范围 0~300。

  • 0：不偏移，效果等于原地不动，只走时长。
  • 50（默认）：推荐值，明显但不夸张。
  • 100 以上：偏移较远，接近普通滑动，慎用。
💡 关于缓动曲线：
当前的版本没有缓动曲线的选择，所有动画使用内置的缓动效果：
· 滑动：入场 OutQuad、出场 InQuad
· 微滑：入场固定 OutQuad（缓出）、出场固定 InQuad（缓入）
· 弹跳：OutBounce
· 弹性：OutElastic / InElastic
· 展开：InCubic 等
你只需要设置「时长」和「微滑距离」两个参数即可。

5.4 应用按钮

  • 应用 (Insert)： 把当前面板的入场/出场设置应用到选中的目标上。多选时，只更新你修改过的字段（比如只改了入场，出场就不动）。
  • 重置： 清空选中目标的所有过渡配置（入场和出场都清掉）。会弹确认框。
  • 应用全部： 多选时出现。把面板上所有设置强制覆盖到每个选中的目标上。会弹确认框。

5.5 修改保护

如果你改了面板上的设置但还没点“应用”，画布上会出现一层半透明拦截层，阻止你点击其他音符。点击拦截层会弹出对话框，让你选择：

  • 是： 丢弃修改，继续操作
  • 应用： 应用当前设置
  • 否： 保留修改，取消操作

六、哪些目标可以设置过渡？

目标是否支持说明
常规弹窗（信息/警告/错误/询问）✅ 支持需要有 CZEmaker 配参
图片框✅ 支持需要有 CZEmaker 配参
视频框❌ 不支持由于技术原因，视频框暂不支持过渡动画（透明度仍可正常设置）
模类框✅ 支持需要有 CZEmaker 配参
调整图层✅ 支持直接设置，不需要 CZEmaker

⚠️ 关于视频框的说明：
视频框是由外部 mpv 播放器独立创建的窗口，它的生命周期由 mpv 进程管理。虽然我们能在窗口出现后调整它的大小、位置、透明度，但无法在它出现/消失的那一瞬间插入 Qt 动画。所以视频框的入场/出场动画配置不会生效，设置的时候请直接忽略。

如果你确实希望视频框有“出现动画”，可以考虑在时间轴上对视频框的位置做窗口位移动画（使用「窗口动画」命令），或者用一层调整图层（特效层）叠加出类似效果。
⚠️ 注意：
如果选中的音符没有 CZEmaker 配参，也没有任何过渡配置，那么过渡菜单和面板会处于禁用状态，你无法设置动画。请先给音符配置 CZEmaker，或者直接选中调整图层。

七、工程文件里的 transition 字段

过渡动画保存在音符或调整图层的 transition 字段里，结构如下：

{
    "transition": {
        "enter": {
            "type": "slide_left",
            "duration": 500
        },
        "exit": {
            "type": "hard_flash",
            "duration": 300
        }
    }
}

如果使用了「微滑」，会多一个 distance 字段：

{
    "transition": {
        "enter": {
            "type": "micro_slide_topleft",
            "duration": 300,
            "distance": 50
        },
        "exit": {
            "type": "micro_slide_bottomright",
            "duration": 200,
            "distance": 30
        }
    }
}
字段含义
enter入场动画配置
exit出场动画配置
type动画类型（英文键名，如 slide_left、micro_slide_topleft、fade、flash、hard_flash）
duration动画时长（毫秒）
distance微滑距离（像素），仅对 micro_slide_* 有效，默认 50，范围 0~300

如果某个方向没有配置，对应的字段就不存在。如果两个方向都没有，transition 字段本身也可能不存在。

📌 调整图层的 transition 是一样的结构：
调整图层的数据里也有 transition 字段，格式完全相同，微滑的 distance 也一起生效。

八、常见问题

Q1：为什么我设置了动画，但弹窗没有效果？

可能的原因：

  • 你设置的音符没有 CZEmaker 配参，或者窗口类型是“执行代码”“气泡/通知”，这些不支持过渡。
  • 窗口类型是视频框，视频框由于技术原因不支持过渡动画。
  • 动画时长太短（比如 0ms），肉眼看不出效果。
  • 动画类型是“展开”类，但窗口本身有自定义尺寸，可能导致动画异常。

Q2：入场和出场可以设成不同的时长吗？

可以。左右两侧的时长输入框是独立的，你可以分别设置。

Q3：调整图层的过渡动画什么时候播放？

调整图层激活时播放入场动画，停用时播放出场动画。具体激活/停用逻辑请参考《调整图层》文档。

Q4：多个音符可以共用同一个过渡配置吗？

可以。选中多个音符，设置好动画后点“应用”，所有选中的音符都会应用相同的配置。如果只想改一部分，用“应用”的智能更新；想全部覆盖，用“应用全部”。

Q5：为什么闪入 / 硬闪入 看不出效果？

这两个动画的节奏比较快，如果时长设置得比较长（比如 2000ms），每一“闪”的时间会被拉得很长，看起来反而不像闪烁。建议闪类动画的时长设置在 300ms ~ 800ms 之间，节奏感最好。

Q6：设置透明度和设置过渡动画冲突吗？

不冲突。透明度是「最终稳定状态」，过渡动画是「从 A 到 B 的过程」。程序会把动画的终点对齐到你设置的透明度上，两者协同工作。具体规则见上面的「四、透明度支持」章节。

Q7：为什么视频框的过渡动画不生效？

视频框由外部 mpv 播放器独立渲染，窗口的创建和销毁时机由 mpv 掌握，Qt 这边没有办法在它出现的瞬间插入帧动画。这是技术限制，不是 bug。视频框的透明度、位置、尺寸都可以正常设置，唯独过渡动画不支持。

Q8：微滑和普通滑动有什么区别？

三个区别：

  • 起点/终点距离：滑动从屏幕外来/往屏幕外去，距离很大；微滑只在目标位置附近偏移一小段（默认 50px，可调）。
  • 手感：滑动看起来是“从外面飞进来”；微滑看起来是“轻轻一推，稳住”。
  • 参数：微滑多一个「微滑距离」参数，滑动没有。

Q9：微滑距离设置多少比较合适？

推荐 30~80px 之间。50px 是默认值，效果比较自然。
0px 表示原地不动，只走时长；100px 以上会接近普通滑动的感觉；超过 200px 就已经不太像“微滑”了。

Q10：微滑的缓动曲线可以改吗？

当前版本不支持改。微滑入场固定用 OutQuad（缓出），出场固定用 InQuad（缓入）。这是为了让微滑始终保持“出现后减速停住、离开时加速消失”的手感。

Q11：镜像克隆组开启“反转编排”时，微滑方向会反吗？

会。镜像克隆的重编排逻辑里已经包含 micro_slide_* 的方向反转规则：
· 水平反转：左 ↔ 右，左上 ↔ 右上，左下 ↔ 右下
· 垂直反转：上 ↔ 下，左上 ↔ 左下，右上 ↔ 右下
· 全面反转：左上 ↔ 右下，右上 ↔ 左下，左 ↔ 右，上 ↔ 下

九、小结

过渡动画让弹窗和调整图层不再生硬地出现和消失，而是带上各种有趣的动画效果。

  • 入场动画和出场动画分别设置
  • 支持淡入淡出、滑动、微滑、弹跳、弹性、展开/收缩、闪烁七大类
  • 微滑有 8 个方向，支持单独设置“微滑距离”（默认 50px，范围 0~300）
  • 微滑入场固定缓出 OutQuad，出场固定缓入 InQuad
  • flash（闪入/闪出）和 hard_flash（硬闪入/硬闪出）两种闪烁动画
  • 所有动画都尊重用户设置的窗口透明度，不会再强制动画到 100% 或从 100% 开始
  • 可以通过菜单快速设置，也可以在过渡配置选项卡里精细设置
  • 支持音符和调整图层
  • 执行代码、气泡/通知不支持过渡
  • 视频框因技术原因暂不支持过渡动画（透明度仍可设置）
  • 配置保存在 transition 字段里，微滑会额外保存 distance
