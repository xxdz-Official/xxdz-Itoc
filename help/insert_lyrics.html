🎤 插入歌词

做音MAD、做鬼畜、做弹窗歌词演出的时候，最高频的操作之一是"把歌词打进去，让每个音符块显示一个字 / 一个词"。手动一个一个音符改文本又慢又容易错，所以 Itoc 提供了插入歌词功能——把一整段歌词贴进去，程序帮你自动切分、自动分配到音符块上。

📌 本篇的范围：
讲的是「插入歌词」对话框：从哪里打开、三栏布局、四种切分模式、标点处理、同时起始音符的处理、三种应用目标、txt/lrc 导入。关于音符块的其它属性（音高、颜色、音效），请参考《MIDI颜色编辑》相关文档。

一、这个功能是干嘛的？

简单说就是：你贴一段歌词，程序按顺序一个一个"词"分配给从起始音符开始的音符块。

  • 第一个词 → 起始音符
  • 第二个词 → 起始音符后面的下一个音符
  • 第三个词 → 再下一个……

一直分到歌词用完，或者音符用完。

💡 一句话理解：
它就是"把一段文本，按顺序、一个词一个词地塞进一串音符块里"。
塞进去的词可以显示在音符块上，也可以同时写进配参的窗口标题 / 窗口内容，看你勾选了哪些目标。

二、从哪里打开？

插入歌词有两个入口：

2.1 右键菜单（推荐）

在画布上右键点击某个音符块，菜单里有一项「插入歌词」。点击后，就以这个音符块为起始点打开对话框。

2.2 编辑菜单

菜单「编辑(E)」→「插入歌词」下面有两个子项：

菜单项起始点
从当前音符块插入歌词 当前选中的音符块（如果选中多个，取时间最早的那个）
从开始插入歌词 工程里时间最早的音符块
⚠️ 起始点必须存在：
如果工程里没有任何音符块，或者当前没有选中音符，「插入歌词」会提示"找不到起始音符"。先画几个音符块再试。

三、对话框布局

对话框是一个横向宽屏（1280×780），分成五大块：

┌──────────────────────────────────────────────────────┐
│  ① 歌词文本   │  ② 切分设置  │  ③ 预览                │
│  （多行文本框）│ （单选框等）  │  （映射结果表格）       │
├──────────────────────────────────────────────────────┤
│  ④ 应用到（三个复选框）                                │
├──────────────────────────────────────────────────────┤
│  工具条：粘贴 / 导入 / 清空      识别：N 个词            │
├──────────────────────────────────────────────────────┤
│  起始音符信息                                          │
├──────────────────────────────────────────────────────┤
│  状态栏：可映射 X 个音符 / Y 个词                        │
├──────────────────────────────────────────────────────┤
│  按钮：刷新预览 / 取消 / ✅ 插入歌词                     │
└──────────────────────────────────────────────────────┘

左边是"输入区"，中间是"设置区"，右边是"预览区"，底部是"应用目标 + 工具 + 操作按钮"。

四、① 歌词文本（左栏）

左栏是一个多行文本框，把你的歌词整段贴进去就行。

4.1 支持的操作

操作说明
直接打字像普通文本框一样输入
粘贴从系统剪贴板粘贴（Ctrl+V）
导入文件点底部「📁 导入 txt / lrc...」，从磁盘读取
清空点底部「🗑 清空」，把文本框清空
撤销输入Ctrl+Z（文本框自己的撤销，不影响工程）

4.2 输入变化实时预览

你在文本框里打字或粘贴时，预览区会实时更新。所以你可以一边改歌词，一边看映射结果对不对。

💡 换行有讲究：
普通换行会被当作"词的分隔"。如果你勾选了中栏的「换行符视作空词」，那么换行还会额外产生一个"空词"，插入到音符时会清空那个音符的文本——这可以用来做"空拍占位"。
详见第五节。

五、② 切分设置（中栏）

中栏决定"怎么把一整段文本切成一个个词"。这是插入歌词最核心的设置。

5.1 切分模式

模式行为
自动识别（默认） 中文逐字切，英文按空格 / 大写字母切，数字成组。适合中日文混合的歌词
逐字切分 每个汉字、每个字母都独立成词。适合"一个字一个音符"的场景
按词切分 按空格、大写字母分隔，把连续的英文当词。适合全英文歌词
jieba 分词 用 jieba 库做中文分词，比如"我爱你中国" → "我 / 爱 / 你 / 中国"。需要额外安装 jieba
📌 jieba 未安装时：
如果没装 jieba，「jieba 分词」这一项会显示"（需 pip install jieba）"并且不可选。其它三种模式照常可用。
安装方法：pip install jieba

5.2 标点处理

歌词里的标点（逗号、句号、感叹号、括号等）怎么处理？三种选择：

规则行为例子
保留为独立词 标点单独占一个词，会分给一个音符 "你好，世界" → "你 / 好 / ，/ 世 / 界"
附加到前一个词 标点拼接到前一个词后面，不单独占音符 "你好，世界" → "你 / 好，/ 世 / 界"
忽略（默认） 标点直接丢弃，不占用音符 "你好，世界" → "你 / 好 / 世 / 界"
💡 一般选"忽略"就够了：
除非你特意想让标点单独占一个音符（比如做特殊演出效果），否则标点直接忽略最干净。

5.3 换行符视作空词

这是一个单选框，默认不勾选。

  • 不勾选（默认）：换行只是"词的边界"，不会额外产生词。
  • 勾选：每个换行会产生一个"空词"（空字符串），插入到音符时会清空那个音符的文本。

勾选它有什么好处？

  • 空拍占位：你的歌词里有一段前奏 / 间奏，没有歌词但有音符，用空行占位后，这些音符的文本会被清空，看起来更干净。
  • 对齐分段：用空行把歌词按段落分开，插入时音符也按段落分配。

5.4 同时起始音符的处理

有时候会有多个音符块在同一个起始节拍上（比如和弦、和声）。这种"同时起始"的一组音符，歌词该怎么分？

选项行为
全部应用同一个字（默认） 这一组音符都填同一个词。比如和弦的三个音符都显示"你"
只应用到最上面那一个 只把词填到这一组里"轨道号最小"的那个音符上，其它保持不动

5.5 边界过滤

两个复选框，控制哪些音符"不该被填词"：

选项说明
跳过已禁用的音符块 被 Ctrl+Q 禁用过的音符（灰色带红斜线的那种）不参与填词
保留已有自定义文本的音符块 已经有自定义文本的音符不覆盖，歌词"跳过它"分给下一个音符
💡 什么时候用这两个过滤？
· 跳过禁用：工程里有些音符是禁用状态的（不播放），你不想给它们填词，勾上即可。
· 保留已有文本：你之前已经手动改过一部分音符的文本（比如特殊标记），不想被歌词覆盖，勾上即可。

六、③ 预览（右栏）

右栏是一个表格，实时显示"这段歌词会怎么分配到音符块上"。

6.1 三列内容

列含义
轨道音符块所在的轨道号（从 1 开始）
节拍音符块的起始节拍
词这个音符会被填上的词（带引号显示）

6.2 颜色标记

  • 蓝色背景的行：这行属于"同时起始"的一组（多个音符同一个节拍）。
  • 灰色文字的行：这行是"被跳过"的音符（禁用 / 已有文本），词列显示为"（空）"，后面跟着"（跳过）"。
  • 普通白底的行：正常映射的行。

6.3 预览上限

为了避免超长歌词把表格撑爆，预览区最多显示 200 行。超过的不会显示，但实际插入时会全部插入。所以预览只是"看个大概"，不是"完整清单"。

七、④ 应用到（底部）

这是决定"歌词最终写到哪里"的三个复选框。

复选框目标字段效果
应用到音符块文本标记（默认勾选） note_custom_text 词会显示在音符块中央，替换掉原本显示的音高数字
应用到配参：窗口标题 cze_makers["window_title"] 词会写进该音符的弹窗配参的"窗口标题"字段
应用到配参：窗口内容 cze_makers["window_content"] 词会写进该音符的弹窗配参的"窗口内容"字段
📌 三个目标可以同时勾选：
勾了多个，同一次填词会同时写入所有勾选的目标。比如同时勾了"文本标记"和"窗口标题"，那么这个音符块上会显示词，配参里的窗口标题也会被改成这个词。
未勾选的字段保持原样不动。
⚠️ 至少要勾一个，否则"插入歌词"按钮是灰的。
状态栏会显示"⚠️ 请至少勾选一个应用目标"。

7.1 窗口标题只取第一行

如果你勾了「应用到配参：窗口标题」，而那个词本身是多行的（比如勾了"换行符视作空词"并且词里带换行），标题只会写入第一行。

窗口内容则会写入完整的多行文本。

💡 关于"不走 CZEmakers 面板"：
勾选"应用到配参"时，程序是直接修改音符的 cze_makers 字段，不会经过 CZEmakers 面板。
好处是不会弹"有未应用修改"的提示，多选填词也不会被打断。
坏处是：如果你正好在 CZEmakers 面板里编辑某个音符的配参，面板上看到的值可能还是旧的，需要重新点一下那个音符刷新一下。

八、起始音符信息和按钮

8.1 起始音符信息

对话框底部有一行"起始音符信息"，会显示：

轨道 3 · 第 12.50 拍 · 音高 69 · 可覆盖后续音符：15 个（含起始音符）

这是让你确认"起始点对不对"的——万一在画布上点错了音符，看一眼这里就能发现。

8.2 状态栏

状态栏显示当前映射的统计，比如：

✅ 可映射 15 个音符 / 20 个词，多出 5 个词将被丢弃，剩余 0 个音符保持原样
  • "可映射 X 个音符"：能填上的音符数
  • "Y 个词"：切分后的词总数
  • "多出 N 个词将被丢弃"：词比音符多，最后 N 个词没用上
  • "剩余 M 个音符保持原样"：音符比词多，最后 M 个音符不会填词

8.3 按钮

按钮作用
刷新预览重新计算一次预览（一般不用点，改设置时会自动刷）
取消关闭对话框，不插入
✅ 插入歌词执行插入，插入完成后自动关闭

8.4 快捷键

快捷键作用
Ctrl+Enter插入歌词（等同点"✅ 插入歌词"）
Ctrl+O导入 txt / lrc 文件
Esc取消并关闭

九、插入的完整流程

  1. 在画布上右键一个音符块 → 「插入歌词」。
  2. 对话框打开，起始音符信息显示在底部，确认无误。
  3. 把歌词贴进左栏文本框。
  4. 中栏选切分模式、标点规则、同时起始处理、过滤规则。
  5. 右栏预览，看分配结果对不对。
  6. 底部勾选至少一个应用目标。
  7. 点「✅ 插入歌词」（或 Ctrl+Enter）。
  8. 程序按顺序填词，标记工程已修改，刷新画布，用轮播图通知"已插入歌词：应用到 N 个音符"。
  9. 对话框自动关闭。
  10. 按 Ctrl+S 保存工程。
⚠️ 插入不会自动保存工程：
插入歌词之后，工程处于"已修改未保存"状态（标题栏出现 *）。如果不保存就关程序，会弹"是否保存修改"。
记得按 Ctrl+S 保存，或者关程序时选"是"。

9.1 二次插入会提示覆盖

如果这次对话里已经插入过一次（没关对话框就再点一次插入），程序会弹一个确认框：

上次已经插入过一次歌词，是否继续覆盖？

确认后会再执行一次覆盖。这是为了防止"手滑点了两次插入"导致文本被覆盖得莫名其妙。

十、导入 txt / lrc

点底部「📁 导入 txt / lrc...」按钮，可以选一个 .txt 或 .lrc 文件。

10.1 编码兼容

Itoc 会自动尝试以下编码，直到成功读取：

  • UTF-8
  • UTF-8 with BOM
  • GBK
  • GB2312
  • Big5

所以无论你的歌词文件是从哪个系统导出的，一般都能正确读取。

10.2 LRC 时间戳自动过滤

如果导入的是 .lrc 文件，Itoc 会自动过滤掉所有时间戳：

  • [00:12.50] / [01:23] 这类时间标签会被去掉，只保留歌词文本。
  • [ti:歌名] / [ar:歌手] 这类元信息也会被过滤。

所以你可以直接把标准 LRC 文件扔进来，不用先手动清洗一遍。

💡 导入后状态栏会显示提示：
"已从 xxx.lrc 导入 N 行"，让你确认导入成功、多少行有效歌词。

十一、设置记忆

你上次用过的所有设置都会被记住，下次打开对话框时自动恢复。包括：

  • 切分模式（auto / char / word / jieba）
  • 标点处理规则
  • 换行符是否视作空词
  • 同时起始音符的处理方式
  • 跳过禁用 / 保留已有文本两个过滤开关
  • 三个应用目标的勾选状态

这些设置保存在 shezhi.txt 里，字段名前缀是 insert_lyrics_。

📌 设置是"软件级别"的：
这些设置跟软件走，不跟工程走。所以换一个工程打开插入歌词，上次的设置还在。发给别人工程，对方打开时用的是他自己的设置。

十二、常见问题

Q1：为什么「插入歌词」是灰的 / 点不动？

常见原因：

  • 没有选中任何音符块。先在画布上点一个音符再右键。
  • 起始音符是工程的最后一个音符，后面没有可承接歌词的音符。选更靠前的音符。
  • 状态栏提示"请至少勾选一个应用目标"，三个复选框都没勾。
  • 歌词文本框是空的，或者切分后没有有效词。

Q2：插入后音符块上显示的是一片空白？

可能的原因：

  • 勾了"换行符视作空词"，而你的歌词恰好在这个音符位置是一个换行 → 空词 → 清空文本。这是正常的。
  • 音高是 0 或者很小，但这不是原因——文本只取决于是否填了词。
  • 词本身是标点被忽略了。检查标点处理规则。

Q3：为什么我只勾了"应用到配参"，音符块上还是显示音高数字？

因为"应用到音符块文本标记"没勾。这个复选框控制的是"音符块上显示的文本"，勾了才会替换成词。只勾"应用到配参"的话，词只写进配参字段，不影响音符块显示。

Q4：为什么"应用到配参"填进去的标题，我在 CZEmakers 面板里看不到？

因为插入歌词是直接改数据的，不走 CZEmakers 面板的加载流程。面板上显示的还是上次加载时的内容。

解决办法：在画布上点一下那个音符块（切换一下选中），CZEmakers 面板就会重新加载显示最新的配参。

Q5：歌词里有很多标点，怎么处理最好？

一般选"忽略"。标点扔掉，只填汉字和英文单词，看起来最干净。

如果你的歌词里标点有节奏意义（比如"你，我"想拆成两个音符），可以选"保留为独立词"，标点会单独占一个音符。

Q6：jieba 分词模式为什么是灰的？

因为你没安装 jieba 库。在终端里跑一下 pip install jieba，重启 Itoc 就能用了。

Q7：多个音符在同一个节拍上，程序怎么分配？

看中栏的「同时起始音符的处理」设置：

  • 选「全部应用同一个字」，这一组音符都填同一个词。
  • 选「只应用到最上面那一个」，只填一个（轨道号最小的），其它不动。

Q8：歌词比音符多怎么办？

多出来的词会被丢弃。状态栏会提示"多出 N 个词将被丢弃"。

如果你想让它们全填上，得先在画布上多画几个音符块，再重新插入。

Q9：音符比歌词多怎么办？

多出来的音符保持原样，不会填词。状态栏会提示"剩余 M 个音符保持原样"。

想让它们也填上内容，可以给歌词末尾加一些占位符（比如换行产生空词），或者勾选"换行符视作空词"手动控制。

Q10：插入歌词和"导入 MIDI 自带歌词"有什么区别？

两条路最终都写进 note_custom_text，效果一样。区别在于：

  • 导入 MIDI 自带歌词：在加载 MIDI 时自动读取，没有对话框、没有切分设置，是 MIDI 里已经切好的。
  • 插入歌词：手动贴文本、手动切分、手动分配，完全可控。

如果你的 MIDI 自带歌词，可以直接用；如果没有，就用插入歌词手动填。

Q11：插入歌词会影响撤销吗？

会。插入歌词前，程序会保存一份撤销快照。所以插入之后如果不满意，可以按 Ctrl+Z 撤回来。

参考《撤销与重做》文档。

Q12：我插入了歌词，然后改了切分设置想重新插入，之前的会被覆盖吗？

会被覆盖。歌词填充是按顺序覆盖式的——同一个音符位置，后一次填的词会替换掉前一次的。

不想覆盖的话，可以先用 Ctrl+Z 撤销上一次插入，再重新插。

Q13：可以一次插歌词给多个轨道吗？

可以。程序会按时间顺序遍历从起始音符开始的所有音符块，跨轨道填词。比如第一个轨道用完了，会自动跳到第二轨道的下一个音符继续填。

如果你只想填某一个轨道，可以先把其它轨道上的音符删掉，或者勾上"跳过禁用"把不想填的音符禁用掉。

Q14：为什么"插入歌词"后，画布上音符块的显示没变？

可能原因：

  • 你没有勾"应用到音符块文本标记"。勾上它，音符块上才会显示词。
  • 音符块太窄，文字放不下。程序只在音符块宽度超过一定值时才显示文本。放大 X 轴缩放试试。

十三、小结

「插入歌词」是把整段歌词高效分配到音符块上的工具。关键要记住：

  • 入口：右键音符块 →「插入歌词」，或者「编辑」菜单 →「插入歌词」。
  • 三栏布局：左栏贴歌词，中栏切分设置，右栏预览。
  • 四种切分模式：自动识别 / 逐字 / 按词 / jieba 分词。
  • 标点三种规则：保留独立 / 附加前词 / 忽略。
  • 换行符视作空词：勾上后换行会产生空词，用于清空对应音符的文本（空拍占位）。
  • 同时起始处理：全部填 / 只填最上层。
  • 两种过滤：跳过禁用、保留已有文本。
  • 三种应用目标：音符块文本标记（默认）、配参窗口标题、配参窗口内容。可多选。
  • 导入支持：txt / lrc，多编码自动识别，lrc 自动过滤时间戳。
  • 设置记忆：所有选项存到 shezhi.txt，下次打开自动恢复。
  • 插入前会保存撤销快照，插入后 Ctrl+Z 可以撤回。
  • 插入不自动保存工程，记得 Ctrl+S。
