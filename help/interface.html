🏠 初识 Itoc 的主界面

你一打开 Itoc，最先看到的就是一个淡紫色调的窗口，标题栏写着 xxdz Itoc V2，后面跟着你当前打开的工程名。整体布局是经典的多段式——上面菜单和工具栏、中间画布、左侧侧边栏、下面选项卡。嗯……第一眼看过去密密麻麻的，但别怕，我带你挨个认一认。

一、窗口大小和默认位置

Itoc 默认窗口尺寸是 2348×1674 像素，启动时会根据你上次保存的位置恢复窗口状态。如果你上次最大化过窗口，这次它也会自动最大化。

如果你用的是小屏幕（比如 1366×768），可以在「视图(V)」菜单里打开「小屏幕模式」，窗口缩放比例会调整为 0.75 倍，界面会变小一圈，所有控件都塞得下。

📌 窗口状态会自动记住：
位置、大小、是否最大化、侧边栏的宽度、上下两半的高度比例，这些都会在你退出程序时保存到 shezhi.txt，下次打开自动恢复。

三、顶部工具栏

菜单栏下方是一大片按钮区域，从左到右依次是这些功能组（每组用 ttk.LabelFrame 框起来，标题在左上角）：

区域里面的东西它是干嘛的
文件选择 打开工程、保存工程、关闭工程、打开MIDI、卸载MIDI、打开音频、卸载音频 图形按钮，鼠标悬浮高亮。每个按钮下面有灰色小标签显示当前加载的文件名（未加载时显示"未加载工程"/"未选择MIDI"等）
快捷操作栏¹ 框选模式、移动模式、跟随模式、添加标记、添加全局命令、绘制调整图层、编译为exe 都是图标按钮，点击切换激活状态。激活时按钮显示"开"的图标，未激活显示"关"的图标
播放控制 播放/暂停、停止 两个图标按钮，播放中显示暂停图标，停止后回到开头
快捷操作栏² 撤销 ↺、重做 ↻、一键测试运行、绘制模式、时间选区模式 撤销/重做在栈空时变灰，测试运行对应 F5

音量控制 总音量、MIDI音量、音频音量 三个垂直堆叠的滑块，各自控制不同通道的音量
💡 工具栏的按钮都是"图标 + 悬浮提示"：
鼠标悬停在任何一个按钮上大约 1 秒，会弹出一个说明气泡告诉你它是干嘛的。忘了按钮功能时，悬浮一下就行。

四、统计信息面板

在工具栏下方、画布上方，有一条横着的统计栏。它默认显示，背景色和窗口边框一样，里面有这些信息：

  • 总音符块：0 —— 当前工程一共多少个音符
  • 框选音符块：0 —— 当前选中了多少个音符
  • 当前节拍：0.0 —— 判定线所在的节拍位置
  • 时间：0.000s / 0.000s —— 音频播放进度
  • 当前速度：120BPM（原速：120BPM） —— 当前 BPM 和原始 BPM
  • 音调强度：1.0x —— 音高偏移的强度
  • 音频起始：0ms —— 音频起始偏移
  • 时间选区的起止时间显示 + 复制按钮（F4 选区相关）

这些都是小字号的灰色标签，横向排在一行里。如果你觉得碍眼，可以在「视图(V)」菜单里点「折叠/展开 统计信息面板」把它藏起来。

五、主画布区域

中间这一大块是 Itoc 的核心工作区，分左右两部分——左边是侧边栏，右边是主画布。

5.1 侧边栏（左侧）

侧边栏是主界面左侧的一整块面板，用来放各种辅助工具。它自己内部又分上下两半，中间有一条可以拖动的分割线。

区域选项卡
上半部分 显示器、历史操作、窗口类名、窗口编组
下半部分 参考媒体、字幕、便签、全局命令

侧边栏右边缘有一条2 像素宽的拖拽把手，鼠标悬浮时会变紫，按住左右拖动可以调整侧边栏宽度。宽度会被记住。

侧边栏有三种显示模式，从「视图(V)」菜单切换：

  • 显示侧边栏（停靠） —— 默认，固定在左侧
  • 隐藏侧边栏 —— 不显示，画布占满整个宽度
  • 侧边栏浮动为独立窗口 —— 变成独立窗口，可以拖到别的屏幕
📌 侧边栏的详细用法：
每个选项卡的具体功能请参考《侧边栏》文档以及对应的分项文档（《显示器》《参考媒体》《字幕》《便签》《全局命令》《窗口类名》《窗口编组》《撤销与重做》等）。

5.2 时间轴（画布最上方）

画布顶部有一条约 30px 高的深紫色条，颜色是 #AE95F7。上面有白色刻度线和数字，每 4 拍一个主要刻度，显示节拍数字。整拍是白色粗线，非整拍是浅灰色细线。

时间轴是"钉住"在视口顶部的——你上下滚动画布时，时间轴不会跟着滚走，始终显示在画布最上方。

5.3 全局命令时间轴（时间轴下方）

紧挨着时间轴下面，有一条约 15px 高的橙色渐变条，从左到右从橘红色过渡到浅紫色。最左侧写着白色的"全局命令"三个字。

如果给音符挂了全局命令，这里会出现亮蓝色的小方块标记，点击可以编辑，拖动可以改时间点。

5.4 媒体轨道（音频波形）

全局命令条下方是一条约 40px 高的媒体轨道，背景是 #DEBFFF 淡紫色。如果你加载了音频文件，这里会显示音频波形图（默认青色），波形上方有一个白色竖线表示当前播放位置。

5.5 标记与轨道便利贴

轨道区域顶部有标记：小三角形旗子，颜色可自定义，用于在时间轴上做点状备注。

轨道区域内可以贴轨道便利贴：彩色便签，可以写多行文字，适合放大段备注、创作思路。双击编辑，拖动移动，右下角可以拉伸大小。

5.6 音符轨道（主要区域）

画布主体是音符轨道，每个轨道约 60px 高，轨道之间间隔 10px。轨道背景是 #F5F0FF 或 #D4C8E0 交替的淡紫色，上面有细网格线（每 4 拍一条虚线）。

音符块是蓝色矩形，颜色根据音高变化——高音偏亮蓝，低音偏深蓝。音符块中央显示音高数字。左上角如果挂了 CZEmaker 配参，会有一个黄色小三角。如果音符被禁用了，整个音符块会变成灰色并画一条红色对角线。

如果有过渡动画配置，音符块的左右边缘会显示一小条绿/橙色的过渡标记。

5.7 判定线（红色竖线）

画布上有一条 1px 宽的纯红色竖线，顶部有红色小箭头，贯穿整个画布高度。这条线就是你的"播放指针"，拖动它可以定位到歌曲任意位置。播放时它会跟着音乐移动。

5.8 画布背景（可选皮肤）

画布最底层是淡紫色背景 #E8DBFF。你可以在首选项里加载自定义图片作为皮肤，皮肤会以一定的透明度（默认 50%）和淡紫底色混合，铺满整个视口。

5.9 滚动条

画布右侧有一根垂直滚动条，画布上方有一根水平滚动条（注意，水平滚动条是放在画布上方的，不是下方）。

  • 鼠标滚轮：垂直滚动
  • Shift + 滚轮：水平滚动
  • 鼠标中键拖拽：自由平移画布
  • 拖动滚动条：带平滑缓动效果

六、底部选项卡

窗口最下面是一个选项卡面板，高度可以拖拽调整。里面有好几个标签页：

选项卡里面是什么什么时候用
CZEmakers 弹窗配参编辑器，左侧是预览区，右侧是属性配置区，有窗口类型选择、位置配置、图标/音效/按钮等设置 默认选中这个，给音符挂弹窗配参就在这操作
过渡配置 音符入场/出场动画配置，比如淡入、缩放、旋转 想让音符动起来的时候用
调整图层 调整图层的属性和列表管理 需要批量调整音符属性的时候用
媒体浏览器 浏览工程目录下的所有媒体文件，缩略图/列表两种视图，右键可以替换/脱机/查看引用表/重命名 管理工程素材的时候用
音频音谱 音频频谱分析显示，能看到实时波形频谱 调音的时候用，蛮酷的
代码视图 以 PyCharm 风格显示并编辑当前工程的 JSON 内容，右侧带查找/替换面板，支持跳转行:列 想直接看/改工程数据的时候用（高级玩法）
终端 内嵌的 Python 终端，可以执行命令、调试脚本 高级玩家用的，可以写脚本控制 Itoc

默认选中 CZEmakers。如果你没选中任何音符，面板会显示"等待选择..."之类的提示。一旦选中一个音符，面板就会自动加载该音符的配参。

📌 底部选项卡的高度可以调：
在画布和底部选项卡之间有一条分割线（很细），鼠标悬浮会变色，按住上下拖动可以调整底部面板的高度。这个高度也会被记住。

七、整体视觉风格

整个 Itoc 用的是紫色系主题：

  • 画布背景：淡紫 #E8DBFF
  • 时间轴：深紫 #AE95F7
  • 全局命令条：橘红到浅紫的渐变
  • 轨道背景：#F5F0FF 和 #D4C8E0 交替
  • 音符块：蓝色系 #66ccff 是唯一的亮眼对比色
  • 判定线：红色，提醒你"现在在哪"

如果觉得默认配色不太好看，可以在「文件」→「首选项」里换皮肤，支持加载自定义图片做背景，也可以单独调整时间轴背景色（canvas_bg_color）。

ttk 控件的主题可以在首选项的「皮肤设置」里切换，比如 vista / winnative / clamp 等，vista 是 Windows 原生的浅色卡片风格。还可以开启「Windows 原生窗口标题栏」，让主窗口标题栏和系统主题保持一致。

九、每日小技巧

主界面准备好后，右下角可能会弹出一个"每日小技巧"的小窗，教你一些冷知识。不喜欢的话可以在首选项里关掉（show_trick_on_startup=False）。

十、小结

这就是你打开 Itoc 后第一眼看到的全部东西。虽然按钮多、面板多，但分工很清晰：

  • 菜单栏：功能总入口
  • 工具栏：高频操作一键直达
  • 统计信息面板：实时数据一览
  • 侧边栏：辅助工具集中地（显示器 / 历史 / 类名 / 编组 / 参考媒体 / 字幕 / 便签 / 全局命令）
  • 主画布：时间轴 + 音符轨道 + 判定线，核心编辑区
  • 底部选项卡：配参 / 过渡 / 调整图层 / 媒体浏览器 / 音频音谱 / 代码视图 / 终端

麻雀虽小五脏俱全，虽然按钮多，但每个都有它的用处。你多玩一会儿，它们就都是你熟悉的小伙伴了。
