关于 Itoc 编辑器 OwO

Itoc编辑器是XXDZ工作室开发的世界首个 Windows crazy error程序开发工具，可以方便、无门槛的开发各种音乐的crazy error程序，释放您的创造力！

无论您是刚接触编程的新手，还是想要快速制作有趣程序的老手，Itoc编辑器都能为您提供简单而强大的工具集。

软件特点 ♪(^∇^*)

  • 可视化界面设计
  • 导入midi谱子文件
  • Windows弹窗效果库
  • 内置节拍分析工具
  • 一键导出可执行文件
  • 支持自定义视觉效果
  • 内置教程和示例
  • 支持全局命令
  • 支持运行cmd命令
  • 可编写python代码

什么是 Crazy Error？ (lll￢ω￢)

Crazy error 就是弹窗类鬼畜，是鬼畜区与软件极客区的结合体，将音乐配上Windows效果音MAD，进行有观赏性、卡点的系统弹窗。
