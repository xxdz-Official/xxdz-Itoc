初识 Itoc 的主界面

你一打开 Itoc，最先看到的就是一个 淡紫色调 的窗口，标题栏写着 xxdz Itoc V2 后面跟着你当前打开的工程名 整体布局是经典的三段式——上面工具栏、中间画布、下面选项卡，左右两侧还有滚动条 嗯...第一眼看过去密密麻麻的，但别怕，我带你挨个认一认

窗口大小和默认位置

Itoc 默认窗口尺寸是 2348×1674 像素，启动时会根据你上次保存的位置来恢复窗口状态 如果你上次最大化过窗口，这次它也会自动最大化 如果你喜欢小屏幕模式，可以在 视图 菜单里打开，窗口缩放比例会调整为 0.75 倍，适合 1366×768 这种小分辨率屏幕

顶部工具栏（一屏的按钮组）

窗口最上方是一大片按钮区域，从左到右依次是：

区域 里面的东西 它是干嘛的
文件选择组 打开工程、保存工程、关闭工程、加载MIDI、卸载MIDI、加载音频、卸载音频 图形样式的按钮，鼠标悬浮会变蓝色高亮，下面有灰色小标签显示当前加载的文件名
快捷操作栏¹ 开启框选模式、进入移动模式、开启跟随、添加标记、添加全局命令 这些按钮长得像普通的 ttk.Button，灰色背景黑字，按下去会切换激活状态
快捷操作栏² 撤销 ↺、重做 ↻、测试运行、进入绘制、开始选区 撤销和重做是圆形的字符按钮，测试运行是宽一点的长方形按钮，绘制按钮文本是 "进入绘制"
播放控制组 播放 ▶、停止 ⏹ 两个方形按钮，播放按钮点击后变成 ⏸ 暂停图标，停止按钮点击后回到开头
曲速调节组 目标BPM输入框、原速显示、使用原曲曲速按钮 一个小框子里：第一行是 "目标BPM" 标签加输入框，第二行显示 "原速：120BPM"，第三行是按钮
缩放组件 X轴缩放滑块、Y轴缩放滑块 两个水平滑块，X轴范围 0.2~10.0，Y轴范围 0.5~3.0，滑块很小巧只有 7px 高
轮播图组件 一个 336×83 的图片轮播区域 会每隔 3 秒自动切换一张宣传图，右下角有提示文字，如果有通知消息也会在这里弹出来
音量控制组 总音量、MIDI音量、音频音量 三个垂直堆叠的滑块，每个滑块上方有文字标签，滑块长度 80px，宽度 8px

这些按钮组之间用 ttk.LabelFrame 框起来，所以你会看到每个分组外有一圈浅色的边框，标题写在左上角 比如 "文件选择"、"快捷操作栏¹"、"播放控制" 这些灰色小标题

统计信息面板（一条横着的状态栏）

在工具栏下方、画布上方，有一条横着的统计栏 它默认是显示的，背景色和窗口边框一样，里面有这些文字：

  • 总音符块：0 - 当前工程一共多少个音符
  • 框选音符块：0 - 当前选中了多少个音符
  • 当前节拍：0.0 - 判定线所在的节拍位置
  • 时间：0.000s / 0.000s - 音频播放进度
  • 当前速度：120BPM（原速：120BPM） - 当前BPM和原始BPM
  • 音调强度：1.0x - 音高偏移的强度
  • 音频起始：0ms - 音频起始偏移

这些标签都是 ttk.Label，字体是 Microsoft YaHei 8号 小小的灰色文字，横向排列在一行里，如果你觉得碍眼，可以在 视图 菜单里折叠它

主画布（最核心的区域）

中间这一大块，背景色是 #E8DBFF 淡紫色，是你的灵感画板 画布上有这些元素：

时间轴（最上方）

画布顶部有一条 30px 高的深紫色条，颜色是 #AE95F7 上面有白色的刻度线和数字，每 4 拍一个主要刻度，显示节拍数字 刻度线的粗细和颜色根据是否"整拍"而变化：整拍是白色粗线，非整拍是浅灰色细线

全局命令时间轴（时间轴下方）

紧挨着时间轴下面，有一条 15px 高的橙色渐变条，从左到右从橘红色过渡到浅紫色 最左侧写着 "全局命令" 三个白色宋体字，如果给音符挂了全局命令，这里会出现亮蓝色的小方块标记，点击可以编辑

标记区域

在全局命令条下面，是标记的显示区域 标记是 5px 高的彩色小条，颜色由你指定（默认橙色），上面有文字描述 右键点击标记可以编辑或删除

音符轨道（主要区域）

画布主体是音符轨道，每个轨道 60px 高，轨道之间间隔 10px 轨道背景是 #F5F0FF 或 #D4C8E0 交替的淡紫色，上面有细网格线（每 4 拍一条虚线）

音符块是蓝色的矩形，颜色根据音高变化——高音偏亮蓝，低音偏深蓝 音符块中央显示音高数字，左上角如果挂了 CZEmaker 配置会有一个黄色小三角 如果音符被禁用了，整个音符块会变成灰色并画一条红色对角线

判定线（红色竖线）

画布上有一条 1px 宽的纯红色竖线，顶部有个红色小箭头，贯穿整个画布高度 这条线就是你的"播放指针"，拖动它可以定位到歌曲的任意位置 播放时它会跟着音乐移动，你可以通过拖拽时间轴区域来手动控制它

媒体轨道（音频波形）

在时间轴和音符轨道之间，有一条 40px 高的媒体轨道，背景是 #DEBFFF 淡紫色 如果你加载了音频文件，这里会显示音频波形图（默认颜色是青色），波形上方有一个白色竖线表示当前播放位置

底部选项卡（功能面板区）

窗口最下面是一个 ttk.Notebook 选项卡控件，里面有好几个标签页：

选项卡 里面是什么 什么时候用
CZEmakers 弹窗编辑器，左边是预览区，右边是属性配置区，有图片预览、文字输入、动画设置 默认选中这个，给音符挂弹窗配置就在这操作
过渡配置 音符入场/出场动画配置，比如淡入、缩放、旋转 想让音符动起来的时候用
调整图层 调整图层的属性和列表管理 需要批量调整音符属性的时候用
媒体浏览器 浏览本地音频、视频文件，快速拖入工程 找素材的时候用，可以预览音频
音频音谱 音频频谱分析显示，能看到实时波形频谱 调音的时候用，蛮酷的
字幕 SRT 字幕编辑器，加载字幕文件后同步显示 要给表演配字幕的时候用
终端 内嵌的 Python 终端，可以执行命令、调试脚本 高级玩家用的，可以写脚本控制 Itoc

默认选中的是 CZEmakers 选项卡，如果你没加载 MIDI 文件，这个面板会显示一个灰色的提示"请先选择音符" 一旦你选中了一个音符，这里就会自动切换成该音符的弹窗配置界面

滚动条

画布右侧有一根垂直滚动条，画布下方有一根水平滚动条 都是 ttk.Scrollbar 样式的，在 Windows 上看起来是那种细细的灰色条 鼠标滚轮可以垂直滚动，Shift+滚轮是水平滚动，中键拖拽画布也可以平移

整体视觉风格

整个 Itoc 用的是 紫色系 主题，所以有的部分带有一点点紫色系——从淡紫 #E8DBFF 到深紫 #AE95F7，再到橙色 #E85D3A 的全局命令条 音符块蓝色系 #66ccff 是唯一亮眼的对比色，红色判定线则负责提醒你"现在在哪"

如果觉得默认配色不太好看，可以在 文件 → 首选项 里换皮肤，支持加载自定义图片做背景，透明度 0.5 左右，会覆盖在画布最底层

主界面准备好后，右下角会弹出一个"每日小技巧"的小窗，教你一些冷知识 不喜欢的话可以在设置里关掉

好了，这就是你打开 Itoc 后第一眼看到的所有东西 麻雀虽小五脏俱全，虽然按钮多，但每个都有它的用处 你多玩一会儿，它们就都是你熟悉的小伙伴了
