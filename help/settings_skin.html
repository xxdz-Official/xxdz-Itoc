🎨 皮肤设置

Itoc 默认是淡紫色调的主题。虽然这个配色已经挺耐看了，但总有那么一些时候——比如你换了新壁纸，觉得淡紫色不太搭；或者你看腻了老配色，想换换心情；再或者你想让整个界面偏向系统原生风格……这些需求，皮肤设置都能满足你。

📌 本篇的范围：
讲的是首选项里「皮肤设置」分类下的所有选项：皮肤图片、皮肤透明度、时间轴背景色、ttk 控件主题、Windows 原生窗口标题栏。
关于其它首选项分类（窗口设置、音频设置、回滚设置等），请参考对应的分项文档。

一、这个功能是干嘛的？

皮肤设置用来调整 Itoc 界面的视觉外观。它管的是这几件事：

  1. 给画布铺一张背景图片——让编辑区看起来更有个性。
  2. 调节背景图的透明度——图片太抢眼会影响看音符，透明度可以淡一点。
  3. 换个时间轴底色——不铺图片时，可以让底色偏别的颜色。
  4. 换 ttk 控件的主题——按钮、下拉框、滚动条这些看起来是什么风格。
  5. 让标题栏跟随系统——Windows 10/11 的浅色卡片风格，和系统更搭。
💡 皮肤设置只影响"外观"，不影响功能：
不管你怎么换皮肤、换主题，Itoc 的功能、工程数据、快捷键都不会变。放心折腾，不会有副作用。

二、从哪里打开？

打开方式：「文件(F)」→「首选项」→ 左侧分类里的「皮肤设置」。

也可以按快捷键（如果设置了的话）或从其它入口进入首选项。首选项窗口打开后，左边是分类导航，右边是内容区，点一下左边的「皮肤设置」就会切到这一分类。

三、界面布局

皮肤设置面板从上到下分成四块：

区块内容
皮肤图片当前皮肤显示、浏览图片、清除皮肤
皮肤透明度一个 0%~100% 的滑块 + 百分比数字
时间轴背景色颜色输入框 + 取色器 + 预览色块 + 恢复默认按钮
ttk 控件主题主题下拉框 + 说明文字
Windows 原生窗口标题栏一个勾选框 + 说明文字

四、皮肤图片

这是皮肤设置里最"直观"的部分——挑一张图片，让它成为画布的背景。

4.1 当前皮肤显示

最上面有一行「当前皮肤:」，后面跟着当前皮肤的文件名（比如 my_wallpaper.png）。如果没设置过皮肤，就显示「无」。

4.2 选择皮肤

点「浏览图片...」按钮，弹出文件选择框，支持这些格式：

  • .png
  • .jpg / .jpeg
  • .gif
  • .bmp

选完之后，图片会立刻生效：画布底层会把它铺上去，并按当前的透明度混合到时间轴底色上。不需要点"应用"或"确定"。

4.3 图片是怎么铺的？

图片的铺法用的是 cover（填满）模式：

  1. 先按画布视口的宽高比例，把图片等比放大到刚好能铺满整个视口。
  2. 如果放大后某一方向超出了视口，就从中心裁剪掉多余的部分。
  3. 最后把裁剪后的图片铺上去。

这样不管你原图是宽的、高的、方的，都能铺满整个画布，不会留白，也不会变形。

💡 背景图会跟随视口：
你水平 / 垂直滚动画布时，背景图不会跟着滚走——它始终钉在视口左上角，就像画布本身的一个"底纹"一样。
这样无论你滚到哪里，背景都是满的，不会看到"图片外的空白"。

4.4 清除皮肤

点「清除皮肤」按钮，皮肤会被移除，画布回到纯底色（淡紫色或你设置的时间轴背景色）。

清除后，skin_path 配置会被清空，下次打开程序也不会再加载图片。

📌 皮肤路径会保存在配置里：
皮肤路径存在 shezhi.txt 的 skin_path 字段里。重启 Itoc 时会自动加载上次用的皮肤。
如果图片被移动到别处或删除了，程序会静默忽略（不报错，画布就显示纯底色）。

五、皮肤透明度

背景图铺上去之后，如果直接 100% 显示，可能会显得太抢眼，看音符的时候容易被干扰。所以 Itoc 给了一个透明度滑块。

5.1 滑块的范围和含义

滑块值效果
0%完全透明，只显示时间轴底色，图片完全看不见
50%（默认）图片和底色各占一半，既有纹理又不太抢眼
100%图片完全不透明，底色被完全盖住

拖动滑块时，右边的百分比数字会实时更新。

💡 拖拽松手才会重绘：
拖滑块的过程中，程序不会每帧都重绘背景图（那样会卡）。松手时才会真正混合一次并铺到画布上。
所以拖的时候画布看着没变是正常的，松手后就生效了。

5.2 混合原理

背景不是"图片盖在底色上"，而是"图片和底色按透明度混合"。具体来说：

最终像素 = 底色像素 × (1 - alpha) + 图片像素 × alpha

其中 alpha 就是透明度的值（0.0~1.0）。所以：

  • alpha = 0：最终像素 = 底色像素（图片看不见）
  • alpha = 1：最终像素 = 图片像素（底色看不见）
  • alpha = 0.5：各占一半

六、时间轴背景色

这是"没有皮肤时"画布的底色，也是"有皮肤时"参与混合的那个底色。它并不只影响时间轴，而是整个画布的底层颜色。

6.1 默认值

默认是淡紫 #E8DBFF。这是 Itoc 的基础色调。

6.2 怎么改？

有三种方式：

  1. 直接在输入框里打字：输入一个十六进制颜色，比如 #FFEEDD。
  2. 用取色器：点「取色器」按钮，弹出系统调色板，选一个颜色。
  3. 恢复默认：点「恢复默认」按钮，立刻回到 #E8DBFF。

输入框右边有一个小色块，显示当前颜色的预览。你打字的瞬间它就会跟着变。

6.3 改完之后会发生什么？

改颜色是立即生效的，不需要点"确定"。具体来说：

  • 画布底图会被重新生成（以新颜色为底）。
  • 所有轨道的背景、轨道标签背景会按新底色重新混合（因为它们原本是 60% 自色 + 40% 底色的混合色）。
  • 音符块、时间轴、判定线这些不受影响。
💡 打错颜色怎么办？
如果输入框里的颜色格式不对（比如少于 7 位、不是以 # 开头），程序不会崩，只是暂时不应用。改成正确的格式就正常了。
实在不行就点「恢复默认」。

6.4 轨道背景为什么会跟着变？

因为轨道背景用的是"混合色"——不是硬编码的固定色，而是60% 的轨道自色 + 40% 的时间轴背景色混合出来的。这样无论你把底色改成什么，轨道背景都会自动"融进"整体色调里，不会突兀。

改了底色之后，程序会遍历所有轨道背景元素，重新计算一次填充色，所以你会看到它们一起变了。

七、ttk 控件主题

ttk 是 Tkinter 提供的一套"现代化"控件库。它有个特性：换一个主题，所有 ttk 控件的外观都会一起变。按钮、下拉框、滚动条、复选框、选项卡……都会跟着换风格。

7.1 有哪些主题可选？

Itoc 会自动检测你系统上可用的 ttk 主题，把它们列在下拉框里。常见的主题包括：

主题名风格
vistaWindows Vista/7/10/11 的浅色卡片风格（Itoc 默认）
winnativeWindows 原生经典风格
xpnativeWindows XP 风格
clam跨平台扁平风格，配色偏灰
alt另一种跨平台风格，和 clam 类似
defaultTkinter 默认风格
classic最老式的 Tk 风格
💡 推荐用 vista：
vista 是 Windows 原生的浅色卡片风格，和 Itoc 默认的淡紫配色最搭。如果你在 Windows 上，建议就用这个。

7.2 换主题会发生什么？

从下拉框里选一个主题，会立即应用。所有 ttk 控件的外观马上改变——包括首选项窗口自身的控件。

主题选择会被保存到 shezhi.txt 的 ttk_theme 字段。下次打开程序时自动恢复。

⚠️ 换主题可能会让某些控件显示异常：
极少数情况下，某个主题可能和某些控件的尺寸 / 内边距不兼容，导致看起来怪怪的。
如果遇到这种情况，换回 vista 就能恢复。

7.3 它和皮肤图片是两回事

注意区分：

  • 皮肤图片 / 背景色：管的是画布的视觉。
  • ttk 主题：管的是按钮、下拉框、滚动条等控件的视觉。

两者互不影响，可以任意组合。

八、Windows 原生窗口标题栏

这是皮肤设置里最"精致"的一个开关，专门给 Windows 10/11 用户准备的。

8.1 它是干嘛的？

Itoc 主窗口的标题栏（就是右上角有关闭 / 最小化按钮的那一条），默认是 Tkinter 绘制的经典样式。开启这个选项后，程序会调用 Windows 的 DWM API，让系统原生的标题栏渲染接管：

  • 标题栏会跟随系统主题（浅色 / 深色）。
  • 在 Windows 11 上，还会应用系统圆角。
  • 整体观感就是"这是一个 Windows 原生应用"。

8.2 怎么开关？

面板里有一个勾选框「启用 Windows 原生窗口标题栏（跟随系统浅色/深色主题）」。勾上就开启，取消就关闭。

勾选 / 取消时会立即预览，不用点"确定"。

8.3 系统要求

系统支持情况
Windows 11完全支持，标题栏跟系统主题，有圆角
Windows 10 1809 及以上支持标题栏跟随主题
Windows 10 1809 以下静默忽略（无效果，不报错）
Windows 7 / 8静默忽略
macOS / Linux静默忽略
📌 状态保存：
开 / 关状态保存在 shezhi.txt 的 native_window_frame 字段，下次打开程序会自动恢复。

8.4 推荐搭配

原生窗口标题栏 + vista 主题，是 Itoc 在 Windows 上的"最佳观感组合"：标题栏是原生卡片风，控件也是原生卡片风，整体特别协调。

九、常见问题

Q1：换了皮肤图片，但画布没变化？

可能是以下原因：

  • 透明度设成了 0%（完全透明，图片被"混合没了"）。把透明度调高试试。
  • 图片本身是纯色的，和背景色接近，看不出来。换张对比明显的试试。
  • 图片太大或太小，cover 之后被裁到看不见主体。建议用和屏幕比例接近的图。

Q2：透明度的拖拽为什么看不到实时效果？

这是设计如此。拖动过程中程序不重绘背景图（避免每帧都做一次图片处理，会卡），松手时才会真正混合并生效。拖的时候只要看数字就行。

Q3：改了时间轴背景色，为什么轨道也变色了？

因为轨道背景是"混合色"——60% 的轨道自色 + 40% 的时间轴底色。改了底色，混合结果自然跟着变。这是有意为之的，让整体色调保持一致。

Q4：ttk 主题换了之后，按钮看着怪怪的？

某些主题可能和控件布局不兼容，导致内边距、尺寸看起来不对。换回 vista 就能恢复。

Q5：Windows 原生窗口标题栏开了之后没效果？

检查一下系统版本：

  • Windows 10 必须是 1809 或更高版本。
  • Windows 11 完全支持。
  • 更老的系统（Win7/8、Win10 早期版本）不支持，会静默忽略。

另外，如果你关了再开，可能需要等 1~2 秒才能看到效果（Windows 需要重绘标题栏）。

Q6：皮肤设置里的修改会自动保存吗？

会。当你点首选项窗口底部的「保存」按钮时，皮肤路径、透明度、时间轴背景色、ttk 主题、原生窗口标题栏状态都会一起写进 shezhi.txt。

如果你点了「取消」，那这些改动不会保存，下次打开程序还是用之前的值。

💡 想临时试试效果，又怕弄乱？
皮肤设置的所有改动都是即时预览的。你可以随便改、随便试，觉得不合适再改回来。
只要最后不点"保存"，原设置就一点没变。

Q7：皮肤图片会随工程一起保存吗？

当然不会。皮肤是软件级别的配置，保存在 shezhi.txt 里，和工程文件（.czemidi）无关。

所以你换了一个工程，皮肤还是同一个（跟软件走的，不跟工程走）。工程发给别人，别人打开时用的是他自己的皮肤设置，不会看到你的皮肤。

Q8：清除皮肤后，之前那张图片会被删掉吗？

不会。清除皮肤只是把配置里的 skin_path 清空，不会去动你磁盘上的图片文件。你的图片还在原来的地方。

Q9：时间轴背景色能设成纯黑吗？

废话当然可以（输入 #000000），但不太推荐——深色背景下音符块的蓝色会显得黯淡，时间轴上的白色文字也会和黑底对比过强，看着比较刺眼。
如果你想做深色主题，建议搭配皮肤图片和较低透明度，效果会更柔和。

Q10：换主题、换皮肤会影响渲染出来的视频吗？

不会。渲染视频时，程序是按固定的渲染规则出图的，和你在编辑器里看到的皮肤、主题、背景色都无关。
换皮肤只影响你编辑时看到的界面，不影响渲染输出的内容。

十、小结

皮肤设置管的是 Itoc 的"面子"，一共五个设置项，彼此独立：

  • 皮肤图片：挑一张图片铺到画布底层，cover 模式铺满，跟随视口。
  • 皮肤透明度：0%~100% 混入底色，默认 50%，拖拽松手才生效。
  • 时间轴背景色：画布底色（默认淡紫 #E8DBFF），会带动轨道背景一起变。
  • ttk 控件主题：按钮、下拉框等控件的风格，推荐 vista。
  • Windows 原生窗口标题栏：让标题栏跟随系统主题，Win10 1809+ / Win11 支持。

所有设置都是即时预览的，随便折腾，最后点「保存」才会写进配置。皮肤只影响编辑时的观感，不影响工程数据和渲染输出。
