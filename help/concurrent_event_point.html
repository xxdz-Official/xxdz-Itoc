🎇 新建并发事件点

上一篇我们讲了"节奏事件点"——按时间顺序等距铺开的一串事件块。这一篇讲它的兄弟功能：新建并发事件点。

节奏事件点是"一条线上的多个点"，并发事件点是"同一个时刻的多个点"。当你想在同一个节拍位置上，一次性生成一堆事件块（比如"同时弹 8 个音符"、"同一帧触发 16 个特效"），就用并发事件点。

📌 本篇的范围：
讲的是"新建并发事件点"窗口的三种来源、参数、堆叠与展开避让、生成逻辑。
关于事件块本身怎么编辑，请参考《音符块自身属性》和《调整图层》文档；
关于节奏事件点，请参考《新建节奏事件点》文档。

一、什么是并发事件点？

并发，就是"同时发生"。并发事件点，就是在同一个节拍位置上，一次性生成 N 个事件块。

举个例子：

  • 你想在第 4 拍的位置，同时放 8 个不同音高的音符块（做和弦）
  • 你想在第 8 拍的位置，同时放 16 个调整图层块（做重叠特效）
  • 你想把当前选中的 3 个音符块，各复制 5 份叠在一起

这些操作如果手动做，要复制粘贴好几遍；用并发事件点，一次就搞定。

二、三种来源

并发事件点有三种"来源"模式，决定了它生成什么样的事件块：

来源怎么进入生成什么
空白来源轨道右键菜单 →「新建并发事件点...」生成全新的、空白的音符块或调整图层块
当前事件块单个音符块/调整图层右键菜单 →「从当前事件块新建并发事件点...」以这个事件块为模板，复制出 N 份叠在一起
选中事件块选中多个后右键 →「从选中的 N 个事件块新建并发事件点...」以每个选中的事件块为模板，各自复制出 N 份
💡 来源决定了属性会不会被带过来：
空白来源： 生成的事件块属性都是默认的（音符块音高 60、无 CZEmaker、无过渡动画）。
当前来源： 会把源事件块的音高、颜色、文本、CZEmaker 配参、过渡动画等全部复制过来。
选中来源： 同上，但每个源各自复制各自的。

三、窗口布局总览

窗口分成几块：

区域作用
顶部信息栏显示来源类型和起点信息（轨道、节拍、时间、BPM）
空白事件块设置只有"空白来源"才显示：事件块类型、起始轨道
参数区数量、长度、编组、方式
预览显示将创建多少个、方式是什么、位置在哪
进度条（默认隐藏）生成时才显示
底部按钮左边"取消"，右边"生成"

四、来源说明

4.1 空白来源

从轨道右键菜单打开时，就是空白来源。此时窗口顶部会显示"来源：空白事件块"。

空白来源会显示两个额外的设置：

设置说明
事件块类型选择生成音符块还是调整图层块
起始轨道从哪条轨道开始（只在"展开避让"模式下才显示）

4.2 当前事件块来源

从单个音符块或调整图层的右键菜单打开时，就是当前来源。窗口顶部会显示源事件块的详细信息，比如：

  • 来源：当前音符块（轨道 X，节拍 Y，音高 Z）
  • 来源：当前调整图层块（轨道 X，节拍 Y）

此时"空白事件块设置"那一块会隐藏起来，因为属性已经从源事件块读好了。

4.3 选中事件块来源

从多个选中事件块的右键菜单打开时，就是选中来源。窗口顶部会显示"来源：选中的 N 个事件块"。

此时"数量"的含义会变化：每个源事件块各自复制 N 份，所以总共生成的事件块数量 = 源数量 × N。

⚠️ 注意：
如果选中来源里有多个事件块，它们的属性是"各自复制各自"，不会互相覆盖。比如源 A 是音高 60，源 B 是音高 64，那么复制出来的 A 副本全是 60，B 副本全是 64。

五、参数详解

5.1 数量

来源数量含义
空白来源总共生成 N 个事件块
当前来源把这一个事件块复制成 N 份（含原件位置）
选中来源每个源各自复制成 N 份，总共 N × 源数量 个

数量范围：1 ~ 2000。超过 2000 会弹确认框。如果填 0 或负数，输入框会变红，生成按钮变灰。

5.2 长度

每个事件块本身持续多少拍。默认 0.25 拍（如果是从源打开的，默认用源的长度）。

比如做和弦，你可能希望这 8 个音符块都只持续 0.1 拍（短促）；做特效，你可能希望都持续 1 拍（拉长）。

5.3 编组

给生成的事件块指定一个编组名，用于后续的阵列绑定、全局命令按编组操作等。

编组只对音符块生效。如果源是调整图层，或者空白来源选的是调整图层，编组输入框会隐藏或变灰。

💡 编组会覆盖源编组：
如果源事件块本身带编组，你在窗口里填了新的编组名，新生成的副本会用你填的新编组；如果你把编组留空，新副本会清除源编组（即不带编组）。

5.4 方式

"方式"决定了这些并发事件点怎么放置：

方式说明
堆叠（全叠在一起）所有事件块都放在同一个轨道、同一个节拍位置上，完全重叠
展开避让（自动找空轨）第一个放在原位置，后续的自动往下找空轨道，尽量不重叠

六、堆叠 vs 展开避让

6.1 堆叠

所有事件块都叠在同一个位置。这在时间轴上看起来就像只有"一个"事件块（因为完全重合了）。

什么时候用？

  • 做和弦：8 个音高不同的音符块叠在一起，看起来像一个厚方块，播放时同时响
  • 做重叠特效：多个调整图层叠在一起，同时生效
📌 堆叠后怎么编辑？
堆叠的事件块虽然视觉上重合，但它们是各自独立的。你可以用 Ctrl+A 全选，或者按住 Shift 逐个点选。选中后可以统一改属性。

6.2 展开避让

第一个事件块放在原位置，第二个往下找一条在当前节拍位置没有冲突的轨道，第三个继续往下找，以此类推。

如果所有已有轨道都冲突，就往下新建轨道。

什么时候用？

  • 做视觉上"层层展开"的效果
  • 你想同时触发多个事件块，但不想让它们视觉上完全重合
  • 你想让每个事件块都能被单独看到、单独选中
💡 展开避让的搜索范围：
从起始轨道开始往下扫，最多扫 200 条轨道。如果还是找不到空位，就新建一条。

七、生成过程

点"生成"之后：

  1. 参数校验（数量、长度是否合法）
  2. 记录一次撤销快照
  3. 弹进度窗口，显示"正在生成并发事件点..."
  4. 每 5 个一块异步生成
  5. 生成完成后：
  • 进度窗口关闭
  • 工程标记为已修改
  • 画布自动重绘
  • 只选中第一个生成的事件块（方便你直接在 CZEmakers 面板验证配参是否被正确带过来）
  • 轮播图显示"已创建 N 个并发事件块"
📌 为什么生成后只选中第一个？
因为并发事件点常常是"堆叠"的，如果全选，你可能看不出哪个是哪个。只选第一个，方便你立刻检查它（比如看看 CZEmaker 配参有没有被正确复制过来）。

八、工程文件里长什么样？

并发事件点生成的事件块，和普通事件块在工程文件里完全一样：

  • 音符块存在 notes 数组里
  • 调整图层存在 adjust_layers 数组里
  • 从源事件块复制过来的 CZEmaker 配参存在 cze_makers 字段里
  • 从源事件块复制过来的过渡动画存在 transition 字段里
  • 如果设了编组，编组名存在 cze_makers 里的 window_group 子字段

没有任何"并发事件点专用字段"，它就是一批普通事件块。

九、注意事项

  • 从源复制会带过来的属性： 音高、颜色、自定义文本、CZEmaker 配参、过渡动画、禁用状态等。
  • 从源复制会覆盖的属性： 长度、编组（如果你在窗口里改了）。
  • 位置： 从源事件块打开时，起点节拍 = 源事件块的开始节拍；从空白打开时，起点节拍 = 你右键点击的位置。
  • 展开避让不会跨源： 如果选中了多个源，每个源各自从自己的轨道往下找空位，不会互相影响。
  • 数量上限： 单次最多 2000 个（选中来源时，是"每个源 2000 个"）。
  • 会自动记撤销： 生成前会记录一次撤销快照，生成错了可以 Ctrl+Z 撤销。
  • 不自动保存： 生成后需要你自己按 Ctrl+S 保存工程。
  • 与节奏事件点的区别： 节奏事件点是"时间上铺开"，并发事件点是"同一时刻堆叠/展开"。

十、与其他模块的关系

并发事件点本身只负责"批量生成事件块"，它不涉及其他模块的核心逻辑。不过，它生成出来的事件块，可以立刻用于其他模块：

  • 过渡动画： 从源事件块复制过来的过渡动画会一起复制，你也可以在生成后批量修改。完整说明请看《过渡动画》文档。
  • CZEmaker 配参： 从源事件块复制过来的配参会一起复制，生成后第一个块会自动被选中，方便你直接在面板里检查。完整说明请看《CZEmaker 弹窗编排》文档。
  • 阵列： 如果生成时勾选了编组，之后可以把编组绑定到阵列。完整说明请看《阵列》文档。
  • 全局命令： 并发事件点不会自动创建全局命令，但你可以在生成之后手动添加。完整说明请看《全局命令》文档。

十一、小结

新建并发事件点，是一个"同一时刻批量生成事件块"的工具：

  • 三种来源：空白来源、当前来源、选中来源
  • 空白来源：生成全新事件块，可选音符块或调整图层块
  • 当前来源：以源事件块为模板复制 N 份
  • 选中来源：每个源各自复制 N 份
  • 参数：数量、长度、编组、方式
  • 两种方式：堆叠（全叠在一起）、展开避让（自动找空轨）
  • 异步分块生成，最多 2000 个
  • 生成后只选中第一个，方便验证配参

如果你想深入了解事件块自身的属性，请参考《音符块自身属性》和《调整图层》文档；想了解过渡动画，请参考《过渡动画》文档；想了解节奏事件点，请参考《新建节奏事件点》文档；想了解全局命令，请参考《全局命令》文档。
