📎 侧边栏

前面我们讲了 CZEmaker 弹窗、全局命令、音符块、调整图层、过渡动画、批量赋音效、渲染为音频文件、渲染视频文件、渲染为 Python 代码、渲染为 CZE 数据文件、编译为 exe、组装打包模式、解释器自定义配置、测试运行。现在讲一个主界面的重要组成部分——侧边栏。

📌 本篇的范围：
本篇只讲“侧边栏是什么、长什么样、有哪些功能模块”。每个具体的选项卡功能（显示器、历史操作、参考媒体、便签等）会在后续的文档里逐个详细讲解。

一、侧边栏是什么？

侧边栏是主界面左侧的一整块面板。它不是编辑区，也不是时间轴，而是用来“辅助查看和操作”的工具区。

用一句话概括：

💡 侧边栏 = 主界面左侧的辅助工具面板
它把一些高频使用的辅助功能集中在一起，让你不用来回切窗口、翻菜单，就能看到历史记录、参考媒体、便签、窗口类名等信息。

它跟主界面的关系是这样的：

┌──────────────────────────────────────────────────┐
│  菜单栏                                           │
├──────────────────────────────────────────────────┤
│  顶部工具栏 / 文件选择栏 / BPM 等                  │
├────────────┬─────────────────────────────────────┤
│            │                                     │
│   侧边栏    │            主画布 / 时间轴           │
│            │                                     │
│  （多选项卡）│                                    │
│            │                                     │
├────────────┴─────────────────────────────────────┤
│  底部选项卡（CZEmakers / 调整图层 / 媒体浏览器...）  │
└──────────────────────────────────────────────────┘

二、侧边栏的布局

侧边栏内部是上下分区的，中间有一条可以拖动的分割线。上下各自是一个选项卡组。

2.1 上下分区

区域选项卡数量说明
上半部分4 个显示器、历史操作、窗口类名、窗口编组
下半部分4 个参考媒体、字幕、便签、全局命令

上下分割线可以用鼠标拖动，改变两个区域的高度比例。

2.2 为什么要分上下

把功能分成上下两组，是为了方便你同时看到两类信息。比如：

  • 上半部分看“工程内的结构信息”（窗口类名、窗口编组、历史操作）
  • 下半部分看“辅助素材信息”（参考媒体、便签、全局命令）

这样你不用来回切换选项卡，上下扫一眼就能找到想要的东西。

三、侧边栏有哪些功能？

侧边栏一共有 8 个选项卡。下面简单介绍一下每个选项卡是干嘛的，具体的细节会在后续文档里逐个展开。

3.1 上半部分

选项卡作用
显示器把“当前帧”或“时间选区”渲染成图片/视频，直接在这里预览。相当于一个内置的迷你视频播放器
历史操作显示撤销/重做的历史记录列表，可以双击某条记录回退到那个状态
窗口类名列出工程里用到的所有窗口类名，支持搜索，双击可跳转到对应音符块
窗口编组列出工程里用到的所有窗口编组，支持搜索，双击可跳转并多选整组音符块

3.2 下半部分

选项卡作用
参考媒体打开图片/视频/音频作为参考，内置播放器支持播放、暂停、进度、音量。用于边看参考素材边做工程
字幕SRT 字幕管理，加载字幕文件、预览字幕时间轴
便签列出工程里所有的轨道便利贴，支持搜索、跳转、编辑
全局命令列出工程里所有的全局命令，支持搜索、跳转、编辑
💡 每个选项卡都有搜索框：
除了显示器选项卡，其它选项卡都自带搜索过滤功能。搜索框旁边还有一个“刷新”按钮，点一下就能重新加载当前数据。

四、侧边栏的通用操作

4.1 调整宽度

侧边栏的右边缘有一条拖拽把手（2 像素宽的细条，鼠标悬浮时会变色）。按住它左右拖动，就能调整侧边栏的宽度。

操作效果
向左拖侧边栏变窄，主画布变宽
向右拖侧边栏变宽，主画布变窄

宽度会被记住，下次打开程序时自动恢复。

4.2 调整上下分割

侧边栏内部上下两部分的中间有一条分割线。鼠标悬浮时会变色，按住上下拖动就能调整两部分的占比。

上下两组各自有一个“最低可见高度”，防止你把某一组拖到看不见。分割位置也会被记住。

4.3 切换选项卡

上半部分和下半部分各有自己的选项卡栏。点选项卡标题就能切换。切到某些选项卡（比如窗口类名、便签）时，会自动刷新一次数据。

4.4 显示 / 隐藏 / 浮动

侧边栏有三种显示模式，可以从菜单里切换：

模式说明
停靠（默认）侧边栏固定在主界面左侧
隐藏侧边栏不显示，主画布占满整个宽度
浮动侧边栏变成一个独立的窗口，可以放到别的屏幕上

菜单位置：「视图(V)」→「显示侧边栏（停靠） / 隐藏侧边栏 / 侧边栏浮动为独立窗口」。

五、侧边栏和主界面的关系

侧边栏本身不编辑数据，它只是“看”和“跳转”。所有的编辑操作还是在主画布、时间轴、底部选项卡里完成。

但有几种情况侧边栏会“主动联动”：

  • 历史操作：双击某条记录，主画布会回退到那个状态
  • 窗口类名 / 窗口编组：双击列表项，主画布的判定线会跳到对应位置，并选中相关音符块
  • 便签 / 全局命令：双击列表项，同样会跳转
  • 显示器：点“当前帧”或“时间选区”，会触发渲染并在侧边栏里播放
  • 参考媒体：播放/暂停会跟主程序双向同步（如果“自动”开启）

六、常见问题

Q1：侧边栏不见了怎么办？

可能是被切换到了“隐藏”模式。去「视图(V)」菜单里点「显示侧边栏（停靠）」就能恢复。

Q2：侧边栏太窄 / 太宽，怎么调？

把鼠标放到侧边栏的右边缘，光标会变成一个左右箭头，按住左右拖动即可。宽度会自动记住。

Q3：上下两部分的高度比例怎么调？

把鼠标放到上下两部分的中间分割线上，光标会变成一个上下箭头，按住上下拖动即可。分割位置也会自动记住。

Q4：侧边栏可以放到另一个屏幕吗？

可以。把侧边栏切换到“浮动”模式，它就会变成一个独立窗口，你可以把它拖到任意屏幕。

Q5：侧边栏会不会影响渲染性能？

不会。侧边栏只在需要的时候读取数据（比如切到某个选项卡时刷新一次），平时不会占用资源。显示器播放器只在渲染时才会启动 mpv。

Q6：侧边栏的选项卡能关闭吗？

不能。侧边栏的 8 个选项卡是固定的，不能单独关闭。但你可以在“显示 / 隐藏”之间切换整个侧边栏。

Q7：侧边栏支持语言包吗？

支持。切换语言后，侧边栏里的选项卡标题、按钮文字、提示文字都会跟着翻译。

Q8：侧边栏里的“自动”是干嘛的？

侧边栏里有两个“自动”复选框，分别在“显示器”和“参考媒体”选项卡里：

  • 显示器自动：判定线静止时自动渲染当前帧，或者在已渲染的选区内自动复用视频
  • 参考媒体自动：参考媒体的播放位置自动跟随主程序判定线

两个“自动”是独立开关，互不影响。具体行为会在对应的功能文档里详细讲。

七、小结

侧边栏是主界面左侧的辅助工具面板，把 8 个高频辅助功能集中在一起。

  • 位置：主界面左侧，宽度和上下分割都可以拖拽调整
  • 上半部分：显示器 / 历史操作 / 窗口类名 / 窗口编组
  • 下半部分：参考媒体 / 字幕 / 便签 / 全局命令
  • 支持三种显示模式：停靠 / 隐藏 / 浮动
  • 支持搜索过滤，大部分选项卡都有搜索框 + 刷新按钮
  • 支持语言包，切换语言后自动翻译
  • 不编辑数据，但会通过双击联动主画布跳转和选中

后续文档会逐个展开这 8 个选项卡的详细用法，敬请期待。
