🎛️ 调整图层

前面我们讲了 CZEmaker 弹窗、全局命令、音符块自身属性。但还有一个很酷的模块——调整图层。它可以让你在时间轴的某个时间段内，给屏幕上指定区域叠加一层滤镜特效，比如故障、扫描线、噪点、像素化等等。

调整图层不是弹窗，也不是音符。它是一条独立的时间轴区间，在画布上表现为一个半透明的紫色矩形，上下各有一条彩色边，中间写着 AL 或你自定义的文字。它的作用是：当时间走到它所在的范围时，在屏幕上激活一层特效，让画面看起来更“鬼畜”。

📌 调整图层是一个独立模块：
本篇讲的是调整图层的绘制、属性、特效模式、与窗口类名/编组的关联、过渡动画、右键菜单和工程字段。涉及其他模块的部分（比如全局命令怎么操作调整图层、阵列是否接管调整图层）只做简要说明，完整功能请参考对应的专门文档。

一、调整图层长什么样？

在时间轴上，调整图层是一个半透明的紫色矩形，上下各有一条颜色边条，颜色由你设置的“时间轴颜色”决定。中间默认显示 AL 两个字，也可以改成自定义文本。

外观元素说明
紫色半透明矩形表示这是一个调整图层区间
上边条 / 下边条颜色与图层的 color 字段一致
中间文字默认 AL，可自定义
左侧绿色小条表示有入场动画
右侧橙色小条表示有出场动画

二、绘制调整图层

2.1 进入绘制模式

在顶部工具栏或「编辑」菜单里找到「绘制调整图层」按钮，点击后进入绘制模式，鼠标会变成十字光标。

2.2 拖拽绘制

在时间轴的轨道区域按住鼠标左键拖拽，画出一个矩形区间，松开鼠标就创建了一个调整图层。绘制长度太短（小于 10 像素）会被忽略。

💡 自动避让重叠：
如果你画的区间和已有的音符或调整图层重叠，程序会自动帮你找一条“同一时间段没有冲突”的轨道，把调整图层放上去。如果所有已有轨道都冲突，会在下方新建一条空轨道。
💡 在空白区域绘制也会自动建轨道：
即使你画的区域下面没有现成轨道，程序也会自动创建一条新轨道，并画好背景、标题和节拍线。

2.3 退出绘制模式

再次点击「退出绘制图层」按钮（或按 Esc），光标恢复，退出绘制模式。

三、调整图层的属性面板

选中一个调整图层后，底部面板会切换到「调整图层」选项卡，显示它的所有属性。

3.1 通用属性

属性说明
滤镜模式选择特效类型：无、故障、像素化、扫描线、噪点、复古、颜色覆盖
窗口类名指定这个调整图层关联的窗口类名。当该类名窗口出现时，特效层会在屏幕上激活
所在编组指定关联的编组。当该编组内的窗口出现时，特效层激活
叠加颜色特效叠加的颜色，可以点击色块选色，也可以直接输入十六进制值，还有预设色块和亮度调节
效果强度控制特效的强度（1-30），不同模式下含义不同
像素大小像素化模式下的像素块大小（4-30）
不透明度特效层的不透明度（0-100）
鼠标事件拦截勾选后，特效层会拦截鼠标点击，防止点到下面的窗口

3.2 局部调整

属性说明
启用局部调整勾选后，特效只显示在指定的矩形区域内；不勾选则全屏显示
坐标 X / Y局部区域左上角的位置，单位是百分比（rpx）
区域宽度 / 高度局部区域的尺寸，单位是百分比（rpx）
⊕ 拾取区域点击后进入全屏拖拽模式，鼠标拖出一个矩形，自动填入坐标和尺寸
边框线是否在局部区域周围显示虚线边框
💡 拾取区域按钮：
点击「⊕ 拾取区域」后，屏幕会变暗，你可以按住鼠标左键拖拽出一个矩形。松开后，坐标和尺寸会自动填入，单位是屏幕百分比。按 Esc 取消。

3.3 应用与重置

  • 应用： 把当前面板的设置应用到选中的调整图层。多选时，只更新你修改过的字段（智能更新）。
  • 应用全部： 多选时出现，把面板所有字段统一覆盖到所有选中的调整图层。
  • 重置： 把选中调整图层的特效参数恢复为默认值。

四、特效模式详解

模式效果主要参数
无不显示任何特效—
故障类似电视故障的彩色偏移和色块抖动效果强度、叠加颜色
像素化把画面变成马赛克方块像素大小、效果强度
扫描线横向扫描线缓慢滚动效果强度（控制线间距）
噪点画面布满随机噪点效果强度（控制噪点数量）
复古泛黄、暗角的怀旧效果效果强度
颜色覆盖用叠加颜色覆盖整个区域叠加颜色、效果强度（控制透明度）

五、调整图层与窗口类名 / 编组

调整图层最重要的功能就是和窗口联动。你可以在属性面板里指定一个「窗口类名」或「所在编组」。当对应类名或编组的窗口弹出时，特效层会自动激活，在屏幕上显示。

5.1 什么时候激活？

  • 按时间激活： 当播放时间进入调整图层的 start_beat 到 end_beat 范围时，特效层会自动激活。
  • 按窗口激活： 当你指定了窗口类名或编组，并且该类名/编组的窗口被创建时，特效层也会立即激活。

5.2 什么时候停用？

  • 当播放时间超出调整图层的范围时，特效层自动停用。
  • 当关联的窗口关闭时，特效层也会停用（如果配置了关闭清理）。
📌 调整图层不是弹窗：
调整图层本身不会弹出一个窗口，它只是屏幕上的一层特效。但它会注册到窗口类名/编组系统，所以全局命令中的「窗口位移动画」「按类名/编组关闭」等命令也可以作用于调整图层。完整说明请参考《全局命令》专门文档。

六、调整图层的过渡动画

调整图层支持入场和出场过渡动画，和音符块一样，会在左侧/右侧显示绿色/橙色小条。

  • 在「过渡配置」选项卡中设置调整图层的入场/出场动画。
  • 支持的动画类型与弹窗过渡一致：淡入淡出、滑动、弹跳、弹性、展开等。
  • 当调整图层激活时播放入场动画，停用时播放出场动画。
📌 过渡动画是一个独立模块：
本篇只讲它在调整图层上的表现。完整动画参数和效果，请参考《过渡配置》专门文档。

七、调整图层的右键菜单

在时间轴上右键点击调整图层，会弹出菜单，包含：

菜单项作用
编辑调整图层基础属性打开一个小窗口，可以改叠加颜色和自定义文本
从当前调整图层新建并发事件点以这个图层为模板创建并发事件点（详见《节奏事件点》文档）
从当前调整图层新建节奏事件点以这个图层为模板创建节奏事件点（详见《节奏事件点》文档）
复制调整图层属性复制效果参数和颜色
粘贴调整图层属性把复制的参数粘贴到当前图层
复制调整图层复制整个调整图层
粘贴调整图层在鼠标位置粘贴一个新图层
禁用/启用调整图层切换禁用状态（禁用后不激活特效）
删除调整图层删除这个调整图层

八、调整图层在工程文件里长什么样？

调整图层保存在工程文件的 adjust_layers 数组里，每个图层是一个 JSON 对象：

{
    "id": 123456789,
    "track_idx": 0,
    "start_beat": 4.0,
    "duration": 2.0,
    "color": "#66ccff",
    "window_class": "我的窗口",
    "window_group": "主弹窗",
    "effect_params": {
        "mode": "故障",
        "glitch_strength": 10,
        "pixel_size": 8,
        "intensity": 5,
        "local_enabled": true,
        "area_width": 30,
        "area_height": 30,
        "area_x": 0,
        "area_y": 0,
        "color": "#66ccff",
        "border_enabled": true,
        "intercept_enabled": false
    },
    "transition": {
        "enter": { "type": "fade", "duration": 500 },
        "exit": { "type": "fade", "duration": 500 }
    },
    "custom_text": "AL"
}
字段含义
id唯一标识符
track_idx所在轨道（从 0 开始）
start_beat开始节拍
duration持续节拍
color时间轴颜色（上下边条的颜色）
window_class关联的窗口类名
window_group关联的窗口编组
effect_params特效参数（详见下表）
transition过渡动画配置
custom_text自定义文本（默认 AL）

effect_params 字段说明

字段含义
mode滤镜模式（无 / 故障 / 像素化 / 扫描线 / 噪点 / 复古 / 颜色覆盖）
glitch_strength效果强度
pixel_size像素大小
intensity不透明度（0-100）
local_enabled是否启用局部调整
area_width / area_height局部区域宽高（百分比）
area_x / area_y局部区域坐标（百分比）
color叠加颜色（十六进制）
border_enabled是否显示局部边框线
intercept_enabled是否拦截鼠标事件

九、全局命令与调整图层的联动

调整图层在激活时，会把自己注册到窗口类名/编组系统。因此，以下全局命令也可以作用于调整图层（完整参数请参考《全局命令》文档）：

  • 窗口位移动画： 可以按类名或编组移动特效层的位置。
  • 关闭弹窗： 可以按类名或编组关闭特效层（停用）。
  • 获取焦点与置顶： 可以调整特效层的层级。
⚠️ 调整图层不是传统窗口：
某些窗口操作（比如全屏、任务栏显示）对调整图层不适用，具体限制以实际表现为准。如果全局命令对调整图层无效，请检查类名/编组是否正确指定。

十、注意事项

  • 调整图层不能直接被阵列接管： 阵列变换只作用于弹窗，调整图层有自己的轨道，不参与阵列排布。
  • 局部调整的坐标是百分比： 以屏幕宽高为 100%，方便适配不同分辨率。
  • 鼠标事件拦截： 勾选后，特效层会挡住鼠标点击。如果不想挡住下面的窗口，请不要勾选。
  • 颜色覆盖模式： 叠加颜色的透明度由“不透明度”控制，注意不要设置过高导致画面完全被遮住。
  • 调整图层过多可能影响性能： 每个激活的特效层都会实时绘制，建议不要同时激活太多。

十一、小结

调整图层是 Itoc 里做鬼畜特效的利器：

  • 用拖拽在时间轴上绘制一个区间
  • 设置滤镜模式、叠加颜色、效果强度
  • 指定窗口类名/编组，让特效和弹窗联动
  • 支持局部调整、边框线、鼠标拦截
  • 支持入场/出场过渡动画
  • 右键菜单可以编辑、复制、粘贴、禁用、删除

如果你想深入了解全局命令怎么操作调整图层，请参考《全局命令》文档；过渡动画的完整参数，请参考《过渡配置》文档。
