🖥️ 显示器

前面我们讲了侧边栏的整体结构。现在开始逐个展开侧边栏里的选项卡，第一个讲的就是显示器。它位于侧边栏上半部分的第一个选项卡，是侧边栏里最常用的功能之一。

📌 本篇的范围：
讲的是显示器选项卡的定位、界面布局、三个按钮（当前帧 / 时间选区 / 自动）、设置按钮、右键菜单和全屏功能。关于侧边栏的整体结构，请参考《侧边栏》文档；关于参考媒体选项卡，请参考对应的文档。

一、这个功能是干嘛的？

显示器是侧边栏里的一块迷你预览播放器。它可以把 Itoc 工程里的画面渲染出来，直接在这里看到效果。

它做两件事：

  1. 渲染当前帧：把判定线所在的那一瞬间渲染成一张图片，显示在显示器里。
  2. 渲染时间选区：把时间选区范围内的一整段画面渲染成视频，然后自动播放。

渲染出来的画面，和最终导出视频、编译 exe 后播放的画面是一致的。所以你可以把它当成一个“实时取景器”，一边编辑一边检查效果，不用每次都完整导出视频。

💡 它跟“渲染视频文件”有什么区别？
· “渲染视频文件”会把整个工程导出成完整的视频文件，耗时较长。
· “显示器”只渲染当前帧或一小段选区，速度快，适合快速检查。
· 渲染出来的临时文件放在 temp/display_render/ 里，不会自动删除，但也不会污染工程目录。

二、从哪里打开？

显示器不是独立窗口，它就在侧边栏的上半部分，选项卡标题是「显示器」。

如果侧边栏当前是隐藏状态，先通过菜单「视图(V)」→「显示侧边栏（停靠）」把它显示出来，然后点「显示器」选项卡即可。

另外，播放菜单里也提供了一些快捷入口：

菜单项作用
【显示器】渲染当前帧等同于点显示器里的“当前帧”按钮
【显示器】渲染时间选区等同于点显示器里的“时间选区”按钮
【显示器】打开设置等同于点显示器里的“设置”按钮

三、界面布局

显示器选项卡从上到下分成三部分：

区域内容
上半部分预览画布（显示渲染出来的图片或视频）
中间部分按钮行：当前帧 / 时间选区 / 自动 / 设置
下半部分空（由渲染内容动态占满）

3.1 预览画布

预览画布是一个灰色区域，没渲染内容时显示一行占位文字「播放器已经就绪ing...」。

  • 渲染当前帧后，这里会显示一张静态图片。
  • 渲染时间选区后，这里会嵌入一个视频播放器，自动播放渲染出来的视频。

3.2 按钮行

按钮作用
当前帧把判定线所在的那一瞬间渲染成图片并显示
时间选区把时间选区渲染成视频并自动播放
自动（复选框）开启后，判定线静止时自动渲染当前帧；在已渲染的选区内自动复用视频
设置打开虚拟机模拟设置窗口，调整渲染参数
💡 “自动”是干什么的？
开启后，每次你松开判定线（判定线静止），程序会自动帮你渲染当前帧。
如果判定线落在已经渲染过的时间选区范围内，它不会重复渲染，而是直接复用已有的视频，把播放位置 seek 到对应时间。
如果判定线在选区之外，它才会重新渲染当前帧。
这样你拖动判定线检查画面时，就不用手动点“当前帧”了哦。

四、当前帧

点「当前帧」按钮后，程序会：

  1. 把判定线所在的时间点换算成秒。
  2. 导出工程数据为 CzeData。
  3. 调用渲染器，只渲染这一帧画面，保存为一张 PNG 图片。
  4. 把图片显示在预览画布里。

4.1 渲染过程

点击后，按钮文字会变成「渲染中...」，画布上会显示进度提示。渲染完成后，按钮恢复，图片出现在画布里。

如果画布尺寸和图片尺寸不一致，图片会等比缩放，居中显示，不会变形。

4.2 注意事项

  • 每次点“当前帧”，程序会先彻底关闭上一次的显示器视频播放器，避免冲突。
  • 渲染只包含画面，不含声音。声音由主程序播放或参考媒体控制。
  • 如果当前没有打开工程，或者工程里没有音符，会弹提示，无法渲染。

五、时间选区

点「时间选区」按钮后，程序会：

  1. 检查时间选区是否存在、是否足够长。
  2. 导出工程数据为 CzeData。
  3. 调用渲染器，把选区范围内的每一帧都渲染出来，合成一个 MP4 视频。
  4. 启动播放器，把视频嵌入预览画布，自动播放。

5.1 前置条件

条件不满足时的提示
有打开的工程“请先打开或保存一个工程文件”
有时间选区“请先在时间轴上划出时间选区”
选区时长足够“时间选区太短，请重新选择”

时间选区怎么划？参考《时间选区》文档：在时间轴上按住拖动，或者用 F4 进入选区模式，或者用 I / O 标记入点出点。

5.2 渲染过程

时间选区的渲染比当前帧慢得多，因为要逐帧渲染。渲染过程中：

  • 按钮文字变成「渲染中...」。
  • 画布上显示进度百分比和已处理帧数。
  • 渲染完成后，视频自动开始播放。

5.3 播放控制

视频播放时，你可以：

  • 拖动进度条 seek。
  • 播放 / 暂停。
  • 全屏播放（见下文）。
📌 关于“复用视频”：
渲染时间选区后，生成的 MP4 会保留在 temp/display_render/ 里。
如果你把判定线拖回这个选区内，开启「自动」的情况下，显示器会直接复用这个视频，不再重新渲染，只是把播放位置跳到对应时间。
只有当你重新点「时间选区」时，才会重新渲染并覆盖旧视频。

六、自动

「自动」是一个复选框，控制显示器是否在判定线静止时自动工作。

6.1 开启后的行为

场景行为
判定线静止，落在已渲染的选区内，视频已在播放把视频 seek 到对应时间
判定线静止，落在已渲染的选区内，视频未播放重新启动视频播放器，seek 到对应时间
判定线静止，落在选区外自动渲染当前帧（不弹提示）
主程序正在播放跳过自动渲染，避免干扰
已有渲染进程在跑跳过，等它跑完

6.2 状态记忆

「自动」的勾选状态会保存到配置文件，下次打开程序时自动恢复。

💡 什么时候开“自动”？
如果你经常拖动判定线检查画面，建议开启，省去反复点“当前帧”的麻烦。
如果你不想让它自动渲染（比如机器性能有限），保持关闭即可。

七、设置

点「设置」按钮，会打开虚拟机模拟设置窗口。这里面的参数决定了显示器渲染出来的画面长什么样。

7.1 分辨率

渲染输出的图片/视频尺寸。可以选预设（1920×1080 / 1280×720 / 640×360 / 3840×2160），也可以自定义。

旁边还有一个「预览」分辨率，专门用于快速预览，尺寸更小，渲染更快。

7.2 屏幕尺寸

视频坐标系里的“真实屏幕尺寸”。它会影响所有基于屏幕尺寸计算的位置、百分比坐标、对齐方式、随机位置、最大尺寸限制等。

比如同一个“屏幕中央”的对齐，在 1920×1080 和 3840×2160 的屏幕尺寸下，计算出来的像素位置是不同的。

7.3 桌面

字段说明
桌面图片渲染时作为底图的桌面背景图片，可以包含任务栏
桌面颜色没有桌面图片时使用的纯色背景

7.4 系统字体

渲染画面里文字使用的字体文件。如果不指定，程序会按优先级自动查找项目自带的字体和系统字体。

7.5 窗口焦点颜色

字段说明
焦点标题背景当前获得焦点的弹窗，标题栏背景色
焦点标题文字焦点弹窗的标题文字颜色
非焦点背景未获得焦点的弹窗，标题栏背景色
非焦点文字非焦点弹窗的标题文字颜色
📌 设置保存后立即生效：
点「应用」后，设置会保存到配置文件，并立即通知渲染器刷新。下次渲染时就会使用新参数，不需要重启程序。

八、右键菜单和快捷键

8.1 右键菜单

在预览画布上点右键，会弹出菜单：

菜单项作用
打开当前预览文件所在位置在资源管理器中定位到当前显示的图片或视频文件
全屏显示器把显示器画面切换到全屏播放（快捷键 Ctrl+`）

8.2 快捷键

快捷键作用
Ctrl + `切换显示器全屏 / 退出全屏
Esc在全屏状态下按，退出全屏

九、全屏显示器

全屏显示器会把预览画面放大到整个屏幕，适合仔细检查画面细节。

9.1 进入全屏

  • 在预览画布上右键，选「全屏显示器」。
  • 或者按 Ctrl+`。

如果当前还没有渲染过任何内容，程序会先进入全屏，然后自动渲染当前帧，渲染完成后显示在全屏窗口里。

如果已经有内容（图片或视频），直接进入全屏显示。

9.2 全屏下的行为

  • 图片：等比缩放铺满全屏，保持宽高比。
  • 视频：自动开始播放，并且循环播放。

9.3 退出全屏

按 Esc 退出全屏，画面重新吸回侧边栏的预览画布里。

十、常见问题

Q1：渲染完没有声音？

显示器渲染的是画面，不包含声音。它只负责让你看到画面效果，声音由主程序播放或参考媒体控制。如果你想听声音，用“渲染为音频文件”或“渲染视频文件”。

Q2：渲染时间选区很慢？

正常。时间选区要逐帧渲染，选区越长越慢。如果只是想快速检查，可以先渲染一小段选区，或者降低预览分辨率。

Q3：BPM 改了但预览没变？

需要重新渲染。显示器不会自动跟着 BPM 变，点一下「当前帧」或「时间选区」重新渲染即可。

Q4：为什么点「当前帧」后，之前的视频被关掉了？

这是设计行为。每次渲染当前帧，程序会先彻底关闭上一次的显示器视频播放器，避免两个播放器同时运行造成冲突。渲染完当前帧后，显示的就是静态图片。

Q5：全屏显示器黑屏怎么办？

先按 Esc 退出全屏，再重新进入。如果还是黑屏，检查一下显卡驱动，或者尝试用不同的分辨率渲染呀。

Q6：渲染出来的图片/视频在哪里？

临时文件放在程序目录下的 temp/display_render/ 里。当前帧保存为 display_frame.png，时间选区保存为 display_output.mp4。

Q7：「自动」开启了，但拖动判定线没反应？

检查以下几点：

  • 主程序是否正在播放？播放中会自动跳过。
  • 是否已经有渲染进程在跑？如果有，会跳过，等它跑完。
  • 判定线是否真的静止了？自动渲染有 300ms 的延迟，静止后才会触发。

Q8：设置里的分辨率改了，预览没变？

设置保存后立即生效，但已经渲染好的图片/视频不会自动重渲。需要重新点「当前帧」或「时间选区」才会用新分辨率渲染。

Q9：显示器占内存吗？

平时不占。只有在渲染时和播放视频时才会占用资源。渲染完成后，视频文件保留在磁盘上，播放器进程会一直运行直到你渲染新的内容或关闭程序。(๓´˘`๓)

Q10：可以同时渲染当前帧和时间选区吗？

不行。同一时刻只能有一个渲染任务。点「当前帧」会关闭之前的视频，点「时间选区」会重新渲染新视频。它们是互斥的。

十一、小结

「显示器」是侧边栏里的迷你预览播放器，把工程画面实时渲染出来给你看。

  • 位置：侧边栏上半部分，第一个选项卡
  • 三个主要按钮：当前帧 / 时间选区 / 自动
  • 当前帧：渲染判定线所在的一帧，显示为静态图片
  • 时间选区：渲染选区范围内的视频，自动播放
  • 自动：判定线静止时自动渲染当前帧；在已渲染选区内自动复用视频
  • 设置：打开虚拟机模拟设置，调整分辨率、屏幕尺寸、桌面、字体、焦点颜色
  • 右键菜单可以定位文件，也可以全屏播放
  • 快捷键 Ctrl+` 切换全屏，Esc 退出全屏
  • 渲染不含声音，只负责画面
