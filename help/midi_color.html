🎵 音符块自身属性

前面我们讲了 CZEmaker 怎么把音符变成弹窗，讲了全局命令怎么控制时间轴上的各种事件。但所有这些的基础，都是同一个东西——音符块。

音符块是 Itoc 时间轴上的主角。你在 MIDI 里听到的每一个音，导入后都会变成一个蓝色系的小方块。它的位置、长短、颜色、上面写的字、点击它弹什么窗口——这些都是它自己的属性。

这一篇专门讲音符块自身的那些属性。和 CZEmaker 相关的配置（窗口类型、标题、内容、位置等等）属于「配参」，不在本篇的范围内，请参考《CZEmaker 弹窗编排》系列文档。过渡动画（入场/出场）虽然挂在音符块上，但它属于「过渡模块」，本篇只做简单说明，完整功能请看《过渡配置》专门文档。

📌 本篇的范围：
只讲音符块「本身」的属性——它在哪、多长、什么音高、什么颜色、写什么字、有没有禁用、挂没挂音效。不涉及 CZEmaker 配参的内部细节，不涉及过渡动画的完整参数，不涉及全局命令。

一、音符块长什么样？

在时间轴上，每个音符块就是一个圆角矩形（实际上是普通矩形，只是视觉上看起来像块）。它的外观由这几个东西决定：

外观元素说明
填充颜色音符块的主色调。默认按音高自动生成，也可以手动指定
边框颜色普通状态是深蓝色，禁用状态是灰色
中间的文字默认显示音高值（比如 60），可以改成自定义文本
右上角小三角金黄色，表示这个音符挂了 CZEmaker 配参
左侧绿色小条表示这个音符有「入场动画」
右侧橙色小条表示这个音符有「出场动画」
红色对角线表示这个音符被禁用了

二、音符块的位置与时间

2.1 轨道位置

每个音符块都住在一条「轨道」上。轨道就是时间轴上横向的一条条「泳道」，从上到下编号（轨道 1、轨道 2、轨道 3……）。

音符块的轨道位置决定了它在屏幕上的垂直位置。你可以把音符块从一条轨道拖到另一条轨道，也可以给轨道重命名（右键轨道 →「重命名轨道」）。

💡 轨道名称：
轨道名称是存在工程文件里的 track_names 字段，默认是「轨道1」「轨道2」……你可以在轨道右键菜单里改名字，改成「主旋律」「伴奏」「鼓点」之类的，方便管理。

2.2 开始节拍

音符块在时间轴上的水平位置由「开始节拍」决定。节拍是从 0 开始的，0 拍就是时间轴的起点。

在工程文件里，音符块的开始节拍保存为 start_beat。注意：这个值是以「原始 BPM」为基准的，显示时会根据当前目标 BPM 换算。

2.3 持续节拍

音符块的长度由「持续节拍」决定。持续节拍越长，音符块在屏幕上就越宽。

在工程文件里，持续节拍保存为 duration_beat。同样，它也是以原始 BPM 为基准的。

💡 拉伸音符块：
把鼠标移到音符块的左边缘或右边缘，光标会变成左右箭头，这时按住左键拖动就可以拉伸音符块。拖左边改开始位置，拖右边改持续长度。
⚠️ 时长换算：
如果你把 BPM 从 120 改到 240，音符块的显示宽度会变成原来的一半（因为一拍的时间变短了），但它的「原始节拍」不变。保存到工程文件时，存的永远是原始节拍，不会因为 BPM 变化而改变。

2.4 时间信息（秒）

在音符编辑窗口里，你会看到「开始时间」和「持续时间」两行，单位是秒。这是根据当前 BPM 自动换算出来的，方便你对照音频。

换算公式：

开始时间(秒) = 开始节拍 × 60 ÷ 目标BPM
持续时间(秒) = 持续节拍 × 60 ÷ 目标BPM

三、音高值

音高值是一个 0 到 127 的整数，对应 MIDI 标准音高。60 是中央 C（C4），69 是标准音 A4（440Hz）。

音高值音名说明
0C-1最低音
21A0钢琴最低音
60C4中央 C
69A4标准音（440Hz）
108C8钢琴最高音
127G9最高音

音高值会影响两件事：

  1. 默认颜色： 音高越高，默认颜色越亮（亮度从 20% 到 85%）
  2. 播放音高： 音符播放时发出的声音频率由音高值决定
💡 音高预览：
在音符编辑窗口里，音高值输入框下方会显示这个音高的音名（比如「C4 (MIDI: 60)」），方便你对照。拖动音高滑块时，音名会实时更新。

四、颜色

音符块的颜色有两个来源：

4.1 默认颜色（按音高自动生成）

如果你没有手动指定颜色，音符块的颜色会按照音高自动生成。规则是：

  • 色相固定： 195°（一种偏青的蓝色）
  • 亮度变化： 从 20%（低音）到 85%（高音）
  • 饱和度固定： 100%

所以低音音符是深蓝色，高音音符是浅蓝色。这样你可以一眼看出音高的高低。

4.2 自定义颜色

你可以给音符块指定任意颜色。在音符编辑窗口的「颜色设置」区域：

  • 选择颜色…： 打开系统颜色选择器，随便挑
  • 重置为默认： 清除自定义颜色，回到按音高自动生成的状态
  • 快速色块： 18 个预设颜色，点一下就能用
  • 亮度调节： 滑块调节颜色的明暗（基于当前颜色，不会累积偏移）
💡 亮度调节的原理：
亮度滑块每次调整都是基于你「选定颜色的那一刻」的基准色来计算的。也就是说，你从基准色出发，调到 1.5 倍亮度，再调到 0.8 倍，最终得到的是「基准色 × 0.8」，而不是「基准色 × 1.5 × 0.8」。这样你不会因为反复拖动滑块而把颜色调乱。
⚠️ 颜色保存规则：
只有你手动改过颜色，工程文件里才会保存 color 字段。如果颜色是默认生成的（和音高公式算出来的一致），保存时不会写入颜色字段，加载时会按音高重新生成。这样工程文件更小，也更好维护。

五、自定义文本

音符块中间默认显示音高值（比如 60）。但你可以把它改成任何文本，比如歌词、注释、提示语等等。

5.1 手动设置

在音符编辑窗口的「自定义文本」输入框里填内容，点应用，音符块中间就会显示你填的文本。

保存到工程文件时，自定义文本存在 custom_text 字段里。

💡 清除自定义文本：
把自定义文本输入框清空，点应用，音符块就会恢复显示音高值。

5.2 从右键菜单填入配参

如果你想让音符块的文本直接变成 CZEmaker 配参的「窗口标题」或「窗口内容」，可以用右键菜单里的「将音符块文本填入配参」功能：

  1. 右键点击音符块
  2. 找到「将音符块文本填入配参」二级菜单
  3. 选「填入窗口标题」或「填入窗口内容」

填入的文本来自哪里？优先用音符块的自定义文本，如果没有自定义文本，就用音高值。

📌 关于「填入配参」的细节：
「填入窗口标题」只取第一行文本（标题一般只有一行）。「填入窗口内容」可以填多行文本。填入后需要点 CZEmakers 面板的「应用」按钮，才会真正保存到工程里。

5.3 插入歌词

右键菜单里还有一个「插入歌词」功能，可以把一段歌词自动分配到一串音符块上，每个音符块显示一个字或一个词。

歌词的切分方式可以选：

切分模式说明
自动识别中文逐字、英文按词、数字作为一个整体
逐字切分每个字符都作为一个词（包括英文字母）
按词切分中文逐字，英文按空格切词
jieba 分词用 jieba 库进行中文分词（需要安装 jieba）

标点符号可以选「保留为独立词」「附加到前一个词」「忽略」三种处理方式。换行符可以选择是否作为一个空词（用于空拍占位）。

⚠️ 同时起始音符的处理：
如果多个音符块在同一个节拍位置开始（比如和弦），可以选「全部应用同一个字」或「只应用到最上面那一个」。

六、音效

每个音符块可以挂一个自定义音效文件（.wav 格式）。播放到这个音符时，会播放你指定的音效，而不是默认的合成音。

6.1 设置音效

在音符编辑窗口的「定义音效」区域：

  • 从下拉框选择已有的音效文件
  • 或者点「浏览」按钮，从磁盘选择 .wav 文件
  • 选择「(无)」表示不挂音效

浏览选择的音效文件会自动复制到工程的 audio/ 目录，保存时记录的是相对路径（比如 audio/ding.wav）。

在工程文件里，音效保存在音符的 cze_makers 字段里的 sound_path 子字段。

6.2 批量赋予音效

如果你想把一堆音符块都设成同一个音效，可以：

  1. 选中所有目标音符块
  2. 右键其中一个 →「编辑选中音符」
  3. 在音效区域选好音效
  4. 点「应用到选中」

另外，主程序菜单里还有一个「根据窗口类型赋予自定义音效」功能，可以按窗口类型批量给音符块赋音效。这个功能在《CZEmaker 弹窗编排 · 进阶篇》里有简单说明，完整功能请参考专门文档。

6.3 音效的播放

播放时，如果音符块挂了音效，会优先播放这个音效（按音高调整音调）。如果没有挂音效，就用当前选中的预览乐器播放。

📌 预览乐器和音效的区别：
预览乐器（Windows Ding / 默认波形 / 钢琴 / 自定义）是全局设置，所有没有挂音效的音符都用它播放。音符挂的音效是单个音符的设置，只影响这一个音符。

七、禁用状态

每个音符块可以被「禁用」。禁用的音符块不会播放，在时间轴上显示为灰色，并且上面有一条红色对角线。

7.1 禁用/启用

有几种方式可以切换禁用状态：

  • Ctrl+Q —— 切换选中音符块的禁用状态
  • 右键菜单 →「禁用音符块」/「启用音符块」
  • 编辑菜单 →「禁用/启用所选音符块」

如果选中的音符块中有一部分是禁用的，切换时会全部变成「启用」（或全部变成「禁用」，取决于当前状态）。

7.2 禁用状态的影响

  • 播放： 禁用的音符不播放声音
  • 弹窗： 禁用的音符不触发 CZEmaker 弹窗
  • 渲染： 渲染音频时也会跳过禁用的音符
  • 插入歌词： 可以选择是否跳过禁用的音符块

在工程文件里，禁用状态保存为音符的 disabled 字段（true 或 false）。

八、过渡动画标记

音符块上可以挂「入场动画」和「出场动画」，让这个音符触发的弹窗以特殊效果出现或消失。

8.1 标记的外观

  • 左侧绿色小条： 表示有入场动画
  • 右侧橙色小条： 表示有出场动画

小条贴在音符块的内边缘，高度占音符块高度的 40%。

8.2 设置过渡动画

在底部的「过渡配置」选项卡里设置。选中音符块后，可以在那里配置入场/出场动画的类型、时长、缓动等参数。

📌 过渡动画是一个独立模块：
本篇只讲它在音符块上显示的那个小条。过渡动画的完整功能（支持哪些动画类型、每个参数什么意思、怎么组合使用）请参考《过渡配置》专门文档。

九、编辑音符块自身属性

双击任意音符块，会打开「音符块基础属性编辑」窗口。这个窗口分左右两栏：

9.1 左侧栏

区域内容
自定义文本 / 定义音效文本输入框 + 音效下拉框 + 浏览按钮
音高设置音高值输入框 + ±1 微调按钮 + 滑块 + 音名预览
时间信息轨道、开始节拍、时长节拍、开始时间（秒）、持续时间（秒）

9.2 右侧栏

区域内容
颜色预览一个色块显示当前颜色 + 十六进制值
颜色按钮选择颜色 / 重置为默认
快速色块18 个预设颜色（3 行 × 6 个）
亮度调节滑块调整颜色明暗
底部按钮应用 / 取消（多选时还有「应用全部」）

9.3 单选编辑 vs 多选编辑

  • 单选： 打开窗口时加载该音符块的当前属性。点「应用」会完整覆盖这个音符块的所有属性。
  • 多选： 打开窗口时只加载第一个音符的属性作为参考。你修改了哪些字段，就只有这些字段会被应用到所有选中的音符块。点「应用全部」会把面板上所有字段统一覆盖到所有选中的音符块。
💡 多选编辑的智能更新：
在多选模式下，只有你「主动碰过」的字段才会被更新。比如你只改了颜色，那么音高、文本、音效都不会动。这样你可以批量改颜色，而不影响其他属性。

十、复制与粘贴

10.1 复制音符块

选中一个或多个音符块，按 Ctrl+C 复制。复制的内容包括：

  • 音符块的相对位置（轨道偏移、节拍偏移）
  • 音高值
  • 持续节拍
  • 颜色
  • 自定义文本
  • CZEmaker 配参

10.2 粘贴音符块

在时间轴上按 Ctrl+V 粘贴。粘贴位置由鼠标当前位置决定（或者判定线位置）。

粘贴时会自动寻找可用的轨道：

  • 如果目标位置有足够的空轨道，直接粘贴
  • 如果没有，会询问你是否创建新轨道

10.3 复制 CZEmaker 属性

如果你只想复制 CZEmaker 配参，不复制音符块本身，可以用：

  • Ctrl+Shift+C —— 复制 CZEmaker 属性
  • Ctrl+Shift+V —— 粘贴 CZEmaker 属性

多选时，复制的属性会按顺序粘贴到选中的音符块上。

📌 CZEmaker 属性的完整说明：
复制/粘贴 CZEmaker 属性的细节，请参考《CZEmaker 弹窗编排 · 基础篇》里的「应用、重置和智能更新」章节。

十一、删除音符块

选中音符块后，按 Delete 键删除。或者右键菜单 →「删除音符」。

删除前会弹确认框。删除后音符块从时间轴上消失，工程标记为已修改。

十二、音符块在工程文件里长什么样？

音符块的数据保存在工程文件的 notes 数组里，每个音符是一个 JSON 对象：

{
    "id": 12345,
    "track_idx": 0,
    "start_beat": 4.0,
    "duration_beat": 1.0,
    "note_value": 60,
    "color": "#66ccff",
    "custom_text": "你好",
    "cze_makers": { ... },
    "transition": { ... },
    "disabled": false,
    "properties": {
        "velocity": 64,
        "channel": 0,
        "selected": false
    }
}
字段含义
id音符的唯一标识符
track_idx所在轨道（从 0 开始）
start_beat开始节拍（原始 BPM 下的节拍）
duration_beat持续节拍（原始 BPM 下的节拍）
note_value音高值（0-127）
color自定义颜色（空字符串表示用默认颜色）
custom_text自定义文本（空字符串表示显示音高值）
cze_makersCZEmaker 配参（详见《CZEmaker 弹窗编排》文档）
transition过渡动画配置（详见《过渡配置》文档）
disabled是否禁用（true / false）
properties额外属性（velocity、channel 等，目前主要用于兼容）

十三、小结

这一篇我们过了一遍音符块自身的所有属性：

  • 位置： 轨道、开始节拍、持续节拍
  • 音高： 0-127 的 MIDI 音高值
  • 颜色： 默认按音高生成，也可手动指定
  • 自定义文本： 可以显示歌词、注释等
  • 音效： 给单个音符挂 .wav 音效
  • 禁用状态： 禁用后不播放、不弹窗
  • 过渡标记： 入场/出场动画的小条（详情看过渡文档）
  • 编辑方式： 双击打开编辑窗口，支持单选/多选编辑
  • 复制粘贴： Ctrl+C / Ctrl+V，也可以只复制 CZEmaker 属性
  • 删除： Delete 键或右键菜单
