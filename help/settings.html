首选项（设置）

Itoc 里有很多可以调的东西——音量、波形、皮肤、解释器、自动保存、文件关联……全都塞在同一个地方，就是首选项。你可以把它理解成"软件的控制面板"：想调啥，来这儿翻就行。

📌 这篇唠的是啥：
首选项窗口里的全部 12 个分类，一个不落：窗口设置、音频设置、波形显示、皮肤设置、界面缩放、默认音量、面板设置、解释器、自动保存、回滚设置、打开方式、语言。
其中皮肤设置因为内容比较多，已经单独写了一篇，这里只做简要说明并指向那篇文档。

一、从哪儿打开？

菜单 「文件(F)」→「首选项」，点一下窗口就弹出来了。

二、窗口长啥样？

首选项窗口是左右分栏的结构：

┌──────────────────────────────────────────────────┐
│  设置分类              │   具体设置内容            │
│  ┌──────────┐         │                          │
│  │ 窗口设置  │         │  （每个分类各自的面板）    │
│  │ 音频设置  │         │                          │
│  │ 波形显示  │         │                          │
│  │ 皮肤设置  │         │                          │
│  │ 界面缩放  │         │                          │
│  │ 默认音量  │         │                          │
│  │ 面板设置  │         │                          │
│  │ 解释器    │         │                          │
│  │ 自动保存  │         │                          │
│  │ 回滚设置  │         │                          │
│  │ 打开方式  │         │                          │
│  │ 语言      │         │                          │
│  └──────────┘         │                          │
├──────────────────────────────────────────────────┤
│  [恢复默认]              [取消] [保存]              │
└──────────────────────────────────────────────────┘
  • 左侧：12 个分类按钮，点一下切换右侧内容
  • 右侧：当前分类的具体设置项（内容多的可以滚动）
  • 底部：恢复默认 / 取消 / 保存 三个按钮
💡 保存才生效：
大部分设置都是"改完点保存"才写进 shezhi.txt。点取消不会保存哦。
但有几个是"即时预览"的（比如 ttk 主题、原生窗口标题栏、皮肤透明度），改的时候就能看到效果。
具体哪些即时、哪些要点保存，下面每个分类里都会说清楚。

三、窗口设置

管的是"窗口和面板"相关的行为。

设置项说明
小屏幕模式 勾上后界面缩放变成 0.75 倍，所有控件都缩小一圈，适合 1366×768 这类小屏幕。
需要重启程序生效。
启动时自动继续上次关闭时的工作 勾上后，下次打开 Itoc 会自动打开最近文件列表里最新那个。
不勾选则每次都从"空工程"开始。
CZEmaker面板高度 底部 CZEmakers 面板的高度，范围 150 ~ 600 像素，默认 350。
拖滑块就能调，松手后立即生效。

四、音频设置

管的是"播放音符的时候用什么音色"。

4.1 预览乐器

四选一，决定试听音符时用哪种音色：

选项说明
Windows Ding系统提示音，就是 Windows 那个"叮"
默认波形用正弦波合成，音调绝对准确
钢琴(88键采样)用 88 键真实钢琴采样，听感最真实
自定义用你自己导入的 wav 文件当音色

4.2 自定义音效文件

如果上面选了"自定义"，这里点「浏览...」选一个 wav 文件。选完后会被复制到 wav/textwav.wav。

4.3 音频起始时间

单位毫秒。让音频从指定的毫秒数开始播放，相当于给音频加一个"起点偏移"。

填 0 就是从音频开头播；填 1500 就是跳过前 1.5 秒，从 1.5 秒处开始。

旁边有个「重置」按钮，点一下归零。

五、波形显示

管的是"音频轨道上那条波形图长啥样"。

设置项说明
启用音频波形显示 勾上就显示波形，不勾就不显示（省资源）
波形采样点数 范围 1000 ~ 50000，默认 5000。
数值越大波形越精细，但吃内存。普通工程 5000 就够。
波形颜色 默认是亮绿色 #00FF00。可以直接在输入框里打字，也可以点「取色器」调色板选。
旁边的色块会实时显示当前颜色。
💡 波形颜色改完是即时的：
改颜色之后，波形会立刻用新颜色重绘。如果没看到变化，看看是不是没加载音频文件。

六、皮肤设置

管的是"界面长啥样"：皮肤图片、透明度、时间轴背景色、ttk 主题、Windows 原生窗口标题栏。

设置项说明
当前皮肤 / 选择皮肤 / 清除皮肤挑一张图片铺到画布底层，支持 png/jpg/gif/bmp
皮肤透明度0% ~ 100%，默认 50%。拖拽松手才重绘（拖的时候不卡）
时间轴背景色画布底色，默认淡紫 #E8DBFF。有取色器和恢复默认按钮
ttk 控件主题按钮、下拉框、滚动条这些的风格，推荐 vista
Windows 原生窗口标题栏让标题栏跟随系统主题，Win10 1809+ / Win11 支持
📌 皮肤设置的详细说明：
每一项的具体行为、即时预览的规则、常见问题，都写在《皮肤设置》专项文档里了，这里就不重复了。
简单记一句话：皮肤设置管"面子"，改完大多能立刻看到效果，点保存才写进配置文件。

七、界面缩放

管的是"画布里各个元素的大小"，分两组。

7.1 时间轴缩放

设置项范围说明
X轴缩放0.2 ~ 10.0横向缩放，越大越能看清细节
Y轴缩放0.5 ~ 3.0纵向缩放，越大轨道越高

这两个跟主界面右上角的缩放滑块是同一个东西，在哪儿调都行。

7.2 事件块缩放

设置项范围说明
音符块字号0.5 ~ 2.0音符块里显示音高/歌词的字号
调整图层字号0.5 ~ 2.0调整图层块里文字的字号
💡 缩放是软件配置，不算工程修改：
调完缩放不会在标题栏出现 *，因为它属于"你怎么看这个工程"，不是"工程本身变了"。
但缩放值会存进工程文件，下次打开工程时恢复。

八、默认音量

三个滑块，都是 0 ~ 100：

设置项说明
总音量所有声音的总开关，最终音量 = 总音量 × 分音量
MIDI音量只影响音符播放的声音
音频音量只影响音频文件播放的声音

这三个也是主界面右上方音量滑块的同一份数据，在哪儿调都一样。

九、面板设置

管的是"主界面哪些面板显示、哪些隐藏"。

设置项说明
统计信息面板显示 / 隐藏切换。
对应主界面工具栏下方那条统计栏
CZEmaker预览区展开 / 折叠切换。
对应 CZEmakers 面板左侧的预览小窗
CZEmarker窗口勾上后 CZEmakers 面板从底部选项卡里"搬"出来，变成一个独立窗口
参考媒体勾上后程序启动时就自动启动 mpv 进程。
不勾选则需要手动点播放才会启动
⚠️ 参考媒体的"启动就启动 mpv"：
勾上之后，程序一打开就会把 mpv 进程拉起来（即使你还没加载参考媒体）。
好处是加载媒体时不用等；坏处是开机就多占一点资源。
如果你的机器比较吃紧，就别勾。

十、解释器

管的是"编译和测试运行时用哪个 Python 解释器"。

按钮作用
打开Itoc解释器配置配置主解释器。编译为 exe、渲染为 Python 代码、渲染 CzeData 时都用这个
打开测试运行解释器配置配置测试运行专用的解释器（按 F5 测试运行的时候用）

测试运行解释器是独立的，留空的话会自动回退到主解释器配置。所以你可以主解释器用一个 Python 版本，测试运行用另一个，互不影响。

点这两个按钮会打开对应的解释器配置窗口，里面有更详细的设置（64位/32位、窗口/控制台等）。具体用法请参考《解释器配置》文档。

十一、自动保存

管的是"定时自动保存工程"。

设置项范围说明
启用自动保存勾选框不勾选的话，下面几项都白搭
保存间隔(分钟)1 ~ 60默认 5 分钟。间隔越短，越安全但也越占磁盘
最大保存数量1 ~ 50默认 10 个。超过会自动删掉最旧的
保存路径文件夹路径默认 TempSave（运行目录下）。点「浏览...」可以改成别的地方

自动保存产生的文件名格式是：

工程名_autosave_20261008_143052.czemidi
💡 自动保存和手动保存是两回事：
自动保存不会覆盖你手动保存的主工程文件，而是单独存到 TempSave 文件夹里。
所以自动保存是"兜底用的"，真正要用的还是手动 Ctrl+S。

十二、回滚设置

管的是"撤销重做保留多少步"和"退出时清不清临时文件"。详细原理请参考《撤销与重做》文档，这里只讲设置项。

设置项说明
最大回滚步数 范围 1 ~ 100，默认 30。
限制两个栈里最多保留多少份快照。超出后自动删最旧的。
启用可休眠的回滚 勾上后程序退出时保留 CTRL_Z/ 和 CTRL_shift_Z/ 两个文件夹，下次启动还能接着用。
不勾则退出时自动清掉，省磁盘。
立即清理所有回滚文件 点一下会把两个文件夹里的所有内容删掉，相当于手动执行一次"清空历史"。
会弹确认框，确认后无法恢复。
⚠️ 立即清理是不可撤销的：
点了确认之后，所有历史快照就没了，撤销栈和重做栈都会变空。
用它之前想清楚，确认真的不需要任何历史了再点。

十三、打开方式（文件关联）

管的是"双击某类文件时用哪个程序打开"。

支持的三种文件类型：

扩展名说明对应启动器
.czemidiItoc 工程文件launcher/OpenCZEmidiFile.exe
.UIclassItoc 模类文件launcher/OpenUIclassFile.exe
.CzeData解释器数据中转文件launcher/OpenCzeDataFile.exe

13.1 怎么绑定？

每种类型都有「绑定」和「解绑」两个按钮，点绑定就写注册表，点解绑就删注册表。

绑定成功后，双击对应文件就会用 Itoc 打开了。

13.2 状态提示

窗口下方有一块状态区域，会显示当前三种扩展名的关联状态：

  • ✅ 已关联到：xxx（绿色）
  • ⚠️ 已关联到其他程序：xxx（橙色）
  • ❌ 未关联（红色）

点「刷新状态」会重新检测一遍。

⚠️ Windows 对默认应用有保护：
注册表写入成功后，Windows 可能还不会立刻把默认程序改过来。
如果双击文件后没有用 Itoc 打开，右键文件 → 打开方式 → 选择其他应用 → 选择对应的 exe → 勾选"始终使用此应用"。
这一步是 Windows 的强制保护，脚本没法绕过。
📌 解绑也可能不彻底：
解绑会删掉扩展名、ProgID、Applications 等注册表项，但 Windows 的"用户选择"（UserChoice）记录受系统保护，脚本删不掉。
想彻底解绑，请去 设置 → 应用 → 默认应用 → 按文件类型选择默认应用，找到对应扩展名改成别的程序。

十四、语言 Language

管的是"界面用哪种语言"。

14.1 当前语言

最上面一行显示当前用的是哪种语言。默认是"中文 简体"。

14.2 导入语言包

点「导入 .mui 文件...」，选一个语言包文件，会把它复制到 Language/ 文件夹里。

14.3 语言列表

中间是一个列表框，列出了 Language/ 文件夹里所有的 .mui 语言包。第一项永远是"中文 简体 (默认)"。

14.4 应用语言

从列表里选一项，点「应用所选语言包（重启生效）」，程序会：

  1. 把选中的语言包加载到内存
  2. 把语言文件名写进 shezhi.txt
  3. 提示你重启程序
⚠️ 语言切换需要重启：
选完语言后，当前窗口不会立刻全部变语言（有些菜单项要重建才能翻译）。
重启 Itoc 之后，整个界面才会完全按新语言显示。

点「刷新列表」会重新扫描 Language/ 文件夹。如果你手动往里面放了语言包，点一下就能看到。

十五、常见问题

Q1：改完设置点了"取消"，为什么有些效果还在？

因为有些设置是"即时预览"的（比如 ttk 主题、原生窗口标题栏、皮肤透明度）。

这些设置在你改的时候就已经写进内存了，点取消只是不写进 shezhi.txt。所以当前会话还是新效果，下次启动才会恢复旧值。

想完全回退，改完之后手动改回来再点保存哦。

Q2：小屏幕模式调完没变化？

需要重启程序。因为 DPI 缩放是进程级别的，程序运行期间改了也不会立即生效。

Q3：语言切换完没变化？

也是需要重启。语言包是在程序启动时加载的，运行期间只改内存里的映射表，很多已经创建好的控件不会自动重新翻译。

Q4：绑定 .czemidi 之后双击还是用别的程序打开？

这是 Windows 的默认应用保护机制。请右键文件 → 打开方式 → 选择其他应用 → 找到 OpenCZEmidiFile.exe → 勾选"始终使用此应用"。

详细说明见 13.2 节。

Q5：自动保存的文件在哪？

在「自动保存」分类里配置的"保存路径"下，默认是运行目录的 TempSave 文件夹。

Q6：回滚设置里的"立即清理"会删掉当前工程吗？

不会。它只删 CTRL_Z/ 和 CTRL_shift_Z/ 两个快照文件夹，不碰你手动保存的 .czemidi 工程文件。

Q7：恢复默认会重置哪些设置？

点「恢复默认」按钮会把大部分设置恢复成出厂值：小屏幕模式关闭、CZEmaker面板高度 350、预览乐器 Windows Ding、波形采样 5000、缩放 1.0x、音量 100%、自动保存关闭、回滚 30 步、ttk 主题 vista、原生窗口标题栏开启、皮肤透明度 50%、时间轴背景色 #E8DBFF。

但它不会立刻应用，只是把界面上的值改了。你还需要点「保存」才会真正生效。

Q8：设置会存在哪里？

存在程序运行目录下的 shezhi.txt 里。这是一个纯文本文件，你可以直接用记事本打开看看，虽然格式不太好看。

Q9：能手动改 shezhi.txt 吗？

可以，但不太推荐。因为格式是 key=value，改错一个字符程序可能就读不出来了。

建议还是在首选项窗口里改呀。(๓´˘`๓)

十六、小结

首选项窗口一共 12 个分类，覆盖了 Itoc 的方方面面：

  • 窗口设置：小屏幕模式、自动继续上次工作、CZEmaker面板高度
  • 音频设置：预览乐器、自定义音效、音频起始时间
  • 波形显示：启用波形、采样点数、波形颜色
  • 皮肤设置：皮肤图片、透明度、背景色、ttk主题、原生标题栏
  • 界面缩放：X/Y轴缩放、音符字号、调整图层字号
  • 默认音量：总音量、MIDI音量、音频音量
  • 面板设置：统计信息面板、CZEmaker预览区、独立窗口、参考媒体
  • 解释器：主解释器配置、测试运行解释器配置
  • 自动保存：启用、间隔、数量、路径
  • 回滚设置：最大步数、可休眠回滚、立即清理
  • 打开方式：.czemidi / .UIclass / .CzeData 的文件关联
  • 语言：导入语言包、切换语言（重启生效）

大部分设置改完点「保存」才写进 shezhi.txt，少数即时预览的（ttk主题、原生标题栏、皮肤透明度）在改的时候就能看到效果。小屏幕模式和语言切换需要重启才完全生效。
