🗂️ 媒体浏览器

做工程的时候，你可能会往工程目录里塞各种素材：图片、视频、音频、字幕、备份的工程文件……时间一久，目录就乱了。想找某个素材，得打开资源管理器一顿翻。

媒体浏览器就是解决这件事的。它把工程目录下的所有媒体文件汇总到一个面板里，用缩略图或列表的方式展示，让你一眼看清有哪些素材，还能直接操作它们。

📌 本篇的范围：
讲的是媒体浏览器面板的双视图模式、分类筛选、搜索、右键菜单（替换 / 脱机 / 引用表 / 重命名）、缩略图预览。关于工程文件的整体结构，请参考《工程文件》相关文档；关于参考媒体（在侧边栏里播放外部素材），请参考《参考媒体》文档。

一、这个功能是干嘛的？

媒体浏览器本质上是一个"工程素材箱"。它做的事：

  1. 扫描：递归扫描工程目录，把所有媒体文件找出来。
  2. 展示：用缩略图或列表两种方式显示，带文件名、类型、大小、修改日期。
  3. 操作：右键可以对文件做替换、脱机、重命名、查看引用表等操作。

它和"参考媒体"是两个不同的东西：

媒体浏览器参考媒体
用途 管理工程目录下的素材 播放外部素材，边做工程边对照
展示方式 缩略图网格 / 列表表格 内嵌播放器
数据来源 工程目录的磁盘扫描 用户手动打开的文件
主要操作 替换 / 脱机 / 重命名 / 查看引用 播放 / 暂停 / 音量 / 全屏
💡 一句话理解：
媒体浏览器是"素材库"，参考媒体是"播放器"。
素材库负责管理，播放器负责看和听。

二、从哪里打开？

媒体浏览器不是独立窗口，它就在底部选项卡栏里，选项卡标题是「媒体浏览器」。它和「CZEmakers」「过渡配置」「调整图层」「音频音谱」「字幕」「终端」这些选项卡并排在一起。

如果底部选项卡栏当前没有显示，先通过菜单「视图(V)」→「显示底部选项卡」把它显示出来，然后点「媒体浏览器」选项卡即可。

如果当前没有打开工程，面板会显示"未打开工程"，什么都不列。打开工程后，它会自动扫描工程目录并展示素材。

📌 自动刷新：
只要你保存工程、修改工程、或者做了任何会标记"工程已修改"的操作，媒体浏览器都会自动重新扫描一遍。所以不需要手动刷新也能看到最新的素材。

四、两种视图模式

媒体浏览器提供两种查看方式，随时可以切换。

4.1 缩略图视图

这是默认视图。文件以网格排列，每个文件显示为一张卡片：

  • 上方是缩略图：
    • 图片：直接显示图片本身（等比缩放到 120 像素以内）。
    • 视频：尝试读取视频第 10 帧作为缩略图（需要 OpenCV 支持）。
    • 其他类型：显示对应的 Emoji 图标（🎵 音频、📝 字幕、📁 工程等）。
  • 下方是文件名：超长会截断成"前14个字 + …"。

缩略图会随着面板宽度自动调整列数，面板越宽一行能显示越多。

💡 缩略图有缓存：
已经生成过的缩略图会缓存起来，再次显示同一文件时不会重新读取，所以翻列表很快。

4.2 列表视图

切换后，文件以表格方式显示，四列：

列内容
名称文件图标 + 文件名
类型音频 / 图片 / 视频 / 字幕 / 工程 / 其他
大小自动格式化为 B / KB / MB / GB
修改日期格式为 年-月-日 时:分

列表视图更适合快速定位某个具体文件，按名称排序或者对比修改时间。

4.3 视图切换

点顶部工具栏的「▦ 缩略图」/「☰ 列表」按钮就可以切换。

当前处于哪个视图，对应的按钮会变灰（禁用状态），另一个按钮亮起。

五、分类筛选

顶部的下拉框可以按文件类型筛选，选项有六个：

选项显示的文件类型
全部不筛选，显示所有扫描到的文件
音频.mp3 .wav .flac .m4a
图片.png .jpg .jpeg .gif .bmp .ico .webp
视频.mp4 .wmv .avi .mov .mkv .flv .webm
字幕.srt
工程.czemidi

选一个类型，只会显示对应的文件。选「全部」恢复完整列表。

📌 不支持的类型会归到"其他"：
"其他"类型不会出现在下拉框里，但如果你选「全部」，它们会一起显示出来。它们只带一个通用文件图标。

六、搜索

搜索框在工具栏中间，输入关键字后会实时过滤列表。

  • 匹配方式：文件名包含关键字（不区分大小写）。
  • 范围：只搜文件名，不搜路径。
  • 防抖：输入后等 300 毫秒才触发过滤，避免每打一个字就刷一遍。

比如输入 bgm，会匹配 bgm.mp3、bgm_loop.wav、theme_bgm_01.flac 等。

搜索和分类筛选可以叠加使用：先选"图片"，再输入关键字，只会在图片类型里搜。

七、双击打开

不管在哪种视图，双击某个文件，都会在资源管理器中定位到它。

  • 缩略图视图：双击卡片。
  • 列表视图：双击表格行。

Windows 上会用资源管理器打开它所在的文件夹，并选中这个文件。

八、右键菜单

在任意文件上点右键，会弹出一套操作菜单。这是媒体浏览器最有用的部分。

8.1 菜单项一览

菜单项作用
替换媒体用新文件替换当前文件，保持文件名不变
脱机媒体把文件移走或删除，让工程"脱机"
查看引用表列出所有引用此文件的音符块和全局命令
重命名改名，并自动更新工程里所有引用
在资源管理器打开定位到文件所在的文件夹
用默认打开方式打开用系统默认程序打开文件

8.2 替换媒体

"替换"是这套菜单里最有用的功能之一。

使用场景：你原本用 A 图片做了弹窗，后来画师给了新版本 B，文件名和格式都一样。这时候不需要改工程里的任何引用，直接替换磁盘上的文件就行。

操作步骤：

  1. 右键要替换的文件，选「替换媒体」。
  2. 文件选择框会弹出，并且已经按原文件类型过滤好了（替换图片只显示图片类型，替换视频只显示视频类型）。
  3. 选好新文件，点确定。
  4. 如果扩展名不同，程序会提示你确认（因为可能影响引用），确认后才会继续。

替换时，程序会：

  • 把原文件备份成 原文件名.backup。
  • 把新文件复制到原文件位置，保持原文件名。
  • 更新文件大小、修改日期等信息。
  • 清除这个文件的缩略图缓存。
💡 引用完全不用改：
因为文件名没变，工程里所有引用这个文件的地方都自动指向新内容。所以替换是"零侵入"的。

8.3 脱机媒体

"脱机"是指：把文件从工程里"挪走"，但保留引用位置，让工程进入一种"素材暂时不在"的状态。

右键选「脱机媒体」后，会弹出一个询问框：

是否同时删除磁盘文件？

文件: demo.png

选择"是"：直接删除文件
选择"否"：移动到脱机文件夹
选项行为
是 直接从磁盘删除文件，同时从媒体浏览器列表里移除
否 把文件移动到工程目录下的 OfflineMedia/ 文件夹里，文件本身保留

脱机后，文件在媒体浏览器里仍会显示（在 OfflineMedia/ 下），但标记为脱机状态。

📌 什么时候用脱机？
当你想临时"断开"某个素材，但又不想真的删掉文件时。
比如：A 素材暂时不用了，先脱机；过一段时间想用回来，直接从 OfflineMedia/ 挪回工程目录，重新引用即可。

8.4 查看引用表

"查看引用表"会打开一个新窗口，列出所有引用了这个文件的音符块和全局命令。

窗口里是一张表格，六列：

列内容
来源"音符块" 或 "全局命令"
轨道音符块所在轨道号（全局命令显示 -）
节拍音符块或命令的起始节拍
时长音符块的长度（全局命令显示 -）
音高/描述音符块的音高，或者全局命令的描述
资源类型图片 / 视频 / 音频
💡 双击某一行可以直接跳过去：
双击引用表里的"音符块"行，主程序会跳到那个音符块并选中它。
双击"全局命令"行，会滚动到那条命令并让它在画布上闪烁几次，方便你找到。
这个功能在"我想看看这个素材到底被哪里用了"的时候特别好用。

8.5 重命名

"重命名"不只是改个名字那么简单——它会同步更新工程里所有引用。

操作步骤：

  1. 右键选「重命名」。
  2. 弹出一个输入框，显示当前文件名，你改一下。
  3. 点确定。
  4. 程序会：
    • 检查新文件名是否包含非法字符（<>:"/\|?*）。
    • 如果有目标文件同名，询问是否覆盖。
    • 重命名磁盘文件。
    • 遍历所有音符块，把引用旧文件名的字段改成新文件名。
    • 更新媒体浏览器的显示。
  5. 状态栏会显示更新了几个引用。
⚠️ 重命名是"批量修改"：
如果这个文件被很多音符块引用，重命名后那些音符块全都会指向新名字。这个操作是有撤销的，但为了保险起见，建议大改动前先手动保存一下工程。

8.6 在资源管理器打开

和双击文件效果一样，在资源管理器中定位到这个文件。

8.7 用默认打开方式打开

用系统默认的程序打开文件。图片用默认看图软件打开，视频用默认播放器打开，音频用默认播放器打开。

这个和"在资源管理器打开"的区别是：前者是"用软件打开内容"，后者是"打开文件夹定位位置"。

九、扫描规则

媒体浏览器扫描工程目录时，有一些规则，了解一下能避免"为什么这个文件没显示"。

9.1 会扫哪些

  • 工程目录本身。
  • 工程目录下的所有子目录（递归）。
  • 常见媒体文件（前面分类筛选表里列的扩展名）。
  • 工程文件本身（.czemidi）。

9.2 不扫哪些

下面这些目录会被跳过，避免干扰：

  • __pycache__（Python 缓存）
  • temp / TempSave（临时文件）
  • CTRL_Z / CTRL_shift_Z（撤销栈）
  • OfflineMedia（脱机文件夹里的文件仍然会被扫描到，但标记为脱机）
  • 以 . 开头的隐藏文件或文件夹

9.3 排序规则

默认按修改时间降序排序，最近改过的排在前面。

所以如果你刚把某个素材换过新版本，它会出现在列表顶部，方便你找到。

十、常见问题

Q1：媒体浏览器里显示的文件数比工程目录里的少？

可能原因：

  • 分类下拉框不是「全部」。
  • 搜索框里有残留的关键字。
  • 有些不常见扩展名被归到"其他"类型，选「全部」能看到，但选其他分类看不到。

Q2：缩略图显示不出来？

缩略图能显示需要满足条件：

  • 图片：需要安装 PIL（Pillow），一般 Itoc 会自带。
  • 视频：需要安装 OpenCV，且视频格式能被 OpenCV 读取。
  • 其他类型（音频、字幕、工程等）：只显示 Emoji 图标，这是正常的。

如果图片缩略图都显示不出来，可能是 PIL 安装有问题，请检查环境。

Q3：替换媒体后工程里的引用会怎样？

不受影响。替换时程序保持原文件名，工程引用的是文件名，所以引用照旧，只是指向的内容变了。

Q4：脱机媒体后，工程还能正常编译吗？

取决于脱机后文件的状态：

  • 如果选的是"删除"，文件真的没了，编译时会报"找不到素材"。
  • 如果选的是"移动到 OfflineMedia"，文件还在工程目录里，只是换了个位置。这时要看编译脚本是否会在 OfflineMedia/ 里找素材。一般不会，所以要慎用。

Q5：重命名后，之前用这个名字的地方都更新了吗？

是的。程序会遍历所有音符块，把匹配旧文件名的 image_path、video_path、sound_path 等字段改成新文件名。状态栏会显示"更新了 N 个引用"。

但全局命令里的字符串路径目前不会被自动更新。如果你有全局命令（比如"设置桌面背景"）引用了这个文件，需要手动改一下。

Q6：右键菜单里的"查看引用表"是空的？

说明这个文件没有被任何音符块或全局命令引用。可能是你手动放进工程目录、但还没被使用的素材。

Q7：媒体浏览器会占用很多内存吗？

不会。缩略图都是缩放后的小图，单个大概几十 KB。扫描是异步的，不会卡界面。

如果工程目录文件特别多（上千个），首次扫描可能稍慢，之后就快了（有缓存）。

Q8：为什么"工程"分类里显示的文件名是 .czemidi，但我看到的是 .CzeData？

这是两个概念：

  • 工程文件：扩展名 .czemidi，是你保存工程时的文件。
  • CzeData：编译/测试运行时的中间数据文件，扩展名 .CzeData，在 runCZE/ 目录下。

媒体浏览器扫描的是工程目录，所以只显示 .czemidi。CzeData 在 runCZE/ 里，不在扫描范围内。

Q9：我在资源管理器里手动改了文件名，媒体浏览器能同步吗？

能。点一下"刷新"，或者随便做点会触发"工程已修改"的操作，媒体浏览器会重新扫描，看到新文件名。

但工程里的引用不会自动更新——因为是你在系统里直接改的名，Itoc 不知道。这种情况建议用媒体浏览器的"重命名"功能，让它帮你同步。

Q10：媒体浏览器支持哪些视频格式的缩略图？

支持 OpenCV 能读的所有格式，常见的有 mp4、avi、mov、mkv、wmv、flv、webm。

如果某个视频的编码比较特殊（比如 H.265 的某些变体），OpenCV 可能读不出来，缩略图会显示成 🎬 图标。

十一、小结

「媒体浏览器」是 Itoc 里的"素材箱"，把工程目录下的所有素材汇总展示，方便管理和操作。

  • 两种视图模式：缩略图网格（默认）和 列表表格，随时切换。
  • 分类筛选：全部 / 音频 / 图片 / 视频 / 字幕 / 工程。
  • 搜索：按文件名包含匹配，不区分大小写。
  • 双击文件在资源管理器中定位。
  • 右键菜单六项：替换媒体 / 脱机媒体 / 查看引用表 / 重命名 / 在资源管理器打开 / 用默认打开方式打开。
  • 替换媒体是"零侵入"的：保持文件名，工程引用不用改。
  • 脱机媒体分两种：直接删除，或移到 OfflineMedia/。
  • 查看引用表能列出所有使用此文件的音符块和全局命令，双击可以跳过去。
  • 重命名会自动更新工程里所有引用，避免路径失效。
  • 扫描时会跳过 __pycache__、temp、CTRL_Z 等临时目录。
  • 默认按修改时间降序排序，最近改过的排在前面。
  • 保存工程或做修改后会自动刷新，不需要手动刷新。
