一、鼠标移动的完整参数

基础篇我们只讲了「屏幕坐标系」模式。其实鼠标移动有三种模式，还有一个「目标窗口」的附加功能。我们把参数拆开看。

1.1 三种坐标模式

模式说明X/Y 的含义
屏幕坐标系默认模式，原点在屏幕左上角鼠标要移动到的绝对屏幕位置（都是正数）
以当前鼠标位置为原点勾选「以当前鼠标位置为原点」后启用，变成平面直角坐标系相对当前鼠标位置的偏移量（可以为负数）
移动到类名/句柄窗口勾选「移动到类名/句柄窗口」后启用X/Y 变成「额外的偏移量」，通常留空

平面直角坐标系模式

勾选「以当前鼠标位置为原点」后，X/Y 的含义变成「相对当前鼠标位置的偏移量」：

  • X > 0 → 向右移动；X < 0 → 向左移动
  • Y > 0 → 向下移动；Y < 0 → 向上移动
  • 例如 X=100, Y=-50 表示「向右 100 像素，向上 50 像素」
💡 这个模式的妙用：
「以当前鼠标位置为原点」可以做出「随机小抖动」的效果——比如 X 随机 -5 ~ +5，Y 随机 -5 ~ +5，鼠标就会在当前位置附近小幅抖动。或者做「相对移动」——鼠标当前位置 + 偏移量。

移动到目标窗口模式

勾选「移动到类名/句柄窗口」后，鼠标会移动到指定窗口的中心位置（或者窗口内某个指定位置）。X/Y 输入框变成「额外的偏移量」，一般在需要微调的时候才用。

目标窗口的配置方式：

字段说明
类名目标窗口的类名，例如 Notepad、Chrome_WidgetWin_1
句柄目标窗口的句柄（十六进制），例如 0x000811CE
标题目标窗口的标题（可选），用于辅助匹配

类名和句柄至少填一个。填了多个时会一起用于查找目标窗口。

💡 用「打开窗口拾取器」按钮抓取：
点「🔍 打开窗口拾取器（获取类名/句柄）」按钮，会打开一个独立的拾取器。把鼠标悬停到任意窗口上，按键盘数字键 1，就能抓取到该窗口的类名、句柄、标题。抓到的值会自动回填到输入框。

1.2 事件触发点

鼠标移动的过程分「开始」和「结束」两个时刻，可以在这两个时刻顺带执行一次鼠标事件：

字段可选值说明
start无 / 单击 / 双击 / 鼠标按下 / 鼠标抬起位移开始时执行
end无 / 单击 / 双击 / 鼠标按下 / 鼠标抬起位移结束后执行

1.3 缓动

缓动决定了鼠标移动的速度曲线：

缓动行为
线性匀速移动，从头到尾一样快
缓入慢起步，快结束
缓出快起步，慢结束
缓入缓出慢起步，快中间，慢结束（默认，最平滑）

二、窗口位移动画

这是全局命令里最强大的一个。它可以让弹窗按照指定路径移动、缓动，甚至做「集中目标」「屏幕边界限制」这些高级效果。

2.1 动画行

一条「窗口位移动画」命令里可以包含多个动画行。每个动画行是独立的一段位移。多个动画行会同时执行（不是先后）。

每一行包含三组参数：

组内容
目标目标类型 + 目标名称
位置注释 + 计算方式 + X/Y 坐标
原点模式以当前窗口位置为原点 / 移动到指定窗口
时间与缓动移动方式 + 时间 + 缓动 + 屏幕边界限制

2.2 目标类型

类型字段说明
窗口编组target_code=group移动某个编组里的所有弹窗
窗口类名target_code=class移动某个类名对应的所有弹窗
第三方窗口target_code=external移动一个指定的第三方窗口
📌 编组和类名是什么？
编组和类名都是 CZEmaker 里的概念，用来把一类弹窗归到一起。完整说明请参考《CZEmaker 弹窗编排 · 基础篇》。

第三方窗口模式的配置：点「🔍 抓取窗口」按钮，打开窗口拾取器抓一个窗口。抓到的类名、句柄、标题会保存到 external_class / external_handle / external_title 字段。

2.3 位置

字段说明
注释给这个动画行起个名字，例如「移动到中间」「向右飞」
计算方式绝对位置 / 相对位置
位置 X/Y目标的 X/Y 坐标。勾选「以当前窗口位置为原点」或「移动到指定窗口」时，这两个值变成「偏移量」，可以留空
拾取坐标点「⊕ 拾取坐标」按钮，鼠标点屏幕抓坐标

2.4 原点模式（两个复选框）

在位置下方有两个复选框，用来改变坐标的参照系：

复选框字段说明
以当前窗口位置为原点origin=selfX/Y 变成「相对当前窗口位置的偏移量」
移动到指定窗口origin=target移动到一个指定窗口的位置（通过类名/句柄/标题定位）
⚠️ 两个复选框互斥：
勾选「以当前窗口位置为原点」会自动取消「移动到指定窗口」，反之亦然。

「移动到指定窗口」的配置

字段说明
类名目标窗口的类名
句柄目标窗口的句柄
标题目标窗口的标题（可选）
抓取器点「🔍 抓取器」按钮打开窗口拾取器抓一个目标窗口

2.5 移动方式和屏幕边界限制

选项字段说明
相对静止move_mode=相对静止根据所有弹窗的统一中心点，将每个弹窗相对静止地移动到另一个位置
集中目标move_mode=集中目标让弹窗全部移动到这个位置，可以只填 X 或 Y，或都填
屏幕边界限制boundary_restrict=True勾选后，窗口移动时会被限制在屏幕边界内，触碰到边界的窗口单独停下来
⚠️ 互斥规则：
· 「集中目标」和「屏幕边界限制」互斥
· 目标类型是「窗口类名」或「第三方窗口」时，「移动方式」永远禁用（强制为「相对静止」）
· 勾选了「屏幕边界限制」时，移动方式也会被禁用
💡 「相对静止」和「集中目标」的区别：
「相对静止」会保持弹窗之间的相对位置关系，只是整体平移；「集中目标」会让所有弹窗移动到同一个目标点（或者同一个 X 或 Y），视觉上像「聚拢」。做鬼畜视频时，「集中目标」经常用来做「弹窗全部飞到屏幕中心」的效果。

2.6 时间与缓动

字段说明
时间(ms)位移从开始到结束持续多少毫秒。范围 0 ~ 10000
缓动线性 / 缓入 / 缓出 / 缓入缓出

三、阵列变换

阵列变换是让整个编组「重排」成另一种阵列形状的命令。比如你有一堆散乱的弹窗，用阵列变换可以让它们瞬间排列成一条直线、一个圆环、甚至一个 SVG 图案。

📌 阵列是一个独立模块：
阵列的完整功能（阵列设计器、阵列管理器、6 种阵列类型）请参考《阵列设计器》专门文档。这里只讲全局命令里这个功能的相关部分。

3.1 顶部配置

字段说明
编组选择要操作的编组。程序会自动找到绑定这个编组的阵列，加载对应的参数面板
目标阵列选择这个编组要变换成哪个阵列的形状。默认选中编组当前绑定的阵列
恢复默认绑定阵列把「目标阵列」下拉切回编组当前默认绑定的那个阵列

3.2 通用几何参数

所有阵列类型都有的参数：

字段字段名说明
重排时长(ms)duration编组重排时的过渡动画时长，50 ~ 5000 毫秒，默认 300
缓动easing / easing_display编组重排时的过渡缓动曲线，与「窗口位移动画」的缓动选项一致
角度angle阵列整体旋转角度（-360° ~ 360°）
间距spacing弹窗之间的排列距离，单位可选 px 或 rpx
偏移offset沿阵列路径整体平移，正负都可以（仅直线阵列和贝塞尔曲线阵列有）

3.3 各阵列类型的特有参数

直线阵列

字段字段名说明
锚点anchor左 / 中 / 右，决定阵列从左边、中间还是右边开始排
偏移offset沿射线整体平移

环形阵列

字段字段名说明
横向直径radius_x环形外框的横向大小
纵向直径radius_y环形外框的纵向大小
单位unitpx 或 rpx
填充fill关闭：绿点沿外框绕圈；开启：绿点从中心点开始，一圈一圈往外填充

多边形阵列

字段字段名说明
边数sides最少 3 条边
横向直径radius_x多边形外框的横向大小
纵向直径radius_y多边形外框的纵向大小
单位unitpx 或 rpx
填充fill同上

贝塞尔曲线阵列

字段字段名说明
节点数量—贝塞尔曲线的控制点数量，最少 3 个，最多 20 个
锚点anchor左 / 中 / 右
偏移offset沿曲线整体平移
贝塞尔节点anchors每个节点的坐标和控制柄（在阵列设计器里编辑）

极坐标阵列

字段字段名说明
挂载点points每个挂载点的自由偏移，在阵列设计器里手动点出来
间距spacing负数时挂载点会穿过锚点翻到对面继续扩

SVG 阵列

字段字段名说明
SVG文件svg_filename使用的 SVG 文件名
缩放scaleSVG 背景和所有弹窗位置的整体缩放（0.1 ~ 5.0）
SVG数据svg_dataSVG 原始内容（Base64 编码）

3.4 效果预览

右侧的预览画布会实时显示阵列形状。绿色的圆点表示弹窗会出现的位置。预览支持：

  • 缩放：用画布上方的缩放滑块，或者鼠标滚轮（以鼠标位置为中心）
  • 平移：鼠标中键拖动
⚠️ 目标阵列已被删除的情况：
编辑旧命令时，如果原来指定的目标阵列已经被删除或重命名，程序会弹窗询问是否放弃本次编辑。如果选择继续编辑，面板会显示为空，你需要手动选一个新的阵列。

四、镜像克隆编组

镜像克隆编组会把一个编组「镜像」出一份新的副本。副本的位置可以指定，内部弹窗的顺序可以重排。

4.1 顶部配置

字段字段名说明
源编组source_group要克隆的源编组
目标编组target_group克隆出的新编组名，默认是「源编组名 + _镜像克隆版」
从当前状态开始from_current_state是否从弹窗的当前位置开始镜像（而不是从初始位置）

4.2 位置选择器

决定克隆出来的第一个弹窗出现在哪里。支持四种模式：

模式字段名说明
屏幕坐标系position.type=screen绝对坐标或相对坐标
屏幕对齐position.type=align3×3 方向按钮矩阵 + 偏移
与窗口链接position.type=link链接到源编组里的某个带类名的窗口
屏幕随机position.type=random随机位置
📌 位置选择器的完整说明：
位置选择器的四种模式和 CZEmaker 里的「窗口位置控制」完全一致，请参考《CZEmaker 弹窗编排 · 基础篇》的「窗口位置控制」章节。

4.3 重编排

决定克隆出来的弹窗顺序如何变化：

模式字段说明
原样rearrange.mode=original顺序不变
全面反转rearrange.mode=full_reverse整体反转
水平反转rearrange.mode=horizontal_reverse左右镜像
垂直反转rearrange.mode=vertical_reverse上下镜像

五、执行代码

执行代码命令可以在后台运行一段 Python 代码。这是一个非常强大的命令，但也有些限制。

5.1 代码编辑器

点击「打开文本编辑窗口」按钮，会打开一个暗色配色的代码编辑器：

功能说明
语法高亮关键字（橙红）、字符串（绿）、注释（亮灰）、数字（蓝）、函数名（黄）、类名（青）、内置函数/类型（亮蓝）
查找编辑菜单 → 查找（Ctrl+F）
全选Ctrl+A
保存点「保存」按钮，或按 Ctrl+S，或按回车
取消按 Esc

5.2 代码上下文

执行代码时，程序会提供一些上下文变量方便你使用：

  • QApplication：Qt 应用程序实例
  • QWidget：Qt 窗口基类
  • player：播放器对象
  • self：当前解释器实例

5.3 编译模式限制

⚠️ 重要提醒：
「预览和组装打包模式无法运用 Python 代码，只有编译模式可以」。也就是说，在 Itoc 里按 F5 测试运行时，代码不会执行。只有编译成 exe 后才会跑。所以别在测试阶段拿它调试逻辑。

六、窗口拾取器（GetWindowClassName）

窗口拾取器是一个独立工具，用来抓取任意窗口的类名、句柄、标题等信息。它在多个命令里都会用到：「关闭某类名的弹窗」「获取焦点与置顶」「鼠标移动」「窗口位移动画」。

6.1 打开方式

在命令的详细设置对话框里，点「🔍 打开窗口拾取器」「🔍 拾取窗口」「🔍 抓取器」等按钮，就会打开。

6.2 界面结构

区域说明
标题区介绍本工具的用途
当前主窗口列表列出当前所有可见的顶层窗口，单击某一项直接抓取
选项「拾取时隐藏本窗口」「深度命中（找最内层控件）」两个复选框
开始拾取按钮进入拾取模式
清空输出 / 复制全部结果清空输出区、复制全部输出为纯文本
输出结果区显示抓取到的窗口信息

6.3 拾取流程

  1. 点「开始拾取」（如果勾选了「拾取时隐藏本窗口」，拾取器会隐藏起来）
  2. 鼠标移动到任意窗口上，会有一个红色的高亮框跟随鼠标，显示当前指向的窗口和层级
  3. 按下键盘数字键 1 确认抓取
  4. 或者按 Esc 取消
  5. 抓取完成后，拾取器重新显示，输出区显示抓取结果
💡 深度命中的作用：
勾选「深度命中」后，鼠标指向的是「最内层控件」（比如一个按钮、一个输入框）；不勾选则指向的是「鼠标下方最直接的窗口」。做「精确点击某个控件」时用深度命中会更好。

6.4 输出结果的内容

抓取后会显示这些信息：

字段说明
鼠标坐标抓取时鼠标的屏幕坐标
WindowFromPoint鼠标位置最直接的窗口句柄
命中控件(最内层)深度命中后的最内层控件句柄
层级深度从顶层窗口到最内层控件经过了多少层
顶层窗口顶层窗口的详细信息：句柄、类名、标题、控件 ID、矩形、可见/启用、样式、扩展样式、鼠标相对位置、线程/进程、进程路径
控件层级链从顶层窗口到鼠标下的完整控件链
鼠标下控件详情如果鼠标下不是顶层窗口，会单独列一份详情

6.5 每条信息可以单独复制

输出区里的每一条信息都是一个「小卡片」，点击卡片任意位置就能把值复制到剪贴板。复制后卡片会短暂变绿提示。

如果你想把整份输出都复制下来，点「复制全部结果」按钮，会复制一份纯文本。

七、其他细节

7.1 智能命名

进阶篇里涉及的命令，智能命名会提取更具体的信息：

命令类型提取逻辑示例
窗口位移动画取第一个动画的目标名窗口位移动画"你好"
阵列变换取编组名阵列变换"主弹窗"
镜像克隆编组取源编组名镜像克隆"登录框"
执行代码直接用「执行代码」执行代码
鼠标移动（移动到目标窗口模式）取目标窗口的标题或类名鼠标移到"记事本"
鼠标移动（屏幕坐标模式）取坐标鼠标到(800,400)

7.2 属性复制粘贴的细节

「复制命令属性」和「粘贴属性」是成对使用的：

  • 复制时会把命令类型、详细配置、描述、参数一起存到剪贴板
  • 粘贴时会弹一个确认框，让你核对即将替换的内容
  • 粘贴只替换「命令配置」，不替换「时间位置」
  • 粘贴完成后，目标命令会短暂闪烁一下绿色
💡 智能命名和复制粘贴的配合：
当你编辑旧命令时，如果描述框还没改，点「重命名为推荐名」会重新生成建议名。如果你编辑一个从别处粘贴过来的命令，可以用这个功能快速给它起个合适的名字。

7.3 时间轴自动扩展

拖动命令到工程尾部之后，时间轴会自动扩展，给你 8 拍的余量。这样你就不用特意去修改工程总长度了。

7.4 撤销快照

每一次修改全局命令（新建、编辑、克隆、删除、拖动、粘贴属性）都会自动保存一份撤销快照。如果你改错了，按 Ctrl+Z 就能撤销回去。
