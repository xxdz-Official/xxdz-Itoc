🎯 CZEmaker 弹窗编排 · 进阶篇

基础篇教会了你「怎么让一个音符弹出窗口」。进阶篇要解决的是：这个窗口弹在哪儿？怎么弹？长什么样？

这里面涉及窗口位置控制（四种模式的完整参数）、特殊窗口类型（图片镂空、视频、模类框的完整配置）、顶部右侧功能区、自定义尺寸与窗口寿命的互斥关系。

特殊窗口类型

图片框

弹窗里显示一张图片。支持 PNG、JPG、GIF（动图）、BMP、ICO。选择图片后会自动复制到工程的 img/ 目录（_copy_image_to_project）。

缩放百分比（scale_percent）： 调整图片显示大小（10%-200%）。滑块和输入框联动（scale_slider 和 scale_percent_var），修改时通过 _update_image_size_from_percent 通知主面板更新 W/H 输入框。

镂空图片窗口（hollow_enabled）： 让图片的背景变透明。支持两种模式：

  • 透明通道（alpha）： 直接使用 PNG 自带的透明通道。选择 PNG 图片时，如果镂空已勾选，会自动切换到此模式（_on_window_type_selected 中自动处理）。
  • 色度抠图（chroma）： 指定一个颜色变成透明。透明色由 hollow_color 控制，点击「选择」按钮可以打开颜色选择器（pick_hollow_color），点击「拾取」按钮可以打开图片拾取窗口（ColorPicker）从图片上取色。

镂空子选项（透明色输入框、选择/拾取按钮、颜色预览方块）的启用状态由 on_hollow_option_changed 和 on_hollow_mode_changed 控制。只有在「镂空已勾选 且 色度抠图模式」时，透明色相关控件才启用。

💡 GIF 动图： 选择 GIF 文件后，load_and_display_image 会检测到 GIF 并自动分离帧（_gif_frames 和 _gif_durations），启动动画播放（_start_gif_animation）。对于较大的 GIF，解释器会使用手动帧播放方式（_scale_gif）来优化性能。

自定义尺寸与图片比例匹配： 当「自定义尺寸」复选框勾选时，W/H 输入框启用。如果用户手动修改了 W/H 的值，_on_image_video_wh_change 会检查当前比例是否匹配原始图片比例：

  • 比例匹配： 启用缩放百分比滑块，并自动将百分比设置为 int(w / orig_width * 100)。
  • 比例不匹配： 禁用缩放百分比滑块，并在缩放后尺寸显示「(自定义比例)」提示。

图片加载时，_update_image_size_for_preview 会通知主面板更新 W/H 输入框（显示原始尺寸，但输入框保持禁用），然后 _sync_slider_from_wh_after_load 检查比例并同步滑块状态。

视频框

弹窗里播放视频。支持 MP4、WMV、AVI、MOV、MKV、FLV、WebM。选择视频后会自动复制到工程的 video/ 目录（_copy_video_to_project）。

缩放百分比（video_scale_percent）： 与图片框类似，通过滑块和输入框控制视频画面大小，通过 _update_video_size_from_percent 通知主面板更新 W/H。

播放视频： 点击「播放视频」按钮会打开一个独立的 Pygame 播放器窗口（open_video_player_window → _run_pygame_player_direct）。播放器窗口包含进度条（可拖拽跳转）、播放/暂停、停止按钮，支持 ESC 键退出。

视频尺寸控制： 与图片框一样，视频也支持「自定义尺寸」复选框。视频加载时，_update_video_size_for_preview 通知主面板更新 W/H，_sync_slider_from_wh_after_load 检查比例并同步滑块。

⚠️ 注意： 视频框在「测试运行」模式下使用独立的 Pygame 子进程播放（create_video_popup），视频需要提前转码为兼容格式。建议使用 MP4（H.264 编码）。Pygame 播放器窗口不会播放视频所带的音频（提示文本已说明）。

气泡/通知

屏幕角落弹出的通知条，几秒后自动消失。配置很简单：在文本框里写通知内容就行。没有窗口标题、类名这些概念。

在解释器中，create_windows_notification 会依次尝试三种方式发送通知：

  1. 使用 plyer 库发送系统通知。
  2. 使用 win10toast 库发送 Toast 通知。
  3. 使用 win32api.MessageBox 作为最后的备选方案。

气泡的通知内容来自 notice_content 字段，窗口标题可自定义（用于通知标题）。

执行代码

这个比较特殊——它实际上 不是一种窗口类型，而是一个 全局命令。在 CZEmaker 面板里把它当成窗口类型来配置，但解释器在检测到 window_type == "code" 时，会将代码内容交给 GlobalCommandExecutor.execute_code() 在后台执行，而不会弹窗。

execute_code 方法会在主线程中执行 Python 代码，并提供了 QApplication、QWidget、player、self 等上下文变量。代码内容保存在 code_content 字段中。

⚠️ 注意： 「预览和组装打包模式无法运用 Python 代码，只有编译模式可以」——也就是说，在 Itoc 里按 F5 测试运行时，代码不会执行。只有编译成 exe 后才会跑。所以别在测试阶段拿它调试逻辑。

模类框

窗口类型里有个特殊的「模类框」——它不直接配置弹窗内容，而是从「模类设计器」（UI Class）制作的模板文件里读取窗口结构。选「模类框」后，窗口类型选择器上方会出现一个「选择模类」下拉框（_create_class_selector）。

模类选择器的交互流程：

  1. 下拉框中的模类名称来自工程内置模类（ui_Class_data）和全局模类（UI_Class_Files 目录）。
  2. 选择模类后，_on_class_selected 会判断该模类是否来自全局文件夹。如果是全局模类，_copy_global_class_to_project 会将其复制到工程内置模类（带进度条窗口）。
  3. 然后 _load_selected_class 在后台线程中读取模类数据，并在主线程中应用：设置窗口标题（禁用状态）、内容文本框显示控件列表（灰色背景）、加载编组、加载位置配置。
  4. 加载完成后，调用 mark_config_modified(force=True) 强制标记为已修改，让「应用」按钮可用。

模类框的特殊限制：

  • 窗口标题输入框被禁用（state="disabled"），内容文本框被禁用并变为灰色背景。
  • 自定义尺寸复选框被强制禁用（_force_disable_custom_size_check）。
  • 图标下拉菜单被禁用（icon_combo.config(state="disabled")）。
  • 「选择模类」下拉框位于 row1 的第一个位置（在「窗口标题」之前）。

在解释器中，模类框由 create_class_popup 方法处理，会解析模类数据中的 components 列表，动态创建 QLabel、QPushButton、QLineEdit、QRadioButton、QCheckBox、QProgressBar、QGroupBox、QTabWidget 等控件。模类数据从工程文件的 class_data_project 字段加载。

顶部右侧功能区

在窗口标题行的最右边，有五个控制选项（top_right_frame）。在「图片框」「视频框」「模类框」模式下，图标下拉菜单会被禁用；在「气泡/通知」「执行代码」模式下，整个 top_right_frame 会被隐藏（_hide_top_right_frame）。

图标（icon_combo）

窗口标题栏的图标样式，可模拟不同 Windows 版本风格。选项包括：自动、Windows11、Windows10、Windows Logon、Windows Vista、Windows 7、Windows 8、Windows XP、Windows XP以下。选择「自动」时，解释器会根据当前系统版本自动选择对应的图标文件夹。

在解释器中，get_icon_for_window_type 会根据 window_icon 字段从对应的风格文件夹加载图标。如果指定风格找不到，会回退到系统检测的默认风格。

效果音（sound_combo）

弹窗出现时播放的音效。选项：自动、信息框、警告框、错误框、询问框、没有。选择「自动」时，解释器会根据窗口类型播放对应的系统提示音。选择「没有」则不播放任何声音。

在解释器中，play_system_sound 会使用 winsound 播放系统提示音，支持 MB_ICONASTERISK、MB_ICONEXCLAMATION、MB_ICONHAND、MB_ICONQUESTION 四种声音类型。

控制钮（control_combo）

窗口标题栏显示哪些按钮（关闭、最大化、最小化）。下拉选项：「自动」和「设置」。选择「设置」后会打开一个对话框（_open_control_settings_dialog），用三个复选框分别控制关闭、最大化、最小化按钮的显示。

选择「设置」并确认后，下拉菜单的选项会变成「自定义: 关闭、最大化、最小化」（_update_control_combo_display），并且在 control_config 中保存详细配置。保存配置时，window_control 字段为 "custom"，window_control_detail 包含三个布尔值。

按钮区（button_combo）

对话框底部的按钮（确定、取消、保存等），可以自定义顺序。下拉选项：「默认」和「设置」。选择「设置」后会打开一个更复杂的对话框（_open_button_settings_dialog），包含：

  • 按钮预览区域： 显示当前按钮列表，点击按钮可以调整顺序（← 向前移动 / 向后移动 →）或删除（✕ 删除）。
  • 预设按钮： 点击即可添加（确定、取消、保存、删除、应用、OK、是、否、关闭、重试、忽略）。
  • 自定义按钮： 输入框 + 添加按钮，可以添加自定义文本的按钮。

关闭对话框时，_update_button_combo_display 会更新下拉菜单显示（如「自定义: 3个按钮」），button_config 中保存按钮列表。保存配置时，window_button 为 "custom"，window_button_detail 包含 buttons 列表。

透明度（opacity_entry）

窗口的透明度（0%-100%）。输入框绑定 mark_config_modified，修改后会自动标记为已修改。在解释器中，透明度会通过 SetLayeredWindowAttributes（Windows）或 setWindowOpacity（Qt）应用。

自定义尺寸与窗口寿命

自定义尺寸（custom_size_var）

勾选后可以手动指定窗口的宽度和高度（单位：像素）。不勾选的话，窗口尺寸由系统根据内容自动决定。

互斥关系：

  • 「模类框」模式下，自定义尺寸复选框被强制禁用（_force_disable_custom_size_check），即使勾选了也会被取消。
  • 「图片框」和「视频框」模式下，复选框本身是启用状态，但 W/H 输入框的启用状态由复选框控制（_toggle_custom_size_controls）。
  • 切换窗口类型时，_restore_saved_fields 会恢复之前的自定义尺寸状态。

W/H 输入框变化时，_on_image_video_wh_change 会检查图片/视频比例是否匹配，并相应地启用/禁用缩放滑块。

窗口寿命（life_var）

指定窗口显示多少毫秒后自动关闭。

「使用音符块时长」（use_note_duration_var）的互斥逻辑：

  • 当「寿命」未勾选时：寿命输入框禁用，「使用音符块时长」复选框禁用。
  • 当「寿命」已勾选但「使用音符块时长」已勾选：寿命输入框禁用，「使用音符块时长」复选框启用。
  • 当「寿命」已勾选且「使用音符块时长」未勾选：寿命输入框启用，「使用音符块时长」复选框启用。

这个逻辑由 _toggle_life_controls 控制。如果「使用音符块时长」勾选，窗口寿命会由音符的 duration_s 字段决定（秒转毫秒），忽略寿命输入框中的值。

在解释器中，get_window_life_time 会先检查 use_note_duration，如果为 True 则直接使用音符的 duration_s 字段，否则使用 value 字段（单位 ms）。

多选编辑的「属性编辑标记」

在多选模式下，mark_property_edited(prop_name) 会被每个控件的变化事件触发。被标记的属性名会加入到 edited_properties 集合中。支持的属性名包括：

  • window_title — 窗口标题
  • window_content — 窗口内容
  • window_class — 窗口类名
  • window_group — 所在编组
  • window_icon — 图标
  • window_sound — 效果音
  • window_control — 控制钮
  • window_button — 按钮区
  • window_opacity — 透明度
  • window_life — 窗口寿命（包括复选框和输入框）
  • window_position — 窗口位置（所有位置相关的控件）
  • custom_size_enabled — 自定义尺寸复选框
  • custom_width / custom_height — 自定义尺寸 W/H
  • scale_percent / video_scale_percent — 图片/视频缩放百分比

应用时，只有 edited_properties 中的属性会被更新，其他属性保持不变。这就是「智能更新」的核心实现。

进阶篇小结

到这里，CZEmaker 的全部功能就都过了一遍：

  • 窗口位置控制（四种模式，每种模式的完整参数和互斥关系）
  • 特殊窗口类型（图片镂空、视频播放、气泡通知、执行代码、模类框）
  • 顶部右侧功能区（图标、音效、控制钮、按钮区、透明度）
  • 自定义尺寸与窗口寿命的互斥关系
  • 多选编辑的智能更新机制
  • 拦截层与修改保护

还有两个相关的模块，这里先提一下，以后会专门讲：

  • 过渡（入场/出场动画）： 在「过渡」选项卡中配置，可以让窗口以滑动、缩放、淡入淡出等方式出现和消失——这个在 「过渡配置」 章节详细讲。
  • 模类设计器： 制作自定义窗口模板的工具——这个在 「模类设计器 (UI Class)」 章节详细讲。
