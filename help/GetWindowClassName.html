🔍 窗口拾取器

前面我们讲了全局命令里的「关闭某类名的弹窗」「获取焦点与置顶」「鼠标移动」「窗口位移动画」这些命令。这些命令在操作第三方窗口的时候，都需要你填一个「类名」或「句柄」。可问题来了——你怎么知道记事本的类名是 Notepad、浏览器是 Chrome_WidgetWin_1、QQ 是 TXGuiFoundation 呢？

答案就是今天要讲的这个工具——窗口拾取器。它能把任意窗口的类名、句柄、标题、层级链通通"抓"出来，一键复制，不用你去猜、不用你去百度 ˵>ㅿ<˵

📌 本篇的范围：
讲的是窗口拾取器的入口、界面布局、左侧面板、右侧面板、拾取流程、输出结果、复制操作、常见问题。关于全局命令里怎么用这些类名句柄，请参考《全局命令 · 基础篇》和《全局命令 · 进阶篇》；关于侧边栏「窗口类名」选项卡，请参考《窗口类名》文档。两者名字有点像但完全不是一回事哦！

一、这个功能是干嘛的？

窗口拾取器是一个独立的抓取工具窗口。它做的事情很简单——你把鼠标移到任意一个 Windows 窗口上，它就把这个窗口的信息实时显示给你，你按一个键就能"抓"下来，抓下来的数据还能一键复制到剪贴板。

它能抓到什么？

  • 类名（Notepad、Chrome_WidgetWin_1 这种）
  • 句柄（形如 0x000811CE 的十六进制数字）
  • 标题（窗口标题栏上的文字）
  • 控件 ID、矩形位置、可见/启用状态
  • 样式和扩展样式（解码成可读的英文标志）
  • 鼠标相对坐标（相对于客户区和父窗口）
  • 线程 ID / 进程 ID / 进程路径
  • 完整的控件层级链（从顶层窗口到鼠标下的每一层）
💡 它和侧边栏「窗口类名」选项卡的区别：
· 侧边栏的「窗口类名」选项卡看的是 Itoc 工程内部你自己给弹窗起的类名（用于链接和编组）。
· 窗口拾取器抓的是 Windows 系统里别的程序的类名（用于全局命令操作第三方窗口）。
两个"类名"完全不是一回事，别搞混了！

二、从哪里打开？

窗口拾取器不是一个独立程序，它是被主程序临时调用出来的。你在这些地方点按钮就能打开它：

入口说明
全局命令 →「关闭某类名的弹窗」→ 指定第三方窗口模式 点「🔍 拾取窗口」按钮
全局命令 →「获取焦点与置顶」→ 指定第三方窗口模式 点「🔍 拾取窗口」按钮
全局命令 →「鼠标移动」→ 移动到类名/句柄窗口模式 点「🔍 打开窗口拾取器」按钮
全局命令 →「窗口位移动画」→ 目标类型选第三方窗口 点「🔍 抓取窗口」按钮

打开之后会弹出一个独立窗口，标题是「抓取窗口 / 控件」。它在任务栏上也会显示（方便你切回来），并且可以作为独立窗口拖到别的屏幕。

四、左栏详解

4.1 标题区：窗口 / 控件抓取器

最上面是一个带边框的小盒子，标题是「窗口 / 控件抓取器」。里面有几行说明文字，写着这个工具是干嘛的、常配合 Itoc 的哪些功能使用：

  • 全局命令 - 鼠标移动（定位到指定窗口）
  • 全局命令 - 窗口位移动画等
  • 其它需要按窗口类名或句柄定位的场景

4.2 当前主窗口列表

这是最方便的一个功能。窗口打开时，它会自动扫描当前所有可见的顶层窗口，把它们列在列表里，按标题字母排序。

列表里的每一行是一个窗口的标题。标题太长会截断（超过 32 个字符显示 …）。

单击列表里的任意一项，就直接抓取那个窗口，并在右栏生成报告。不需要自己用鼠标去点窗口，特别是当目标窗口被别的窗口挡住的时候，用列表选超级方便 (๑•̀ㅂ•́)و✧

列表下方有一个「刷新列表」按钮。什么时候用？

  • 你刚打开了一个新窗口，列表里没显示
  • 你关掉了某个窗口，列表里还留着
  • 窗口标题变了（比如浏览器换了标签页）
📌 列表不显示哪些窗口？
列表会自动跳过这些窗口，避免干扰：
· 不可见的窗口（IsWindowVisible 为假）
· 拾取器自己（不会把自己列出来）
· 工具窗口（带有 WS_EX_TOOLWINDOW 扩展样式的，一般是悬浮小窗）
· 没有标题的窗口（标题为空或只有空白字符）
所以列表里显示的都是"正经的"可见主窗口。

4.3 选项

有两个复选框：

选项默认说明
拾取时隐藏本窗口 勾选 开始拾取时，拾取器窗口会自动隐藏，避免挡住你要抓的目标窗口。抓取完成后自动恢复显示
深度命中（找最内层控件） 勾选 从鼠标位置的顶层窗口开始，一层层往下找，找到最内层的那个控件（比如按钮、输入框）。不勾选则只抓鼠标下面"最直接"的那个窗口
💡 什么时候开「深度命中」？
· 你想抓某个具体按钮、输入框的句柄 → 开着
· 你想抓整个窗口的句柄（比如整个记事本窗口）→ 关掉
默认开着是因为它更好用，抓控件精确度更高。

4.4 按钮区

按钮作用
开始拾取（大按钮） 进入拾取模式，鼠标可以开始移动选目标
清空输出 把右栏的输出结果清空，回到初始状态
复制全部结果 把整份报告复制成纯文本到剪贴板

4.5 状态栏

最下面的状态栏会显示当前状态，比如：

  • 就绪 · 点击任意卡片可复制值（初始状态）
  • 已加载 23 个窗口（刷新列表之后）
  • 拾取中… 移动鼠标 / 按 1 确认 / ESC 取消（拾取中）
  • 已抓取 · 点击任意卡片可复制值（抓取完成）
  • 已复制：0x000811CE（刚复制了一个值）

五、右栏详解

右栏显示的是抓取结果。整个区域是可滚动的，内容多的时候可以上下翻。每一行数据都是一张小卡片，样子长这样：

┌──────────────────────────────────────────────┐
│ 类名        Notepad                    ⧉     │
└──────────────────────────────────────────────┘

左边是字段名（灰色），中间是值（等宽字体、黑字），右边是一个复制图标 ⧉。

5.1 卡片交互

操作效果
鼠标悬停在卡片上 卡片背景变浅蓝，边框变蓝色，复制图标变蓝
点击卡片任意位置 把这个字段的值复制到剪贴板，值短暂变绿，复制图标变成 ✓
点击复制图标 ⧉ 和点击卡片一样的效果
鼠标在输出区滚动滚轮 上下滚动结果列表
💡 点击哪都能复制：
整张卡片都是可点区域——点标签、点值、点空白都行，不用非得精确点那个小图标。
复制成功后值会变绿 0.6 秒，状态栏也会提示「已复制：xxx」。

5.2 输出的内容结构

抓取完成后，右栏从上到下分成这几块：

① 顶部基础信息

字段含义
鼠标坐标抓取时鼠标在屏幕上的坐标 (x, y)
WindowFromPoint鼠标位置"最直接"的那个窗口句柄
命中控件(最内层)深度命中之后找到的最内层控件句柄
层级深度从顶层窗口到最内层控件经过了多少层

② 【顶层窗口】

这一块描述的是顶层窗口（比如整个记事本窗口）的详细信息：

字段含义
句柄形如 0x000811CE (528910)，十六进制和十进制都显示
类名窗口的类名，比如 Notepad
标题窗口标题栏的文字
控件ID对话框控件的 ID（顶层窗口一般是 0）
矩形窗口在屏幕上的位置 (left, top, right, bottom) 和尺寸
可见/启用两个布尔值，True / True 表示都正常
样式窗口样式 0xXXXXXX 后面括号里是解码后的标志列表
扩展样式扩展样式和解码后的标志
鼠标相对鼠标相对于客户区和相对于父窗口的坐标
线程/进程窗口所属的线程 ID 和进程 ID
进程路径进程的完整可执行文件路径

③ 【控件层级链（顶层 → 鼠标下）】

这一块列出从顶层窗口到鼠标下的每一层控件。每层一行，格式类似：

[0] 0x000811CE  Notepad  "无标题 - 记事本"  (100, 100, 900, 700)
[1] 0x000911CE  Edit     ""                (108, 160, 892, 692)   ◀ 鼠标下

带 ◀ 鼠标下 标记的那一行，就是你鼠标当前所在的最内层控件。当「深度命中」关掉时，这一链会比较短（只有顶层窗口一层）。

④ 【鼠标下控件详情】

如果鼠标下的控件不是顶层窗口本身（也就是命中了更内层的控件），就会单独再列一份详情，字段和上面的「顶层窗口」一样，只不过这次描述的是那个内层控件。

📌 为什么顶层窗口和鼠标下控件要分开列？
因为大多数时候，你想要的其实是鼠标下那个最内层控件的句柄（比如某个按钮），而不是整个窗口的句柄。
但有时候你又需要顶层窗口的信息（比如整个记事本窗口的类名），所以两个都给你列出来，各取所需。

六、拾取流程

完整走一遍，让你心里有个数：

  1. 点左栏的「开始拾取」按钮。
  2. 如果勾选了「拾取时隐藏本窗口」，拾取器窗口会自动藏起来。
  3. 屏幕上出现一个红色高亮框，跟着你的鼠标移动。
  4. 高亮框上方（或下方，根据屏幕空间自动调整）会显示一行红色标签，内容形如 [2层] Edit · 无标题 - 记事本 【按'1'拾取，按 ESC 取消】。
  5. 把鼠标移到你要抓的窗口（或控件）上，看红框和标签确认是不是想要的那个。
  6. 按键盘数字键 1 确认抓取。
  7. 拾取器窗口重新显示出来，右栏立刻生成报告。
  8. 状态栏显示「已抓取 · 点击任意卡片可复制值」。
  9. 点击你要的字段卡片复制值，粘贴到全局命令的输入框里，搞定！

6.1 高亮框长什么样？

鼠标跟随的红框是这样的：

  • 红色边框（2px 粗），围住当前鼠标下的控件区域
  • 内部有一层淡淡的红粉渐变填充（半透明，不遮挡内容）
  • 上方或下方有一个红色小标签，白字写着当前控件的类名和标题
  • 标签里还有一行浅黄色提示：「按'1'拾取，按 ESC 取消」

标签显示在框上方还是下方，程序会自动判断——如果框上方空间不够（贴着屏幕顶了），就显示在下方。

6.2 快捷键

按键作用
1（数字键 1）确认抓取当前鼠标下的窗口/控件
Esc取消拾取，退出拾取模式，不生成结果
⚠️ 拾取过程中不要点鼠标！
拾取模式下，你只需要移动鼠标和按键盘。鼠标左键点下去不会触发拾取，而是会把点击传给你鼠标下面的那个窗口（比如你点在记事本上，记事本就会获得焦点）。
确认抓取只能按 1，取消只能按 Esc，别搞错啦 ˵>ㅿ<˵

七、从窗口列表直接抓取

如果你知道目标窗口的标题，用左栏的「当前主窗口列表」会更快：

  1. 找到目标窗口的标题（列表按字母排序，可以滚一滚）。
  2. 单击它。
  3. 右栏立刻生成报告。

这种方式不需要进入拾取模式，也不需要隐藏窗口，特别适合以下场景：

  • 你要抓的窗口被其他窗口挡住了
  • 你要抓的窗口在另一个屏幕上，鼠标过去很麻烦
  • 你要抓的窗口是任务栏上的隐藏窗口
  • 你知道窗口标题，懒得自己去瞄鼠标
💡 从列表抓取时，「深度命中」和「拾取时隐藏本窗口」不起作用：
从列表抓取时，程序是拿窗口的中心点当作"鼠标位置"来算的，深度命中也按那个中心点算。所以如果你抓一个窗口，发现「鼠标下控件详情」是窗口内部某个子控件，那是正常的。

八、复制操作

8.1 复制单个字段

点击任意一张卡片，就把这张卡片的值复制到剪贴板。状态栏会显示「已复制：xxx」。卡片视觉上：

  • 值短暂变成绿色（0.6 秒）
  • 复制图标从 ⧉ 变成 ✓
  • 0.6 秒后恢复正常

8.2 复制全部结果

点左栏的「复制全部结果」按钮，会把整份报告以纯文本格式复制到剪贴板。复制的内容和右栏显示的结构一致，只是去掉了卡片样式，变成一段一段的文本。

复制成功后按钮文字会短暂变成「✓ 已复制」，1.2 秒后恢复。

这个功能特别适合：

  • 你想把抓取结果贴到论坛上请教别人
  • 你想存档对比两个窗口的信息
  • 你想把结果发给开发者排查问题

九、常见问题

Q1：为什么点了「开始拾取」之后，鼠标点了没反应？

因为拾取模式下，鼠标点击不会触发拾取。你需要把鼠标移到目标上，然后按键盘数字键 1 确认。这是有意设计的，避免你误点把点击传给目标窗口。

Q2：为什么拾取器窗口会突然消失？

因为你勾选了「拾取时隐藏本窗口」。这是正常行为，方便你看清目标窗口。抓取完成后它会自动显示回来。

Q3：高亮框没跟到我最内层的控件上？

检查「深度命中（找最内层控件）」有没有勾选。勾上了才会一层层往里找。如果没勾，只会抓鼠标"最直接"的窗口（通常是顶层窗口）。

Q4：窗口列表里找不到我要抓的窗口？

可能的原因：

  • 那个窗口当前不可见（比如最小化到托盘了）
  • 那个窗口没有标题（程序故意跳过了无标题窗口）
  • 那个窗口被识别成工具窗口（带有 WS_EX_TOOLWINDOW）
  • 列表没刷新，点一下「刷新列表」再试试

遇到这种情况，用「开始拾取」模式直接鼠标抓吧，那个不受列表限制。

Q5：抓到的句柄每次都不一样？

是的，句柄是运行时分配的。同一个程序每次启动，同一个窗口的句柄都会变。所以：

  • 如果你的全局命令只需要定位"这一类窗口"，用 类名 更稳定
  • 如果你需要精确锁定"某一个窗口"，用 句柄 更精确，但那个句柄只在当前这次运行里有效

Q6：我把拾取器窗口拖到另一个屏幕，还能正常抓吗？

能。拾取器支持作为独立窗口拖到别的屏幕。抓取时鼠标跟随红框也会跟着到那个屏幕，正常工作。

Q7：复制的时候提示「复制失败」？

一般是系统剪贴板被其他程序占用了。等一两秒再点一下，或者先在其他程序里复制点东西，把剪贴板"抢"回来再试。

Q8：「进程路径」显示为空？

说明读取进程路径失败了。常见原因：

  • 目标进程是系统进程（比如 csrss.exe），权限不够读不到
  • 目标进程是管理员权限运行的，而拾取器不是
  • 目标进程是 UWP 应用，路径有特殊处理

这种情况不影响类名和句柄的抓取，只是进程路径空着而已。

Q9：抓 UWP 应用（比如计算器、设置）有什么特别要注意的？

UWP 应用有"顶层外壳窗口"和"内部实际内容"两层。用「深度命中」抓到的一般是内部实际内容那一层。如果你要操作整个 UWP 窗口，可以关掉深度命中再抓一次。

Q10：这个工具会修改我的工程吗？

不会。窗口拾取器只是一个"看"和"复制"的工具，它不修改工程数据、不保存任何东西，纯粹的只读工具。放心折腾 (´▽`ʃ♡)ƪ

十、小结

窗口拾取器是操作第三方窗口时必备的工具，帮你抓出那些"看不见"的类名和句柄。

  • 入口：全局命令里所有需要指定第三方窗口的地方，点「🔍 拾取窗口」类按钮
  • 左栏：标题说明、当前主窗口列表（单击直接抓）、两个选项、三个按钮、状态栏
  • 右栏：可滚动的卡片式结果，点击任意卡片复制该字段的值
  • 拾取流程：点「开始拾取」→ 移动鼠标 → 看红色高亮框 → 按 1 确认 或 Esc 取消
  • 输出内容：鼠标坐标、WindowFromPoint、命中控件、层级深度、顶层窗口、控件层级链、鼠标下控件详情
  • 选项：拾取时隐藏本窗口、深度命中（找最内层控件）
  • 快捷操作：从列表单击直接抓取，不受拾取模式限制
  • 复制：单卡片点击复制单值，或者用「复制全部结果」复制整份报告
  • 只读工具：不改工程、不保存任何数据

如果你想了解抓到的这些类名和句柄到底怎么用，去看《全局命令 · 基础篇》和《全局命令 · 进阶篇》；如果你把类名和句柄填进了命令却还是没效果，去看看《窗口类名》文档里关于第三方窗口的那一节。
