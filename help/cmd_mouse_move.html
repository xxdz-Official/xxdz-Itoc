🖱️ 全局命令 · 鼠标移动

鼠标移动是「让鼠标自己跑到某个地方去」。听起来简单，但它有三种坐标模式、两个事件触发点、四种缓动曲线，玩起来比你想的花。这一篇专门讲它。

📌 一句话理解：
鼠标移动 = 「把鼠标从当前的位置，按某种路径，挪到另一个位置」。
挪的过程中可以顺带按一下、松一下；挪到终点也可以再按一下。
挪的方式可以匀速、可以缓入缓出。

一、三种坐标模式

模式启用条件X/Y 的含义
屏幕坐标系默认（两个都不勾）鼠标要移动到的绝对屏幕位置（都是正数）
以当前鼠标位置为原点勾「以当前鼠标位置为原点」相对当前位置的偏移量（可以为负数）
移动到指定窗口勾「移动到类名/句柄窗口」X/Y 变成「额外的偏移量」，通常留空

1.1 屏幕坐标系（默认）

  ┌───────────────────────────┐
  │  (0,0)                    │
  │                           │
  │              ● (800,400)  │
  │                           │
  │                           │
  └───────────────────────────┘

  X 越大越往右，Y 越大越往下。
  X/Y 都是正数。

1.2 以当前鼠标位置为原点

      Y
      ↑
      │
  ────●────▶ X
  第二 │ 第一
  象限 │ 象限
  ─────┼─────
  第三 │ 第四
  象限 │ 象限
      │

  鼠标当前位置 = 原点 (0,0)
  X > 0 向右，X < 0 向左
  Y > 0 向下，Y < 0 向上
💡 「以当前鼠标位置为原点」的妙用：
· 做「鼠标随机小抖动」：X 随机 -5 ~ +5，Y 随机 -5 ~ +5
· 做「相对移动」：鼠标当前位置 + 偏移量
· 做「以鼠标为锚点的拖动」：按住鼠标，然后在这个模式下移动到另一个位置

1.3 移动到目标窗口

勾上「移动到类名/句柄窗口」后，鼠标会自动移动到指定窗口的中心位置（或者窗口内某个指定位置）。X/Y 输入框变成「额外的偏移量」，一般在需要微调的时候才填。

字段说明
类名目标窗口的类名，例如 Notepad、Chrome_WidgetWin_1
句柄目标窗口的句柄（十六进制），例如 0x000811CE
标题目标窗口的标题（可选），用于辅助匹配
💡 「🔍 打开窗口拾取器」一键抓：
点按钮打开窗口拾取器，鼠标悬停到任意窗口上按 1，类名/句柄/标题会自动回填到输入框。
拾取器还能勾「深度命中」，抓到的就是最内层的控件（比如一个按钮、一个输入框）。 
  ┌──────────────────────────────┐
  │  ┌──────────────┐            │
  │  │   目标窗口   │            │
  │  │        ●  ←──┼── 鼠标挪到窗口中心
  │  └──────────────┘            │
  │                              │
  └──────────────────────────────┘

二、事件触发点：开始 / 结束

鼠标移动的过程分「开始」和「结束」两个时刻，可以在这两个时刻顺带执行一次鼠标事件：

字段可选值说明
start无 / 单击 / 双击 / 鼠标按下 / 鼠标抬起位移开始时执行
end无 / 单击 / 双击 / 鼠标按下 / 鼠标抬起位移结束后执行
 
  时间轴：  ─────┤开始├────────────位移────────────┤结束├─────▶

  开始 = none    结束 = none     →  纯粹的移动
  开始 = none    结束 = click    →  移过去自动点一下（最常用）
  开始 = press   结束 = release  →  移过去的路上是"按住拖拽"
💡 最常用组合：
「鼠标移动（位移结束后执行 → 单击）」= 一步完成「移动 + 点击」。
不用再单独写一条「点击行为」命令。
💡 做「拖拽」效果：
开始 = 鼠标按下，结束 = 鼠标抬起，中间就是拖拽。
runCZE 会检测到「按下」状态，用 mouse_event 增量移动鼠标，让系统识别为「按住拖动」，而不是简单地把鼠标挪过去。

三、缓动：速度曲线

缓动行为什么时候用
线性匀速，从头到尾一样快机械感、程序感
缓入慢起步，快结束「加速冲过去」
缓出快起步，慢结束「刹车停在目标点」，最自然
缓入缓出慢起步，快中间，慢结束平滑自然，默认
 
  鼠标位置随时间变化：

  线性：       │        ╱
              │      ╱
              │    ╱
              │  ╱
              └───────────▶ 时间

  缓出：       │          ╱
              │      ╱╱
              │ ╱╱╱
              │
              └───────────▶ 时间

  缓入缓出：   │        ╱
              │      ╱
              │    ╱
              │╱╱
              └───────────▶ 时间

四、组合示例

4.1 「移过去点一下」

  坐标：800,400
  位移结束后执行：单击
  缓动：缓出

效果：鼠标平滑地跑到屏幕 (800, 400)，停稳后自动单击一次。

4.2 「移过去，按住不动，等下一步」

  坐标：600,300
  位移结束后执行：鼠标按下

效果：鼠标跑到 (600, 300)，按下左键保持不动。这条命令本身不松开，靠后续命令（比如另一条鼠标移动的「鼠标抬起」）松开。

4.3 「以当前位置为原点，抖一下」

  勾选：以当前鼠标位置为原点
  X：0
  Y：-3
  缓动：缓出
  时间：80ms

效果：鼠标在原位置向上抖 3 像素。配合循环/多次触发，可以做出「鼠标在轻微呼吸」的效果。

4.4 「拖拽窗口标题栏」

  坐标：目标标题栏的起始位置
  位移结束后执行：鼠标按下

  第二条鼠标移动：
  坐标：目标标题栏的结束位置
  位移结束后执行：鼠标抬起

效果：模拟「按住标题栏拖动窗口」。两条命令前后配合，就完成了拖拽动作。

五、常见问题

Q1：为什么「移动到目标窗口」勾了之后 X/Y 输入框是灰的？

因为目标窗口模式本来就不需要填 X/Y（它会自动定位到窗口中心）。只有当同时勾上「以当前鼠标位置为原点」时，X/Y 才会变成可填的「额外偏移量」。

Q2：「移动到目标窗口」和「以当前鼠标位置为原点」能同时勾吗？

可以。两个都勾的情况下，鼠标会先移动到目标窗口位置，再叠加一个偏移量。X/Y 变成额外偏移哦。

Q3：起始事件和结束事件都用「单击」会怎样？

移动开始会点一下，移动结束会再点一下，总共两次单击。一般不会这么用，但技术上是可以的。

Q4：怎么让鼠标「瞬移」到目标点？

把「时间」设得非常小（比如 1ms），或者直接用系统原生速度。不过 runCZE 的鼠标移动是按帧插值的，时间再小也会走几帧，肉眼几乎看不出，但确实不是瞬移呀。

Q5：为什么鼠标有时候会跑偏？

检查一下是不是在「以当前鼠标位置为原点」模式下，勾了「位移结束后执行 → 鼠标按下」。按住状态下 runCZE 用 mouse_event 增量移动，会和 SetCursorPos 有细微差别。如果不是拖拽场景，建议取消按住状态。

Q6：能移动到自己吗？

能，但没意义。鼠标移动是「把鼠标挪到某个位置」，如果目标就是当前位置，那什么都不会发生。qwq

六、小结

  • 三种坐标模式：屏幕坐标系 / 以当前鼠标位置为原点 / 移动到目标窗口
  • 两个事件触发点：位移开始（start） / 位移结束（end）
  • 事件选项：无 / 单击 / 双击 / 鼠标按下 / 鼠标抬起
  • 四种缓动：线性 / 缓入 / 缓出 / 缓入缓出
  • 「移动 + 结束时单击」可以一步完成「移过去点一下」
  • 「按下 + 移动 + 抬起」可以模拟拖拽
  • 第三方窗口用「🔍 打开窗口拾取器」一键抓
