## 什么是 Crazy Error？ <span style="color:#AB92F5">(lll￢ω￢)</span>

**Crazy error** 就是弹窗类鬼畜，算是鬼畜区与软件极客区的结合体，特点为将一段音乐，配上Windows效果音MAD，视觉上进行有观赏性、卡点的系统弹窗，有极大的自由性。
