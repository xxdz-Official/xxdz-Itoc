🎞️ 全局命令 · 窗口位移动画

全局命令里最强大的一个，没有之一。窗口位移动画能让编组、类名、甚至第三方窗口自己动起来——直线滑过去、斜着飞出去、聚到屏幕中心、被屏幕边界拦住、想怎么动怎么动。

这一篇专门把它单拎出来讲清楚。前置知识请先看 《全局命令 · 基础篇》 和 《全局命令 · 进阶篇》。

📌 一句话理解：
窗口位移动画 = 「让一批窗口，从 A 点走到 B 点」。
A 点是窗口当前的位置；B 点由你填的 X/Y 坐标算出来；
走的路径可以有缓动、可以被边界拦住、可以只走一半。
就这么简单。剩下的都是细节。

一、动画行：一次动多个方向

一条「窗口位移动画」命令里可以包含多个动画行。每个动画行是一段独立的位移，多个动画行同时执行（不是先后！）。

  动画行1: 编组"你好"  →  向右滑 800px
  动画行2: 编组"登录"  →  向下滑 400px
  动画行3: 类名"Menu"  →  聚到屏幕中心

  三条动画同时跑，谁也不等谁。
💡 什么时候用多个动画行？
想让「几个编组分别去不同的位置」→ 一个动画行写一个编组。
想让「同一个编组同时做两件事」→ 这个做不到，同一编组一个动画行就够，参数会叠加计算。

二、目标类型：动谁？

目标类型字段名说明
窗口编组target_code=group动某个编组里的所有弹窗
窗口类名target_code=class动某个类名对应的所有弹窗
第三方窗口target_code=external动一个指定的外部窗口（记事本、浏览器等）
⚠️ 目标类型是「窗口类名」或「第三方窗口」时：
「移动方式」会被强制禁用（等于固定为「相对静止」），因为你没法给一堆不一样的窗口算统一中心点。

三、位置：去哪？

3.1 计算方式：绝对 / 相对

方式字段名X/Y 含义
绝对位置position_type=绝对位置屏幕像素坐标，比如 800,400
相对位置position_type=相对位置屏幕百分比，比如 50,50 表示屏幕正中
 
  绝对位置 (800, 400)：                  相对位置 (50, 50)：
  ┌──────────────┐                    ┌──────────────┐
  │              │                    │              │
  │    ●─────────┼─▶ (800,400)       │    ●─────────┼─▶ 屏幕正中
  │              │                    │              │
  └──────────────┘                    └──────────────┘
  以像素为单位                          以百分比为单位，跨屏幕自适应

3.2 原点模式：以谁为参考？

位置下方有两个互斥的复选框：

复选框字段名X/Y 变成什么
以当前窗口位置为原点origin=self相对窗口当前位置的偏移量，可正可负
移动到指定窗口origin=target相对另一个窗口左上角的偏移量，可正可负
都不勾origin=screen原来的逻辑，按屏幕坐标算
 
  ┌─────────────── 屏幕坐标系（默认）───────────────┐
  │  (0,0)                                          │
  │    ┌─────────┐                                  │
  │    │  窗口   │ ─────▶ 直接移动到 (800,400)      │
  │    └─────────┘                                  │
  └─────────────────────────────────────────────────┘

  ┌─────────────── self 模式 ───────────────────────┐
  │                                                 │
  │    ┌─────────┐                                  │
  │    │  窗口   │ ─────▶ 相对自身偏移 (+100, -50)  │
  │    └─────────┘                                  │
  └─────────────────────────────────────────────────┘

  ┌─────────────── target 模式 ─────────────────────┐
  │    ┌─────────┐                                  │
  │    │  目标   │ ← 对齐到这个窗口的左上角          │
  │    └─────────┘                                  │
  │    ┌─────────┐                                  │
  │    │  窗口   │ ─────▶ 目标左上角 + 偏移          │
  │    └─────────┘                                  │
  └─────────────────────────────────────────────────┘

3.3 target 模式的目标窗口配置

字段说明
类名目标窗口的类名，例如 Notepad
句柄目标窗口的句柄，例如 0x000811CE
标题目标窗口的标题（可选，用于辅助匹配）
💡 用「🔍 抓取器」一键抓：
点动画行里的「🔍 抓取器」按钮，打开窗口拾取器，鼠标悬停到任意窗口上按 1，类名/句柄/标题会自动回填。

四、移动方式：怎么动？

方式字段名行为
相对静止move_mode=相对静止所有弹窗保持相对位置，整体平移
集中目标move_mode=集中目标所有弹窗都往同一个目标点跑（可以只填 X 或只填 Y）
 
  ┌──────── 相对静止 ────────┐    ┌──────── 集中目标 ────────┐
  │                          │    │                          │
  │  ● ● ● ●  ────▶  ● ● ● ● │    │  ●  ●                  │
  │                 （整体平移）│    │    ● ●  ────▶ ●●●●   │
  │                          │    │    ●  ●        (全部聚拢)│
  │                          │    │                          │
  └──────────────────────────┘    └──────────────────────────┘
     相对位置保持不变                  所有弹窗冲到同一点
💡 集中目标为什么很酷？
做鬼畜视频时，经常用「集中目标」把一堆散乱的弹窗一下飞到屏幕中心，视觉冲击力很强。
或者只填 X 不填 Y → 所有弹窗挤到一条竖直线上，做「对齐列」效果。

五、屏幕边界限制

勾选 boundary_restrict=True 之后，窗口在移动时触碰到屏幕边缘就会单独停下来。没碰到的继续跑。

  ┌──────────────────────────┐
  │  ●  ●  ●  ●  ● ─────▶    │
  │        ●      （撞墙了就停）│
  │        │                 │
  │  ●  ●  ▼  ●  ●            │
  │   （这几个还在跑）         │
  └──────────────────────────┘
⚠️ 三个互斥规则：
① 「集中目标」和「屏幕边界限制」不能同时选
② 目标类型是「窗口类名」或「第三方窗口」时，边界限制也不生效
③ 勾了「屏幕边界限制」，移动方式下拉框会被禁用

六、时间和缓动

字段说明
时间(ms)位移动画持续多久，0 ~ 10000 毫秒
缓动速度曲线，见下表
缓动行为什么时候用
线性匀速，从头到尾一样快机械、冷峻的场景
缓入慢起步，快结束「加速冲出去」
缓出快起步，慢结束「刹车停住」，最常用
缓入缓出慢起步，快中间，慢结束平滑自然，默认
 
  线性：       ────────────▶  匀速

  缓入：       ───────▶▶▶▶▶  越来越快

  缓出：       ▶▶▶▶▶──────  越来越慢

  缓入缓出：   ──▶▶▶▶▶▶──   两头慢，中间快

7.1 「弹窗全部飞到屏幕中心」

  目标：编组"主弹窗"
  移动方式：集中目标
  位置：50,50（屏幕正中）
  时间：800ms
  缓动：缓入缓出

7.2 「弹窗被屏幕边界拦住」

  目标：编组"飞舞"
  移动方式：相对静止
  位置：-2000,0（往左飞很远）
  屏幕边界限制：勾
  时间：1500ms

结果：所有窗口往左飞，但触到屏幕左边缘就停下，不会被飞出屏幕。

7.3 「把记事本挪到右下角」

  目标类型：第三方窗口
  抓取：记事本
  位置：1800,900
  时间：600ms
  缓动：缓出

八、常见问题

Q1：动画行能不能先后执行？

不能。多个动画行是同时执行的。要先后执行就写两条「窗口位移动画」命令，放在时间轴的不同位置。

Q2：为什么勾了「集中目标」，X 或 Y 只填一个也行？

因为集中目标是「只朝一个方向对齐」。比如只填 X=960，就是所有弹窗挤到屏幕上 960 像素这条竖线上，Y 保持各自原样。

Q3：第三方窗口的动画是不是也是同样效果？

是的。类名 / 句柄 / 标题抓到的是外部窗口，动画通过 SetWindowPos 逐帧移动，效果和自家弹窗一致。缓动曲线也完全一样。

Q4：动画跑起来之后我再点同一条命令会怎样？

新动画会打断同一个目标上正在跑的旧动画。窗口以「当前位置」为起点开始新动画，不会有闪烁。

Q5：怎么让窗口动完之后自动关掉？

窗口位移动画只负责移动。移动完自动关掉需要另写一条全局命令（比如「关闭编组内的弹窗」），时间点排在动画结束之后一点点。

Q6：多个动画行同时跑，会冲突吗？

如果两个动画行的目标有交集（比如同一个编组），它们会互相覆盖，以最后生效的那个为准。建议每个编组只在一个动画行里出现。

九、小结

  • 一条命令里可以放多个动画行，同时执行
  • 目标类型：窗口编组 / 窗口类名 / 第三方窗口
  • 位置：绝对 / 相对（百分比）
  • 原点模式：屏幕 / 自身（self） / 目标窗口（target），后两者用偏移量
  • 移动方式：相对静止（整体平移） / 集中目标（聚拢）
  • 屏幕边界限制：触边即停，和集中目标互斥
  • 时间和缓动：线性 / 缓入 / 缓出 / 缓入缓出
