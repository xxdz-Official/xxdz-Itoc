🔊 根据窗口类型赋予自定义音效

前面我们讲了 CZEmaker 弹窗、全局命令、音符块、调整图层、过渡动画。现在讲一个"批量工具"——根据窗口类型赋予自定义音效。它能让你一次性把工程里所有"信息框"的音符配上某段音效、所有"警告框"的音符配上另一段音效，不用一个个点音符去改。

📌 本篇的范围：
讲的是这个批量工具的界面、应用范围、音效文件管理，以及它写进工程文件的字段。关于单个音符怎么定义音效，请参考《音符块基础属性编辑》；关于音效在渲染时怎么用，请参考《渲染为音频文件》。

一、这个功能是干嘛的？

在 Itoc 里，音符块可以挂一段 自定义音效（比如一声"叮"、一句提示音、一小段采样），窗口弹出时就播放这段音效，而不是系统默认提示音。

问题是：一个工程里可能有几十上百个音符，每个都要手动挂音效，太累了。

「根据窗口类型赋予自定义音效」就是来干这件事的。它的逻辑很简单：

  • 你告诉它："信息框 → ding.wav"、"警告框 → warn.wav"
  • 它遍历工程里的音符，凡是 window_type 是 info 的就挂 ding.wav，是 warning 的就挂 warn.wav
  • 一次操作，全工程覆盖

这个工具在渲染音频、导出视频、播放弹窗时都能用得上。它是"批量赋值"，不是"单个编辑"——单个编辑请用音符块属性编辑器里的"音效"下拉框。

二、怎么打开？

在菜单栏找到 「工具」 或 「批量」 相关的菜单，里面有 「根据窗口类型赋予自定义音效」 这一项。点开就是工具窗口。

窗口是无模态的，打开后你可以一边看主界面一边操作。窗口右下角有 「应用」 和 「取消」 两个按钮。

三、界面详解

窗口从上到下分成三大块：窗口类型 → 音效映射表、应用范围、跳过已自定义 + 统计 + 按钮。

3.1 窗口类型 → 音效 映射表

这是最核心的区域。每一行是一个窗口类型，右边有一个下拉框，让你选这个类型对应哪段音效。

窗口类型对应的 window_type 值
信息框info
警告框warning
错误框error
询问框question
图片框image
气泡/通知notice
执行代码code
视频框video
模类框UIclass

下拉框的选项有三个来源：

  • （不设置） —— 默认值。选这个表示"这个窗口类型不覆盖"，如果音符原本有音效就不动它，原本没有也不加。
  • 工程已有的音效文件 —— 工程目录下 audio/ 文件夹里的所有 .wav 文件，会自动列出来。
  • 通过"浏览..."按钮导入的音效 —— 见下一节。
💡 只处理 .wav 格式：
这个工具的音频文件只支持 .wav。如果你有 .mp3 或其它格式，需要先转成 wav 再导入。因为底层播放引擎只对 wav 做采样加载。

3.2 浏览并导入音效

每个窗口类型右侧有一个 「浏览...」 按钮。点它会弹出文件选择对话框，让你从电脑里挑一个 .wav 文件。

选好之后，程序会做两件事：

  1. 把文件复制到工程的 audio/ 文件夹里（如果还没有的话）。
  2. 把该窗口类型对应的下拉框选中这个新文件。

如果工程里已经有同名文件，会弹出确认框问你是否覆盖。

📌 音效统一放在工程的 audio/ 目录下：
所有导入的音效都会集中到 工程目录/audio/。这样分享工程时，把整个工程目录打包带走，音效就跟着走了。

3.3 应用范围

跟音频渲染工具类似，这里也有三种范围：

选项说明
全部音符工程里所有音符都参与筛选（默认）
仅时间选区范围只处理时间轴上有选区的那一段。如果当前没有时间选区，这个选项是灰色不可点的
自定义范围手动输入起止秒数，只处理这一段。输入框单位是秒

注意：这里的"范围筛选"是两层筛选之一。第一层是范围，第二层是"跳过已自定义"。

3.4 跳过已自定义音效

这是一个复选框，默认勾选。

勾选时，如果一个音符已经有 sound_path（也就是已经被手动挂过音效），就会被跳过，不会被这次批量赋值覆盖掉。

不勾选时，所有符合条件的音符都会被覆盖。哪怕它之前挂过音效，也会被改成新的。

⚠️ 不勾选"跳过"时请谨慎：
如果你已经为某个音符单独配过一段特别的音效（比如某个关键弹窗要播一段专属语音），然后把"跳过已自定义音效"取消掉再应用一次，那段专属音效就会被统一音效覆盖掉。而且撤销之后，原本的专属音效设置也会一起回退——虽然能撤销回来，但操作前最好心里有数。

3.5 统计信息

窗口底部有一行蓝色的统计文字，例如：

当前范围内共 128 个音符可处理（信息框:56、警告框:20、错误框:12、询问框:8、图片框:32）

它会实时告诉你：

  • 当前范围里一共有多少个音符会被处理（已经过滤掉跳过项）
  • 按窗口类型分别有多少个

这个统计是"实时的"——切换范围、勾选/取消"跳过已自定义"时，数字会立刻更新。所以你可以先用它来检查一下即将影响的范围对不对，再决定要不要点"应用"。

3.6 应用按钮

点击 「应用」 后会：

  1. 遍历筛选出的音符
  2. 对每个音符，读取它的 window_type，从映射表里查对应的音效文件名
  3. 把音效文件名写进该音符的 cze_makers.sound_path
  4. 标记工程已修改
  5. 刷新画布（更新音符块高亮小三角）
  6. 通过主界面右下角的轮播图弹出结果提示

结果提示会显示三行数据：

  • 成功赋予音效的数量
  • 跳过（无窗口类型）的数量 —— 那些没配过 CZEmaker 的音符
  • 跳过（该类型未指定音效）的数量 —— 映射表里是"（不设置）"的窗口类型

四、工程文件里的字段

赋予的音效写在音符的 cze_makers 里，字段名是 sound_path：

{
    "cze_makers": {
        "window_type": "info",
        "window_title": "提示",
        "window_content": "操作成功",
        "sound_path": "ding.wav"
    }
}
字段含义
sound_path音效文件名（不含路径）。实际文件在 工程目录/audio/ 下

如果某个音符没有 sound_path，弹窗时会用系统的默认提示音（跟 window_type 匹配的那种）。

sound_path 的值是纯文件名（比如 ding.wav），不是绝对路径。这样分享工程时，音效文件跟着 audio/ 目录一起走，不需要重新指向。

五、和"单个音符音效编辑"的关系

Itoc 里有两个地方可以给音符挂音效：

入口适用场景
音符块属性编辑器里的"音效"下拉框单个音符需要专属音效时用
本工具（根据窗口类型赋予）批量给同一类型的音符统一音效时用

两者写的是同一个字段 sound_path，所以会互相覆盖。本工具的"跳过已自定义音效"就是用来避免误覆盖的——它会把已经手动配过音效的音符排除在外，只处理"还没配过"的那些。

💡 推荐工作流：
1. 先用本工具批量给一类窗口挂上统一的默认音效；
2. 再手动挑出几个"需要专属音效"的音符，用单个编辑器改掉。
这样批量操作一次搞定，专属音效只改一两个。

六、渲染时怎么用？

本工具只是"赋值"，真正"播放"发生在渲染和弹窗时。

6.1 在弹窗播放器里

当播放器弹出这个音符对应的窗口时，会读取 sound_path，从工程的 audio/ 目录加载对应的 wav 文件并播放。如果没有 sound_path，就退回系统默认提示音。

6.2 在音频渲染里

「渲染为音频文件」工具的音源设置里，有一项是"工程内嵌音效（按音符配置）"：

  • 选这个音源时，只渲染有 sound_path 的音符，其它音符静音。
  • 选其它音源时（比如"自动跟随预览乐器"、"钢琴采样"），如果勾选了 "应用工程内嵌音效配置"，那么有 sound_path 的音符会优先用这段音效，其它音符用统一音源。

所以本工具批量挂上的音效，在渲染时也会被用上。

七、常见问题

Q1：为什么"仅时间选区范围"是灰的？

因为时间轴上当前没有选区。先在时间轴上拖拽出一段选区，再打开工具（或者重新打开工具），这个选项就能点了。

Q2：为什么应用完之后统计说"跳过（无窗口类型）"很多？

说明这些音符还没配过 CZEmaker。只有配过 CZEmaker（也就是音符的 cze_makers 里至少有 window_type）的音符才会被处理。如果想让它们也有音效，得先给它们配上 CZEmaker。

Q3：为什么我的音效文件是 .mp3，导入时点不动？

这个工具只支持 .wav。转一下格式即可。很多免费工具（Audacity、格式工厂等）都能无损转 wav。

Q4：音效文件被我删了，工程还能打开吗？

能。工程里只是记录了一个文件名，打开工程不会检查文件是否存在。但是弹窗播放、音频渲染时如果文件不在，就会退回默认提示音（或者静默，取决于场景）。

Q5：可以只处理某一个窗口类型吗？

间接可以。在映射表里把其它窗口类型都留在"（不设置）"，只给想要的那个类型选音效，然后应用。这样只有那一个类型会被处理，其它类型的音符会被统计为"跳过（该类型未指定音效）"。

Q6：应用后能撤销吗？

可以。工具在应用前会自动保存一次撤销快照。直接 Ctrl+Z 就能把整批操作一次性撤销。

八、小结

「根据窗口类型赋予自定义音效」是一个提高效率的批量工具，帮你把"按类型挂音效"这件事从手工活变成一键操作。

  • 按窗口类型批量赋音效，覆盖全工程或指定范围
  • 支持 9 种窗口类型：信息 / 警告 / 错误 / 询问 / 图片 / 气泡通知 / 执行代码 / 视频 / 模类
  • 音效文件自动复制到 工程目录/audio/，跟着工程走
  • 支持"跳过已自定义音效"避免误覆盖
  • 支持时间选区和自定义范围
  • 写入的是 cze_makers.sound_path 字段，和单个编辑器共用
  • 只处理 .wav 格式
