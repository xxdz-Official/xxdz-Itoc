🤝 协作

一个人做工程做久了，总有需要"和别人一起弄"的时候——可能是搭档做了一个片段想合并进来，可能是从网上下载了一个别人做的 CZEmidi 工程想借鉴一下，也可能是想把当前工程某一段单独摘出来发给别人……这些事，都归「协作」菜单管。

📌 本篇的范围：
讲的是「协作(B)」菜单里的所有功能：置入CZEmidi工程、对比媒体文件哈希值(MD5)、对比工程文件差异、使用小電AI协作当前工程、导出时间选区工程片段。
关于工程本身的保存/加载，请参考《文件操作》相关文档；关于时间选区的创建，请参考《时间选区》文档。

一、这个功能是干嘛的？

简单说，「协作」是 Itoc 里"和别的工程打交道"的一组工具。它管的是这几件事：

  1. 把另一个工程合并进来——置入CZEmidi工程。
  2. 检查两个工程有没有相同的素材——对比媒体文件哈希值。
  3. 看两个工程具体差在哪——对比工程文件差异。
  4. 把当前工程的一段单独导出——导出时间选区工程片段。
  5. 让 AI 帮你看看工程——使用小電AI协作当前工程。
💡 一句话理解：
「协作」是"工程与工程之间"的桥梁。不管你是想合并、对比还是拆分，它都能帮你把活干了。

二、从哪里打开？

所有协作功能都在主菜单的「协作(B)」里，按 Alt+B 也能直接展开。

菜单项作用
置入CZEmidi工程把另一个 .czemidi 工程的所有内容合并到当前工程
对比媒体文件哈希值(MD5)对比当前工程和另一个工程的媒体文件 MD5
对比工程文件差异逐项对比两个工程的所有内容差异
使用小電AI协作当前工程打开 AI 协作窗口，让 AI 帮你看看当前工程
导出时间选区工程片段把当前 F4 选区内的内容导出为独立工程
⚠️ 除了「AI协作」外，其它四项都需要先打开一个工程：
如果当前没有打开的工程，点了会弹"请先打开或保存一个工程文件"的提示。
这几个功能都需要一个"当前工程"作为操作对象。

三、置入CZEmidi工程

这是协作里最"重"的一个功能，做的事是：把另一个 .czemidi 工程的全部内容合并到当前工程里。

3.1 操作流程

  1. 点「协作(B)」→「置入CZEmidi工程」。
  2. 弹出文件选择框，选一个 .czemidi 文件。
  3. 如果两个工程有窗口类名冲突，会弹出"窗口类名去重"窗口（见 3.3）。
  4. 弹出"媒体文件对比"窗口（见 3.4），确认后点「继续导入」。
  5. 弹一个进度窗口，显示正在导入什么。
  6. 导入完成，用轮播图通知你导入了多少内容。

3.2 会导入什么？

内容处理方式
音符块 重新分配 ID，轨道索引整体偏移到当前工程最大轨道之后
调整图层 重新分配 ID，轨道同样偏移
标记 按原始节拍位置插入
全局命令 按原始节拍位置插入
模类（UIclass） 内嵌模类按内容哈希去重，重名的自动加「_导入N」后缀
轨道名称 按轨道偏移一起挪过去
轨道便利贴 轨道偏移一起挪过去
音频 / 图片 / 视频 / SRT / MIDI 自动复制到当前工程目录，并改写为相对路径（见 3.5）
💡 轨道偏移是怎么算的？
假设当前工程最大轨道索引是 5，那么导入进来的所有轨道会从 6 开始往后排。
这样两边的轨道不会"叠"在一起，一眼就能看出哪些是导入的。

3.3 窗口类名冲突处理

如果导入的工程里有和当前工程重名的窗口类名，会弹出一个"窗口类名去重"窗口：

  • 左侧是输入框「新类名」，右侧是一个列表，列出所有冲突的类名。
  • 列表有 3 列：原类名、引用次数、操作。
  • 默认是「重命名 → 原类名_1」。
  • 双击列表项可以切换「重命名」/「保持原样」。
  • 右键也有「切换为重命名 / 切换为保持原样」菜单。
  • 选中某一项，可以在上方输入框里改新名字。
操作含义
重命名导入的音符使用新的类名，不会和当前工程的类名混在一起
保持原样直接使用原类名，会和当前工程的同名类合并为同一个类
⚠️ 两个类不能重名：
如果你把两个不同的原类名，都改成了同一个新名字，点确认时会提示"重命名冲突"，要求你改成不同的名字。

3.4 媒体文件对比窗口

类名冲突处理完之后（或没有冲突时），会弹出"媒体文件对比 (MD5)"窗口。这是让你在导入前先看一眼两边的媒体文件情况。

符号含义
✓ 绿色相同（MD5 一致）
⚠ 黄色MD5 不同（同名但内容不一样）
◀ 橙色仅当前工程有
▶ 蓝色仅导入工程有

窗口左右分栏，左边是"当前工程"，右边是"导入工程"，支持列表 / 缩略图两种视图：

  • 列表视图：Treeview 表格，显示状态、文件名、类型、MD5。
  • 缩略图视图：图片和视频会显示缩略图，其它类型显示 Emoji 图标。
  • 双击资源可以在资源管理器中打开。
  • 右键可以复制 MD5 值、在资源管理器中打开、用默认方式打开。

看完了，点右下角的「继续导入」或「取消导入」。

💡 这个窗口不是"必须看"的：
如果你对两边的素材心里有数，直接点「继续导入」就行。它存在的意义是防止你"导入完才发现有重复素材"。

3.5 资源文件复制规则

导入时会把外部资源文件复制到当前工程目录，具体规则：

资源类型存放子目录
音频audio/
SRT 字幕srt/
图片img/
视频video/
MIDImidi/
  • 如果目标文件不存在：直接复制。
  • 如果目标文件存在且内容相同（MD5 一致）：跳过，直接复用。
  • 如果目标文件存在且内容不同：弹框询问，确认后自动重命名为 文件名_1.ext、文件名_2.ext……

3.6 导入结果

导入完成后，会在控制台打印详细统计，同时用轮播图显示简短摘要：

置入完成！已导入 N 个音符、
M 个图层、
K 个标记、
J 个命令。
  • 模类: X 个
  • 便签: Y 个
📌 导入可以撤销：
导入之前会自动保存一份撤销快照，所以导入完如果不满意，按 Ctrl+Z 可以撤回来。

四、对比媒体文件哈希值(MD5)

这个功能是只对比，不导入。当你只想看看两个工程的素材有没有重复、有没有冲突时用它。

4.1 操作流程

  1. 点「协作(B)」→「对比媒体文件哈希值(MD5)」。
  2. 选一个要对比的 .czemidi 文件。
  3. 弹出对比窗口，左右分栏展示。

4.2 窗口内容

  • 顶部标题栏：显示"工程媒体文件差异对比"，右侧有四个彩色徽章：🟢 相同 / 🟡 MD5不同 / 🔴 仅当前 / 🔵 仅导入。
  • 左侧：当前工程的媒体文件列表。
  • 右侧：导入工程的媒体文件列表。
  • 底部：彩色图例说明。

列表是 GitHub 风格的，每行有状态图标、文件名、MD5，背景色会根据状态变化：

状态行背景图标
相同白 / 浅灰交替● 绿色
MD5不同浅黄● 黄色
仅当前工程浅橙◆ 红色
仅导入工程浅蓝◇ 蓝色

4.3 行操作

  • 单击：高亮这一行。
  • 双击：在资源管理器中打开该文件。
  • 右键：复制 MD5 / 在资源管理器中打开 / 用默认方式打开。
  • 滚轮：上下滚动列表。
  • Esc：关闭窗口。
💡 什么时候用？
· 你下载了别人的工程，想看看里面有没有和你手上一模一样的素材。
· 你想确认"两个工程引用的音频是不是同一个"。

五、对比工程文件差异

这个功能比"对比媒体文件"更全面，它会逐项对比两个工程的所有内容差异。

5.1 操作流程

  1. 点「协作(B)」→「对比工程文件差异」。
  2. 选一个要对比的 .czemidi 文件。
  3. 弹出对比窗口，顶部是统计 + 图例，下面是一个 Notebook 分页。

5.2 Notebook 分页

每一页都对比一类内容，左右分栏显示：

页签对比内容
CZEmaker配置窗口类型、标题、内容、类名、编组、销毁模式、图标、效果音、透明度、图片/视频/代码有无
音符轨道、起始节拍、时长、音高
调整图层轨道、起始节拍、时长、颜色
标记节拍、描述、颜色
全局命令节拍、描述、命令
模类模类名称
轨道名称轨道索引、名称
便签轨道、节拍、文本、颜色

5.3 差异高亮

和"对比媒体文件"一样，用颜色区分：

  • 绿色：两边都有且一样。
  • 黄色：两边都有但不一样（modified）。
  • 红色：仅当前工程有（removed）。
  • 绿色（新增）：仅导入工程有（added）。

5.4 顶部统计

左上角显示当前页面的统计，例如：

当前: 120 项  |  导入: 115 项  |  相同: 100  |  差异: 20

下面还有一行蓝色的总计，把 8 个页面的数据加起来。切换页签时，顶部统计会跟着更新。

📌 这个对比是"逐项配对"的：
程序会把两边按相同的排序规则（轨道、节拍等）排好，然后一项一项配对。
所以如果两边的音符数量不一样，多出来的部分就会显示为"仅当前"或"仅导入"。

六、导出时间选区工程片段

如果你只想把当前工程里的某一段单独发给别人，或者单独存一份备用，用这个功能最合适。

6.1 前置条件

  • 必须已经打开一个工程。
  • 必须先用 F4 在画布上划出一个时间选区。
  • 选区内必须有内容（音符、图层、标记、命令、便签至少要有一个）。

6.2 导出对话框

这是一个横版左右分栏的窗口，左边是设置，右边是预览：

区域内容
左上 深色信息卡：起始拍 / 结束拍 / 时长 / BPM
左中 📁 导出范围设置：「保留时间位置」复选框
左中下 📎 素材附带设置：图片 / 视频 / 音频 / 脱机 / 仅附带选区内引用
左下 ⚠️ 窗口类名与窗口编组的外部依赖检查
右上 📋 导出内容摘要：音符 / 图层 / 标记 / 命令 / 便利贴 / 轨道 的彩色统计卡片
右中 📎 待复制资源列表：Treeview 显示文件名、类型、大小
右下 💾 导出位置：路径输入框 + 浏览按钮
底部 📄 预览导出内容 / 取消 / ▶ 导出

6.3 各项设置说明

设置项说明
保留时间位置 开启：保持原始节拍位置。
关闭：把选区内容平移到工程起始（节拍 0）。
附带图片文件 是否把 CZEmaker 里引用的图片一起复制过去。
附带视频文件 是否把 CZEmaker 里引用的视频一起复制过去。
附带音频文件 是否把当前工程的音频文件复制过去。
附带脱机媒体文件 是否把脱机媒体一起复制过去（当前版本暂未实现具体逻辑）。
仅附带选区内引用的文件 开启：只复制选区音符引用到的资源。
关闭：复制全部资源。
忽略外部依赖 只有当检测到外部依赖时才可勾选，见 6.4。

6.4 外部依赖检查

这是一个很"聪明"的检查。程序会看：

  • 选区内的音符引用了哪些窗口类名和窗口编组。
  • 选区外的音符有没有引用同样的类名 / 编组。

如果"选区外的音符也用了这些类名 / 编组"，就说明导出的片段缺少这些类 / 组的定义（定义在工程里，片段没有）。

情况表现
无外部依赖 ✅ 绿色提示"未检测到外部依赖，可安全导出"，导出按钮可用
有外部依赖 ⚠️ 红色提示，列出所有依赖的类名 / 编组和引用次数，导出按钮禁用
⚠️ 必须勾选"忽略外部依赖"才能导出：
如果你明知道缺类定义、但还是要导出去，勾上「忽略外部依赖（导出的工程可能无法完整运行）」，导出按钮才会启用。
否则你会看到"⚠️ 必须勾选'忽略外部依赖'才能导出"的红色提示。

6.5 预览导出内容

点左下角的「📄 预览导出内容」，会弹一个预览窗口，用表格列出所有即将导出的内容：

列含义
类型🎵 音符 / 🎨 图层 / 📌 标记 / ⚙️ 命令 / 📋 便利贴
轨道所在轨道（从 1 开始）
节拍起始节拍（保留位置模式下会显示原始节拍）
时长/描述音符显示时长，其它显示描述
备注音高、滤镜、颜色等附加信息

6.6 导出过程

点「▶ 导出」后，会弹一个进度小窗，分 5 个阶段：

  1. 0-10%：提取选区内数据。
  2. 10-30%：收集资源文件列表。
  3. 30-70%：复制资源文件（带进度，如"正在复制资源文件 (3/8)..."）。
  4. 70-90%：生成工程文件数据。
  5. 90-100%：写入磁盘。

完成后弹一个"导出成功"提示框，告诉你文件保存到哪了。过程中可以点「取消」中止。

💡 一个实用场景：
你想把工程里"最精彩的那 10 秒"单独发给朋友看，就先 F4 划个选区，然后导出时间选区工程片段。朋友拿到的是一个完整的、能直接打开的 .czemidi 文件，不用你手动裁。

七、使用小電AI协作当前工程

这是「协作」菜单里最特别的一项——让 AI 帮你看看当前工程。

7.1 操作流程

  1. 点「协作(B)」→「使用小電AI协作当前工程」。
  2. 弹出 AI 协作对话窗口。
  3. 在对话框里描述你的需求，AI 会读取当前工程的数据来回答 / 修改。
📌 关于 AI 协作的详细用法：
这个功能由 Cooperation_AI 模块提供，具体能问什么、能改什么，请参考《小電AI协作》专项文档。

八、常见问题

Q1：置入工程后，为什么音符都跑到下面的轨道去了？

这是正常设计。导入的轨道会自动偏移到当前工程最大轨道之后，所以看起来"跑到下面了"。这样两边的内容不会混在一起。

Q2：置入工程后，为什么有些图片/视频"不见了"？

可能是这几个原因：

  • 源工程里的图片/视频文件本身就不存在（路径失效），导入时会打印警告并跳过。
  • 资源复制过程中出现了同名冲突，你选择了"取消"，那个文件就没复制过去。
  • 路径是绝对路径但指向了别的盘符，复制失败。

打开工程目录下的 img/、video/ 文件夹检查一下。

Q3：对比媒体文件时，为什么两个文件显示"MD5不同"但名字一样？

说明这两个文件文件名相同但内容不同。可能是：

  • 同一个文件被改过（比如重新导出了一遍）。
  • 两个不同来源的文件恰好重名。

导入时遇到这种情况，程序会弹框问你是否重命名，一般选"是"就好。

Q4：对比工程差异时，为什么有些行明明看起来一样却标了黄色？

因为对比是逐字段的。哪怕只差一个空格、一个颜色值、一个透明度数字，也会标记为"modified"。放大看每一列就能找到差异。

Q5：导出时间选区片段时，为什么导出按钮是灰的？

最常见的原因是：检测到了外部依赖，但你还没勾选"忽略外部依赖"。

看左下角的红色提示文字，上面会写"⚠️ 必须勾选'忽略外部依赖'才能导出"。勾上那个复选框，按钮就亮了。

Q6：导出的工程片段，打开后发现"窗口类名"丢失了？

因为类名定义在模类里，而导出的片段默认不携带模类数据。这是设计如此——类名和编组属于"工程级别"的配置，不适合跟着片段走。

如果片段里确实需要类名，可以考虑手动在目标工程里也建一份同名模类，或者干脆导出整个工程而不是片段。

Q7：置入工程会覆盖我当前工程的内容吗？

不会覆盖，只追加。 导入的内容会以"新增"的方式加进来，你原来工程里的所有东西都原封不动。

Q8：置入工程可以撤销吗？

可以。导入前会自动保存一份撤销快照，按 Ctrl+Z 就能撤回整个导入操作。

Q9：为什么"对比媒体文件"里有些文件显示为"—"（没有 MD5）？

说明那个文件在磁盘上不存在，或者读取时出了错。程序会显示"—"占位。

这种情况一般意味着工程里引用的资源丢了，建议检查一下资源路径。

Q10：导出时间选区片段时，资源复制用了很久怎么办？

如果资源很多（比如几十个视频），复制会需要一点时间。进度窗口会实时显示"正在复制资源文件 (5/20)..."，耐心等一下就好。

如果实在不想等，可以取消，然后在设置里关掉"附带视频文件"，只导出工程数据。

九、小结

「协作」是 Itoc 里"工程与工程打交道"的一组工具，一共 5 项：

  • 置入CZEmidi工程：把另一个工程合并进来，自动处理类名冲突、媒体 MD5 对比、资源复制、轨道偏移。
  • 对比媒体文件哈希值(MD5)：只看不导入，左右分栏对比两边的媒体文件。
  • 对比工程文件差异：8 个页签逐项对比所有内容，GitHub 风格高亮。
  • 使用小電AI协作当前工程：打开 AI 对话框，让 AI 帮你看看工程。
