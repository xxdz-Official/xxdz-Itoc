🧩 插件使用指南

Itoc 本身功能已经挺全了，但总有人想要更多——比如批量改音高、批量导出音符、自定义工具栏按钮……这些"额外需求"不需要等官方更新，你可以自己写插件，也可以用别人写好的插件。插件系统就是为这个准备的。

📌 本篇的范围：
讲的是怎么用插件：插件管理器怎么打开、怎么导入、怎么启用禁用、怎么卸载。
如果你想自己写插件，请参考《插件开发指南》文档。

一、插件是什么？

插件（Mod）是一个独立的小程序，放在 Itoc 运行目录下的 mod/ 文件夹里。每个插件可以：

  • 在菜单栏加一个新菜单（比如「音符工具」）
  • 在主程序已有菜单里插一个菜单项（比如「编辑」菜单里加一项）
  • 在工具栏的四个位置之一加一个按钮（快捷操作栏¹ / 快捷操作栏² / 文件选择栏 / 播放控制栏）
  • 在右键菜单里加一项（音符右键、轨道右键、画布空白右键、调整图层右键）
  • 在侧边栏加一个选项卡（上组或下组都可以）
  • 注册全局快捷键
  • 订阅主程序的事件（比如"选中音符变化"）
  • 读写工程数据（音符、音高、位置……）

插件加载后，会融进 Itoc 的界面里，用起来和原生功能一模一样。唯一的区别是：插件的功能是否可用，取决于它有没有被启用。

💡 插件不会破坏工程数据：
插件通过官方 API 读写工程，所有修改都会走正常的"标记已修改"流程，也会被 Ctrl+Z 记录。所以放心用，出问题可以撤销。

二、从哪里打开插件管理器？

插件管理器的入口：菜单「插件(M)」→「插件管理器」。

打开后是一个横向宽窗口，左边是插件列表，右边是选中插件的详细信息。

四、插件列表

左边那一列是所有扫描到的插件。每一行有四列：

列含义
插件名称插件的显示名（来自 Attribute.txt）
状态「已启用」或「已禁用」，如果加载失败会额外显示「(错误)」
版本插件版本号
作者插件作者

行颜色也有讲究：

  • 正常颜色：插件已启用，状态正常。
  • 灰色：插件已禁用。
  • 红色：插件加载失败（可能缺依赖、语法错误等）。

五、插件详情

点一下左边的插件，右边会显示它的详细信息：

  • 插件名称：显示名
  • 版本 / 作者：基本信息
  • 作者网站：如果填了网址，点一下会用浏览器打开
  • 插件描述：一段文字说明，告诉你这个插件是干嘛的
  • 插件路径：插件文件夹的位置，点一下会在资源管理器里打开
  • 启用此插件：勾选框，控制是否启用
  • 插件文件：列出插件目录里的所有文件（文件名、大小、修改时间）

文件列表下面有三个按钮：

按钮作用
📄 查看文件打开选中的文件，查看内容
📋 复制路径把选中文件的完整路径复制到剪贴板
📝 查看属性文件直接查看插件的 Attribute.txt

六、导入插件

点工具栏的「📥 导入插件」按钮，选一个文件夹（不是单个文件），Itoc 会检查这个文件夹里有没有 ItocMod.py：

  • 有 ItocMod.py：这是有效的 Itoc 插件，会被复制到 mod/ 目录下。
  • 没有 ItocMod.py：提示"该插件不是 Itoc 插件"。
  • 有 ItocMod.py 但没有 Attribute.txt：会弹一个警告，说这是"来自未知源头的插件"，问你要不要继续。如果你确认来源可靠，可以继续导入。

如果 mod/ 下已经有同名文件夹，会问你要不要覆盖。

⚠️ 插件有安全风险：
插件本质上是一段 Python 代码，它可以读写你电脑上的文件。所以：
· 只导入来源可靠的插件（比如官方论坛、作者直接发的）
· 看到"未知源头"的警告时，想清楚再继续
· 不确定的插件，可以先用文本编辑器打开 ItocMod.py 看看它做了什么

七、启用 / 禁用插件

有三种方式切换插件的启用状态：

  1. 在右侧详情面板里勾选 / 取消勾选「启用此插件」。
  2. 选中插件后，点底部的「✅ 启用插件」或「⛔ 禁用插件」。
  3. 直接改配置文件（不推荐，详见第九节）。

启用 / 禁用状态是立即生效的，但插件本身的功能要等下次启动 Itoc 才会加载或卸载。比如你禁用一个插件，它的菜单项、工具栏按钮、侧边栏选项卡会在下次打开 Itoc 时消失。

💡 禁用 ≠ 删除：
禁用只是"下次启动不加载它"，插件文件还在 mod/ 里，随时可以重新启用。

八、卸载插件

点底部的「🗑️ 卸载插件」，会弹两次确认框：

  1. 第一次：显示插件名称、版本、作者，问你是否确定要永久删除。
  2. 第二次：显示插件路径，再次确认。

确认后，Itoc 会直接删除整个插件文件夹，并清掉它的配置记录。这个操作无法撤销。

⚠️ 卸载是永久删除：
如果你只是想暂时不用这个插件，请用「禁用」，不要用「卸载」。
卸载后插件文件就没了，只能重新下载或重新导入。

九、配置文件

插件的启用 / 禁用状态保存在 Itoc 运行目录下的 ModShezhi.txt 里，格式是 JSON：

{
  "音符批量工具": {
    "status": "enabled",
    "enabled": true,
    "visible": true,
    "priority": 50,
    "settings": {}
  },
  "另一个插件": {
    "status": "disabled",
    "enabled": false,
    "visible": true,
    "priority": 50,
    "settings": {}
  }
}

字段含义：

字段含义
status状态字符串：enabled / disabled / hidden
enabled是否启用（true / false）
visible是否在插件管理器的列表里显示
priority优先级，0~100，数字越大越优先
settings插件自己的设置项（每个插件不一样）
📌 一般不用手改：
配置文件是给程序读写的，手动改容易格式出错。建议用插件管理器操作。

十、搜索插件

右上角有个搜索框，输入关键字会实时过滤插件列表。搜索范围包括：

  • 插件名称
  • 插件描述
  • 插件作者

搜索是不区分大小写的，中文英文都支持。清空搜索框就会恢复完整列表。

十一、常见问题

Q1：为什么我导入插件后，菜单里没出现？

插件导入后需要重启 Itoc（或至少重新扫描）才会加载。你可以：

  • 点插件管理器里的「🔄 重新扫描」按钮（会重新扫描并加载）。
  • 或者直接关掉 Itoc 重新打开。

Q2：为什么插件状态显示「(错误)」？

说明插件加载失败了。常见原因：

  • 插件缺 Python 依赖（比如用了 requests 但没装）。
  • ItocMod.py 有语法错误。
  • Attribute.txt 格式不对。

可以打开插件目录，用文本编辑器看看 ItocMod.py，或者去问插件作者。

Q3：怎么知道一个插件有哪些功能？

看右侧的「插件描述」，作者一般会在这里写清楚。如果描述写得含糊，可以看插件目录里的文件，或者直接问作者。

Q4：禁用插件后，它加的菜单项还在？

禁用是"下次启动不加载"，当前这次运行里，已经加载的菜单项不会立刻消失。重启 Itoc 后就没了。

Q5：我删了 mod 文件夹里的插件，但管理器里还显示？

点一下「🔄 重新扫描」，列表会更新。

Q6：插件会不会让 Itoc 变卡？

看插件本身怎么写。写得好的插件对性能影响很小；写得不好的插件（比如在循环里频繁刷新界面）可能会让界面变卡。遇到这种情况，禁用那个插件就行。

Q7：插件和工程文件的关系？

插件是软件级别的，跟工程文件无关。你换一个工程，插件还是那些插件；你把工程发给别人，别人打开时用的是他自己的插件配置。

Q8：插件能自动更新吗？

目前不能。插件更新需要你手动下载新版本，然后重新导入（导入时会问你是否覆盖）。

Q9：在哪里找插件？

菜单「插件(M)」→「去获取插件」会打开插件市场页面。也可以去 Itoc 官方论坛的插件区看看。

Q10：我自己写了一个插件，怎么分享给别人？

把你插件的整个文件夹（包含 ItocMod.py、Attribute.txt 和其他文件）打包发给别人，对方用「📥 导入插件」导入就行。具体怎么写插件，参考《插件开发指南》。

十二、小结

插件系统让 Itoc 变得可扩展。使用插件的关键操作：

  • 入口：菜单「插件(M)」→「插件管理器」。
  • 导入：点「📥 导入插件」，选插件文件夹（必须含 ItocMod.py）。
  • 启用 / 禁用：在详情面板勾选，或点底部按钮。下次启动生效。
  • 卸载：点「🗑️ 卸载插件」，双重确认后永久删除。
  • 配置：保存在 ModShezhi.txt，一般不用手改。
  • 搜索：右上角搜索框，按名称 / 描述 / 作者过滤。
